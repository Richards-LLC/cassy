# Phone reply contract

When answering a verified Commander row from a phone, use this contract:

- Answer first: the first line is the answer in one sentence.
- Use at most 5 bullets, one line each.
- Bold the decision word or the thing waiting on the operator.
- Keep the reply under ~600 characters unless the operator asks for detail.
- Do not include file paths or ticket IDs unless the operator asks for them.
- Do not narrate the process.
- Use only the Markdown subset the hub renders: **bold**, bullets, numbered lists, `inline code`, and links.
