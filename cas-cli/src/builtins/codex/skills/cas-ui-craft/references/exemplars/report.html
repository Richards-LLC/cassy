Eighty-four minutes from promotion to rollback

The timeline answers the question the hero raises: if a deploy did this, why did it take an hour and a half to reverse? Elapsed time is printed on the spine so nobody has to subtract timestamps.

  1. 08-29 13:58Z checkout@4.18.0 canary passes — 2% of traffic, p95 402 ms, no alerts.
  2. +9 min
  3. 14:07Z 4.18.0 promoted to 100% — the decisive event. The build adds a synchronous validate_address call to a third-party API, awaited inside the request path. Mean call time 820 ms; it only runs when the address carries a unit number, which the canary's 2% sample never hit.
  4. +4 min
  5. 14:11Z p95 crosses 1,000 msalert — checkout-p95-high fires; p95 1,238 ms.
  6. +19 min
  7. 14:30Z On-call engaged — first hypothesis is the database; ruled out at 14:52Z (db p95 flat at 38 ms).
  8. +24 min
  9. 14:54Z Diff review finds the blocking call — 4.18.0 vs 4.17.3, 41 files; the validator is the only change on the request path.
  10. +37 min
  11. 15:31Z Rollback to 4.17.3 started — 84 min after promotion; 37 of them spent waiting for a second approver.
  12. +52 min
  13. 16:23Z p95 back at 418 msclear — alert resolves; drain of in-flight validator calls accounts for the tail.

Design note · Fit to argument

The line, not the timeline, is the hero because its geometry equals the claim: a wall, not a slope. The timeline explains duration, which is the second question, so it is the second section.

Design note · Hierarchy

Nothing sits above the verdict — no KPI cards, no severity badge, no contents. The eyebrow names the type, audience, and window in one mono line so the reader knows what they hold without a block of metadata.

Design note · Distinctiveness

The verdict is set in the display serif on the sandstone surface, and only the one word that carries the magnitude takes the indigo. A template would bold it; this italicises it.

Design note · Craft

Elapsed time is printed on the spine in mono between events. Timestamps alone make the reader subtract; the 37-minute approval wait is the finding, so it must be visible as a number.

Design note · Accessibility

Status colour marks only the alert firing (danger) and clearing (good), each with a text tag. The decisive event is indigo, which is never a status, so nothing on the timeline reads as "bad" by colour alone.

Design note · Hierarchy

The ledger is the third element on the page, not the first. A reader who wants to audit gets exact values here; a reader who wants the answer already has it.

Design note · Craft

Numbers are mono, tabular, right-aligned; the unit appears once in the header; the sum row sits above a stronger rule. No zebra stripes, no box, no icons — a ledger is ruled, never boxed.

Design note · Fit to argument

The decisive row carries the verdict-soft band and a left rule in indigo. It is the only coloured row: the argument turns on one window, so one window is marked.

All four regions stepped in the same minute

A regional cause — a bad node, a cross-region hop — would show up as one panel diverging. Shared scale, shared alignment: the only difference is magnitude, and ap-south is highest because its validator endpoint is farthest.

Design note · Fit to argument

Small multiples on one scale exclude the alternative explanation in a glance: four identical steps at one minute cannot be a regional fault. The panel that fired the alert carries the verdict mark; the others stay muted.

Design note · Accessibility

Every panel is an SVG with a role, a title, and an aria-label that says its numbers in words; the exact values sit in a real table under the panels so a screen reader and a spreadsheet both get them.

Why the canary missed it

The canary looked clean because the validator only blocks when the address has a unit number. Two percent of traffic for nine minutes never hit one.

On-call note, 2026-08-29 14:54Z · oncall/2026-08-29-checkout.md

The follow-up is a canary rule, not a latency rule: a code path that is conditional on request content must be exercised by the canary's traffic shape, or the canary is measuring nothing. That change is tracked separately from this review.

Design note · Distinctiveness

One sentence from a human, in the serif italic on the sandstone surface, does what a "Root cause" heading and three bullets would not: it is memorable, and it is evidence with a source line.
