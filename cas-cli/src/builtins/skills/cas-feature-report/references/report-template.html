Saved views

Store managers can save a filtered sales view and reopen it in one click.

For managers who check the same stores every morning: no more rebuilding the same filters each visit.

Product
Northwind sales
Available
every store manager account
Date
2026-10-26

What changed

Each change as it was and as it is now.
WasNowWho it helps
Filters reset every time the sales page opened.Save the current filters as a named view and reopen it from the menu. See itStore managers
The filter panel listed every store in one long list.Stores are grouped by region, with a search box. See itRegional managers

How to use it

  1. Filter the sales pagePick stores, dates and products as usual.
  2. Choose Save viewName it, for example “North stores, this week”.
  3. Reopen itOpen the Saved views menu and pick the name.

Example views

Good to know

  • Saved views belong to your account; other managers do not see them.
  • You can keep up to 20 views. Rename or delete one from the same menu.
  • Planned Sharing a view with a colleague. It is not available yet.
