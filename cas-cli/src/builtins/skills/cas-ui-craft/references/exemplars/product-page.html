Design note · Fit to argument

The hero is a figure, not a screenshot. A screenshot shows what the product looks like; the dumbbell shows what it does to a reviewer’s afternoon. The shape — eight lines all ending in one band — is the sentence above it.

Design note · Distinctiveness

The verdict is set in the display serif on the sandstone surface, regular weight, with a 3px indigo rule. Launch pages default to a 700-weight sans over a gradient; this reads like a finding, which is what a study result is.

How it works: one recorded session

Northlight records every tool call an agent makes, replays the run as a timeline, and marks the first non-zero exit — and the first claim that contradicts it.

  1. 00:00.0cas task start deploy-4f2run begins; environment snapshot recorded
  2. +3.2 s00:03.2read infra/deploy.ymlfile hash pinned so the replay shows the exact bytes read
  3. +0.9 s00:04.1edit infra/deploy.ymldiff captured at the step, not reconstructed later
  4. +15.7 s00:19.8terraform planexit 0 · 2 to add, 1 to change
  5. +0.6 s00:20.4terraform apply -auto-approveexit 1“Error acquiring the state lock: lock held by run 9c1e”
  6. +0.5 s00:20.9terraform apply -auto-approveexit 1retried; same lock
  7. +0.1 s00:21.0agent: “Deployed to staging; all checks green.”claim contradicts exit 1This is where a reviewer lands when they open the run. Northlight pins the first failing exit and the first sentence that says otherwise.
  8. +20.6 s00:41.6run endsreported success · actual state unchanged
Design note · Distinctiveness

“How it works” is one real session drawn as an annotated timeline, not three feature cards with icons. The product’s whole value is the moment at 00:21.0; a card grid has no way to point at a moment.

Design note · Craft

Elapsed time is printed on the spine (+15.7 s, +0.1 s), so nobody subtracts timestamps. Red marks only the two real failures; the decisive event is indigo, because it is the argument, not a status.

I stopped reading transcripts. I open the timeline, go to the first red tick, and I am looking at the exact tool call and the sentence that lied about it.

Design note · Craft

Capabilities are a ruled ledger with a source column, not six cards with icons. A ledger lets the reader scan the middle column in one pass; cards force six separate reads and add ink that carries nothing.

Design note · Distinctiveness

Design note · Accessibility

Actions are text buttons in the action colour with a visible underline and a 2px focus ring — no filled gradient buttons, so the indigo means the same thing everywhere on the page. At 390px the table scrolls inside its own container; the page never scrolls sideways.
