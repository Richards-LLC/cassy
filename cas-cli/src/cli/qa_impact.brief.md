# Journey impact output

| Field | Contract |
| --- | --- |
| First two lines | Show missing/stale product-map warnings before the selected journey count and source. |
| Scannable | List journeys in status/share/id order, then unowned files and CODEMAP areas. |
| Readable | Each journey names its required walk/read-back; Markdown exposes the same evidence in a PR-friendly table. |
| Machine output | Global `--json` emits one version-1 object with source, registry, journeys, areas, unowned, ignored, upkeep and warnings. |
| Omitted | No script/spec execution, deployment or network lookup occurs for registry matching; matches and full metadata are in JSON. |

JSON preserves full identifiers and paths when a plain row exceeds a terminal's width.
The legacy adapter runs the project's existing read-only Python selector to preserve
its import/CSS selection; the registry engine itself has no subprocess boundary.

## Critique

Candidate binary/terminal captures are NOT VERIFIED by the worker. The supervisor's
candidate and merge queue own those captures; worker proof uses real Git snapshots
and the existing legacy selector through the public impact library.
