### Fixed — Release train

- **Install-on-publish completes when the binary is current** — Was: `cas update` exits 1 whenever an unrelated project refresh fails, so a successful install was logged as failed and the release timer never completed. Now: the installed binary version is the success test; a non-zero refresh exit is noted in the log line and the timer still completes, while a binary that did not swap keeps the failure and retry path.
