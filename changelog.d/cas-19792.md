### Fixed — Factory

- **Worker checks run the gate registry scan when a delivery touches a refusal** — Was:
  a delivery that changed a refusal, an `McpError` result, a gate tag or a
  Boolean parameter could park green on its own tests, then go red in lane CI
  on `gates::registry_tests`. Now: the capped worker check adds
  `gates::registry_tests` to its guarded run when the delivery's changed lines
  touch any of those sites, so the worker's ordinary run covers it. Deliveries
  that touch none of them run no extra test.
