### Fixed — Release CI

- **Release capacity stays clear of factory lanes** — Factory CI now queues
  every job, including Rust impact tests and legacy lane checks, on the existing
  self-hosted lane pool. Busy lanes no longer consume GitHub-hosted capacity
  needed by release PR checks, frozen-train validation, the merge queue and
  Release Prebuild. Local lanes disable compiler-cache wrappers so concurrent
  listeners do not collide on the shared host's default sccache server port.
  Shared Rust setup also restores the local Cargo PATH and prepares the pinned
  toolchain when it is missing.
  Nextest preparation shares the setup lock, preventing concurrent local ring
  shards from corrupting the installer's shared temporary archive.
  Local compiler/test temporaries now use the service's short, private,
  disk-backed `/var/tmp` paths outside the checkout and HOME, avoiding RAM-backed
  `/tmp` growth, oversized sockets and inherited Git/CAS state in fixtures.
  Each listener keeps its Cargo target on disk across jobs, without remote
  cache restoration replacing it. Impact tests overlap disk fixture I/O with
  sixteen nextest slots while retaining the existing service CPU limits.
