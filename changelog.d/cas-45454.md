### Fixed — Close gate

- **Playwright skips with a stated reason pass close** — Was: the close gate
  refused Playwright 1.65 runtime skips such as `test.skip("reason")` and
  `test.skip(condition, "reason")` as unreasoned, and counted a reformatted
  existing skip as new. Now: those forms count as reasoned and an identical
  call rewritten in the same hunk is not new. A bare `test.skip()`, a
  condition-only skip, a skipped test declaration and `test.fixme` still need
  `cas-allow-skip`.
