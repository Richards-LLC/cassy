### Fixed — MCP

- **MCP calls no longer stall for up to 55 seconds every five minutes** — Each `cas serve` runs a history provenance repair every five minutes. It scanned every task twice for each of 500 commits, about 40 seconds on a large store, while holding the server's shared database connection. Any tool call that arrived during that scan waited behind it, sometimes until the 55-second response deadline. Even a refused message took 53 seconds. The repair now reads the task table once per batch.
