### Fixed — Pre-merge verification

- **Peer evidence reaches the verifier** — Was: merging another machine's delivery stalled on a verifier supervisor_call, because the task's evidence lived only in the publishing machine's artifacts directory, and a supervisor had to copy it by hand. Now: before a pre-merge review is dispatched, each committed artifact the peer published for the task is downloaded from Cloud into this machine's task evidence directory under its published name. Local files are kept, and each artifact is fetched once.
