### Fixed — Focused proof commands for data and migration changes

- **Package proof names a file the capped runner accepts** — A delivery that changes a JSON catalogue or a Prisma SQL migration next to a JavaScript change no longer gets a `worker-check -- jest <file>.json|.sql` prescription that the runner always refuses. The gate now names the changed JavaScript file that widened the package. When no such file exists, it describes the proof it needs instead of printing a command that cannot run.
