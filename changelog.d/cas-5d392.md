### Fixed — Factory

- **Python source edits can mention credential fixtures** — The worker credential guard distinguishes literal replacement text from the file a validated pathlib source-edit program reads or writes. Direct, constructed and nested credential reads keep their H-09 refusal. A script containing a bare carriage return, form feed, vertical tab, NUL or any parse error never takes the source-edit path, because CPython and the parser could split its lines differently.
