### Added — Release

- **Publishing or promoting a release closes it out once** — A cas-src publication (`cas release published`, run by the install-on-publish timer before installing) and a staging-to-main promotion merge (`cas release promoted --pr <N>`) each run the release's one reconciliation exactly once. `cas release installed` and `cas release backfill` become recovery triggers that do nothing once that operation completes. Each release sends one supervisor notice naming every remaining task, held epic, inventory exception and unfinished issue, with its owner and next action. `cas release review-blocks` prints the transformation and epic blocks the release review publishes.
