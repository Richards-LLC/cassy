### Added — Factory

- **Explicit release-train owner transfer** — `cas factory train owner-transfer <train> prepare|quiesce|accept|abort` (and MCP `factory action=train_owner_transfer`) moves train publication to a named, registered successor supervisor. The first prepare enrolls the train in a shared Git authority ref (`refs/cas/train-owner/<train>`). While a transfer drains, every Cassy publication to the train target is refused, because each one must advance the target and the authority ref in a single atomic push. Accept issues a fresh generation, so stale owner messages and queued merges stay held. A stale heartbeat or an unreachable host never allows a competing publisher. Operator-only `force` and `adopt-target` handle a dead prior owner or a diverged target.
