### Fixed — Factory

- **An epic no longer closes while its work has not shipped** — Was: tasks close as delivered when they merge into their epic's branch, and the epic then closed on its children's status alone, so finished work sat in epic branches that never reached main, three whole epics for days, while the board reported it done. Now: closing an epic outside a release checks the branch it closes against, and refuses with the commit count when the default branch lacks it; a supervisor can still close with the existing stranded-branch override, and a release close keeps its batch-receipt path.
