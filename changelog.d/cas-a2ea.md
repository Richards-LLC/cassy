### Changed — Factory guards

- **Most pre-tool guards warn instead of block** — Was: every pre-tool guard refused the call it matched. Now: only the guards for unsaved work, secrets, policy and role tampering, production database writes (including a worker's `neonctl`), host build caps and Slack through Violet still refuse; every other guard, including the post-release and CI merge checks, records one counted refusal and lets the call run with a one-line warning.
- **Unparseable shell commands run** — Was: a command the shell recognizer could not parse was refused. Now: it runs unless it names an existing real secret file or literally writes or deletes outside the worktree, including inside `$(...)`, backticks and fake heredoc starts. A Bash command that names an existing `.env`, key or credential file is refused, and only gitignored test env files such as `.env.test` stay editable.
- **Codex hook failures fail open** — Was: an unreadable Codex hook payload or a hook error refused the tool call. Now: it runs with a recorded refusal, still stopped when the payload names a secret file or a store-free guard refuses it; the capped Cargo route keeps refusing.
