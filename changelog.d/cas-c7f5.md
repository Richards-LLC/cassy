### Changed — Mux tests

- **Live-provider mux tests wait on the harness's own turn record instead of sleeping** — Was: the live Codex and Claude mux tests slept a fixed 1.2 to 8 seconds to guess that a turn was in flight or the pane was idle, which false-passes on a slow host and cannot tell a long tool call from idle. Now: `cas_mux::readiness::RolloutTurnObserver` tails the Codex rollout's `task_started`, `task_complete` and `turn_aborted` rows and the tests wait on them (the Claude test waits for an assistant row in its transcript); a turn that never starts fails the wait with a typed timeout naming what the rollout did show. Measured: six of the fourteen sleep sites converted, the red run at 909f5a9e3e fails 2 of 3 observer tests and the green run passes all 3; the eight startup and trust-prompt waits are unchanged because no native signal exists before the first prompt, and the live tests themselves are ignored, so they still need an opt-in provider run.
