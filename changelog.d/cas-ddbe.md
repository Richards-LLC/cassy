### Fixed — Factory director

- **The factory's board refresh no longer re-reads every task each time it runs** — Was: each two-second refresh read and parsed all ~7,900 task rows of a long-lived project (the store file changes about once a second in a live factory, so the refresh never found nothing to do), and the director snapshot was the slowest sampled read job: 235 over-budget completions and 203 s of wall time in ten minutes. Now: a refresh on the factory's long-lived store takes from the table only the tasks whose change counter moved since the last refresh and reuses the rest, and a finished task's unread receipts are no longer parsed. The board shows the same tasks in the same order. Measured on a copy of the 1.7 GB store at the same machine load: a full task read per refresh 224 ms, a refresh that reuses unchanged tasks 112 ms.
