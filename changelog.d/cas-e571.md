### Fixed — Factory routing

- **Routed builds ship their evidence to the reviewing machine** — Was: a delivery built on another machine (a routed build) left its LEDGER.md and logs in that machine's artifacts root, so the routing machine's pre-merge verifier found no evidence directory and a supervisor copied the files by hand. Now: parking a routed build publishes each file in the task evidence directory through the artifact path and records a sha256 manifest; the reviewing machine restores those exact bytes where its verifier reads before dispatch. If a file cannot be published or restored, park or review refuses and names both machines' evidence directories.
