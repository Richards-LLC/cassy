## Single idea

Keep durable task and review authority in Cassy while projecting supported
roles and events into native harness implementations. The companion
[cas-9ca1 Codex report](2026-10-17-cas-9ca1-codex-integration-research.md)
provides a linked crosswalk of shared boundaries and harness-specific evidence.

## Hero form

Use the reusable accessible system-flow pattern: one existing authority bar
above two native adapter branches, then an outlined evidence requirement. This
form shows where authority stays, which is the deciding criterion; it is more
direct than turning version counts into a decorative chart. A text alternative
and the first open table repeat all responsibilities. The required options
comparison visibly marks the recommended existing-adapter approach.

## Emotional register

Collected, precise and cautious about evidence. No root DESIGN.md is present;
use Petrastella's canonical tokens.css: sandstone hero, regular serif verdict,
sans reading, mono provenance, one indigo authority mark, no network fonts.

## Distinctive move

The authority remains one continuous solid rail while optional native execution
branches are outlined. The figure makes the retained responsibility visible
before the reader encounters the detailed adopt/test/defer matrix.

## Deliberately omitted

No KPI-card row, invented cost/effort scores, new connector interface or claim
that current documentation validates an installed runtime. Stable292,
latest302 and retained conformance280 stay separate. Full official source
corpora are not republished. The report creates no 3.63 release dependency.
