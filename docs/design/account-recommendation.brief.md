# Commander account recommendation

## Single idea
The New-session sheet proposes the eligible subscription with the best reset/headroom tradeoff while leaving the account decision with the operator.

## Hero form
Existing selectable account ledger: one checked row and a Recommended tag with a short reason, inside the New-session sheet.

## Emotional register
Calm and explicit: use the current chosen-row treatment and existing quiet tag and secondary text tokens.

## Distinctive move
Put the reset and remaining capacity beside the recommendation so the choice can be assessed before Start.

## Deliberately omitted
No new colour, card, dialog, countdown or automatic submission; the existing radio group and Start action carry the decision.
