# Brief: continuous SOW print evidence

## Single idea

The client reads full-width comparison evidence through a compact sequence of
A4 pages, without mostly empty sheets between related screens.

## Hero form

Retain the outcome strip and the existing full-width before/after evidence:
each image remains readable, and its caption stays attached while pairs and
sections flow across page boundaries.

## Emotional register

Calm and economical: preserve the existing sample typography, palette and
screen spacing while using tighter print spacing for prose and missing-shot notes.

## Distinctive move

A missing historical screenshot becomes a short honest print note, rather than
an empty image-sized panel; that space carries the next delivered screen.

## Deliberately omitted

No screenshot shrinking, reduced image text, invented historical image or
print-only forced section start. Keep the fictional Northwind sample's palette
because this repairs its template rather than creating a Cassy publication.
Shared capture/inlining/print scripts receive no layout or vocabulary logic.

## Critique

Pending same-input PDF measurement and page inspection, strict browser checks,
and independent second-reader scoring.
