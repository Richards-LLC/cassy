# Brief: Supervisor phase line

## Single idea

The conversation names the supervisor's reported phase and its measured duration; a waiting or unavailable supervisor never looks busy.

## Hero form

A quiet inline status beside a tabular elapsed clock in the existing conversation tail. The stationary waiting mark and moving active mark make the difference visible without another panel.

## Emotional register

Calm and exact: Commander Glass's existing secondary ink, body type and mono clock, with no new palette or attention color.

## Distinctive move

The clock follows the daemon's lifecycle start/end rather than the browser's arrival time. A reconnect freezes the last observed duration and qualifies it as last known.

## Deliberately omitted

No guessed setup/compaction interval, phase inferred from prose, raw output subscription, elapsed time from the oldest retained event, or animated waiting dots. A missing lifecycle says Phase not reported. A completed compaction boundary cannot imply Compacting.

## Boundaries and states

The daemon projects only lifecycle identity, kind, timestamps and observation freshness through session status. It reuses the v2 transcript adapter and never exposes tool inputs or reasoning through this field. Native factory hooks bind the selected supervisor to its real transcript even when its registration lags; a PreCompact observation starts a measured interval and its matching SessionStart(compact) ends it. The selected session's own project supplies these facts, independent of the hub's launch environment. An unobserved harness compaction start remains unknown. The existing status/event owner refreshes it; the browser's clock changes display text only. Show work remains opt-in and its routine turn bookends stay collapsed. Explicit unresolved operator asks may report Waiting on you without inventing a start time.

Active phases animate only when the source and transport are fresh. Waiting, ended, stale, disconnected and unreported states are still. Reduced motion and forced colors remove motion. The elapsed clock is not a live announcement every second; phase changes remain accessible. The existing empty durable-history state remains empty.
