# Brief: machine version badges

## Single idea

Each machine names the Cassy runtime it actually reported and quietly identifies a newer published release.

## Hero form

Annotated register: the existing project machine chips carry the installed version beside their machine, while the paired-machine register repeats the same facts for machines without conversations.

## Emotional register

Calm and factual: mono version numerals inherit the glass chrome's quiet ink; only the explicit update sentence uses the existing warning ink.

## Distinctive move

Keep installed and available versions together on each machine, with a separately labeled Web release and build receipt in the footer so the two cannot be confused.

## Deliberately omitted

No modal, toast, upgrade button or success badge: a cached hourly release lookup informs the operator without interrupting a conversation. Missing or invalid versions never imply an upgrade is required.
