# Brief: short supervisor status tables

## Single idea
A short evidence table in a supervisor update remains a readable, reusable table.

## Hero form
Evidence table: native columns and two named copy controls preserve the relationship between each name and value.

## Emotional register
Quiet and precise: reuse Commander's body type, evidence surface and existing clipboard feedback.

## Distinctive move
Reserve the coalesced progress line for plain ticks; structured evidence keeps the same table presentation as a supervisor answer.

## Deliberately omitted
No new status badge, palette, component or animation: the existing evidence renderer already carries the interaction.

## Implementation boundary
`threadModel` derives presentation from server history; `messageBlocks` owns fence-aware table recognition. The same parser decides whether a short status needs the existing `ConversationView` table. Clipboard ownership and error recovery remain in that renderer.

Design: `hub-web/DESIGN.md@3c25c3fb3`. Existing semantic roles, body/mono families, Cassy mark and plain voice apply. No new visual tokens or markup.

## Critique
Pending rendered desktop/phone light/dark and native clipboard proof.
