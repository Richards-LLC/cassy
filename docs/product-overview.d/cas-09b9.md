## Core Concepts

Park records missing local proof and delivery upkeep as warnings. Green lane CI on the delivered tip and named passing tests provide test proof; tests run once without red-first receipts. Risk notes are optional. Delivery close does not wait for a batch QA receipt. Fixture and integration receipts suffice for review; unrun rows need no supervisor decision. Independent review owns screenshots, and lane CI runs selected journeys. Release budget misses remain measurements rather than automatically filed tasks.
