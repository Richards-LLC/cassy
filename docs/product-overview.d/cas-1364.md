## Core Concepts

- **Interrupted work after supervisor exit** - a confirmed stopped worker's started task is no longer released to the ready queue. It stays Blocked under that worker, with a session-end hold and its worktree, branch, dirty and unpushed counts and checkpoint tip in the task notes. Spawn pre-assignment refuses it; the successor supervisor recovers it with `recover_branch` and `transfer adopt_branch=true`, or discards it with `task reset`. Unstarted pre-assignments are still released.
