## Core Concepts

Worker shell guards share source positions and shell input boundaries. A literal
script's remaining arguments are data. Local arithmetic requires numeric
initialization in the command and proof that every possible later writer keeps
the value numeric; ambient values, arrays and namerefs do not establish proof.

Unsupported shell input and deferred or dynamic program text receive a stable
rule identifier, source position and supported alternative. The shared execution
walk supplies command scopes to operator, role, browser, build and signal checks.
Filename consumers retain credential and write-root policy; a listing does not
authorize reading the files it names.

Complete compound commands, pipelines and redirects share admission boundaries.
Known text-only filename-list pipelines keep names as data; unknown options,
dynamic arguments and filename-opening modes do not inherit that exemption.

Credential checks cover every admitted shell scope and distinguish program text
from literal script arguments. Bash single-bracket comparisons handle integer
data; recursive arithmetic remains checked. A literal realpath directory at
the start of a command can resolve artifact writes without granting new roots.
Pattern/rule inputs stay separate from lists of filenames to open.

Git scope checks read each statement's original word facts and projected
arguments, preserving existing ownership and raw syntax-check requirements.
