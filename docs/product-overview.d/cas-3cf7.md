## Core Concepts

- **Doc fragments at park** - Park refuses a delivery that changes product source without its `docs/product-overview.d/<task>.md` fragment (G-167), and a bug fix that changes files a live journey owns without a `docs/qa/bug-families/<slug>.yaml` naming the task (G-168). Both misses appear in the same park reply. A decision note `no overview: <reason>` or `no bug family: <reason>` waives each; docs- and test-only deliveries owe neither.
