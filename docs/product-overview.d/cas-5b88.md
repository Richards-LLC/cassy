## Core Concepts

Release admission reuses the nearest green train ancestor when every intervening commit changes only the release asset allow-list. Source changes, including changes reverted before the cut, require fresh train proof. Receipt identity, complete logs, successful full-set jobs and the current main baseline remain mandatory. A pending CODEMAP refresh can join the release commit. Release review gaps remain recorded in the cut preview and are resolved for delivery closure after publication; the merge queue proves the final tree.

Prepared release assets include the compiled product overview and journey registry as well as their input fragments. Terminal no-code members are reported from their saved outcome without reinterpreting their original external link as an artifact. Active report deliveries retain artifact integrity checks and review debt until closure after publication.
