## Core Concepts

Factory credential checks use each shell statement's effective working-directory alternatives from the existing shell-effects recognizer. Child scopes restore the parent directory and directory stack. A directory change before a pipe or inside a background list is undone; one after a pipe, or anywhere in a command that defines a function or runs a piped or background compound, is kept only as an alternative, and function bodies are judged from every reachable directory. An unresolved working directory refuses the read. The command grammar and file-open policy stay unchanged.
