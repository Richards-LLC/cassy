## Core Concepts

- **Find or file** - `system action=report_cas_bug` files a Cassy issue only when no open issue or task already names the same refusal. It keys on the refusal's registry gate codes plus its normalized first line (lowercased, ids and numbers collapsed); on a match it adds the new report as an evidence comment with +1 to the issue, or as a note on the task, and records the key as a `Fingerprint` line so later reports with wrapped wording still match.
