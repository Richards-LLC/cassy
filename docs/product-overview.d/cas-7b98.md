## Core Concepts

- **One shell reading for factory guards** - the credential, workspace-write and commit guards judge the same projected statements. These cover `-c` payloads, `eval` and quoted substitutions, each with its working-directory alternatives and variable values. The projection reads `sh`-family options and binds `$0`, `$1`, … for a `-c` payload. A child shell receives only exported variables. `pushd`, `popd`, `cd -` and `$OLDPWD` are followed for writes and pushes as well as reads. Numeric counters, `$(date +%s)` arithmetic, array literals and unlinking a worktree symlink resolve. Command output inside arithmetic, a computed working directory and a glob-chosen write root still refuse. An unresolved working directory is reported as unresolved, not as a credential request.
