## Core Concepts

- **Home-gateway routing in Commander** - New session offers a **Worker route** for the chosen project: Direct or Home gateway. Its preselection follows the project's `factory.gateway.enabled`, so it is off unless the project opted in. The step names the routed workers (Claude and Codex, or the project's `clients`) and says the supervisor and other workers stay direct. The gateway option is disabled, with the readiness reason, when the hub's private endpoint, mode-0600 key or model listing fails. The choice is sent as `routing` and pinned on the session's factory daemon (`CAS_FACTORY_GATEWAY`), so worker spawns follow it rather than a later config edit. A session started outside Commander pins the project's setting when its daemon starts, so a later config edit never changes that session's workers. Each Team lane shows the worker's effective route: Home gateway, Direct, or Direct · gateway fallback with its reason. The hub address is never sent. Accounts adds a read-only **Home gateway** section per machine with hub readiness and the hub's upstream accounts: masked label, provider, state, and requests and failures in the recent window. A machine with only the dashboard keys (no routing endpoint) shows routing off and still lists these accounts read-only. They come from the hub's existing dashboard, configured by the user-level `factory.gateway.dashboard` and `factory.gateway.dashboard_key_file` settings. Cassy uses that key only to GET the dashboard's auth-file listing and refuses every other path. A native profile does not pin a hub account; the hub picks per request. Codex Team accounts are counted, never listed, and nothing in the section is selectable. **Shared quota:** with those dashboard keys set, Accounts and New session read each login's quota from the hub's per-login rate-limit signals, matched by provider and login email on the machine. Every machine reading the same hub shows one number for the same login. An unreachable hub shows no number, never a local read in its place. A ↻ check while a hub is configured is drawn muted and named as that machine's own check. The keys are read-only and separate from routing: without `factory.gateway.endpoint`, a machine never routes its workers.
