## Core Concepts

Factory worker and automatic verifier launches omit optional context they do not
need for their assignment. Codex disables plugin, app and native memory context;
automatic Codex verifiers also omit the native skill catalog. Claude skips its
local auto-memory index and imported Exa skill documents. Existing worker skill
selection and Cassy's on-demand skill tools remain available. The settings apply
to launches only, preserving shared account files and supervisor configuration.
