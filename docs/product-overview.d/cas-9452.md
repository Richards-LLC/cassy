## Core Concepts

- **Epic close measures shipping** - Children close when they merge into their epic's branch, so closed children do not show the work reached the default branch. Closing an epic outside a release now checks the branch it closes against: if the default branch (local or origin) lacks commits that branch carries, the close is refused as EPIC NOT SHIPPED with the commit count, and it goes through once the branch is merged. A release close keeps its batch-receipt path and is not measured this way. `epic_status` prints the same answer as one `epic_shipping` line (shipped, unshipped with the commit count, or unknown), so the board shows merged-to-epic apart from shipped before anyone tries to close.
