## Primary Journeys

A Codex worker's Cassy wake remains ready while a connection from its current launch that listed the tool catalog is still live. Closing a sibling connection or replacing the MCP backend behind a live connection does not discard that acknowledgment. A private probe does not count, and a fresh worker launch clears earlier acknowledgments.

During a mixed-version upgrade, an older supervisor still reads only the single-connection readiness record. An older MCP backend cannot acknowledge a launch stamped by the newer supervisor; that launch needs a catalog listing through an updated backend.
