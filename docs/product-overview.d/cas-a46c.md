On macOS, automatic target retirement no longer inventories open files or mounted volumes. Retirement of a verified Cassy target requires the worker, lifetime and Cargo locks and a clear process-argument check. Unverified output is retained; the factory log records retirement holds and `cas factory gc report --full` shows cache sizes. `cas factory gc deep-reclaim <worker>` requires terminal confirmation and can trigger macOS privacy prompts while checking open handles for one retired worker target.
