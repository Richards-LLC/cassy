## Core Concepts

On macOS, automatic target retirement no longer inventories open files or mounted volumes. Retirement of a verified Cassy target requires the worker, lifetime and Cargo locks and a clear process-argument check. Unverified output is retained; the factory log records retirement holds and `cas factory gc report --full` shows cache sizes. Named reclaim through the factory API is preview-only on macOS. Run `cas factory gc deep-reclaim <worker>` or `cas factory gc deep-reclaim --target <absolute-path>` to reclaim one target after terminal confirmation. Both commands check open handles host-wide and can trigger macOS privacy prompts.
