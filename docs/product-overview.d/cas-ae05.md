Automatic pre-merge review keeps small review contexts inline. When serialized context exceeds 256 KiB, it writes the complete task, parent, dispatch and review context to a content-addressed JSON file under the dispatch's verification-runs directory and tells the reviewer to read it. This keeps accumulated repair history out of the harness's launch request without discarding evidence or changing verification authority.

The independent historical reviewer-eval script checks Linux bubblewrap namespace support before invoking Codex. Its explicit --source-input-only mode supplies pinned base/head source and diff on stdin, keeps the read-only sandbox, disables shell/integration tools, and rejects reports accompanied by tool events. It remains a simulated evaluation without live verification authority. Additional pinned dependencies can be supplied with --source-path.
