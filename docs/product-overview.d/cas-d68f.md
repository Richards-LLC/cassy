## Core Concepts

- **Dead-code sweep at park** - park compares the delivery's diff with its head tree and refuses, in one list, every TS/JS function, method, export or type, Rust `pub` item and CSS class whose last reference the delivery removed (gate G-166). Base counts come from the head counts and the diff, so symbols already unused at the base are never blamed. A new definition with no caller yet is left to compilers and linters, and a class that markup builds from its prefix (`status-chip--${tone}`) counts as used. The sweep reads source files outside `dist/`, `node_modules/`, `vendor/` and minified bundles, runs in seconds and needs no build or model call. A supervisor override with a reason waives it.
