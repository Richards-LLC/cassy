## Primary Journeys

A task briefed onto a release train or epic and later moved to a successor train keeps that train's reviewed history as upstream, so its close parks instead of being refused for another task's commits; an ordinary branch with no owning epic is still refused. The history survives a supervisor's branch rebind and a hand-off to another worker. After a hand-off, the receiving worker can start the task on its adopted branch, and the commit it pushes is the delivery that parks. If the task's target branch has been deleted, the refusal names it.
