# v2.53.0 — Slack runtime-release posts

## User — top-level

**CAS went from knowing only today’s code to remembering how the code got here. Now it can bring relevant history, current code, and project knowledge into your work automatically.**

- Search can explain what changed and why, not just what files look like now.
- Relevant context arrives briefly at the start of a turn without saving the prompt as memory.
- Messages and wake-ups work reliably for installations using a separate account configuration.

## Dev — top-level

**CAS went from indexing a snapshot to maintaining a live, queryable code-history corpus. Now history, symbols, issues, release notes, and embeddings stay connected and current.**

- Git commits, changed files, mapped symbols, GitHub discussions, and changelog content are indexed with provenance and coverage.
- History is a blended-search channel; exact symbol hits prioritize commits that changed the symbol.
- Background indexing and bounded embedding drains keep the corpus current; executable-epoch evidence makes fixed-status answers honest.
