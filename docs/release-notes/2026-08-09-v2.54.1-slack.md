# v2.54.1 — Slack runtime-release posts

## User — top-level

**Cassy went from a Linux download that could fail on supported computers to a portable replacement that starts normally. Now anyone on 2.54.0 should install 2.54.1.**

- The Linux x86_64 package no longer inherits instructions from a newer build machine.
- Terminal startup works on the supported x86_64 baseline without requiring AVX-512.
- The original 2.54.0 download remains intact for traceability; 2.54.1 is the replacement.

## Dev — top-level

**The release path went from trusting the build host’s CPU to enforcing an explicit portable baseline. Now every Ghostty target is pinned and the packaged archive is instruction-audited.**

- Native and cross builds pass an explicit Zig target mapping.
- Unknown target mappings fail closed rather than falling back to host features.
- The release gate rejects EVEX/AVX-512 encodings before publication.
