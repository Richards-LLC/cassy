# v2.55.0 — Slack runtime-release posts

## User — top-level

**Cassy went from making you stay at one machine to giving you a phone-friendly view of your paired machines. Now you can see and securely control live work from a paired device.**

- Each machine can provide its live sessions and terminal panes through a durable local hub.
- You can view panes, choose a pane, resize, send input, or interrupt from the embedded client.
- Pairing, permissions, and device access are designed to fail closed.

## Dev — top-level

**Cassy went from isolated local terminals to a bounded, paired-device Commander control plane. Now hubs multiplex live sessions with explicit authorization and one-controller input leases.**

- One bounded upstream connection serves multiple observers while slow viewers remain isolated.
- Device keys, DPoP, exact Origin/CORS checks, one-use credentials, scoped authorization, revocation, and audit bind every control operation.
- The hub uses durable session state and managed Tailscale Serve transport while refusing unsafe plaintext exposure.
