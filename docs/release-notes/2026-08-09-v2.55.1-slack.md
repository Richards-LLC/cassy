# v2.55.1 — Slack runtime-release posts

## User — top-level

**The 2.55.0 Linux download could still contain instructions some supported machines cannot run. Now 2.55.1 is the portable replacement to install.**

- Upgrade Linux installations from 2.55.0 to 2.55.1.
- The replacement keeps the published 2.55.0 artifacts unchanged for traceability.
- On AVX-512-capable machines, only indexing and fingerprinting work may be a little slower.

## Dev — top-level

**The Linux release went from auditing an intermediate archive to auditing the executable that actually ships. Now inactive AVX-512 code is excluded and the final artifact is checked before upload.**

- Cassy uses ring as its process-wide TLS provider; the unused AWS-LC provider is not compiled into Linux releases.
- BLAKE3 retains portable through AVX2 paths while its inactive AVX-512 archive is omitted.
- The strict ISA scanner now audits the staged executable and locked release features.
