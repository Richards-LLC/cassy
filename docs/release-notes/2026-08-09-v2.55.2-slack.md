# v2.55.2 — Slack runtime-release posts

## User — top-level

**Commander went from needing a pre-made home folder and sometimes hiding why a background program stopped. Now it prepares its secure home safely and reports a real illegal-instruction stop accurately.**

- A clean installation can start Commander without a manual setup step.
- Existing safe state is preserved, while unsafe folders and links are refused.
- When the operating system reports an illegal instruction, the guidance is based on that real evidence.

## Dev — top-level

**Commander startup went from assuming a valid filesystem and ambiguous disconnects to evidence-bound setup and exit reporting. Now hub directories are validated and daemon death receipts are bound to the exact process.**

- Missing hub directories are created owner-only; symlinks, bad modes, ownership mismatches, and unsafe ancestors fail closed.
- Exit receipts bind session, PID, and process-start fingerprint, reject stale epochs, and distinguish live transport loss from a confirmed SIGILL.
- Portable-release remediation is suggested only after the OS actually reported SIGILL.
