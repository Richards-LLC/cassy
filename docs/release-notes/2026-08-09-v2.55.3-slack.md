# v2.55.3 — Slack runtime-release posts

## User — top-level

**Commander HTTPS connections went from relying on a browser’s next request to staying protected after the first secure visit. Now verified secure routes tell browsers to keep using HTTPS for a year.**

- The policy applies only when Cassy has verified the secure Tailscale route.
- Local plaintext use remains local; it cannot claim the HTTPS policy through spoofed headers.
- Existing browser protections and error handling remain in place.

## Dev — top-level

**Verified Commander TLS responses went from omitting transport persistence to emitting strict HSTS. Now `Strict-Transport-Security: max-age=31536000` is bound to the trusted server-owned proxy path.**

- HSTS is emitted only for verified Tailscale Serve TLS traffic.
- The plaintext loopback listener cannot opt in through forwarded identity or proxy headers.
- CSP, referrer, content type, frame, authentication, and CORS behavior are preserved on success and error paths.
