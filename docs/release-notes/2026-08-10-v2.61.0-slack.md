# v2.61.0 — Commander runtime-release threads

Channel: #cas-internal (`C0B44GUKDK2`)

Publish in this order after the annotated `v2.61.0` tag, official Release
workflow, and both release-asset digests are verified: user top-level, user
reply, dev top-level, dev reply. This release does not restart an already
running daemon or hub; the next ordinary restart loads v2.61.0.

---

## User — top-level post

**Live on production · User · Was: keeping a Commander hub alive and recovering its public address could require manual intervention. Now: CAS can keep hubs running as a service and restores their public connection more reliably.**

## User — reply

- Was: a hub could disappear when a session ended, leaving fleet control dependent on a manually managed process. Now: CAS can install, inspect, and remove a managed hub service on supported systems.
- Was: restarting a macOS hub could leave its public address unavailable when the Tailscale command was not already on the shell path. Now: CAS finds the signed app command and republishes the hub's normal public connection.
- Was: a controller could appear connected even when its capabilities differed from the hub it reached. Now: the controller makes version-skew capability differences visible, and the sanctioned hosted controller origin is clearly documented.

---

## Dev — top-level post

**Live on production · Dev · Was: hub lifecycle receipts and scoped CI output could misstate the operational outcome. Now: v2.61.0 preserves the final Serve teardown truth and recognizes ANSI-coloured scoped-test summaries.**

## Dev — reply

- Was: a foreground hub could tear down its owned Tailscale Serve mapping during shutdown, while `cas hub stop` reported that no mapping was removed. Now: stop captures the owned receipt before termination and confirms whether that exact mapping is absent afterward.
- Was: persistent-hub operation required external service wiring and hosted-controller deployment rules were implicit. Now: `cas hub service install/status/uninstall` covers launchd and systemd, while the hosted static origin has an explicit trust and immutable-byte deployment contract.
- Was: macOS restart depended on a `tailscale` binary already visible on `PATH`, and ANSI escapes could hide scoped-test failure matching. Now: the signed app-bundle CLI is discovered for Serve republish and scoped CI normalizes terminal formatting before matching summaries.
- Was: deploying a release could be mistaken for restarting active processes. Now: existing daemons and hubs are untouched; the next ordinary restart loads v2.61.0.
