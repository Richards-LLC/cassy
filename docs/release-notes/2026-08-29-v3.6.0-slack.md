# Release notes — 2026-08-29 — CAS v3.6.0

**Channel:** `#cas-internal` · **Deploy:** Live on production · **POSTING EMBARGOED until 2026-08-31 (operator hold)**

## User thread

**Top-level:**
Live on production — **User** — Cassy can now design with you: ask any agent for a logo, background, icon, or web asset and it generates one that matches your project's own colors and style.

**Reply:**
- **Was** → needing a background, logo, or icon meant leaving your workflow, prompting some image tool by hand, and usually getting something that ignored your product's look. **Now** → every agent carries an image-generation skill that first reads your project's design (palette, motifs, typography feel) and bakes it into the prompt, so the output actually fits. Bring one Google AI Studio key; the skill tells you exactly how to set it up if it's missing.
- **Was** → vector needs (icons, favicons, dividers, simple marks) had no good path at all. **Now** → agents write clean SVG directly for those — tiny, crisp, and themed with your site's CSS variables — and can trace a generated mark into vector when you need both.
- **Was** → after months of shared syncing, tasks from other projects could crowd the top of your task list. **Now** → every task knows which project it belongs to, and foreign ones stay out of your queue.
- Cassy also has a new logo — generated by its own new skill.

## Dev thread

**Top-level:**
Live on production — **Dev** — CAS v3.6.0: style-aware image generation (raster + agent-authored SVG), origin-project identity on tasks, and merge-request suppression made environment-proof.

**Reply:**
- **Was** → no asset-generation surface. **Now** → `cas-image-generate` builtin (all three harness flavors): style-token harvest, per-asset routing to Nano Banana (draft/final tiers), reference-image consistency, file-backed payloads (no ARG_MAX on real reference sizes), MIME-honest output naming, dry-run, and explicit missing-key degradation. Plus an SVG & web-assets reference: author-vs-generate-vs-trace decision table, 24px-grid standards with palette CSS vars, tool-probing raster→vector bridge, favicon/OG/WebP pipeline.
- **Was** → tasks had no project column; rows replicated by the old unscoped pulls ranked in every project's ready queue. **Now** → `origin_project` (m241) stamped on create/push/pull, foreign rows excluded fail-closed from ready/available/list/start, audited supervisor reassignment path; global-scope tasks carry no project identity.
- **Was** → merge-request suppression silently queued stale requests in some environments: repo context consulted the host registry before the explicit root, linked git worktrees collapsed to the primary checkout, and ambient `CAS_AGENT_ROLE` overrode explicit registration. **Now** → explicit-root-first resolution with debug branch markers, `--show-toplevel` identity for linked worktrees, registered role wins, and test fixtures scrub the ambient factory env family.
