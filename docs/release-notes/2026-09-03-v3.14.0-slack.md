## User thread

**Top-level:**
Live on production — **User** — Commander on a phone now actually works: pairing succeeds first try, you can switch sessions and go back, messages to the supervisor send, and streaming output is readable.

**Reply (Was → Now):**
- Was: pairing from a phone failed with "unauthorized", there was no way to switch sessions or return, Enter and Send did nothing in the supervisor composer, agent output was squeezed into a 46-column grid, the bottom bar had stray outlines, and attaching a phone shrank the desktop console. Now: a default pairing link pairs on the first attempt and explains any refusal; the session name in the header opens a picker of every session with a back control and the last session is restored on reopen; Enter and Send both deliver and every refusal states its reason; phones get a readable transcript view with the real terminal one tap away, in portrait and landscape; the bottom bar is one clean rail; and a phone viewer can no longer resize the operator's console.
- Install: use `cas update` for an existing installation, or download the
  v3.14.0 archive for Linux x86_64 (SHA-256 `0584cd096dedd5aac0a912e0cee0b0514acdff0bbeb71a80aa0fb483eac35ed3`) or macOS ARM64

## Dev thread

**Top-level:**
Live on production — **Dev** — hub-web gains a session-selection model, scope-aware pairing, a signature-gated render path, a transcript view over the Ghostty row snapshot, and daemon-owned pane geometry with audited viewer refusals.

**Reply (Was → Now):**
- Was: `cas hub pair` minted read-only invitations while the form requested six scopes; selection was two loose globals; `render()` rewrote `app.innerHTML` on every hub push; the PTY took the minimum size across all viewers; attach called `AbortSignal.any` bare; the phone breakpoint was written twice and width-only; `/v1/sessions` reported the session file's empty `workers[]`. Now: invitation URLs carry `&scopes=` and the exchange clamps to the ceiling (`pairing-scopes.ts`, `Scope::as_wire`); `session-selection.ts` owns a (machine, session) stack with localStorage restore; `render-model.ts` decides shell/regions/defer with a gesture-aware `DeferredRenderScheduler`; `transcript.ts` reflows logical lines from the emulator snapshot and the surface floors the PTY at 80 columns below the compact breakpoint; the daemon's `pane_size.rs` makes the local dashboard the geometry authority, replying `DaemonMessage::PaneSize` and auditing `websocket_pane_resize` refusals; `viewport.ts` defines one `PHONE_MEDIA_QUERY` for CSS and JS with a landscape block; `anySignal()` and a declared `UnsupportedBrowserError` replace the bare call; the hub projects sessions via `hub_session()` using each project's live agent registry.
- Validation and artifact: the assembled tree passes hub-web vitest (354 tests, 23 files) and typecheck, the hub and factory Rust suites, and `scripts/release-gate.sh 3.14.0`; the phone-viewport live pass runs against the new daemon after this release restarts the factory. The published archives are
  `cas-x86_64-unknown-linux-gnu.tar.gz` (SHA-256 `0584cd096dedd5aac0a912e0cee0b0514acdff0bbeb71a80aa0fb483eac35ed3`) and
  `cas-aarch64-apple-darwin.tar.gz` (SHA-256 `fbea208c54c3d2c5df33fe170d0917b4aadb8c8e6f13f3cd12964c4780f952d5`). Linux and
  macOS are both available from CI, regardless of the tagger's host.
