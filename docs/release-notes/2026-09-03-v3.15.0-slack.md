## User thread

**Top-level:**
Live on production — **User** — Cassy v3.15.0: `cas doctor` finishes in seconds instead of minutes, cloud sync stops resurrecting deleted dependencies and stops leaking other projects' tasks onto your board, and MechaCassy sets up on any machine with one command.

**Reply (Was → Now):**
- Was: doctor took over two minutes on large projects with no way to tell which check was slow; task rows leaked from other projects sat on the ready queue with no remedy; a deleted dependency came back on the next pull; the machine with the wrong clock could silently win a sync conflict; setting up MechaCassy meant hand-editing config; the embedding backlog was frozen for days on one oversized commit; doctor printed ids like `cas-7,791`; UTF-16 source files broke the code index permanently; tasks with no recorded project were refused as an "unassigned legacy row"; a merge request sent after a fresh push was told the fix had "already landed". Now: doctor runs in about three seconds and `--verbose` shows each check's duration; `cas doctor --fix-cloud-rows` sets leaked rows aside (reversible) and reports unattributed and colliding rows; deletions propagate everywhere and stay deleted; the server's revision decides a conflict, not the clock; `cas integrate mecha-cassy` does the setup and doctor confirms it; oversized text is capped, a bad unit is quarantined with the provider's reason and the rest keep flowing; identifiers print exactly as they are; UTF-16 files index like any other and anything undecodable is skipped with a named reason; ownerless tasks are adopted and can be started; merge requests are checked against the live branch tip.
- Install: use `cas update` for an existing installation, or download the
  v3.15.0 archive for Linux x86_64 (SHA-256 `e27a03388acacba069750c939d352838d217735ccb1540579b2a575998af3072`) or macOS ARM64
  (SHA-256 `cdea102261f9080b2bc35ee6f8504b7c881c11f08379f338157ec2c6c99dfe89`) from the GitHub release.

## Dev thread

**Top-level:**
Live on production — **Dev** — v3.15.0: revision-based conflict resolution (m251/m252), quarantine ledger for unattributed rows (m250), dependency tombstones (m249), per-unit embedding quarantine (m253), code-index skip ledger (m254), per-phase doctor timing, live-tip merge-request revalidation, and tmpfs-safe isolated roots — with migration cursor guards now derived from the registry.

**Reply (Was → Now):**
- Was: pull attribution trusted the server scope stamp; no remediation for leaked rows; dependency deletes were re-healed from stale snapshots; LWW by `updated_at` only; push outcomes were opaque; the history-index provenance check ran a correlated `json_extract` over every task per commit (77 s); the embedding drain halted on the first failed chunk and retried a 502-wrapped provider 400 forever; code-vector counters came from queue rows; whole-line digit grouping corrupted ids in doctor; `read_to_string` failed UTF-16 forever; the merge-request suppressor compared the recorded anchor; `worktree_merge` merged into a stale local target and reported a rejected push as "origin is BEHIND"; probe-comm leaked roots into tmpfs; hermetic proxy tests inherited the host `.cas/proxy.toml`. Now: `origin_project` outranks the stamp and ephemeral checkouts never mint an identity (GH #701); `quarantined_rows` side ledger with read-time hiding at the task-store seam (GH #701); `task_dependency_tombstones` with reconciliation at most every 6 h (GH #640); `sync_revisions` + `sync_conflicts` revision columns, base revision on push, `revision_conflict` retryable, explicit strategy outranks revisions (GH #668); per-row `last_outcome`/`last_reason` with requeue-once (GH #668); anchors materialized once, 125.7 s → 3.3 s on the reporter's store with a budget test (GH #700); `EmbedError::Rejected`, chunk bisection, `embedding_error` column, 24k-char cap, `cas history embed --retry-quarantined` (GH #695); `coverage()` over `code_symbols` with current-hash completion and a `rebuilt.json` receipt (GH #696); grouping pass removed (GH #697); std-only BOM transcode and a skipped-files ledger (GH #698); shared `resolve_live_branch_tip` with `anchor_tip` on drift, `worktree_merge` fetch + fast-forward / refuse on divergence / honest non-fast-forward (GH #703); RAII scratch roots under `~/.cas/scratch`, tmpfs refusal for bulk roots, `gc_report` inventory (GH #704); canonicalization parity and alias record (GH #669); shared-clone supervisor warning (GH #699); `mecha-cassy-post` folded into the `mecha-cassy` builtin with a per-harness `user skills` doctor row.
