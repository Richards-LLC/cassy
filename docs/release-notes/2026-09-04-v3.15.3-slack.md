## Dev thread

**Top-level:**
Live on production — **Dev** — v3.15.3: doctor task-health resolves off-board endpoints through the unfiltered store with Present/Absent/Unresolved; `cas index code` ends with a code-vector queue reconcile inside one immediate transaction; integrate mecha-cassy edits the project proxy.toml with toml_edit; foreign-row peers gain a skipped set and `known-repos forget`; the tmpfs proof gate matches cited receipts, not prose.

**Reply (Was → Now):**
- Was: doctor compared the quarantine-filtered `list()` against unfiltered `list_dependencies()`; `cas index code` never touched `code_vector_queue` rows for deleted symbols or `failed` rows, and code-store retire writes were bare autocommit statements that surfaced SQLITE_BUSY as file failures; `run()` in integrate/mecha_cassy only loaded the user-level registration while `merged.allowlist = project.allowlist` made the project file authoritative; `foreign_rows::scan` treated every `known_repos` row as a peer store and any open error as unreadable; the close gate returned any token with a `/tmp/` prefix anywhere in the reason. Now: `EndpointResolution` via `TaskStore::get` with only `TaskNotFound|NotFound` meaning absent, `PruneOutcome::Skipped` on any other error, `--fix` prunes only dangling rows; `SqliteCodeVectorStore::reconcile(force)` (orphaned drop, failed re-arm with a permanent-error deny-list, hash-drift rewrite, never-queued enqueue) called from `reconcile_code_tree` and `index_cmd`, code-store writes through `shared_db::with_write_retry` / `with_immediate_write_txn`, a run-scoped `WriterLockBudget` for the Tantivy lock; `plan_project_proxy` rewrites routes with toml_edit, drops `[servers.mecha-cassy]` only when it parses equal to the machine registration, drift reported against the effective allowlist with the source file named; `RegistrySkip{Artifacts,Scratch,Temp}` in `register_repo`/`seed`, `read_peer_snapshot → Ok(None)` for stores without `tasks` feeding `ForeignRowReport::peers_skipped` (absent from the WARN expression), `cas known-repos forget <path> [--yes]`; `tmpfs_receipt_path_in_close_reason(reason, artifacts_root)` with `PROOF_CUE_WORDS`, a 5-token window, line-opening detection, and a durable-citation fallback.
