User top-level

```text
*Live on production — User — Cassy v3.17.0*
Was: pairing left you guessing, and an update could leave another folder showing stale files. Now: each step is clear, and stale folders are named.
```

User reply

```text
• *Pairing you can follow* — Was: a pairing step could offer several actions at once and leave you unsure what to do next. Now: each step has one clear action, tells you which machine it means, and lists exactly what access you granted.

• *Saved is not connected* — Was: a machine you had merely saved could look like a live one. Now: saved and connected are shown differently, and the confirmation names the machine you installed on.

• *Recovery you can see* — Was: a failed or cancelled pairing could leave you stuck with no way back. Now: cancelling cleans up after itself, a failure that happens late still tells you, retry is offered by name, and an expired or invalid link says so plainly.

• *Fleet at a glance* — Was: the fleet view could empty itself when the page rebuilt, and was hard to read on a phone. Now: it stays filled, shows workers and tasks as proper rows, and has touch-sized controls and readable contrast.

• *No silently stale folders* — Was: updating one folder could leave another one still showing older files, with the new work appearing there as if it had been deleted. Now: Cassy leaves a folder holding unsaved work alone and names it.

• *Skill files that open* — Was: a description containing a Windows path could produce a skill file that tools refuse to read. Now: those files are written and read through a real reader, and a wide set of awkward descriptions is tested to survive unchanged.

• *Setup checks stay honest* — Was: an installation check could pass while comparing against the wrong wording, and a build check could report "nothing changed" after failing. Now: both report what actually happened.

Install
Update with `cas update`, or download the Linux x86_64 or macOS ARM64 archive from the Cassy v3.17.0 release. SHA-256: Linux `{{LINUX_SHA256}}` · macOS `{{MACOS_SHA256}}`.
```

Dev top-level

```text
*Live on production — Dev — Cassy v3.17.0*
Was: generated frontmatter, ref advancement, and sync intent each trusted a happy path. Now: a serializer, git itself, and the store enforce them.
```

Dev reply

```text
• *YAML frontmatter* — Was: three drifted `escape_yaml` copies emitted frontmatter a parser rejects, and `argument-hint: [title]` read as a sequence. Now: one shared serializer writes it, a parser reads it back, and a hostile corpus round-trips byte-identical.

• *Linked-checkout merges* — Was: a ref advance was invisible to a second worktree holding that branch, which kept an older index and showed merged content as staged deletions. Now: a dirty holder refuses before any ref moves, a clean one advances under git's own guard.

• *Divergence classification* — Was: a target ahead of origin with nothing behind it was refused as diverged, with a recovery that was a no-op. Now: ahead-only is its own state and the guidance matches it.

• *Sync intent durability* — Was: a task write could commit locally while its outbox enqueue error was discarded, leaving nothing to retry. Now: the mutation and its intent are bound, recovery is serialized, and a failed enqueue is retained.

• *Close-path corrections* — Was: an inline `execution_note` on close was ignored, so a no-code task needed a separate update first. Now: the inline intent is honored and bounded.

• *CI and runner storage* — Was: `classify-ci-diff.sh` reported empty with exit 0 when git failed, and runner caches had no budget. Now: it fails closed, and a guarded periodic prune ships — serialized against running jobs, rejecting descendant mounts — enforced only where its timer is enabled.

• *Retrieval and release receipts* — Was: ambient recall admitted identity noise and stale procedures, and a tag push was recorded as a publication. Now: recall rejects both and parses expiry instants, and tag and publication receipts are separate events.

• *Removed* — Was: a dormant Slack upload staging helper overwrote a symlink target before rejecting the write, reachable only from its own tests. Now: it is deleted rather than shipped as a repaired feature nothing calls.

Validation
Record the gate, pipeline and exact-tip CI receipts from the merged v3.17.0 tree before publication. Published archives: `cas-x86_64-unknown-linux-gnu.tar.gz` (`{{LINUX_SHA256}}`) and `cas-aarch64-apple-darwin.tar.gz` (`{{MACOS_SHA256}}`).
```
