User top-level

```text
*Live on production — User — Cassy v3.17.3*
Was: reports, screens, terminal output, and drawings came out serviceable but forgettable. Now: every project inherits a design system that starts from an argument, checks itself, and looks the part.
```

User reply

```text
• *A house design language* — Was: each report or page picked its own look and usually landed on a gradient header and a row of number cards. Now: every project vendors the Petrastella design language and tokens, writes a one-page concept brief before rendering, and scores the result against a critique rubric with a floor.

• *Mistakes caught before you see them* — Was: white-on-white text, clipped boxes, and overlapping labels shipped and got noticed by people. Now: a visual-QA gate renders every public surface in light and dark at desktop and phone widths and blocks on any of those defects.

• *Terminal output you can read* — Was: `cas doctor` coloured whole lines, split words at the edge, and repeated one warning 14 times. Now: it leads with a verdict, colours only the marks, folds repeats, wraps remedies, and stays readable on light terminals.

• *Doctor that fixes things* — Was: most doctor warnings were paragraphs telling you what to run. Now: safe repairs run with `--fix`, riskier ones show a plan and wait for `--yes`, host-level findings appear once instead of per project, and a published matrix says which is which.

• *Technical drawings* — Was: workshop drawings were hand-drawn figures with dimensions inside outlines and a fake isometric. Now: a drafting toolkit produces orthographic, isometric, section, exploded, joint, and part sheets from one model, with mechanical checks that also catch errors in the plan itself.

• *No more silent stalls* — Was: a coding worker could sit for an hour on a hidden approval prompt while status said “busy”. Now: workers no longer trigger the prompt for edits inside their own worktree, and status names a pending approval when one exists.

• *Model routing by measurement* — Was: which model ran which work was set by reputation. Now: a cross-project scorecard over every harness home records cost, send-backs, and speed per model and effort, and the routing brief is written against it.

Install
Update with `cas update`, or download the Linux x86_64 or macOS ARM64 archive from the Cassy v3.17.3 release. SHA-256: Linux `{{LINUX_SHA256}}` · macOS `{{MACOS_SHA256}}`.
```

Dev reply

```text
• *Design skills* — Was: `cas-html-reports` and `cas-dataviz` were compliance contracts with safe examples. Now: `cas-ui-craft` (brief → render → critique, floor ≥4), `cas-frontend-engineering`, an API/DX taste section in `cas-codebase-design`, Petrastella `design-tokens.json` with per-scheme contrast pairs and a series palette that passes `validate_palette.js`, and annotated exemplars with before/after pairs, mirrored byte-identical across Claude, Codex, and Grok.

• *Visual QA gate* — Was: no automated check for contrast, clipping, overlap, or invisible text. Now: `node scripts/visual-qa.mjs --strict` renders light and dark at 1280 and 390, exempts accessibility-only text, dedupes per node, resolves gradient backgrounds by pixel sampling, and writes a PASS receipt under the task artifacts root; wired into report review, the UI rubric, and worker close.

• *Terminal craft* — Was: doctor, update, and factory status were ad-hoc println output. Now: `cas-cli-craft` plus `scripts/terminal-qa.mjs` (pty captures at 80/120 columns on four palettes, contrast, overflow, word-split, truncation, numeric alignment, Unicode fallback, NO_COLOR, piped, JSON checks); the `Formatter` gained verdict, mark, rule, remedy, and receipt primitives; `COLORFGBG` `0;15` now classifies as light.

• *Doctor self-heal* — Was: every warning was text. Now: `docs/doctor/check-matrix.md` classifies each check as auto-fix, consent-fix, human, or info; `--host`/`--full` report host findings once; safe fixes (known-repo prune, code and search index rebuild, projections) run under `--fix`; consent fixes (purge-foreign, cloud row quarantine/release, `config.toml` repair) dry-run by default and apply with `--yes`; snapshot updated for the named row changes.

• *Technical drawing* — Was: no drafting capability. Now: `cas-technical-drawing` with `draft.mjs` (parts+joints JSON → third-angle ortho set, 30° isometric, hatched sections, exploded assembly with chain lines, joint sheets, part cards, parts list, DXF) and `check` (projection angles, extents, collisions, dimension chains, notes-block containment, cut-list parity, interference).

• *Worker approval hang* — Was: Claude Code team-mode routed `rm`/heredoc Bash calls to a leader prompt nobody could answer, and the hung call never reached the transcript. Now: the launcher passes `--permission-mode bypassPermissions`, the PreToolUse guard expands variable `rm` targets and heredoc writes, and `worker_status`/`is-wedged` read the team inbox `permission_request` records and report an approval-hang state (ignoring MCP sidecar children).

• *Epic branch authority* — Was: epic create printed an `epic/<slug>-<id>` branch but recorded no WorkTarget, and spawn recomputed a title slug and fell back to the pinned epic. Now: `epic_branch_name(title, id)` is shared, create persists the WorkTarget, spawn refuses a title-derived base, and a spawn fast-forward inventories and refreshes checkouts holding the epic branch.

• *Model scorecard* — Was: lane routing evidence covered one session window. Now: `scripts/factory-model-history.py` reads every `.codex*`/`.claude*` home in one run, recovers model/effort from rollout `turn_context`, counts shell tool calls, bills Codex cached tokens once, and emits per-session and per-model×effort scorecards; the lane rubric review is rewritten verdict-first under the new design contract.

Validation
Require the full release gate, protected-main pipeline, exact landed SHA, and published-asset receipts before publication. Published archives: `cas-x86_64-unknown-linux-gnu.tar.gz` (`{{LINUX_SHA256}}`) and `cas-aarch64-apple-darwin.tar.gz` (`{{MACOS_SHA256}}`).
```
