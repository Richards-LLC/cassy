User top-level

```text
*Live on production — User — Cassy v3.20.0*
Was: work could begin without naming the user-visible outcome or preserving the evidence behind it. Now: Cassy makes outcomes explicit, QA evidence honest, and release reporting easy to follow.
```

User reply

```text
*Clearer work requests*

• *Observable task outcomes* — Was: user-facing work could start without saying what someone should see. Now: configured labels require a demo statement, with clear exemptions for internal work and epics, and worker briefs repeat the outcome.

*Honest QA*

• *Capped exploration* — Was: exploratory QA could expand past the useful decision window. Now: `cas-qa-craft` gives each demo statement an exploration matrix, adjacent-risk checks, evidence labels, and a 30-minute box.

• *Durable evidence* — Was: a close could rely on prose that did not show what was exercised. Now: every QA pass can leave a `LEDGER.md` with row-level verdicts, captures, and honest NOT EXERCISED results.

• *Memory that finds the right thing* — Was: Cassy's automatic recall could miss a lesson saved the same day and time out on its semantic search. Now: recent, closely matching memories rank first and semantic search runs within its budget.

*Release clarity*

• *A report you can inspect* — Was: release changes and publication proof lived in separate, inconsistent places. Now: a reusable release report carries the source, brief, standalone HTML, verified PDF, and QA receipt.

• *Quiet waiting* — Was: an idle code watcher could keep a CPU core busy. Now: `cas serve` waits for file changes without spinning.

Report: [docs/release-reports/v3.20.0.html](../release-reports/v3.20.0.html) · [docs/release-reports/v3.20.0.pdf](../release-reports/v3.20.0.pdf) (forthcoming).

Install: update with `cas update`, or download the Linux x86_64 archive (`927ce9b5a594bb7d6d14858c043415587e61c30f3a377ab4e432b22242425b35`) or macOS ARM64 archive (`a39b21961c94d1f77174e257b27503c76b04b1db6a816704e47aa05ef2ef49c5`) from the Cassy v3.20.0 release.
```

Dev top-level

```text
*Live on production — Dev — Cassy v3.20.0*
```

Dev reply

```text
*Task and QA contracts*

• *Creation gate* — Was: a task label could imply a public surface without requiring a demo. Now: `qa.user_facing_labels` defaults to the five user-facing labels, requires a non-empty demo statement, and preserves explicit exemptions for epics, unlabeled tasks, and supervisor overrides.

• *Verification gate* — Was: a verifier could read a close reason before checking the underlying QA evidence. Now: the evidence-mode REJECT table runs first, and the verifier records capture judgments before comparing the close reason with acceptance criteria.

*Release controls*

• *Report recipe* — Was: every release needed a bespoke path from source to a readable report and PDF. Now: `cas-release-report` supplies the renderer, template, design brief, and pagination recipe for source-faithful A4 and Letter output.

• *Publication handoff* — Was: Slack preparation could omit the report artifacts or publication receipts. Now: release step 13 produces and links the report before posting, and the release-notes rubric preserves four ordered POSTED receipts.

• *Ambient recall quality* — Was: the semantic embedder kept a 30 s connect timeout outside the 400 ms budget, lexical ranking let month-old rules outrank same-day exact-overlap memories, prompts were padded with unrelated task titles, and PostToolUse trigger terms were hex ids. Now: connect and request deadlines are bounded with timings in the decision trace, recency and overlap depth feed the fusion score, strong prompts are not padded, and trigger terms must be dictionary-like.

*Runtime efficiency*

• *Watcher idling* — Was: the code watcher could spin when no files changed. Now: its idle path blocks for filesystem events and leaves the core available to other work.

Validation: `scripts/release-gate.sh 3.20.0 --only changelog-and-versions,version-literals`; `cargo check -p cas --lib --tests`.

Install: `cas-x86_64-unknown-linux-gnu.tar.gz` (`927ce9b5a594bb7d6d14858c043415587e61c30f3a377ab4e432b22242425b35`) and `cas-aarch64-apple-darwin.tar.gz` (`a39b21961c94d1f77174e257b27503c76b04b1db6a816704e47aa05ef2ef49c5`) will be published by CI for Linux and macOS.
```
