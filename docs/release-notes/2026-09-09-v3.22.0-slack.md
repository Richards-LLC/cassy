User reply

```text
*Release reports*

• *One command* — Was: each release report was assembled by hand from the changelog, issues, and receipts. Now: `cas release report <version> --pdf` builds the Markdown, the standalone HTML, and the PDF for any project, and re-running it never overwrites your edits.

• *Required before announcing* — Was: an announcement could be posted without the report. Now: the release checks refuse to call a release announced until the report exists and its Slack file receipt matches the bytes.

• *Two reports shipped* — Was: only the v3.19.0 report existed. Now: the v3.20.0 and v3.21.0 reports are in the repository with their PDFs.

*Already live on hosts that updated from main*

• *Recall that survives long briefings* — Was: when the start-up briefing grew too long, your recalled memory was the first thing cut, silently. Now: static lists go first, recall and inbox stay, and the briefing says what it trimmed; `cas doctor` warns before headroom runs out.

• *Fair task closes* — Was: finishing a task could be blocked by changes another task had already shipped on the same branch. Now: only the task's own commits are judged.

• *Honest start-up line* — Was: a Codex helper's start-up line claimed a Claude account folder. Now: it names the tool and account folder actually in use.

Install: update with `cas update`, or download the Linux x86_64 archive (`6a0e7b36a21ebb1458fdcd6d10e2c7c374a3deb0963e69fdbb7ba9399b27249c`) or macOS ARM64 archive (`77ae01610d2093193e9847ee56b98b484b3a63c61ed969bcbcc4b42d542485c5`) from the Cassy v3.22.0 release.
```

Dev reply

```text
*Release report command*

• *Assembler* — Was: report sources were gathered by hand. Now: `cas release report <version> [--out] [--pdf] [--json]` parses the Keep-a-Changelog section, finds the release-notes draft, queries `gh` release/PR/issues through `issues.repo` with bounded timeouts, reads receipts under `~/.cas/artifacts/release/`, writes fixed-skeleton Markdown with YAML front matter, invokes the built-in renderer (front matter accepted in all three mirrors), and renders the PDF via Playwright with a Node remedy. Label-first then keyword themes; explicit Unclassified row; `--refresh-sources` to regenerate.

• *Terminal output* — Was: paths and warnings overflowed 80 columns and printed Unicode marks under LC_ALL=C. Now: Formatter-based rendering with width-aware wrapping and ASCII fallbacks; terminal-qa PASS at 80 and 120 columns; `--json` unchanged.

*Release train*

• *`--report` step* — Was: `--status` gated only on workflow, published, and latency receipts. Now: `--report` requires verified publication, runs the report command, delegates the authenticated file post to `CAS_RELEASE_TRAIN_REPORT_POST_CMD`, and validates `release-report.receipt` (TAG, worktree-confined PDF/HTML paths, both SHA-256 values, page count, file ids, PDF permalink, user and dev thread ts); `--status` revalidates bytes and pages. Self-test 127 checks.

*Carried from main since 3.21.0*

• *SessionStart compaction* — Was: sections compacted by byte saving, ambient recall first. Now: priority order static → context → ambient → factory inbox, in-payload marker, production-shape regression, guidance trimmed >1 KB, doctor `SessionStart budget` row with a 512 B floor (PR #783).

• *Close-gate attribution* — Was: posture, no-code, receipt-stat, and epoch gates each diffed `target..branch`. Now: one first-parent delivery-range seam with an audited supervisor exception and unchanged-proof posture clearing (PR #781, closes #767).

• *Spawn audit* — Was: the PTY audit always printed a Claude account directory. Now: it names the launched CLI, model, effort, and `CLAUDE_CONFIG_DIR`/`CODEX_HOME` source, with a routing regression (PR #780).

Validation: full release gate on the exact candidate tip; merge queue validates the synthetic tree.

Install: `cas-x86_64-unknown-linux-gnu.tar.gz` (`6a0e7b36a21ebb1458fdcd6d10e2c7c374a3deb0963e69fdbb7ba9399b27249c`) and `cas-aarch64-apple-darwin.tar.gz` (`77ae01610d2093193e9847ee56b98b484b3a63c61ed969bcbcc4b42d542485c5`), published by CI for Linux and macOS.
```
