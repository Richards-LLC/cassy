**Only reply:**

```text
• *Artifact publish* — Was: no durable record for a produced file. → Now: `cas artifact publish|show|list` plus the MCP tool records size and SHA-256, refuses escaping symlinks and `.cas`/`.git`, caps at 25 MiB before any request, and falls back to local-only when Cloud storage answers 404/501.

• *Operator turn kinds* — Was: `target=operator` required `in_reply_to`, so only answers could reach the hub. → Now: payload v2 carries `kind` and `attachments`; unprompted kinds route to the latest verified device, v1 still decodes.

• *SessionStart budget* — Was: protected guidance grew and the assembler compacted the issue-triage evidence instead. → Now: the Codex note is degradable and a pin fails the build when guidance leaves under 2400 B of the 9216 B budget.

• *Credential redaction* — Was: fourteen structs derived `Debug` over a live bearer, API key or pre-signed URL. → Now: each redacts, with a repo-wide guard test that resolves its tree at runtime.

• *Docs-only CI tier* — Was: every docs change ran the full required tier. → Now: a classifier routes docs-only events to `Docs Lint`, which lints only Markdown; required contexts still report.

• *Close gate* — Was: expected proof base came from the current checkout, so a merged-before-close delivery was unprovable. → Now: it comes from the delivery's first parent, and a supervisor can widen proof targets in one reasoned call.

• *Doctor* — Was: alias checks passed while the git remote matched neither canonical id nor alias, and `--fix --json` emitted two documents. → Now: drift is a warning with the exact remediation, identity conflicts count separately, and the JSON is one document.

• *Assets* — Was: n/a. → Now: `cas-x86_64-unknown-linux-gnu.tar.gz` `281e936daa2650fab1ab426edb3090a4187fe2ba1d62acc6fe166c8d5515ce70`; `cas-aarch64-apple-darwin.tar.gz` `f36e0573d736c6b66d5d01ff1eecfb53cde677fd8ce2ebf1d12a1b8495bbe212`.
```
