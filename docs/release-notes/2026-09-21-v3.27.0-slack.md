```text
• *Conversations at a glance* — Was: a list of session names. → Now: each supervisor is a row in its machine's colour with its project, the last line said, and a clear mark for "waiting on you" versus "unread".

• *Reports you can open* — Was: a link inside a bubble. → Now: a paper sheet with a folded corner; tap it to open the report.

• *Phone first* — Was: desktop layout squeezed onto a phone. → Now: the list fills the phone with a compose button, and even a long evidence table fits without sideways scrolling.

Update with `cas update`. Published downloads and installation checks passed on Apple Silicon macOS and Linux.
```

**Top-level:**


**Only reply:**

```text
• *Tokens and accents* — Was: one shell palette. → Now: PAPER semantic tokens (canvas, panel, bubble pairs, ask, crit, four lift shadows) light and dark, plus three machine accent sets assigned by FNV-1a + jump consistent hash (append-safe); a unit test measures 144 rendered pairs ≥ 4.5:1.

• *Thread model* — Was: render logic in the view. → Now: `thread-model.ts` is a pure grouping/coalescing/day/working/evidence-table model with tests; `conversation-view.ts` renders pebbles from it and exposes `registerTurnRenderer(ask|blocker|attachment)` as the single seam for object turns.

• *Ask, blocker, attachment objects* — Was: `data-kind` bubbles and a link row. → Now: fused-tray ask/blocker with quick-reply chips and a pinned copy above the composer; dog-eared attachment sheet per artifact; empty state; accent composer.

• *Reply reference* — Was: `ClientMessage::SendMessage` had no `in_reply_to`, and hub/server re-parsed the frame, dropping it. → Now: optional `in_reply_to` (serde default, keyless when absent), forwarded unchanged; the daemon validates it names a supervisor→operator turn of the session, prefixes the queued text with the explicit reply reference, and acks the ask.

• *Pane mirror* — Was: the transcript article in the default conversation. → Now: removed; the ghostty terminal stays as the explicit alternate view.

• *Assembly QA* — Was: per-lane screenshots. → Now: strict visual QA 25 fixtures × 2 schemes × 3 viewports with 0 findings, a 68-pair contrast table (tightest 4.85:1), 134 Playwright receipts including the `in_reply_to` frame on the built bundle, and side-by-side composites against the design PNGs with every deviation named; dist rebuilt once from the assembled tree.

• *Assets* — Was: n/a. → Now: `cas-x86_64-unknown-linux-gnu.tar.gz` `92f5235ac45bf83bba4e2d8315ac9c0173a2270339ef5b1d9e778f29c1168cee`; `cas-aarch64-apple-darwin.tar.gz` `e8c928186cb08d54a86ba0c13d35c23ca2da89a0363af7ccc33f8870834dd28e`.

Install: `cas update`.
```
