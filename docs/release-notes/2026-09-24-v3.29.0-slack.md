## Dev thread

**Top-level:**

```text
*Live on production — Dev — Cassy v3.29.0*
Was: restart_stale_hub skipped non-live hubs. → Now: the post-swap child restarts, verifies and recovers any hub, including old versions.
```

**Only reply:**

```text
• *Update hub convergence* — Was: `restart_stale_hub` returned early when `record_is_live` was false, so a wedged hub was never touched. → Now: the new binary's post-swap child classifies the prior state and force-stops a wedged holder. It restarts with the recorded or receipted Tailscale setting and checks the lock, loopback /v1/health, the Serve route to the live shim and the public /v1/health. On failure it saves evidence and recovers once. A current healthy hub is `verified` without a restart, and a public-DNS-only failure is a warning. Tested against real v3.27.8, v3.28.1 and v3.28.2 hubs in 4 states each, 12 of 12 passing (PR #979).

• *launchd parity* — Was: `restart_supervised` bailed on a plist without Tailscale. → Now: the plist ProgramArguments are rewritten atomically, with bootout and bootstrap. It takes over from a detached or stuck no-phase holder, refuses ambiguous holders, and adds PATH to EnvironmentVariables (PR #979).

• *Lifecycle state* — Was: one boolean readiness check drove every message. → Now: `HubDisplayState` is exited, starting, startup_wedged, stopping, unresponsive or running, in text, `--json` and authorize (PR #979).

• *Serve ownership* — Was: the receipt was written after `serve --bg`, and the process record was overwritten before `ensure`. → Now: the receipt is written before publishing, the prior target is passed to the replacement, and a dead loopback shim on a Cassy-receipted port is reclaimed (PR #979).

• *macOS suite* — Was: 96 failures running the full nextest suite on macOS. → Now: 9788 of 9789 pass in each of two loops (two separate timing-sensitive flakes are tracked). Includes a shared `warm_stub` for dyld first-launch stalls, BSD socket and `/private/var` fixes, a Rust flock/timeout for light-lane jobs, and unknown-safe Mac worker liveness with a proc_pidpath kill check (PR #979).

• *Commander mirroring* — Was: Commander history held only Commander-sent messages and explicit target=operator rows. → Now: the factory daemon tails the supervisor transcript (Claude and Codex) and queues each completed turn's final text as a schema-2 operator reply. It is an answer with reply_to when a verified Commander message started the turn, otherwise a status to all devices. Text is redacted, capped at 4,000 characters and deduped by turn key, and it only starts after first pairing (PR #983).

• *Close gate* — Was: a red base on the host blocked every close, the parked-task anchor followed branch reuse, and the parser read "failure" in test names as failures. → Now: an audited inherited-failure close path, frozen parked anchors, and structured result parsing that accepts short bases (PRs #974, #975, #977).

• *Assets* — Was: n/a. → Now: `cas-x86_64-unknown-linux-gnu.tar.gz` `{{LINUX_SHA256}}`; `cas-aarch64-apple-darwin.tar.gz` `{{MACOS_SHA256}}`.

Install: `cas update`.
```
