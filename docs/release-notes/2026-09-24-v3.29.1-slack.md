## User thread

**Top-level:**

```text
*Live on production — User — Cassy v3.29.1*
Was: on some Macs the hub came back local-only after `cas update`. → Now: it comes back on Tailscale and Commander reaches it.
```

**Only reply:**

```text
• *Mac hub on Tailscale* — Was: after `cas update`, a Mac hub could come back without its Tailscale address, and Commander showed the host as unreachable. → Now: the hub republishes its Tailscale address every time, whether Tailscale came from Homebrew or the Mac app.

• *Hub service repair* — Was: an older Mac hub service kept settings that hid the Tailscale command. → Now: every restart repairs those settings, with no manual fix needed.

Update with `cas update`. Published downloads and installation checks passed on Apple Silicon macOS and Linux.
```

## Dev thread

**Top-level:**

```text
*Live on production — Dev — Cassy v3.29.1*
Was: a TERM-less hub ran the Tailscale app binary in GUI mode. → Now: TERM is set, Homebrew CLI preferred, launchd env repaired.
```

**Only reply:**

```text
• *Tailscale CLI mode* — Was: detached and launchd hubs ran with PATH=/usr/bin:/bin:/usr/sbin:/sbin and no TERM, so they fell back to /Applications/Tailscale.app/Contents/MacOS/Tailscale. That binary chooses GUI mode without TERM, so `status --json` returned "The Tailscale GUI failed to start" and every restart stayed loopback-only. → Now: every Tailscale child command sets TERM=dumb when TERM is unset (PR #1003).

• *CLI selection* — Was: the app bundle was the only macOS fallback. → Now: /opt/homebrew/bin/tailscale and /usr/local/bin/tailscale are tried before the app bundle, and an explicit TAILSCALE override survives the detached launcher's environment scrub (PR #1003).

• *launchd env* — Was: EnvironmentVariables were only written at install. → Now: install and restart_supervised always rewrite PATH (with Homebrew dirs) and TERM, so existing plists are repaired (PR #1003).

• *Proof* — Was: n/a. → Now: an isolated launchd test with the app-bundle CLI forced under a sparse PATH published and verified public HTTPS across restarts and updates. The real v3.27.8, v3.28.1 and v3.28.2 update matrix passes (PR #1003).

Install: `cas update`.
```
