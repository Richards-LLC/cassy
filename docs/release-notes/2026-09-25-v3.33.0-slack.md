## Dev thread

**Top-level:**

```text
*Live on production — Dev — Cassy v3.33.0*
Was: skill tests froze sentences and red lane CI could merge. → Now: tests check behaviour, red CI refuses, and QA gains a feature-map gate.
```

**Only reply:**

```text
*Verification and QA*

• *Claim verdicts* — Was: verify-before-claim and task-verifier had no shared verdict. → Now: VERIFIED / NOT VERIFIED / INCONCLUSIVE per claim, a four-rung blast-radius ladder, same-command baseline/treatment.

• *Verification kit* — Was: no reusable launch and drive recipe per project. → Now: `cas-qa-craft` generates `docs/qa/verify.md` and `docs/qa/features/`; `check-feature-map.mjs` checks headings, Touches globs and the index.

• *Feature-map close gate* — Was: nothing tied a diff to its feature doc. → Now: opt-in on `docs/qa/features/`; a touched glob without its feature file refuses unless a `map unchanged: <reason>` decision note exists.

*Merges and closes*

• *Red lane CI* — Was: `worktree_merge` treated CI as advisory, so a red lane merged. → Now: red refuses with the run URL; `supervisor_override=true` needs a reason and is logged; pending never waits.

• *Repeat refusals* — Was: the same close gate could refuse the same patch loop again and again. → Now: repeatable refusals end with a premise-note stop; the merge-required handoff omits it.

• *Failure policy* — Was: retries and close reasons were free-form. → Now: retry by failure mode with a two-retry cap, four required brief fields, PASS/ISSUES close reasons, patch-id re-verify.

*Learning and skills*

• *Session-learn cadence* — Was: every Stop reread the whole transcript. → Now: `memory.session_learn_min_turns` (10) and `memory.session_learn_min_minutes` (120) gate runs; a path+mtime index mines only the delta.

• *Enforcement ladder* — Was: every lesson ended as a prose rule. → Now: reviewers tag `enforceable:<lint|hook|gate|type>`; promoting one with two or more sources files a single encode chore.

• *Text pins* — Was: rewording a skill sentence could fail a release gate. → Now: tests assert call shapes, files and links; literal substring probes 1,026 → 809.

• *Vocabulary lint* — Was: stock AI phrasing could ship in builtin text. → Now: a word-list lint covers every builtin, with a reasoned allowlist.

• *cas-why* — Was: no workflow for "why was it built this way". → Now: blame, history provenance, tasks and memories feed tiered claims and a coverage map that keeps null results.

• *Cleanup* — Was: `search` `doc_type` help omitted `spec`/`artifact`; hub-web and slack-bridge carried dead scripts and exports. → Now: both fixed; hub dist is byte-identical.

Validation: the full nextest suite plus doctests at the assembled head. Published `cas-x86_64-unknown-linux-gnu.tar.gz` SHA-256: `72a59378cf2039d2992fa334bae9c4980ac77201d519000fe2ad94360b395d84`. Published `cas-aarch64-apple-darwin.tar.gz` SHA-256: `407149b6ce474df5d1ed6e03dfe99ba55d9c27285f286870c5958d06fcaba071`.
```
