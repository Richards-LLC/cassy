## Dev thread

**Top-level:**

```text
*Live on production — Dev — Cassy v3.42.0*
Was: tests could pass without asserting. → Now: they fail on real breakage, and found a loop-ID collision.
```

**Only reply:**

```text
• *Loop ID collisions* — Was: `SqliteLoopStore::generate_id` kept the last 4 hex digits of the millisecond clock, so two `loop_start` calls in one millisecond, or IDs a multiple of ~65.5 s apart, hit `UNIQUE constraint failed: loops.id`. → Now: `loop-` plus 64 random bits, checked against stored rows with bounded retries; existing IDs unchanged.

• *Revoked-pairing footer* — Was: `machineFooterMarkup` chose "Reconnecting" from `everConnected` alone and ignored auth loss. → Now: the footer uses the shared `machineConnectionLabel`; auth-lost rows are excluded from reconnect aggregation.

• *False-green tests removed* — Was: six semantic-search tests returned before asserting; the cloud-sync CLI e2e was unwired and accepted auth/config failure; PTY smoke tests matched the echoed command; 41 tests for removed CLI commands sat ignored. → Now: current-seam replacements with independent assertions, request counts and durable read-back.

• *Env-guard ownership* — Was: 1,066 recorded unguarded env/cwd mutation sites and a private mutex in `mcp_tools_test`. → Now: one canonical `TestEnvGuard` held for each test's lifetime; the baseline is 143 sites and `check-test-env` flags raw mutation under a held guard.

• *CI and journeys* — Was: a stdin-race flake in the scoped-proof inventory, a 121 s network journey built on fixed waits, and a text-matching CI policy script. → Now: a draining checker stub, a protocol-clock journey at 60 s, and parsed CI policy with PyYAML installed into an isolated venv only when missing.

Validation: the full nextest suite (10,584 tests) and archive mode (10,556 tests) on the assembled head, the CI script tier, and hub-web Vitest (841) plus 23 journey tests. Published `cas-x86_64-unknown-linux-gnu.tar.gz` SHA-256: `421bea2cf90c5b508b13581f1663fe179b83b14f3df2e2b353dc49c715d0044c`. Published `cas-aarch64-apple-darwin.tar.gz` SHA-256: `22a5f36973f3d546be0f1b0526f69c4cf164147db4f41cea7fd2c09854f344a1`.

• *Publication timing* — Tag to published: 928s; over budget (600s); WITHIN_BUDGET=false.
```
