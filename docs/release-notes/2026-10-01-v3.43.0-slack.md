```text
• *Text fits the pane* — Was: text could run past the right edge and disappear after the layout changed. → Now: it wraps to the width you can actually see, including when a web viewer connects.

• *The diff panel closes* — Was: clicking ✕ on Claude Code's diff panel did nothing. → Now: one click closes it, and it still works after reopening the panel with `/diff`.

• *Slack posts go through Violet* — Was: posts could use a personal Slack connection instead of the shared hub. → Now: Violet is the required default, with a warning when a Codex Slack app is detected. To explicitly allow another route, use `cas config set slack.transport any`.

• *Large task groups finish closing* — Was: closing a large group could time out and repeat the same checks on every retry. → Now: each retry continues from the completed checks.

• *Checks follow the right work* — Was: closing a task could demand approval for unrelated changes or work added later. → Now: checks follow that task's own changes.

• *Completed checks count* — Was: a task already merged into its group could still demand another build check. → Now: the group's completed build checks count when the task closes.

• *Archiving gives the right answer* — Was: archiving a memory could save it and still say "entry not found". → Now: archiving reports success, and you can inspect, restore or change the storage tier of an archived memory by its ID.

• *Useful activity* — Was: isolated test runs could fill the activity feed with blocked pushes. → Now: those test events stay out of the live feed.

• *Explained merge exceptions work* — Was: merging with an authorized exception for a failed check could still fail with "unsupported". → Now: the merge accepts the exception, checks its authority and explanation, and records it.
```

**Top-level:**


**Only reply:**

```text
• *Pane width follows the layout* — Was: a stale pane-size snapshot could restore a PTY wider than the visible pane. → Now: PTY sizing uses the live layout allocation, including resize, layout toggles and web attachment.

• *Diff-sidebar mouse input* — Was: mouse clicks never reached Claude Code's fullscreen diff sidebar. → Now: clicks reach the focused pane when it requests SGR mouse input, so ✕ closes the sidebar.

• *Violet migration* — Was: `mecha-cassy` proxy entries, integration aliases and installed redirect skills survived alongside Violet. → Now: only `violet` is registered, `cas update` migrates production-URL entries in Claude/Codex profiles and project/user proxy files, and sync removes managed retired skills. Credential env references, legacy env fallbacks and custom upstreams are preserved.

• *Violet Slack policy* — Was: connector and Slack-app writes could bypass the shared hub. → Now: `slack.transport` defaults to `violet`, pre-tool hooks deny other Slack writes, and guidance routes reads/posts through `violet.violet_read` / `violet.violet_post`. Native Codex MCP calls without hook support receive guidance and a doctor warning based on local cached app evidence. `cas config set slack.transport any` explicitly disables the write guard.

• *Resumable group close* — Was: the close budget could expire before every child was checked, restarting that work on retry. → Now: stable verdicts are cached against their delivery and target state, and retries continue from remaining checks.

• *Delivery attribution* — Was: close gates could include unrelated snapshots, next-task commits and target changes merged into the delivery branch. → Now: snapshot, proof and QA checks use the delivered task's changes, excluding those foreign changes.

• *Merged build proof* — Was: closing a merged child could require another scoped build proof despite a completed assembly proof. → Now: the close accepts the parent group's assembly receipt.

• *Archived memory lookup* — Was: an active-only reread after saving archived state returned "entry not found". → Now: archive/unarchive operations and ID-targeted handlers resolve the correct stored state, including archived inspection and tier changes.

• *Activity isolation* — Was: push refusals emitted by isolated test runs appeared as live activity. → Now: foreign test push-block events are filtered from the activity feed.

• *Failed-CI override parameters* — Was: `worktree_merge` documented `supervisor_override` and `reason` but rejected them before dispatch. → Now: both reach the existing authority and reason checks, and a successful override leaves its decision receipt.

Validation: the assembled source passed 10,625/10,625 tests. Published `cas-x86_64-unknown-linux-gnu.tar.gz` SHA-256: `b13334a430bff39cc59177719488ae5b288b51f0e566e5446f391424a9677739`.
```
