**Only reply:**

```text
• *Updates finish with linked account configs* — Was: if a Claude or Codex account's config file was a link to a shared file, `cas update` refused it and skipped the skills refresh in every project. → Now: it updates the shared file through the link, keeps the link and its permissions, and finishes in every project. Earlier sessions appear in a labelled, collapsed section, and a session with no messages yet says so and shows what it last did.

• *Sessions are easier to tell apart* — Was: several live sessions of one project looked alike. → Now: they are grouped under the project, with the most recent one marked and each row's last activity shown. You can end a session from Commander after confirming.
```

## Dev thread

**Top-level:**

```text
*Live on production — Dev — Cassy v3.43.1*
Was: one symlinked profile config aborted the whole skills phase. → Now: profile migration resolves links safely and failures stay per file.
```

**Only reply:**

```text
• *Symlinked profile migration* — Was: the Violet retirement read profile configs through the symlink-refusing reader, and its error propagated through `retire_installed_hub` into the update and sync skills phase, failing all projects plus the user-level store. → Now: profile config and skills paths are canonicalized and must resolve inside HOME or an explicit `CLAUDE_CONFIG_DIR`/`CODEX_HOME`. Shared targets are deduplicated and edited once through an atomic temp-and-rename that keeps the link. Dangling, cyclic, out-of-root, unparsable or directory paths become per-file warnings.

• *Config permissions kept* — Was: the atomic writer created replacement files with default permissions. → Now: it copies an existing file's mode, so a 0600 credential config stays 0600.

• *Session-scoped Commander history* — Was: conversation history was project-wide, so every session of a project returned the same rows. → Now: history binds to the requesting factory session. Earlier sessions arrive as separate read-only sections, and the catalog carries last-activity, most-recent and end-session data per live session.

Validation: the hotfix branch passed 8,193/8,193 tests in the `cas` package before integration. Published `cas-x86_64-unknown-linux-gnu.tar.gz` SHA-256: `{{LINUX_SHA256}}`. Published `cas-aarch64-apple-darwin.tar.gz` SHA-256: `{{MACOS_SHA256}}`.
```
