## Dev thread

**Top-level:**

```text
*Live on production — Dev — Cassy v3.44.0*
Was: Commander's connection, send and history state lived in memory and raced on reconnect. → Now: it is persisted, bounded and generation-checked.
```

**Only reply:**

```text
• *Connection state machine* — Was: a stale opening could open a second machine socket whose handshake timeout downgraded the page, and blockAuthentication left the heartbeat running so a refused pairing flipped back to live. → Now: machine sockets carry a generation, a superseded socket only closes itself, and an auth block stops the heartbeat until re-pairing.

• *Persistent conversation store* — Was: drafts, pending sends and turn times were memory-only. → Now: a per-conversation ConversationStore persists them with write and read bounds, purges a machine's entries on revoke or removal, and never auto-sends an over-bound or malformed entry.

• *History anchoring* — Was: a reconnect re-offered "Load earlier" and the browser silently reset scroll, and late file-card growth left a following thread short of the tail. → Now: the history cursor survives reconnects, the reader's turn is restored, and the thread re-pins on content-height changes while following.

• *Delivery proof binds to the parked anchor* — Was: close and verification measured a worker's live HEAD, so a worker moving to another task invalidated its parked delivery's proof. → Now: a delivery reachable from its parked or origin factory ref keeps its proof; rewritten heads are still refused. Delivery also retries a declined wake after the turn instead of marking the message read (#1082, #1080, #1084).

• *Release and journey tooling* — Was: fast gate rows crashed after a force-push, and several journeys ran on wall-clock budgets that timed out under host load. → Now: rows fall back to merge-base (#1075), J3/J5/J8/J9 wait on hub-double and DOM events with budgets sized from measured runtime, and every HUB-J12 test leaves receipts.

Validation: the assembled branch passed 8,218/8,218 tests in the `cas` package and 968/968 Commander unit tests, every touched journey passed at one worker, and the shipped bundle passed a full journey evaluation. Published `cas-x86_64-unknown-linux-gnu.tar.gz` SHA-256: `46a5e2875f86beee08b2d23061aee65805c6ed62ca4672211891948a2a137fbb`. Published `cas-aarch64-apple-darwin.tar.gz` SHA-256: `e32a04571adf6eec5a1c2e2b5c4d95b32d8c5b306a9cfb27f288bc2a9369d736`.
```
