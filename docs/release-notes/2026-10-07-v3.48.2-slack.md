## Dev thread

**Top-level:**

```text
*Live on production — Dev — Cassy v3.48.2*
Was: `IS_DEMO` left Claude workspaces untrusted, so worker hooks never ran. → Now: trust is set at spawn; a SessionStart canary refuses hookless workers.
```

**Reply (Was → Now):**

```text
*Claude worker hooks enforced, wake bodies, Commander credential retry*

*Safety*

• *Workspace trust at spawn* — Was: the PTY launch's `IS_DEMO=true` skipped Claude Code's trust dialog without trusting the cwd, so no SessionStart or PreToolUse hook ran and Claude workers had no capped cargo runner, worker-memory admission, or Slack, publication and browser guards. → Now: the Claude backend's `prepare_workdir` merges only `projects[<cwd>].hasTrustDialogAccepted` into `.claude.json` before spawn, or refuses the launch.

• *Locked, atomic trust write* — Was: Cassy wrote no Claude trust at all. → Now: the merge runs under `.claude.json.cas-lock` via temp file, fsync and rename, is read back and retried once, and an empty or unparseable config refuses the launch untouched.

• *SessionStart hook canary* — Was: nothing proved a Claude worker's hooks fired. → Now: SessionStart writes `.cas/factory/hook-canary/<agent>.json`, and spawn, respawn and recycle verification kill and report a Claude worker with no fresh marker 60 s after launch.

• *Respawn after upgrading* — Was: running Claude workers were started unguarded. → Now: respawn them on 3.48.2; raw `cargo`, `&` jobs under worker-memory admission, non-Violet Slack writes, publication and unfiltered browser runs start being denied.

*Messaging and Commander*

• *Pointer wake carries its body* — Was: a Claude teams handoff's `transport_claimed` receipt hid the row from the turn-start hook and `inbox_poll` while Claude Code held its copy, so the wake read "see inbox" over an empty inbox. → Now: UserPromptSubmit surfaces the row named by `CAS wake: message N` over its claim as `hook_surfaced`.

• *Rendered vs claimed* — Was: `message_status` could not tell a body rendered into a turn from one only claimed by the transport. → Now: it reports `recipient_receipt`, and ordinary turns and polls still skip claimed rows.

• *Hook-free read* — Was: without the turn-start hook, a claimed message could not be read until the next turn. → Now: `inbox_poll notification_id=N` returns it to its recipient, and the wake text names that call.

• *Stale-credential retry* — Was: two requests signed with a credential a peer tab had rotated were both refused `unknown_credential`, and only the adopter retried, so the other read "pairing was revoked". → Now: `authorizedFetch` retries whenever the machine's `credentialId` differs from the one it signed with.

• *Phone header codename* — Was: `fitMachineLine` kept 8 ch of codename beside the machine, drawing a cut "patient…", and sub-pixel overflow ellipsised. → Now: the phone header passes `wholeCodename`, so the codename is whole or aside, with 2 px slack on every fit test.

*Gates and tests*

• *Journey reason at the delivered head* — Was: `qa_pass::catalog_journeys_for` ran the store checkout's `journeys-for-diff.py`, so the close gate and QA dispatch could name a different set than journey-eval. → Now: it runs the selector and catalog committed at the delivered head.

• *Hub fixture waits for exit* — Was: fixture cleanup sent SIGTERM, waited a fixed 0.5 s and escalated only while the hub held its lock, so a slow shutdown failed the reap test. → Now: it waits up to 15 s, then SIGKILLs the group.

• *Worker-memory spawn deadline* — Was: the concurrent-admission tests gave counted commands 2 s to start and missed by 7 ms on a loaded host. → Now: `CAS_TEST_SPAWN_DEADLINE_SECS` bounds start-up at 20 s, and serial admission still fails.

• *Worker-memory refuses `&`* — Was: a backgrounded suite lost its receipt launcher when the shell returned, while its Playwright runner lived on unreported. → Now: `--shell-command` refuses a bare `&` before admission; `&&`, `>&`, `&>` and `|&` pass.

Published archives: `cas-x86_64-unknown-linux-gnu.tar.gz` (SHA-256 `{{LINUX_SHA256}}`) and `cas-aarch64-apple-darwin.tar.gz` (SHA-256 `{{MACOS_SHA256}}`), both built by CI regardless of the tagger's host.
```
