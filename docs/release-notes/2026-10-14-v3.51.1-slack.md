## Dev thread

**Top-level:**

```text
*Live on production — Dev — Cassy v3.51.1*
Was: the operator-only gate treated any CAS_FACTORY_/CLAUDE_CODE_/CAS_AGENT_ name as an agent marker. → Now: exact identity markers only.
```

**Reply (Was → Now):**

```text
*Operator launch, merged-epic close, Jev removal (PR #1191)*

• *Operator-only gate* — Was: `AGENT_ENV_PREFIXES` matched `CAS_FACTORY_`, `CLAUDE_CODE_` and `CAS_AGENT_`. `cas` exports `CAS_FACTORY_NICE_WORKER` itself when `factory.nice_cargo` is on (the default), so `cas factory` and `cas claude <account>` refused their own launch. A shell exporting `CLAUDE_CODE_NATIVE_CURSOR` was refused too. → Now: the prefix list is gone and only exact markers count: `CAS_AGENT_NAME`, `CAS_AGENT_ROLE`, `CAS_AGENT_ID`, `CAS_SESSION_ID`, `CAS_CLONE_PATH`, `CAS_SUPERVISOR_NAME`, `CAS_FACTORY_MODE`, `CAS_FACTORY_SESSION`, `CAS_FACTORY_WORKER_NAMES`, `CLAUDECODE`, `CLAUDE_CODE_ENTRYPOINT` and the Codex sandbox markers. The harness-ancestor and worker-cgroup checks are unchanged. The refusal text names the remedy.

• *Merged-epic journey receipt* — Was: the epic close gate required a full-suite journey receipt at the epic's own tip, inside its own artifact directory. That can't be produced honestly once the epic is in main, and branchless epics failed as "journey tip unreadable". → Now: an epic contained in `origin/main` accepts a full receipt whose head is a trunk commit containing the epic tip (or a branchless epic's children's trunk deliveries), cited from any task artifact directory under the project root. Unmerged epics keep the exact-tip rule. The decision note records the containment proof.

• *Jev removed* — Was: `cas jev`, the `jev` MCP tool, a PreToolUse shadow observer, the `cas-jev` builtin skill and the `jev.*` config keys. → Now: all removed. A `[jev]` config section loads with a one-line note, and `cas update` prunes installed `cas-jev` skill copies.

• *Docs* — the agent-to-agent communication review is in `docs/reports/2026-10-14-agent-communication-review/`.

Published archives: `cas-x86_64-unknown-linux-gnu.tar.gz` (SHA-256 `10c73bbfcc176baf9cc67a2e21437d67711951cc2bc53009ccadd40fdddc6afd`) and `cas-aarch64-apple-darwin.tar.gz` (SHA-256 `af22248d3a0fd8c0fc77853d59b989e1209de5af2dcfaeb31b04d25838ae5f62`), both built by CI regardless of the tagger's host.

• *Release effort* — 1 manual interventions were needed to publish this release.

• *Publication timing* — Tag to published: 169s; within budget (600s); WITHIN_BUDGET=true. INTERVENTIONS=1.
```
