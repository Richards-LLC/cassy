## User thread

**Top-level:**

```text
*Live on production — User — Cassy v3.52.0*
Was: a finished change took hours to reach a release. → Now: proven work is reused, so releases go out much faster.
```

**Reply (Was → Now):**

```text
*Faster, steadier releases*

• *Proof is reused* — Was: every release re-ran the full set of checks several times on work that had already passed. → Now: the release reuses the checks it already passed, so the final step skips the repeats.

• *Checks no longer block each other* — Was: a browser check could wait ten minutes and fail while a background build check was running. → Now: both run side by side when there is room.

• *Parallel work merges cleanly* — Was: two pieces of work that both added release notes, or both changed the web app, collided when merged. → Now: they combine automatically.

• *Fewer wasted retries* — Was: small mistakes were found only after a long remote check, and old checks kept running after a newer change. → Now: they are caught before sending, and outdated checks stop on their own.

• *Clearer messages* — Was: some finished work was wrongly called already merged, and a missing proof note asked for a full re-run. → Now: each is judged on its own and the message says exactly what is missing.

• *Phone conversations* — Was: scrolling up through a long thread on a phone could pull you back to the bottom as new messages arrived. → Now: you stay where you are, and "Jump to latest" appears when you want it.

Install: `cas update` for an existing installation, or download the v3.52.0 archive for Linux x86_64 (SHA-256 `{{LINUX_SHA256}}`) or macOS ARM64 (SHA-256 `{{MACOS_SHA256}}`) from the GitHub release.
```

## Dev thread

**Top-level:**

```text
*Live on production — Dev — Cassy v3.52.0*
Was: the merge queue re-ran checks the release gate had just proved. → Now: tree-bound statuses let it skip them.
```

**Reply (Was → Now):**

```text
*Release latency (PR #1193)*

• *Merge-queue reuse* — Was: Fast Validation re-ran nextest, doctests, preflight and the Commander journeys on the release commit the full gate had just proved. → Now: `--pipeline` posts `cas/full-gate`, and `cas/full-journeys` when `journey-receipt.py verify-full` passes, naming the proven tree. A queue entry with exactly that tree skips those steps. Compile checks and `macOS Check` still run, and any other tree runs everything.

• *QA beside an assembly proof* — Was: a bounded Playwright, visual-QA or Vitest run waited 600 s for proof memory admission and expired. → Now: one bounded run is admitted when the proof's reserve and fresh memory keep its estimate plus headroom. The sweep waits `[factory].merge_sweep_quiet_secs` (default 300 s) after the last merge, so one proof covers a burst.

• *Merge drivers* — Was: parallel `## [Unreleased]` sections and `hub-web/dist` conflicted. → Now: `cas-changelog` unions Unreleased sections (released sections still conflict) and `cas-generated` keeps the target bundle, then `regenerate-generated-artifacts.sh` rebuilds it. Both are installed by Cassy's merges and are available via `scripts/cas-merge-drivers.py install`. A QA verdict carries over a rebase whose source patch, excluding dist, is byte-identical.

• *Fewer CI rounds* — Was: a park accepted a tip with no fast-rows receipt, and superseded `factory/*` pushes kept running CI. → Now: park requires a `release-gate.sh --fast-rows` PASS for the exact commit, and a newer push cancels the run it supersedes.

• *Close and merge correctness* — Was: a resumed per-task merge request was judged by the worker's default branch, and a missing `qa-bundle:` citation was reported as "missing journey receipt". → Now: it is judged by `factory/<worker>-<task>`, and the close message names the bundle to cite (GH #1179).

• *Hub* — Was: a phone reader scrolling off the tail could be re-pinned while a pin was pending or after unseen growth. → Now: that scroll counts as reading, and "Jump to latest" shows.

Published archives: `cas-x86_64-unknown-linux-gnu.tar.gz` (SHA-256 `{{LINUX_SHA256}}`) and `cas-aarch64-apple-darwin.tar.gz` (SHA-256 `{{MACOS_SHA256}}`), both built by CI regardless of the tagger's host.
```
