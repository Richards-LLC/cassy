## User thread

**Top-level:**

```text
*Live on production — User — Cassy v3.56.0*
Was: the factory screen could freeze and messages to workers could get stuck. → Now: typing stays responsive and messages arrive.
```

**Reply (Was → Now):**

```text
• *No freezes while waiting* — Was: the factory screen could stall while checking on outside events. → Now: those checks run in the background.

• *Messages arrive* — Was: a message to a worker could sit undelivered while later ones got through. → Now: each message is delivered and marked read only when the worker actually received it.

• *Fewer false alarms* — Was: you could be told you had abandoned a conversation, or that a busy worker had stalled. → Now: those warnings appear only when they are true.

• *Your phone sees the conversation* — Was: some replies never reached Commander. → Now: replies are mirrored, and the phone shows each question together with its answer. The mirror can be turned off and back on.

• *Starting workers* — Was: new workers could be stopped during startup, or fail midway after an update. → Now: they finish starting, and a version mismatch is caught up front with the fix named.

• *Stopping and resetting workers* — Was: stop and reset requests could be ignored silently. → Now: they take effect, or say why not.

Install: `cas update` for an existing installation, or download the v3.56.0 archive for Linux x86_64 (SHA-256 `{{LINUX_SHA256}}`) or macOS ARM64 (SHA-256 `{{MACOS_SHA256}}`) from the GitHub release.
```

## Dev thread

**Top-level:**

```text
*Live on production — Dev — Cassy v3.56.0*
Was: external reminder probes and gated Teams inboxes blocked the daemon loop and message delivery. → Now: probes run off-loop and Teams members own their inboxes.
```

**Reply (Was → Now):**

```text
• *Daemon loop* — Was: `branch_contained_in`, `tag_exists` and `ci_completed` probes ran `git fetch`/`gh` on the loop (#1208). → Now: off-loop, one fetch per ref per pass, with backoff and expiry.

• *Teams inbox* — Was: a Claude Agent Teams member's mail stayed gated (#1209). → Now: the `<name>@<session>` member owns its inbox, and confirmation needs a transport receipt.

• *Spawn* — Was: boot verification killed Claude workers waiting on the CAS server, and build drift failed at provision (#1173, #1174). → Now: the boot window is honoured, and a known daemon/provisioner mismatch is refused before queueing. `spawn_brief` delivers the brief before task start.

• *Close and merge gates* — Was: waivers bound to the default worker branch, receipts were misattributed and merge requests were falsely suppressed (#1175, #1177, #1179, #1180, #1181, #1199, #1200, #1202). → Now: everything binds to the task's delivery branch and the receipt's own first-parent diff. A park sends one relay.

• *Lifecycle* — Was: `shutdown_workers` and `clear_context` silently failed under a spent store budget (#1185, #1190, #1195). → Now: they take effect or record a failed outcome.

• *Coordination* — Was: `remind` refused one requirement at a time, `verification add` rejected `issues` arrays and broadcasts couldn't be superseded (#1207, #1197). → Now: one refusal lists everything, arrays work, and broadcasts take `supersede_key` and `sticky`. The schema is held to its 3,600 B cap.
```
