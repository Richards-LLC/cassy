**Reply (Was → Now):**

```text
• *Sessions start on their own* — Was: a new `cas claude` session opened and waited until you typed. → Now: it starts its first turn by itself.

• *Reminders arrive on time* — Was: a reminder could sit unseen until something else woke the session. → Now: it wakes the session when it fires.

• *Commander sends after a hiccup* — Was: a brief problem on the machine made Commander refuse every message and blame browser storage. → Now: messages send again once the machine answers, and errors name the real cause.

• *Commander inbox keeps updating* — Was: the inbox could silently stop showing new messages. → Now: new messages keep arriving.

• *Ask to reply* — Was: a read-only Commander browser couldn't ask to reply. → Now: it asks, you tap Allow, and the same browser replies without signing in again.

• *Slack threads, once each* — Was: after a restart, a Slack message could be missed or answered twice. → Now: in Cloud-managed channels each message arrives once, with its text, even across restarts.

• *Finished work closes itself* — Was: merged work waited for one more manual close. → Now: Cassy closes it once the merge is green and the review approves.

• *Holds stick* — Was: a task you put on hold reopened when the work it waited on finished. → Now: it stays held until you release it.

• *Updates refresh old instructions* — Was: some projects kept running outdated Cassy instructions after `cas update`. → Now: old Cassy-written copies are replaced and only your own edits are kept.

• *Disk stays free* — Was: test recordings piled up (784 GB on one machine), and cleanup called finished work unfinished. → Now: recordings go a day after their task closes, and cleanup checks the latest code first.

• *Codex starts cleanly* — Was: on Codex 0.162, new sessions stuck on a "Hooks need review" screen, and starting one could change your main checkout. → Now: they start normally and leave your checkout alone.

• *Memory you can see* — Was: nothing showed how much memory each session's background server used. → Now: the cleanup report shows it per session, with a total.

• *Release reports* — Was: report links were dead text and timing was typed by hand. → Now: links work and timing comes from the measurement.

Install: `cas update`, or download v3.62.0 for Linux x86_64 (SHA-256 `{{LINUX_SHA256}}`) or macOS ARM64 (SHA-256 `{{MACOS_SHA256}}`) from <https://github.com/Richards-LLC/cassy/releases/tag/v3.62.0|the release>.
```
