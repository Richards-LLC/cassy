## Dev thread

Top-level:

```text
*Live on production — Dev — Cassy v3.78.0*
Was: Channel links, task closes and write outcomes were hard to audit. → Now: Cassy makes each state inspectable and keeps retries safe.
```

Reply (Was → Now):

```text
*Channels and patterns*

• *Multi-channel inspection* — Was: Projects declared one Slack channel, and existing links were difficult to inspect.
→ Now: `cas violet channels` lists configured, Violet and Cloud links; `slack.channels` feeds multi-channel `cas update` checks.

• *Pattern response handling* — Was: Pattern reads assumed wrapped Cloud rows, and any transport error after create could imply an uncertain write.
→ Now: Reads validate bare or wrapped rows; create/adopt writes are uncertain only after request-body transmission and retain the error plus reconciliation ID.

*Task lifecycle*

• *Merged task closes* — Was: Squash-merged work could be refused, and already-live changes could trigger a redundant QA pass.
→ Now: Close proves tip containment plus target ancestry and skips independent QA for deliveries already on the target.

• *Origin-based merge advice* — Was: A merge using an origin-only successor told users to merge on their stale local branch, then push a rejected result.
→ Now: Cassy says to fast-forward first; a divergent local successor keeps its own advice.

• *Supervisor identity after `/clear`* — Was: A Claude supervisor's cached identity could register a second row after `/clear`.
→ Now: Session end preserves the live row, and session start rebinds it by process and name.

*Operations and recovery*

• *Wake measurements* — Was: Transcript turns wrapped in pasted-content or `Message from` text were missed by wake accounting.
→ Now: Both body shapes are trimmed before turn matching, so token and latency reports include them.

• *macOS socket cleanup* — Was: A refused connection could be mistaken for proof that a stream or datagram socket had no holder.
→ Now: A complete native holder inventory and ownership/inode fences gate removal; unknown results preserve the path.

• *Review checkout durability* — Was: A failed directory sync left a fresh checkout that a retry reused without syncing.
→ Now: New task and scratch parents sync before Git, and a failed sync removes only that fresh checkout.

• *Repository runner registration* — Was: Repository tokens were labelled as organization tokens and got an organization-only runner group.
→ Now: Diagnostics distinguish token types and repository registration omits that group.

*Terminal and release tooling*

• *Consistent CLI wrapping* — Was: Initialization, activity, doctor and release reports handled overlong words differently.
→ Now: A shared wrapper applies an explicit policy, with long initialization paths kept on their own row.

• *Factory viewer resizing* — Was: Full-width non-owner resizes paused drawing, and compact viewers could miss a frame.
→ Now: Shared layout resize runs only when compact membership or owner dimensions change.

• *User announcement lint* — Was: Forbidden user wording was checked only in the User top-level post.
→ Now: Validation checks both User bodies and leaves technical wording allowed in Dev.
```
