Reply (Was → Now):

```text
*Violet diagnostics (GH #1267)*

• *Daemon consumer receipt* — Was: Neither `cas factory status` nor `cas doctor` reported the running daemon's consumer id or capabilities.
→ Now: Each daemon writes a locked per-session receipt (PID, start time, build, capabilities, wake_enabled at start); a mismatch reads unknown, and a failed write is named only when its failure record matches.

• *Configured-channel doctor row* — Was: Doctor did not check `slack.channels`.
→ Now: Up to 16 configured channels are checked with GETs under a shared 3 s budget that also bounds DNS; an overrun reports unchecked, and the snapshot save is skipped if the deadline has passed when it is reached.

• *Offline session-start evidence* — Was: Session start said nothing about configured channels.
→ Now: It reads `.cas/violet-channel-check.json` with no channel network call and warns on unchecked, flagged or 24-hour-stale channels.

*Task close and tooling*

• *Epic close verification* — Was: Epic close proof could bind to the supervisor checkout's HEAD, so unrelated local work could break verification.
→ Now: Proof binds to the published origin epic branch (local when unpublished or local_merge); commit_receipt accepts a default-branch merge containing the epic tip.

• *terminal-qa backspace and CR runs* — Was: Backspace deleted the last cell, and a CR run ending at LF counted as a redraw.
→ Now: Backspace moves the cursor left without deleting, and that CR run is not counted.
```
