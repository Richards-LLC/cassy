## User thread

Top-level:

```text
*Live on production — User — Cassy v3.84.0*
Was: you remembered which folder was which. → Now: every subscription is listed by email, and the one with room is picked for you.
```

Reply (Was → Now):

```text
*Your accounts in one place*

• *One list* — Was: There was no single view of your subscriptions and their usage.
→ Now: `cas accounts list` shows every Claude and Codex account by email, with its plan, usage, reset times and any problem such as a duplicate or a login that no longer works.

• *Names you recognise* — Was: The pickers showed folder names like `main` and `alt`, and two folders with one login looked unrelated.
→ Now: Rows show the email and folder name, and the original is listed before its copies. Your old names still work.

• *A recommended account* — Was: You had to remember which account still had room.
→ Now: The account that resets soonest with room left is marked "recommended" with its reason, and the cursor starts on it. You can still pick any account, and nothing starts until you press Enter. Commander's New session sheet does the same.

• *Reset times you can plan around* — Was: Usage showed only a percentage or "in 6h".
→ Now: Everywhere usage appears, it reads like "resets Tue 14:00 (in 6h)" in your local time, with the date for later days.

• *Tidy up* — Was: A mistyped or retired account folder could not be removed.
→ Now: `cas accounts remove`, `rename`, `disable` and `enable` manage them. Your main account and accounts in use are protected, and removing asks first.

• *Clean new logins* — Was: A cancelled or failed login left an empty folder that looked like an account.
→ Now: A new login only becomes an account when it succeeds.

• *Work keeps going* — Was: A background session that hit its usage limit stopped until someone moved it by hand.
→ Now: It restarts once on the next recommended account and carries on with its task. If none has room, you are told when one will.

• *Mac usage* — Was: Claude usage on a Mac could show nothing.
→ Now: It reads the login from the Mac Keychain.

*After installing*

• *Restore shared settings* — Was: Account folders recreated after linking lost their shared settings.
→ Now: Run `cas doctor --fix` once after installing to restore them.

• *Removal is final* — Was: There was no way to remove an account.
→ Now: Removing one deletes it after you confirm; there is no backup copy.

• *Backup folder names* — Was: A folder named `~/.claude-backup` or `~/.codex-old` was hidden.
→ Now: It counts as an account. Name a backup like `~/.claude-x.backup` to keep it hidden.

Install: run `cas update`, or choose the Linux x86_64 or macOS ARM64 release download.

Published SHA-256: Linux `{{LINUX_SHA256}}`; macOS `{{MACOS_SHA256}}`.
```

## Dev thread

Top-level:

```text
*Live on production — Dev — Cassy v3.84.0*
Was: each provider scanned its own folders. → Now: one typed account registry drives the list, pickers, Commander, spawns and limit recovery.
```

Reply (Was → Now):

```text
*Account registry*

• *Shared read model* — Was: Claude and Codex pickers scanned `~/.claude-*` and `~/.codex-*` separately.
→ Now: One registry returns provider, folder, email, plan, login state, structured usage windows and flags (`duplicate_of`, `never_logged_in`, `stale_login`, `disabled`) under one 4-second deadline. Identity is a typed object.

• *Name resolution* — Was: An unknown launch name created a new folder.
→ Now: Launch and spawn resolve aliases, emails and symlinked folders through the registry. Unknown names are refused with the login command, and ambiguous emails list their aliases.

• *Selection policy* — Was: There was no shared recommendation.
→ Now: One selection function honours `accounts.selection` and `accounts.threshold` (default 90); idle windows count as unused, reset-unknown ones rank last, and excluded accounts carry reasons. Pickers, Commander and `spawn_workers` without `config_dir` use it.

• *Lifecycle* — Was: Account folders had no lifecycle commands.
→ Now: `cas accounts remove|rename|disable|enable`. In-use checks read live process environments and registered agents, including on older Cassy databases. Logins are staged in a hidden temp folder, symlink aliases follow their physical account, and `accounts.disabled` stores the canonical path.

• *Limit notices* — Worker status identifies the provider correctly. The automatic account rotation originally shipped in 3.84 was subsequently removed: usage-limited workers now wait on their current account and report its absolute local reset date/time once per episode. Picker recommendations and new-spawn selection remain unchanged.

• *Reset display* — Was: Reset text was relative or locale-dependent.
→ Now: One `format_reset` gives local `resets Tue 14:00 (in 6h)` and `(in 1d 23h)`, and `--compact` stays one line with `+N more`. `cas limits --json` `reset_at` is now RFC3339 UTC.

• *macOS Keychain* — Was: Claude usage read only `.credentials.json`.
→ Now: It reads the account's Keychain item first, keyed by the NFC-hashed config selector, and never prints it.

• *Doctor and launch links* — Was: Link drift after `cas accounts link` went unnoticed.
→ Now: `cas doctor` reports account link drift, `--fix` repairs it with a backup, and launches restore the chosen account's shared links.

• *Tooling* — Was: Commander browser tests ran on Playwright 1.63.
→ Now: They run on Playwright 1.64.1.

Validation: Rust suite, Commander unit tests, type check, visual QA and browser journeys pass on the release tree. SHA-256: Linux `{{LINUX_SHA256}}`, macOS `{{MACOS_SHA256}}`.
```
