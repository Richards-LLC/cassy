## User thread

Top-level:

```text
*Live on production — User — Cassy v3.86.0*
Was: following the work meant a terminal. → Now: Commander opens fast, shows the whole picture and rich content, and takes phone pastes.
```

Reply (Was → Now):

```text
*Commander, no terminal needed*

• *Opens fast* — Was: A long conversation drew every message at once and kept redrawing as replies arrived; a busy thread took over 30 seconds to settle on a phone.
→ Now: It opens on the newest messages, loads older ones as you scroll up and keeps your place.

• *The whole picture* — Was: You saw only the coordinator's final replies.
→ Now: Turn on Show work to see its thinking notes, each step it took and task events between the replies. It remembers your choice on each device.

• *Helper timelines* — Was: Seeing what a helper was doing meant opening its terminal.
→ Now: Tap Timeline next to a helper in Tasks & progress for a live view of its task, recent steps and state.

• *Paste anything* — Was: There was no way to paste or attach in Commander.
→ Now: Paste text, screenshots or files, or pick them from your phone. You see a preview before sending, and the coordinator gets the files.

• *Big files on slow phones* — Was: A large photo on a slow connection could not be sent.
→ Now: Uploads get time to finish. If one fails, the message names it and keeps your attachments. iPhone photo and video formats work.

• *Rich content* — Was: Diagrams, code changes and media arrived as raw text or bare links.
→ Now: Diagrams draw in your theme, code changes show line by line, and images, video, audio and PDF previews show inline.

• *Pages inside the chat* — Was: A report page the coordinator made had to be opened elsewhere.
→ Now: It shows inline in a locked-down frame that matches light or dark mode, with an open-in-tab button.

• *Private media* — Was: Pictures and video could not load inside Commander's strict safety rules.
→ Now: They come through your own hub, only to signed-in devices, and video seeking works.

*Steadier and cheaper*

• *Usage limits* — Was: A helper that hit its usage limit could be moved to another of your accounts.
→ Now: It waits on its own account, and one notice gives the account, what it holds and the local reset time.

• *New sessions come up ready* — Was: A session started from Commander's New session could come up blank.
→ Now: It comes up with its coordinator running.

• *No repeated replies* — Was: Some answers replayed every time Commander reconnected.
→ Now: Each answer shows once, and earlier stuck ones clear.

• *Notices clear* — Was: Commander's attention notices were never confirmed, so they piled up behind the scenes.
→ Now: Each notice is confirmed once it is safely saved.

• *Less reading, fewer interruptions* — Was: Coordinators re-read long task histories and were woken for every routine event.
→ Now: Task reads are short by default, routine events arrive as one digest, and less is re-sent on each start.

• *Honest restart advice* — Was: Cassy said restarting a coordinator was safe for its helpers.
→ Now: It says a restart stops every helper and points you to the reconnect that keeps them running.

*Fixes*

• *Codex logins* — Was: With the default Codex folder retired, Cassy could not start Codex helpers by type, though naming the model worked.
→ Now: It uses your saved, signed-in Codex logins and keeps the one you started on.

• *Mac logins* — Was: On a Mac, starting a Claude helper refused a signed-in login with no settings file.
→ Now: Cassy reads the login from Keychain and treats a missing settings file as empty.

• *Messages behind a draft* — Was: Leaving unsent text in the box for about 40 minutes could make a waiting message never arrive.
→ Now: It waits without limit and goes through once the box is clear.

• *Quoted /finish* — Was: A Codex helper treated `/finish` quoted in a task as your request and stopped work.
→ Now: Only a request you make right now wraps up a session.

• *Slack setup* — Was: Slack setup could recreate a folder you had retired, and its health warning could never clear.
→ Now: It uses your real Codex folders, skips a broken one with a warning, and the warning clears.

• *Updates with sessions open* — Was: `cas update` could not finish Slack setup while any session was running.
→ Now: It finishes.

• *Pairing and alerts* — Was: Too many pairing codes gave a vague refusal, and a faded alert left hidden text behind.
→ Now: It says to try again in a minute, and faded alerts clear.

Install: run `cas update`, or choose the Linux x86_64 or macOS ARM64 release download.
```

## Dev thread

Top-level:

```text
*Live on production — Dev — Cassy v3.86.0*
Was: Commander redrew whole threads and showed only final replies. → Now: windowed paging, a zero-token work-event stream, sandboxed rich media and leaner reads.
```

Reply (Was → Now):

```text
*Commander*

• *Windowed threads* — Was: Opening a thread rebuilt every row and re-measured on each scroll frame. The real 354-turn, 327-pending baseline settled in 36.8 s on a 4× throttled phone.
→ Now: Newest page first, cursor paging on scroll with a kept anchor, a measured row window plus margin, and a daemon index of open decisions.

• *Work events* — Was: Commander received only final replies.
→ Now: The daemon serves typed `work_events` (schema v1, opaque cursors, detail on demand) from Claude transcripts, Codex rollouts, hook events and task rows, needing `pane:read`.

• *Show work and timelines* — Was: Supervisor work and worker state were visible only in terminals.
→ Now: A per-device Show work switch renders thinking, tool rows and task chips. Tasks & progress opens a live per-worker timeline. Covered by HUB-J25.

• *Composer uploads* — Was: hub-web had no paste or attach handler.
→ Now: Pastes and files preview before send, DPoP-authenticated idempotent host storage with MIME sniffing, and payload-sized deadlines. HEIC, AVIF and QuickTime are recognized.

• *Rich evidence* — Was: Mermaid, diffs and media rendered as text or links.
→ Now: Lazy Mermaid with sanitized SVG, unified diffs with line numbers and collapse, reserved-space media and PDF first-page previews, plus full license notices in the lazy bundle.

• *Visual replies* — Was: A supervisor HTML page could not render in Commander.
→ Now: A ticketed route serves it to a sandboxed iframe under strict CSP, with no same-origin, top navigation or outside network. The frame follows the theme.

• *Media proxy and chunks* — Was: Attachments resolved to signed blob URLs outside `img-src 'self'`, and `inlineDynamicImports` blocked lazy chunks.
→ Now: A session-scoped proxy streams bytes with Range, SVG sandbox CSP and about 1 s auth rechecks. Hashed chunks are served from an allowlist.

• *Reply and notice queues* — Was: `operator_label: null` replies were rejected and replayed, notices were never ACKed, and device-addressed rows bounced about 10 times a second.
→ Now: Labels normalize, writes batch, `OperatorNoticePersisted` ACKs after fenced storage, and only a row-closing receipt clears backoff.

*Agent context and noise*

• *Bounded task reads* — Was: `task show` and notes returned every note body, 6.49% of recorded input.
→ Now: Default reads stay within about 2,000 UTF-8 bytes, with full and byte-page reads. Brief starts are the factory default and reuse unchanged start context.

• *Ambient recall* — Was: Packets carried code-symbol cards that matched later work 8.6% of the time, 3.6% of input.
→ Now: Exact task and epic evidence first, IDs with bodies on demand, about 800 characters per packet, and no Code cards for supervisors unless requested.

• *Relays and receipts* — Was: Relays copied QA link lists and proof prose, and SessionStart re-sent unchanged base context.
→ Now: One evidence-manifest reference, compact success receipts with full failures, and fingerprinted SessionStart context.

• *Supervisor wakes* — Was: Routine lifecycle events each woke the supervisor, and receipts could raise delivery-stalled alarms.
→ Now: Routine events fold into digests, one actionable merge wake per delivery is kept, and receipts and terminal recipients raise no stall.

• *Codex resident core* — Was: The Codex startup prompt and checklist still pointed at the full supervisor skill.
→ Now: Startup runs `cas-codex-supervisor-checklist` once and triages from the resident core.

*Accounts and spawns*

• *Usage limits* — Was: A usage-limited worker could be rotated to another account.
→ Now: Rotation is removed. Report-only episodes give the absolute reset time, notice dedupe survives restarts, and queued legacy switches are refused.

• *Lane routing* — Was: The capability probe checked only the default Codex folder, so `lane=standard` found no active recipe candidates.
→ Now: Routing admits usable registered Codex accounts, keeps the requester's `CODEX_HOME` and leaves unscoped choice to the recommender.

• *macOS preflight* — Was: The `config_dir` preflight required both a settings file and a credentials file.
→ Now: Missing settings count as empty, and a macOS Keychain login is checked by metadata only. Invalid or unreadable settings are still refused.

*Fixes*

• *Blank Commander launch* — Was: A deferred startup inbox reservation stayed `TransportClaimed`, so the startup wake never retried.
→ Now: The reservation is released after its durable deferral marker succeeds.

• *Held relay budget* — Was: Each composer-held recheck spent one of 20 re-nudges, so a draft of about 40 minutes stranded the relay.
→ Now: Held rechecks keep the budget.

• *Renamed epic lanes* — Was: The close merge guard checked a retired epic ref while `task show` showed the new target.
→ Now: Delivery mutations and director snapshots share current-lane resolution and never publish a retired ref.

• *Regenerated dist at close* — Was: The close gate called regenerated `hub-web/dist` dropped content and refused reviewed-drop.
→ Now: Regeneration with merged source and script provenance passes, and reviewed-drop is recorded.

• *Finish trigger* — Was: A Codex worker read a quoted `/finish` in task text as an operator request.
→ Now: The finish skill needs a current operator request.

• *Violet integration* — Was: `cas integrate violet` revived the retired default Codex folder, pinned a two-tool allowlist, aborted on one malformed config and overstated its receipt.
→ Now: Discovered homes only, the current hub contract, a named skip and a build-scoped receipt.

• *Update binding* — Was: The session-inventory revision changed every ~2 s under any live factory, so `cas update` never bound Slack.
→ Now: The revision changes only on socket transitions.

• *Browser tier guard* — Was: Bare suffixes, regex-shaped specs and a trailing word widened targeted Playwright runs, while named `.spec.mjs` tests were refused.
→ Now: Every file filter is validated, with basename stems, line selectors and named `.spec.mjs` support.

• *Test isolation* — Was: Codex spawn tests read real account catalogues, and the real-hub fixture wrote invalid config and raced cleanup.
→ Now: Fixture accounts and config, and cleanup waits for launch children.

Validation: the Rust suite and Commander journeys passed on the release tree in the merge queue (run 40646861659).
```
