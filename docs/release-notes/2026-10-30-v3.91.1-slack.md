## User thread

Top-level:

```text
*Live on production — User — Cassy v3.91.1*
Was: a Commander conversation could stop for good when the background service restarted. → Now: it picks back up on its own.
```

Reply (Was → Now):

```text
*Commander*

• *Conversations resume after a restart* — Was: If Cassy's background service was replaced while a conversation was open, the conversation stopped and never came back.
→ Now: Commander reconnects to the new service and continues the same conversation automatically.

• *Clear message when clocks disagree* — Was: Commander silently corrected for any clock difference between your device and the machine, however large.
→ Now: Differences up to 60 seconds are still corrected automatically. A larger difference shows "Device and machine clocks differ by more than 60 seconds" so you can fix the device clock.


*Safety*

• *Protected commands cannot be disguised* — Was: A command reserved for the operator could slip past the safety check when it was wrapped inside certain shell expressions.
→ Now: Every part of a command that would run is checked, so those commands are refused however they are written.
```

## Dev thread

Top-level:

```text
*Live on production — Dev — Cassy v3.91.1*
Was: stream resume died on an early session end, and substitutions could hide operator-only commands. → Now: replacement-daemon resume, tokenizer-checked substitutions and a capped clock correction.
```

Reply (Was → Now):

```text
*Commander*

• *Replacement-daemon resume* — Was: When Commander saw the old daemon's session end before its replacement was live, the stream stopped and was never retried.
→ Now: Commander resumes the requested conversation on the replacement daemon; a session that ends with no replacement still stops retries and sends.

• *Clock correction cap* — Was: After a stale-proof refusal, Commander adopted any offset the hub reported, and the old 10-minute auto-correction applied.
→ Now: Corrections are capped at the hub's 60-second proof window; a larger offset is refused with "Device and machine clocks differ by more than 60 seconds" instead of signing with a skewed time.


*Worker guard*

• *Substitution checks* — Was: An operator-only command inside a double-quoted `$(…)`, an expanding heredoc, or a substitution containing a case pattern or comment parenthesis could pass the pre-tool guard.
→ Now: Every executable substitution goes through the shared shell tokenizer, parameter and arithmetic boundaries are preserved, unfinished heredoc scopes are refused, and single-quoted words and quoted heredocs stay data.

Update with `cas update`, or choose <https://github.com/Richards-LLC/cassy/releases/tag/v3.91.1|the Linux x86_64 or macOS ARM64 downloads>.
Published SHA-256: Linux `{{LINUX_SHA256}}`; macOS `{{MACOS_SHA256}}`.
```
