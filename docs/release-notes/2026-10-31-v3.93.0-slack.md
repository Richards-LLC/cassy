# Slack draft — Cassy v3.93.0 runtime release

Channel: #cas-internal (`C0B44GUKDK2`).

Status: Draft. Checksums are filled after publication.

## User thread

Top-level:

```text
*Live on production — User — Cassy v3.93.0*
Was: dismissed sessions came back, idle supervisors looked offline and Usage hung on Claude. → Now: dismissals stick everywhere, idle reads as idle and Usage opens and closes.
```

Reply (Was → Now):

```text
*Commander*

• *Dismissed sessions stay dismissed* — Was: An ended session you dismissed came back after a live update or a reload, and dismissing it on one device never reached your others.
→ Now: Dismiss and Clear ended are saved on the machine itself, so the session stays hidden through updates, reloads and every browser you have paired. A new session with the same name still shows up once.

• *Idle no longer looks offline* — Was: A supervisor that was running but quiet showed the same gray dot as one that was offline.
→ Now: Working is solid green, idle is a hollow green ring, and only offline is gray. Each dot names its state when you hover or use a screen reader, and high-contrast mode tells them apart by shape. Team's Waiting and Offline labels follow the same colors.

• *Usage works on Claude again* — Was: Sending Usage to an idle Claude supervisor from Commander hung for about 90 seconds, showed no Close button, and blocked the next Usage until the screen was cleared.
→ Now: Usage opens within a second with a working Close, and later commands and messages go through.
```

## Dev thread

Top-level:

```text
*Live on production — Dev — Cassy v3.93.0*
Durable hub-side session dismissals, distinct idle/offline status marks, Claude Usage observation for Claude 2.1.312, and supervisor takeover of a gone worker's parked task.
```

Reply (Was → Now):

```text
*Commander and hub*

• *Durable dismissals* — Was: Dismissals lived only in each browser's localStorage, keyed by session plus end time.
→ Now: The hub writes an atomic marker per dismissed session in its own folder, keyed by a hash of session name and start time. `GET /v1/sessions` returns `dismissed=true`, and dismissing a live or stale generation returns 409.

• *Status marks* — Was: Live-idle and offline supervisors computed the same gray mark.
→ Now: Working, Idle and Offline each have one DESIGN.md rule and matching CSS. Each mark carries `role="img"` with a state label, forced colors distinguish Idle (square) from Offline (round), and Team's Waiting and Offline pills have explicit styles.

• *Claude Usage observation* — Was: The daemon confirmed `/usage` only when the screen said "Current session", which Claude 2.1.312 no longer prints, so receipts went unconfirmed at 90 s and blocked later commands. 3.91.1 failed the same way.
→ Now: Observation matches the Usage view Claude prints today, and an uncertain receipt keeps a Close control so the native view can be dismissed before the next command. A regression test is built from the real captured screen.


*Factory*

• *Takeover of a gone worker's task* — Was: After a worker was gone, a replacement's delivery could not be merged: `rebind_branch` refused because the assignee differed from the recorded start, and `worktree_merge` then refused the unresolved source.
→ Now: `rebind_branch` accepts the current assignee when it is a live registered worker in the supervisor's session, holds no conflicting lease and has its own clean task branch in the same repository. The old owner, branch and anchor stay in the audit. The route is documented in CONTRIBUTING.

Also in this release: a regenerated CODEMAP.

```
