# Slack draft — Cassy v3.94.0 runtime release

Channel: #cas-internal (`C0B44GUKDK2`).

Status: Draft. Checksums are filled after publication.

## User thread

Top-level:

```text
*Live on production — User — Cassy v3.94.0*
Was: noisy memory cards, a token in help text, faster-but-flaky tests. → Now: leaner sessions, safer help, steadier Commander connections.
```

Reply (Was → Now):

```text
*Sessions and Commander*

• *Quieter sessions* — Was: Every prompt and tool step carried automatic memory cards that almost nobody used (5 uses in about 39,500 injections).
→ Now: Those cards are gone. Saved handoffs, memory search and related context on new tasks still work.

• *Steadier connections* — Was: Replacing a machine's connection could leave the old one sending one late request.
→ Now: Stopping or replacing a connection cancels everything it had in flight.

• *Help text keeps secrets secret* — Was: Showing help for login or the bridge server could print a token that was set in your environment.
→ Now: Help names the setting but never shows its value.

• *Correct login instructions* — Was: Some errors told you to run a login command that does not exist.
→ Now: They name the real command, `cas login`.


*Measuring what helps*

• *Friction you can see* — Was: There was no record of manual rescues, release timing or which features were noise.
→ Now: Cassy records checks, rescues, escapes and releases, and each session can rate a feature in one line. `cas ledger report` shows it, and projects share metrics, never code, through Cassy Cloud.
```

## Dev thread

Top-level:

```text
*Live on production — Dev — Cassy v3.94.0*
Was: dead code in the tree and blind merge admission. → Now: about 26,000 lines removed, a friction ledger, honest CI admission.
```

Reply (Was → Now):

```text
*Removed*

• *Ambient recall* — Was: Per-turn recall injection across every harness. → Now: Removed (about 7,700 lines); handoffs, explicit search and task-create context kept.

• *Dead subsystems* — Was: A never-enabled notification pipeline, a recording index nothing wrote, a second factory session manager and dead search modules. → Now: Removed (about 8,400 lines); a forward migration drops the six empty tables, and retired notification keys still load.

• *Release train* — Was: The pre-3.54 release train and its lane checkers. → Now: Removed (about 9,500 lines); release-cut lessons now follow the one-command release, proven by a whole-path release dry run.

• *Expired aliases* — Was: Factory actions still ran through `coordination`, and the `bypass_code_review` close alias still worked. → Now: Both are refused with an error that names the live route.


*Fixed*

• *Merge admission* — Was: A failed change classifier read as red CI, and a code commit with no runs of its own was admitted while the tip's CI was still pending. → Now: Missing code CI reads as unconfirmed, with the run link, and a pending covering run holds the merge.

• *Close gate* — Was: A file renamed inside its own delivery read as dropped content. → Now: Measured against the delivery's net tree; real drops are still refused.

• *Store IDs* — Was: The collision fix lived in one of four id generators. → Now: One shared generator for tasks, skills, specs and code.

• *Release gate* — Was: An aborted row could leave Cargo children running. → Now: Cleanup terminates and reaps the whole tree, with bounded escalation.

• *Secrets in help* — Was: `--help` showed env values for the Cloud and bridge tokens. → Now: Hidden, with a sentinel test.


*Added and changed*

• *Friction ledger, phase 1* — Append-only quality events (check runs, interventions, escapes, releases, feature feedback), batched sync to Cloud's team quality-events endpoint (metrics, titles and links only), and `cas ledger report --release vX`.

• *Test hygiene* — Builtin test guidance names the measured bad-test patterns, and proof claims must name what ran. Style-pinning and copied-logic tests are gone, and slow tests use injected clocks.

• *CI coverage* — 16 previously unrun script and visual-QA suites now run when their inputs change, and visual QA captures pages in parallel.

Update with `cas update`, or choose <https://github.com/Richards-LLC/cassy/releases/tag/v3.94.0|the Linux x86_64 or macOS ARM64 downloads>.
Published SHA-256: Linux `{{LINUX_SHA256}}`; macOS `{{MACOS_SHA256}}`.
```
