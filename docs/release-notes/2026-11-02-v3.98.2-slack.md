## Dev thread

Top-level:

```text
*Live on production — Dev — Cassy v3.98.2*
Was: CI repeated work and shell protection missed indirect signals. → Now: receipt reuse, release caches and composed signal checks cover those paths.
```

Reply (Was → Now):

```text
• *Process signal protection* — Was: some automation roles bypassed the pattern-kill guard, and compound shell commands could separate a process search from its signal.
→ Now: every automation role refuses pkill, killall and dynamic or piped kill operands combined with process searches, including loops, eval and assigned command names. Literal PID and PID-file signals remain available.

• *Main check reuse* — Was: main repeated test compilation despite an identical tree already passing the merge queue.
→ Now: Test Compile Guard reuses that receipt. A matching Darwin cache avoids download and compilation, a miss restores a partial cache, and Clippy always runs on main.

• *Scoped tooling checks* — Was: visual-QA fixtures ran for unrelated changes, and the codemap fixture built a large repository.
→ Now: registered inputs select the fixtures, the measured codemap run fell from 226 seconds to 7 seconds, and unreachable PR-recording work is removed.

• *Release build reuse* — Was: release prebuilds missed main-scoped dependencies, and sccache could expire during a long compile.
→ Now: compatible dependency and Zig caches restore from main, missing entries are seeded there, and the sccache idle timeout is disabled.

• *Main-only cache writes* — Was: manual dispatches could save dependency and Zig cache entries that later main builds could not restore.
→ Now: only automatic main runs save cache misses. Manual dispatches can restore entries without saving new ones.

• *Browser job setup* — Was: journey jobs started Vite as well as the built-app server and downloaded an unused Chromium headless shell.
→ Now: journeys use the built-app server, fixtures use Vite, and pinned Chromium runs without the extra shell download. One evidence upload remains per shard.

• *Platform publication* — Was: Linux audit waited for macOS and the publisher checked out more source than it needed.
→ Now: each uploaded platform archive starts its audit independently, publication checks out only the release commit, and only a missing platform is rebuilt.

→ Now: the provider exposes that composer, and the acceptance checks exercise both controls through the real hub.
```
