## User thread

Top-level:

```text
*Live on production — User — Cassy v4.0.4*
Was: questions sat unseen, work stalled overnight silently, tools froze up to a minute. → Now: idle sessions wake in about a second; stalls page you.
```

Reply (Was → Now):

```text
*Faster, quieter, more honest*

• *Questions wake the other session* — Was: a question to an idle session could wait minutes or hours.
→ Now: an idle session wakes in about a second; one that was busy moments ago within about two and a half minutes.

• *Stalls page you* — Was: when work stopped overnight nothing said so; two nights lost 8 and 9 hours.
→ Now: 45 minutes without progress wakes the session; 45 more pages you.

• *No more freezes* — Was: Cassy calls froze for up to 57 seconds every five minutes.
→ Now: the slowest call measured 0.09 seconds.

• *Safe close* — Was: closing a session could report work as saved when it was not.
→ Now: unsaved work is rescued first, and the summary says what was saved and what was rescued.

• *Honest status* — Was: "pushed", "done" and "clean" could come from stale information.
→ Now: each is checked live or says how it knows, for example "as of last fetch".

• *Less test churn* — Was: one change could trigger the full test run several times.
→ Now: a change runs the tests it touches; the full run happens once.

• *Commander tables* — Was: number columns zig-zagged away from their headings.
→ Now: columns line up and size to their content.

• *Current instructions everywhere* — Was: most projects ran on instructions up to ten days old, while updates reported "0 failed".
→ Now: every project and account refreshes on update; a real conflict is reported, never hidden.

• *Problems are tracked* — Was: problems found during the day were not recorded anywhere.
→ Now: every filed problem is logged with its status, found to fixed.

Update with `cas update`, or choose <https://github.com/Richards-LLC/cassy/releases/tag/v4.0.4|the Linux x86_64 or macOS ARM64 downloads>.

macOS ARM64 SHA-256: `{{MACOS_SHA256}}`
```

## Dev thread

Top-level:

```text
*Live on production — Dev — Cassy v4.0.4*
Was: declined wakes never retried; history repair held the shared DB connection 41 s per tick. → Now: bounded retries; worst call 0.09 s.
```

Reply (Was → Now):

```text
• *Wake receive (#1514, #1517)* — Was: a wake declined for "pane not silent" or "tool call in flight" was never retried, and the 6/hour pair cap held asks.
→ Now: declined wakes retry at 10, 20, then 30 s; ask, answer and blocker skip the pair cap and the 20 s debounce; single-target urgent rows hold while a tool call is in flight, up to 60 s, then interrupt with a "Cassy interrupted" notice. The broadcast hold bound lands in 4.0.5.

• *History provenance repair* — Was: `repair_commit_links(500)` ran 1,000 task scans under the process-wide connection every five minutes.
→ Now: one task scan plus indexed commit events; repair 40.9 s to 1.41 s, worst MCP call 57.44 s to 0.087 s.

• *Cross-machine verdicts (#1519)* — Was: a pre-merge verdict on one machine was invisible to the peer's close gate.
→ Now: approved verdicts travel in an authenticated peer envelope bound to task, source and landed tree; sharing is best-effort and never fails a merge.

• *Release branch check (#1520)* — Was: a branch missing a task's fix commit could still be released.
→ Now: `release.sh` refuses when a red, test or fragment claim has no fix commit or patch-equivalent; 0 false refusals over the last 21 releases.

• *Progress watchdog* — Was: liveness and heartbeats hid stalls.
→ Now: one rule, 45 minutes without task, lane or message change wakes once, then pages.

• *Merge holds and decisions* — Was: merges could pass an unanswered peer review ask, and routine calls escalated.
→ Now: an open ask that names the PR holds the merge until answered, with a visible override; routine calls settle on written standards.

• *Status words and safe close* — Was: "[clean] [pushed]" and "done" came from cached refs or stored flags.
→ Now: live checks or explicit "as of last fetch"; shutdown rescues unpushed work to `refs/cas/rescue/` first.

• *Proof scope (#1515)* — Was: instructions ordered whole-module plus every-harness runs and a local full suite on top of CI.
→ Now: touched tests at park; the full suite runs once on the landing tree.

• *Skill sync (#1525)* — Was: the shared claude-base and codex-base skills were frozen since Oct 27, and 17 of 19 projects since v3.82.0, behind a false managed-file conflict.
→ Now: the full builtin set syncs to both bases, Cassy-only lines repair automatically, real conflicts fail loudly, and cas-src-only text stays in cas-src.

• *Also* — friction ledger (#1516), Commander table alignment (#1518), version badge showing installed vs running (#1511), merge landing past regenerated artifacts (#1510), message expiry, noise suppression, worker instructions 21% shorter.

Validation: the merge queue checks the final release tree.
```
