# Slack draft — Cassy v4.6.0 runtime release

Channel: #cas-internal (`C0B44GUKDK2`).

Status: Prepared for review. Post only after the published-asset receipt.

## User thread

Top-level:

```text
*Live on production — User — Cassy v4.6.0*
Was: long Cassy sessions got slower and costlier every hour. → Now: they hand off and start fresh on their own.
```

Reply (Was → Now):

```text
*Self-refreshing sessions, branded reports, Commander preview*

• *Sessions refresh themselves* — Was: a long session re-read its whole history every time it woke, so each wake cost more until someone cleared it by hand.
→ Now: when wakes get too expensive, the session saves a handoff and starts fresh at a quiet moment, never mid-task.

• *Fewer pointless wakes* — Was: a session could be woken again for a message it had already read.
→ Now: that second wake is skipped.

• *Reports that meet the bar* — Was: reports could arrive unbranded, unclear and too long.
→ Now: a report parks only with its brief, the project's brand, one verdict first and no outside network loads.

• *Preview Commander changes safely* — Was: a Commander change could only be seen after it shipped.
→ Now: a candidate build can be previewed against live data in a read-only window that can't send, launch or change anything.

• *Quieter, steadier workspace* — Was: blocked work waiting on the operator raised stall alerts, and synced notes could be stored twice.
→ Now: operator waits stay quiet, and each note is stored once.

Update with `cas update`, or choose <https://github.com/Richards-LLC/cassy/releases/tag/v4.6.0|the Linux x86_64 or macOS ARM64 downloads>.
```

## Dev thread

Top-level:

```text
*Live on production — Dev — Cassy v4.6.0*
Was: supervisor per-wake input grew unbounded. → Now: auto-handoff and context clear at an idle boundary, plus a report quality gate at park.
```

Reply (Was → Now):

```text
• *Supervisor auto-handoff* — Was: per-wake input grew with session length; one v4.4.0 session spent about 1.3M input tokens per wake.
→ Now: past a per-wake budget, the supervisor writes a handoff and clears its context at the next idle boundary, never mid-turn.

• *Wake and stall noise* — Was: pointer wakes reopened turns for rows already shown, and operator-gated blocked epics triggered stall nags and pages.
→ Now: shown rows don't wake, and operator waits are excluded until a factory-owned blocker appears.

• *Report gate at park* — Was: no quality gate on docs/ reports.
→ Now: park needs the concept brief, a complete 1–5 rubric meeting the floors, declared DESIGN.md brand tokens, no network loads and a verdict first.

• *Commander preview* — Was: no way to view a candidate build on live data.
→ Now: `cas hub preview --dist <build> --task <id>` serves it on its own loopback origin, and the hub refuses every mutation from it.

• *Trains and peers* — Was: new trains had no origin branch, the first cross-machine merge failed premerge on a missing local ref, and the auto verifier used a logged-out Codex home.
→ Now: trains publish on create, premerge falls back to origin, and the verifier picks an eligible account or says why not.

• *CI and tests* — Was: failing shards printed "FAIL: 0 flaky test(s)", script-test output was cut off, and the capped runner refused auto-discovered tests.
→ Now: failures name their tests and show output, and the runner accepts tests/<name>.rs.

• *Smaller fixes* — Task release advances the worker queue. Synced notes are deduplicated. QA ledger scopes quoting "FAIL:" stay valid. A timing-bound test is load-independent. Supervisor guidance fits its session-start budget.

Validation: the merge queue checks the final release tree.
```
