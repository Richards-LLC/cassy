## User thread

Top-level:

```text
*Live on production — User — Cassy v4.8.0*
Was: shipped work sat open as "waiting to merge". → Now: a release closes what it shipped.
```

Reply (Was → Now):

```text
*Releases tidy up after themselves, and Commander is clearer*

• *Shipped work closes itself* — Was: after a release went out, the work inside it stayed open as "waiting to merge" and piled up on the board.
→ Now: the release closes what it shipped and moves anything unfinished to the next release. Items held by their own checks stay open and are listed.

• *Project cards name each session* — Was: a project card showed only a role, so two live sessions of one project looked the same.
→ Now: each row shows the session's name before its machine.

• *Stuck commands can be dismissed* — Was: a Finish command that never completed blocked every later command in Commander.
→ Now: Dismiss cancels it, and a later exit or command works.

• *Fewer tool-setup failures* — Was: some sessions could not find the Rust tools and stopped to ask for help.
→ Now: they find the installed tools on their own.

• *Steadier checks before merge* — Was: the automatic reviewer gave up when no Codex account was free, and could miss a task's evidence.
→ Now: it falls back to an available Claude account and is told where the evidence lives.
```

## Dev thread

Top-level:

```text
*Live on production — Dev — Cassy v4.8.0*
Was: a published tag left its train's children AwaitingMerge. → Now: `cas release installed` and `cas release backfill` reconcile shipped trains from the tag.
```

Reply (Was → Now):

```text
• *Published-train reconcile* — Was: shipped children stayed AwaitingMerge and the train stayed open after publish.
→ Now: the tag supplies a delivery verdict, shipped children close through the ordinary gates, and unfinished work moves to the oldest uncut train. A shipped child on a reused worker lane is decided by its parked anchor, not by later lane commits.

• *Known limit in reconcile* — Was: nothing reconciled a published train.
→ Now: reconcile runs, but a child whose own close gate refuses stays open while the report still prints CLOSE for it. The report fix ships next release.

• *Batch QA receipts* — Was: a receipt could be written on a ledger the close gate rejects; qa_status on an epic asked for an impossible receipt; a reopened delivery waited for a receipt that already covered it.
→ Now: the receipt runs the ledger check first, epic qa_status lists the covering child receipts, and close falls back to the retired anchor.

• *Verifier* — Was: a second task-verifier could spawn under a running one, and the automatic verifier stopped when every Codex home was unusable.
→ Now: the duplicate spawn is refused, and the verifier falls back to an eligible Claude account with its evidence directory in the prompt.

• *Re-run worktree_merge* — Was: a delivery already in its train was asked for a fresh review.
→ Now: it reports already contained and changes nothing.

• *Task start after reassignment* — Was: the new worker's branch never inherited the source.
→ Now: it rebinds only when both old tips are inherited, with an audit note and a ledger event.

• *Release receipts and lint* — Was: an untracked train printed FIRST_CHILD_TO_MAIN_SECONDS=unavailable, the report showed a 10m publish budget, and lint passed drafts Violet refuses.
→ Now: the PR's first commit is the fallback, the budget comes from the shared stage-budget table, and lint applies the hub's file-name and time-zone rules.

• *QA sandbox and capped tests* — Was: a QA `cas serve` could register in the live store, and capped tests could not find Cargo outside PATH.
→ Now: `cas serve --sandbox <dir>` refuses outside stores with cloud sync off, and capped tests stage rustc and rustdoc from the resolved toolchain.

• *Commander* — Was: project cards showed only a role, and a stuck Finish blocked later commands.
→ Now: the supervisor name shows before the machine, and Dismiss cancels queued Finish or chooser tracking in the daemon.

Validation: one full train review, one batch fix, one batch QA round (31 PASS) and the merge queue on the final release tree.
```
