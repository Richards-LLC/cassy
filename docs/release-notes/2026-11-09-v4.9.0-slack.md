## User thread

Top-level:

```text
*Live on production — User — Cassy v4.9.0*
Was: after a reload, Commander quietly stopped showing answers. → Now: every answer keeps arriving, and finished commands clear themselves.
```

Reply (Was → Now):

```text
*Commander stays in sync, and cleanup is tidier*

• *Answers keep reaching Commander* — Was: after `/clear` and a reload of Cassy's tools, later answers silently stopped showing up in Commander.
→ Now: they keep arriving, once each.

• *Finished commands clear themselves* — Was: a finished command such as Reload Cassy left a result card that needed Dismiss.
→ Now: a short message appears and fades on its own. Failed or unconfirmed commands keep their card.

• *Project card names are readable* — Was: the first letters of a name hid under the avatar, and long names ran past the edge of phone-width cards.
→ Now: the name starts after the avatar and fits; the machine name gives way first.

• *A stuck Cancel recovers* — Was: a refused or timed-out Cancel left the command stuck at queued and blocked every later command.
→ Now: Cassy keeps following the command to its real outcome, and later commands work.

• *Finish cleans up after itself* — Was: Finish could leave background shells and servers it started still running.
→ Now: it stops its own background work and checks that none is left.

• *Releases start themselves when ready* — Was: a release that passed every check waited for someone to start it.
→ Now: Cassy starts it once every check is green and the notes are ready.

• *Mac Claude logins stay put* — Was: account linking could move a Claude login kept in the macOS Keychain and report it as drift.
→ Now: active logins are left in place.

• *Search and memories* — Was: tasks made on another machine could be missing from search, and renaming a memory by title alone did not save.
→ Now: search reads the current task list and stops exact duplicates, and title-only renames save.

Update with `cas update`, or choose <https://github.com/Richards-LLC/cassy/releases/tag/v4.9.0|the Linux x86_64 or macOS ARM64 downloads>.
```
