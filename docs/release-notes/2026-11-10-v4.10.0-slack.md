Top-level:

```text

```

Reply (Was → Now):

```text
*Your settings are respected, and reviews read clearly*

• *Your chosen account is used* — Was: new helpers could start on a different Codex account than the one you set for the project.
→ Now: they use your configured account, and the receipt says where that choice came from.

• *Review questions stay readable* — Was: a review question that mentioned a file location was replaced by a blank placeholder.
→ Now: only the location is hidden, and the question itself stays readable.

• *Release holds ask before they apply* — Was: holding a release for checks could not be undone by anyone but you, without a warning.
→ Now: it must be confirmed first, and the message says only you can lift it.

• *Answered questions stop repeating* — Was: after you or Cassy answered a stuck question, the same alert kept coming back.
→ Now: an answer closes it, and a new question gets its own alert.

• *Artifacts can be revoked* — Was: a shared file could not be withdrawn once published.
→ Now: it can be revoked with a reason; viewing and new shares stop at once, and a record is kept.

• *Steadier builds and syncing* — Was: a restarted helper could leave its build running and locking others out, and a working task could be reset by an old copy from Cloud.
→ Now: builds stop cleanly on restart, and a task you're working on keeps its status.

• *Slack replies stay with the right owner* — Was: when the owner of a Slack thread was uncertain, an older intake could still pick up the message.
→ Now: it reports the problem and waits instead.
```

```text
→ Now: released-train landings close, local_merge recovers without a remote, and verification survives retirement.

• *QA evidence* — Was: batch ledgers could not declare coverage, and repeated rounds shared directories.
→ Now: `--covers` declares receipt deliveries, rounds get head-scoped paths, and premerge review honors batch-QA deferrals.
```
