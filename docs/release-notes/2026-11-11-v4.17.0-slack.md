## User thread

Top-level:

```text
*Live on production — User — Cassy v4.17.0*
Was: some replies never reached Commander. → Now: every reply reaches any signed-in Commander device.
```

Reply (Was → Now):

```text
*Replies that arrive, releases that check themselves*

• *Commander replies arrive* — Was: replies addressed to any device expired unread, even with Commander open.
→ Now: the first signed-in device to receive a reply settles it.

• *Commands reach an idle session* — Was: Commander could refuse a command as "busy" while the session was idle.
→ Now: readiness is read from the live pane, not a scrolled view.

• *No unreviewed work ships* — Was: a release could go out with its own changes never reviewed.
→ Now: the cut refuses until every change in the release has a review.

• *No self-graded approvals* — Was: the session running the work could approve a design it had commissioned.
→ Now: anything you are asked to approve gets an independent review first.

• *One notice per review* — Was: recording a release review sent one notice per held task.
→ Now: one notice lists what closed and what is held, grouped by reason.
```
