# Slack draft — Cassy v4.20.0 runtime release

Channel: #cas-internal (`C0B44GUKDK2`).

Status: Prepared for review. Post only after the published-asset receipt.

## User thread

Top-level:

```text
*Live on production — User — Cassy v4.20.0*
Was: an automatic context reset could cut off the end of your session's saved plan. → Now: the whole plan comes back.
```

Reply (Was → Now):

```text
*Fewer interruptions, nothing lost*

• *Your saved plan survives a reset* — Was: when a long session reset itself, the end of its saved plan was cut off for good, and day-old notices crowded the summary.
→ Now: the whole plan is kept and shown first, old notices fold into one line, and each helper shows whether it is really working.

• *Notices from your other machine stop asking for replies* — Was: a note that work had landed from the other machine arrived as a question that asked for an answer.
→ Now: it arrives as a status update with nothing to answer, and you still see it right away.

• *No false "stalled" alarms* — Was: work that was waiting on purpose, for another task or a paused helper, could raise stall warnings and pages.
→ Now: deliberate waits stay quiet until the work can move again.

• *Merging work from the other machine no longer stalls* — Was: the check before a merge could stop and wait while someone copied the other machine's evidence over by hand.
→ Now: the evidence is downloaded automatically before the check starts.

• *No false version-check failures* — Was: a file path that happened to contain the release number could fail the release check.
→ Now: only a real copy of the version number counts.

• *New work joins the right release* — Was: a new task could be pointed at an old or replaced release train.
→ Now: it joins the current shared train, and finished releases tidy up old entries without closing unfinished work.
```

## Dev thread

Top-level:

```text
*Live on production — Dev — Cassy v4.20.0*
Was: the auto-clear handoff stored a truncated judgement with a self-referential pointer. → Now: the memory keeps it whole; only injections clip.
```

Reply (Was → Now):

```text
• *Auto-clear handoff* — Was: merge_judgement clipped the judgement to the section budget before storing it, pending rows were capped at 100 regardless of age, and worker lines used registry status.
→ Now: judgement is stored whole and first; worker_idle/task_lifecycle rows older than 60 min collapse to a count and sort last; worker lines carry worker_status liveness.

• *Peer landing render* — Was: a bare CAS_PEER_PREMERGE_V1 body fell through to kind=ask with the reply instruction.
→ Now: render_prompt classifies it as Status, keeps the wake, and omits the reply line.

• *Progress watchdog* — Was: tasks blocked by open dependencies or assigned to held workers produced stall notices and operator pages.
→ Now: both are excluded until actionable.

• *Peer evidence* — Was: pre-merge review of a peer delivery raised supervisor_call because the evidence lived only in the publisher's artifacts root.
→ Now: committed peer artifacts are fetched from Cloud into the local task evidence directory before fingerprinting; local files win and a restored QA ledger no longer self-refuses.

• *version-literals row* — Was: the gate matched the release version as plain text, so a Node v24.x path failed pushes (GH #1865).
→ Now: whole-version match; suffixed versions such as -rc.1 still fail.

• *Default train* — Was: new tasks could target stale or superseded trains.
→ Now: shared origin history selects the live train, refuses divergent candidates, and cuts retire stale admissions without closing open work.

• *Review retention* — Was: a sibling's independent journey-registry edit invalidated an approval.
→ Now: the approval holds while the delivery's hunks and context are unchanged.

• *Parent verification* — Was: release reconciliation from an unregistered CLI process held the epic on an agent registration error.
→ Now: it requests parent verification under its recorded release identity.

• *Worker Git guards* — Was: returning from a detached historical checkout was refused.
→ Now: checkout/switch navigation across branch, previous-tip, detach, create and orphan forms is recognised; detached commits, path restores and forced ref rewrites stay guarded.

• *Cut gate* — Was: a train whose review and QA receipts had already closed every member was refused as "zero would-close".
→ Now: the cut refuses only when members are held or not eligible.

Validation: the merge queue proves the final release tree.
```
