# Slack draft — Cassy v4.25.0 runtime release

Channel: #cas-internal (`C0B44GUKDK2`).

Status: Prepared for review. Post only after the published-asset receipt.

## User thread

Top-level:

```text
*Live on production — User — Cassy v4.25.0*
Was: checks ran almost every test and approvals reset on each merge. → Now: checks run what a change touches; approvals stick.
```

Reply (Was → Now):

```text
*Faster checks, fewer repeat reviews*

• *Checks run only what a change touches* — Was: a change to a few scripts ran almost the whole test suite. → Now: it runs the tests those files affect, cutting a typical check from about 24 to about 6 minutes.

• *Approvals survive unrelated changes* — Was: an approved change was re-reviewed whenever anything else landed first. → Now: the approval stays unless the change's own files were touched.

• *No message lost in the same millisecond* — Was: a message that arrived in the same millisecond as the last inbox check stayed hidden. → Now: it is shown at the next step.

• *Evidence follows the work* — Was: work built on the second machine left its proof files there, so reviews stalled. → Now: the proof files travel with it.

• *Releases skip repeat reviews* — Was: every release needed its own separate review on top of each change's approval. → Now: a release uses the approvals each change already has.
```

## Dev thread

Top-level:

```text
*Live on production — Dev — Cassy v4.25.0*
Was: lane impact diffed from the recorded start base and escalated to workspace. → Now: live merge-base selection, approval carry and approval-based release verdicts.
```

Reply (Was → Now):

```text
• *Delivery-only lane selection* — Was: impact diffed from the recorded start base; unmapped paths selected the workspace. → Now: the live target merge-base; script/workflow changes select only the Rust tests that read them; config and docs select nothing. One delivery: own job 24.1 → 6.4 min.

• *Exact-base attribution reuse* — Was: lane attribution rebuilt the base to classify failures. → Now: it reuses configuration-matched failing-test receipts within a bounded replay.

• *Release verdict from member approvals* — Was: batch mode needed a separate release review ledger and recorder. → Now: the verdict comes from each member's pre-merge approval plus the green frozen-train receipt; missing approvals are named and refused.

• *Docs-only commits keep train proof* — Was: a CODEMAP, changelog or notes commit after a green train run forced fresh train CI. → Now: the green receipt carries; source changes still require fresh proof.

• *Approval carry* — Was: a train move rebuilt the candidate and re-ran review. → Now: disjoint train changes carry the approval; changed paths and conflicts still re-review.

• *Inbox equal-millisecond signal* — Was: a signal equal to mail_checked_at was skipped. → Now: one extra drain, no duplicates.

• *Routed evidence sync* — Was: routed builds' artifacts stayed on the build host. → Now: park publishes the whole task evidence tree (nested and empty files) and pre-merge restores it, failing loudly if incomplete.
```
