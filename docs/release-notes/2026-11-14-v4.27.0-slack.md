## User thread

Top-level:

```text
*Live on production — User — Cassy v4.27.0*
Was: Commander history could fail to load while Cassy was busy. → Now: history loads every time.
```

Reply (Was → Now):

```text
*Reliable history, faster releases*

• *Working indicator* — Was: fresh output sometimes showed no working sign. → Now: recent output lights it, with no placeholder text.
```

## Dev thread

Top-level:

```text
*Live on production — Dev — Cassy v4.27.0*
Was: history reads shared the daemon's SQLite writer and failed under load. → Now: a read-only WAL connection serves history.
```

Reply (Was → Now):

```text
• *History connection* — Was: conversation history shared the daemon's SQLite connection and failed when its wait budget ran out. → Now: history uses its own read-only WAL connection.

• *macOS prebuild* — Was: the hosted macOS prebuild compiled cold (Build 30.7 min). → Now: trusted merge-queue and main builds run on a self-hosted Apple Silicon runner with a persistent target, with hosted fallback.

• *Auto-cut scope* — Was: auto-cut froze trains ignoring their blocking deliveries. → Now: it waits for them and names those still pending.

• *Freeze dispatch* — Was: a frozen tip could get two full-validation runs, and a cancelled newer one hid the green receipt. → Now: one run per frozen tip.

• *Lane journeys* — Was: lane CI ran no Commander journeys. → Now: hub-web deliveries run the affected journeys and name any failure.

• *H-11 help* — Was: `--help` on an operator-only command was refused. → Now: help and version output pass.

• *Delivery fixtures* — Was: slow setup could erase a fixture's proof scope. → Now: fixtures create the task before the delivery commits.

Validation: the frozen train ran its full suite once, and the merge queue proves the final release tree.
Published archives: Linux x86_64 and macOS ARM64, available from <https://github.com/Richards-LLC/cassy/releases/tag/v4.27.0|the GitHub release>.
```
