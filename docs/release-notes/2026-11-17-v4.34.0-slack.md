Channel: #cas-internal (`C0B44GUKDK2`).

Status: Prepared for review. Post only after the published-asset receipt.

## User thread

Top-level:

```text
*Live on production — User — Cassy v4.34.0*
Was: security advisories, an outside code dependency and stuck merges slowed every day. → Now: patched, self-contained, and merges keep moving.
```

Reply (Was → Now):

```text
*Safer, self-contained, and fewer stalls*

• *Security updates* — Was: the MCP library and several network and archive libraries carried known advisories. → Now: they're upgraded, and the credential guard closes a way to pass a stored token to a child program.

• *No outside code repos* — Was: Cassy pulled one library straight from someone else's repository. → Now: Cassy has its own Claude client and depends on no outside git repos.

• *Merges keep moving* — Was: one rejected fix froze the whole merge queue, reviewers sometimes failed to start, and waits had to be watched by hand. → Now: the rejected fix drops out on its own, reviewers start reliably, and every pending merge watches its own CI.

• *CI tells you what broke* — Was: a stuck CI build sat for an hour and ended as "cancelled". → Now: it stops early, names the step it was stuck on, and retries once.

• *Fewer duplicate issues* — Was: the same refusal reported again filed a new issue each time. → Now: Cassy adds the new report to the existing issue or task instead.

• *Releases* — Was: a release-repair could be blocked, the post-release notice could go missing, and only the operator could lift a freeze. → Now: repairs are admitted, the notice is sent, and a freeze can be lifted with a recorded reason. Your own freezes stay yours.

• *Accounts* — Was: new Codex sessions could start on a nearly used-up account. → Now: Cassy picks the account with the most room left.
```
