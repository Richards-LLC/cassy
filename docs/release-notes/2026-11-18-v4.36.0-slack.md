## User thread

Top-level:

```text
*Live on production — User — Cassy v4.36.0*
Was: work stalled on false refusals, lost evidence and stuck merges. → Now: uncertain checks run more tests, evidence travels, merges finish.
```

Reply (Was → Now):

```text
*The close-out release: dozens of reported problems fixed at their source*

• *Unsure means run more* — Was: when Cassy couldn't classify a changed test, it refused the work. → Now: it runs the broader tests once instead, and refuses only a missing or failing test.

• *Evidence works across machines* — Was: proof saved on one computer was missing on the other, so merges stalled. → Now: parked work publishes its evidence where the reviewer can read it.

• *Safer test runs* — Was: a local test could overwrite real Cloud login details. → Now: test scratch lives outside the project, and real credentials are protected.

• *Cloud logins recover* — Was: an expired session showed "Invalid API key". → Now: Cassy re-reads your login and retries once, or says "Cloud session expired, run cas login".

• *Faster, truer releases* — Was: shipped work could look reverted or stuck waiting to merge, and release previews were slow. → Now: shipped work closes with its release, and previews are about a fifth faster.

• *Local databases in JavaScript tests* — Was: a declared local test database URL never reached the test, so integration tests skipped. → Now: a password-free local URL passes through to the test only.

• *Steadier CI* — Was: heavy test jobs died on hosted machines with no logs. → Now: they run on our own runners and keep full logs.

• *Also* — Commander status cells stay truthful, Violet replies and reactions work from the command line, and Mac updates keep the same signing identity.
```

## Dev thread

Top-level:

```text
*Live on production — Dev — Cassy v4.36.0*
Was: G-61 refused on uncertainty, park evidence was machine-local, closeout misjudged reverts. → Now: widen-never-refuse, portable proof, source-path revert checks.
```

Reply (Was → Now):

```text
• *Widen, never refuse* — Was: unclassified changed tests refused park. → Now: one capped pass of the file, JS package or Rust crate, isolated per input; a typed missing or failing test still refuses (G-61).

• *Deletion-only deliveries* — Was: removing a test next to an unchanged out-of-line callback refused discovery. → Now: pure deletion anchors are ignored.

• *Selection reasons* — Was: receipts didn't say why a test ran. → Now: rows carry `changed-test`, owner, import-consumer or widened cause.

• *Portable park evidence* — Was: cited logs stayed on the parking machine. → Now: park publishes task evidence through the artifact store.

• *Capped scratch* — Was: TMPDIR sat inside the checkout, so fixtures reached the real store. → Now: scratch lives outside Git and `.cas` ancestry; credential fixtures guard real logins.

• *Cloud 401 recovery* — Was: every 401 surfaced as invalid key. → Now: a rejected key re-reads the login and retries once; other 401 causes stay verbatim.

• *Release closeout* — Was: unrelated reverts of regenerated docs held shipped members; conventional `fix(cas-x):` commits weren't owners. → Now: reverts are judged by source paths, and prefix ownership counts.

• *Preview speed* — Was: per-member hunk walks and per-commit Git spawns. → Now: shared indexed hunks and batched reads; a live preview went from 32.84s to 26.13s with identical JSON.

• *Generator staging* — Was: regeneration staged an intentionally untracked projection and failed with exit 128. → Now: only tracked outputs are staged.

• *CI* — Was: own-tests on hosted runners died with no logs. → Now: they run on `cas-lane-light` with full step logs, and the gate-registry audit runs for production Rust deliveries.

• *Also* — Approval reuse after dispatch expiry, bounded reviewer input, account tie-breaks on the binding window, SSH repository identities, isolation after git init, director alerts owned by current work.
```
