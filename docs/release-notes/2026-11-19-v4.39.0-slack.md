# Slack draft — Cassy v4.39.0 runtime release

Channel: #cas-internal (`C0B44GUKDK2`).

Status: Prepared for review. Post only after the published-asset receipt.

## User thread

Top-level:

```text
*Live on production — User — Cassy v4.39.0*
Was: releases stalled on the wrong check and repeated reviews. → Now: the right check runs at freeze and finished reviews carry over.
```

Reply (Was → Now):

```text
*Smoother releases and less wasted work*

• *The right check starts at freeze* — Was: freezing a release didn't start its full check, and the guidance named the wrong one, so a release could wait over an hour for nothing. → Now: freezing starts the full check right away and shows its link.

• *Only the owner's machine cuts a release* — Was: a second machine with default settings could freeze a release on its own. → Now: only the machine that owns the release can cut it, and every freeze says which machine did it.

• *No more work on a release that's already gone* — Was: after a release was cut, unfinished work kept testing against it and was only turned away at the end. → Now: unfinished work moves to the next release automatically, and anything still aimed at the old one is stopped before tests run.

• *Reviews aren't repeated* — Was: work that was already reviewed got reviewed again when it moved to the next release, and queued work was reviewed one at a time. → Now: an approved review carries over when nothing changed, and queued work is reviewed together.

• */standby* — Was: pausing a session meant ending it and losing its place. → Now: `/standby` saves, pauses the session's helpers and goes quiet; Resume brings them back with their work.

• *Briefs follow the testing rules* — Was: a brief could ask for a test per item or for exact wording checks with no warning. → Now: Cassy flags those asks when the brief is written.

• *Also* — quieter busy machines, a faster board refresh, clearer store and write-root messages, safer Codex starts and restarts, and the reply fact-check prefix is gone.

Update with `cas update`, or choose <https://github.com/Richards-LLC/cassy/releases/tag/v4.39.0|the Linux x86_64 or macOS ARM64 downloads>.
Linux x86_64 SHA-256: `{{LINUX_SHA256}}`
macOS ARM64 SHA-256: `{{MACOS_SHA256}}`
```

• *Owner-only auto-cut* — Was: a peer daemon cut a shared train from its own defaults while the owner set auto_cut_max_per_day = 0. → Now: only the train owner's machine auto-cuts; freeze notes name the machine.

• *Verdict carry-over* — Was: proof_scope_fix invalidated the approved verdict even for a merge-only carry-over. → Now: an unchanged reviewed patch reuses its verdict through merge, publication and close.

• *Parallel train_merge review* — Was: only the queue head got a candidate and verifier. → Now: every queued delivery is prepared and verified on enqueue; publication stays ordered.

• *Capacity before classification* — Was: worker-check classified changed tests for minutes on each capacity retry before admission refused it. → Now: a saturated host refuses first.

• *Brief warnings* — Was: no signal for per-item tests or wording asserts in briefs. → Now: N-106 and N-107 warnings from a phrase list owned by cas-writing-tests.
