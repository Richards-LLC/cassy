# Slack draft — Cassy v4.58.0 runtime release

Channel: #cas-internal (`C0B44GUKDK2`).

## User thread

Top-level:

```text
*Live on production — User — Cassy v4.58.0*
Was: big jobs ran on Fable, and old sessions haunted Commander. → Now: big jobs run on Opus 5.5, and the ghosts are gone.
```

Reply (Was → Now):

```text
*Model choice and clearer closes*

*Sessions*

• *Heavy work runs on Opus 5.5* — Was: heavy work ran on Fable 5.2 at high effort.
→ Now: heavy work runs on Opus 5.5 at extra-high effort; design and taste work stays on Fable 5.2.

• *Every effort level a model supports* — Was: each model allowed only a few effort levels, so asking for one it supports could be refused.
→ Now: any effort level the model supports, from low to max, can be requested.

*Commander*

• *No more ghost conversations* — Was: Commander kept showing old, ended sessions as live and waiting, sometimes for weeks.
→ Now: when the server no longer lists an old session, Commander drops it from the list; live sessions are unchanged.

*Closing work*

• *Slow closes say what happened* — Was: on some merged deliveries a close ran out of time, reported "in progress" and left the task stuck with no error.
→ Now: the close finishes within its time limit, or it stops with a message naming the check that ran out of time.
```

## Dev thread

Top-level:

```text
*Live on production — Dev — Cassy v4.58.0*
Was: heavy=Fable 5.2/high, narrow effort lists, silent close-gate timeouts. → Now: heavy=Opus 5.5/xhigh, full effort lists, named refusals.
```

Reply (Was → Now):

```text
*What changed under the hood*

*Routing*

• *Heavy lane* — Was: `lanes.heavy` resolved `claude_fable_5_2_high`.
→ Now: new `claude_opus_5_5_xhigh` recipe; fallbacks Opus 5.5/high, then Codex Astra. `lanes.taste` unchanged.

• *Effort lists* — Was: recipes allowed subsets (Opus 5.5 low/high only), and a legacy Luna xhigh-only guard sat outside the registry.
→ Now: each active recipe lists every level its model documents (low through max); the Luna guard is gone; minimal stays refused.

*Commander*

• *Cached ghost rows* — Was: `reconcileCatalog` kept every omitted cached row flagged live, so legacy sessions with no hub record showed a green dot and the waiting label forever.
→ Now: an unreachable cached row the hub omits, older than the expiry cutoff, is dropped on a fresh catalog; HUB-J12 covers it.

*Close gates*

• *Shared close budget* — Was: a delivery-content walk that hit its deadline was treated as a merge candidate, and a retry started with a fresh quota, pushing close past 55 s with no refusal.
→ Now: the walk and its retry share one budget, identical targets are not rewalked, and a timeout refuses with the gate named. Notes size does not affect timing (42 B vs 164 KB fixture: 2.15 s vs 2.02 s).
```
