## What you can do now

### Quality at the epic level

#### Walk the whole feature once

Was: each task could be exercised alone, leaving interactions between tasks to surface after release.

Now: when any child task names a demo outcome, Cassy walks the assembled epic once with a combined 60-minute matrix, records coverage and misses, and checks for contradictions across children.

#### Close an epic on evidence

Was: an epic could close on the strength of individual task reports.

Now: epic verification requires the flow-walk note and ledger on the current tip, then applies the evidence REJECT table before reading the close reason.

### Telemetry in QA

#### Let a project sweep its own analytics

Was: QA had no contract for production analytics, and a reporter with no events could look like a clean run.

Now: an optional read-only `qa.telemetry_sweep` command records NEW, RISING, HIGH_RATE, and BLACKOUT findings in the QA ledger, or says plainly when no sweep is configured.

### Memory

#### Keep recall arriving in long sessions

Was: long Claude Code sessions could silently stop receiving Cassy's recall and factory mail when the prompt hook was omitted.

Now: PostToolUse or an MCP response delivers the same turn context once per prompt when UserPromptSubmit is silent, and the doctor report makes observed hook silence visible.

#### Rank the matching lesson first

Was: recent exact-match memories could lose to an eight-row recency window, semantic search could miss its budget, and unbound commits could outrank guidance.

Now: discovery ranks term overlap before recency, caps prompt terms at 16, gives semantic search a 1,500 ms deadline, and keeps commit history behind guidance.

### Release

#### Re-check an unchanged release quickly

Was: the release gate ran the workspace suite twice and retained no per-row timing evidence.

Now: the suite runs once across complementary nextest and archive rows, each row records timing, and `--reuse` can re-gate an unchanged tree from content-keyed receipts without authorizing the pipeline.

### Doctor

#### See when the prompt hook goes quiet

Was: a missing UserPromptSubmit invocation left a live session without a visible diagnosis.

Now: `cas doctor` reports prompt-hook silence and counts the observed misses so an operator can distinguish a quiet hook from an empty result.

## Under the hood

### Epic flow walk

#### Supervisor procedure

Was: the supervisor checklist ran the suite on the epic branch and closed without one cross-child product pass.

Now: after the detached gate launch, one verifier-class evidence agent derives a capped matrix from every child `demo_statement`, walks the assembled tip for 60 minutes, and writes one `LEDGER.md` plus one `Epic flow walk` note; retries resume the same pass.

#### Verifier gate

Was: `verification_type=epic` checked subtasks and the close reason.

Now: the gate enumerates child demos, requires the walk note and ledger for the current tip, and applies the Step 0A REJECT table before reading close prose.

### Telemetry sweep contract

#### Configuration seam

Was: project analytics had no QA configuration seam.

Now: `qa.telemetry_sweep` is an optional project-relative string that round-trips through config get, list, and set.

#### Evidence labels

Was: QA ledgers had four evidence labels and no defined treatment for analytics findings.

Now: a read-only sweep runs first with `--reporter` when configured; six-field TSV findings become `eyewitness/telemetry` rows, and the header records configured or not configured.

### Memory and context delivery

#### Turn-context fallback

Was: the UserPromptSubmit hook was the only delivery path for ambient recall, supervisor reminders, and factory inbox context.

Now: PostToolUse and MCP response paths share a once-per-prompt turn-context receipt, using a local-only recall path that does not wait on the cloud when the prompt hook is silent.

#### Ambient ranking

Was: an eight-row recency window could omit a same-day nine-term match, the 400 ms semantic budget was too short, and unbound history could outrank guidance.

Now: overlap-first discovery, a 16-term cap, a 1,500 ms semantic deadline, strong lexical evidence, and at most one history commit keep relevant guidance in front.

### Release controls

#### One workspace suite

Was: in-tree nextest and the archive row repeated almost the same workspace execution.

Now: the nextest row covers the snapshot complement and the archive row executes the workspace once, preserving coverage without duplicate execution.

#### Reuse without authorization drift

Was: a one-line release fix required a full re-gate and there was no content-keyed unchanged-tree reuse.

Now: `--reuse` restores eligible PASS rows by exact content inputs while the pipeline still requires its own exact-SHA gate receipt.

### Doctor observability

#### Hook-silence row

Was: prompt-hook silence had no durable operator-facing count.

Now: `cas doctor` reports the silent-hook condition and the number of observed misses, making a missing invocation diagnosable rather than inferred from an empty prompt.
