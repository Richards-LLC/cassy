## What you can do now

### Release

#### Build the report in one command

Was: Each release report was assembled by hand from the changelog, issues, release notes, and receipts.

Now: `cas release report <version> --pdf` builds the Markdown, standalone HTML, and PDF for any project, and rerunning it preserves an existing Markdown source unless refresh is requested.

Source: [CHANGELOG 3.22.0](https://github.com/Richards-LLC/cassy/blob/v3.22.0/CHANGELOG.md), Added.

#### Require the report before announcing

Was: A release announcement could go out with no report or with a file whose bytes were not tied to the receipt.

Now: The release train's `--report` step runs after verified publication, posts the HTML and PDF through its adapter, and makes `--status` revalidate the byte-verified `release-report.receipt`.

Source: [v3.22.0 announcement draft](https://github.com/Richards-LLC/cassy/blob/v3.22.0/docs/release-notes/2026-09-09-v3.22.0-slack.md), developer release-train section.

#### Carry two report editions forward

Was: Only the v3.19.0 report existed as a committed exemplar.

Now: The v3.20.0 and v3.21.0 reports ship under `docs/release-reports/`, with the reusable template's continuous print flow.

Source: [CHANGELOG 3.22.0](https://github.com/Richards-LLC/cassy/blob/v3.22.0/CHANGELOG.md), Added.

### Memory

#### Keep recall visible in long briefings

Was: When a start-up briefing grew too long, recalled memory and factory context could be cut before static listings, without saying what changed.

Now: SessionStart compaction orders static sections first and keeps ambient recall and the factory inbox last, with a one-line marker when content was compacted.

Source: [CHANGELOG 3.22.0](https://github.com/Richards-LLC/cassy/blob/v3.22.0/CHANGELOG.md), Changed.

#### See the budget before headroom runs out

Was: Operators had no doctor row showing how much protected SessionStart prompt headroom remained.

Now: `cas doctor` reports the SessionStart budget and fails under the 512 B protected ceiling, making a briefing risk visible before it becomes a silent omission.

Source: [CHANGELOG 3.22.0](https://github.com/Richards-LLC/cassy/blob/v3.22.0/CHANGELOG.md), Added.

### Verification

#### Close only the work this task delivered

Was: Additive-only and value-only close gates could diff the entire long-lived factory branch, attributing an earlier task's files to the later task.

Now: Posture, no-code, receipt-stat, and epoch gates share one first-parent delivery range bounded by the target merge-base and task work window; an audited supervisor override and unchanged-proof path are explicit.

Source: [issue #767](https://github.com/Richards-LLC/cassy/issues/767), [CHANGELOG 3.22.0](https://github.com/Richards-LLC/cassy/blob/v3.22.0/CHANGELOG.md), Changed.

### Factory

#### Make the worker start line honest

Was: A Codex helper's spawn audit could print a Claude account directory, obscuring which launcher and credentials were actually used.

Now: The audit names the launched CLI, model, effort, and the provider's account directory, with a regression pinning Codex routing to the Codex launcher.

Source: [CHANGELOG 3.22.0](https://github.com/Richards-LLC/cassy/blob/v3.22.0/CHANGELOG.md), Changed.

## Under the hood

### Release assembly

#### Source and rendering seam

Was: Release preparation had no reusable command seam from Keep-a-Changelog, release notes, GitHub, and publication receipts to a report.

Now: `cas release report` parses those sources, assigns label-first then keyword themes with an explicit Unclassified row, preserves an existing source, invokes the built-in renderer, and can render a Playwright PDF.

#### Publication receipt seam

Was: The release train's status check stopped at workflow, publication, and latency receipts.

Now: `--report` validates worktree-confined HTML/PDF paths, both SHA-256 values, page count, Slack file ids, and user/developer thread timestamps; `--status` rechecks the bytes.

#### Continuous report surface

Was: Report pagination forced fresh pages per section and the repository had no carried v3.20.0 or v3.21.0 report editions.

Now: The report template flows continuously with keep-together rules and the two prior report editions are committed alongside their PDFs.

### Session memory

#### Compaction priorities

Was: SessionStart compaction ordered sections by byte savings, allowing ambient recall to disappear before less valuable static material.

Now: Static listings compact first, then context and ambient recall, with the factory inbox last; compacted sections leave an in-payload marker.

#### Budget observability

Was: Prompt-size pressure had no operator-facing doctor measurement or protected floor.

Now: `cas doctor` reports SessionStart budget usage and protects 512 B of headroom.

### Close verification

#### Delivery-range attribution

Was: Each posture, no-code, receipt-stat, and epoch gate independently diffed `target..branch`, so a long-lived branch could make an unrelated task fail.

Now: The gates share one first-parent delivery range bounded by target merge-base and task work window; supervisor exceptions carry a reason, and clearing `execution_note` does not invalidate unchanged proof.

### Spawn audit

#### Provider routing evidence

Was: PTY audit output always showed a Claude account path, even when the worker launched through Codex.

Now: Spawn records name CLI, model, effort, and `CLAUDE_CONFIG_DIR` or `CODEX_HOME`, with a regression test for Codex routing.
