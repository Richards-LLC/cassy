## What you can do now

### Release changes

#### Work in progress

Was: background tasks could look inactive, including on Mac.

Now: Cassy recognizes work that is still running and waits before sending an idle alert.

#### Reliable stopped state

Was: late crash information could make a stopped session look merely inactive.

Now: stopped sessions stay stopped, so recovery starts from the correct state.

#### Moving on sooner

Was: repeated checks and duplicate cleanup could slow the move to the next task.

Now: cleanup remembers when it is ready and avoids repeating work while protecting unpublished changes.


## Under the hood

### Running work

#### macOS process evidence

Was: child-process evidence was unavailable on Mac.

Now: native discovery reports owned descendants and their ages, excludes persistent MCP sidecars and keeps missing evidence explicit.

#### Idle alerts

Was: live background work could still trigger an idle delivery alert.

Now: an owned live child suppresses the alert until it finishes, alongside the existing locks and reminder rules.

#### Terminal retirement

Was: a delayed pane-exit observation could change shutdown into stale.

Now: shutdown remains terminal after late observations.

#### Cleanup readiness

Was: adoption reopened the agent store each tick and shared checkouts could get duplicate intents.

Now: readiness persists on disk, staging groups by checkout and partial retries preserve frozen task facts.

### Checks and CI

#### Bounded proof searches

Was: changed paths and public symbols caused repeated integration-test scans.

Now: source paths share Git searches in bounded batches, and builtin literals share one search without losing consumer coverage.

#### Queued-run watchdog

Was: a sweep could report success even when cancellation requests failed.

Now: rejected requests are checked again, and queued or unreadable runs keep the sweep red while completion races remain safe.

#### Sandbox availability

Was: finding Bubblewrap selected isolation even when the host could not create a sandbox.

Now: capability probing selects the existing fallback with a warning, while required isolation still fails closed.

#### Dependency cache reuse

Was: hosted queue archive builds could lack a compatible dependency cache.

Now: a cache miss can request advisory priming from main after archive reuse, without adding a required check or saving queue-ref copies.

### Test review

#### Read-only test audit

Was: test-value and CI-cost reviews lacked a shared procedure.

Now: the test audit skill supplies five review buckets, detector precision checks and runner timing recipes, with approval required before cuts.

#### Remove dead scaffolding

Was: tests exercised unused routing overrides, parsing, validation, silence intent and report helpers.

Now: those unused paths are removed, while live owner-session routing, relay completion and component reporting retain their coverage.

#### Accurate capacity coverage

Was: a limits test name implied account-picker coverage it no longer provided.

Now: the test names limits rendering, and the journey check names the actual account-choice test separately.
