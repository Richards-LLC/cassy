What you can do now

01

Clearer work requests

Name the outcome before work begins

Wasuser-facing work could start without an observable outcome.

Nowconfigured labels require a demo statement, repeated in worker briefs. Epics, unlabeled work and supervisor overrides are exempt.

02

Honest QA

Explore within a useful decision window

Wasexploratory QA lacked a clear stopping point.

Nowcas-qa-craft supplies a matrix, adjacent-risk checks, evidence labels and a 30-minute box.

Keep the evidence behind the result

Wasclose prose could hide what was actually exercised.

NowLEDGER.md records verdicts, captures and honest NOT EXERCISED results; verification checks that evidence before the close reason.

Recall the relevant lesson

Wasrecall missed same-day lessons while semantic search timed out.

Nowrecent, deeply matching memories outrank old shallow rule matches; semantic search has bounded deadlines.

03

Release clarity

Open a report you can inspect

Wasrelease reporting needed a bespoke source-to-PDF path.

Nowcas-release-report provides the renderer, brief, template and PDF recipe; the v3.19.0 exemplar demonstrates them, and the announcement draft links the report.

Leave the CPU free while waiting

Wasan idle code watcher could keep a core busy.

Nowcas serve waits for filesystem events without spinning.

Under the hood

03 / 06
01

Task and QA contracts

A configurable creation gate

Waspublic-surface labels did not require a demo statement.

Nowqa.user_facing_labels defaults to ui, hub, cli-ux, commander and frontend; creation requires a statement, except for epics, unlabeled tasks and deliberate supervisor overrides.

An exploration ledger with evidence labels

WasQA prose blurred inference, fixtures and actual-build observations.

Nowcas-qa-craft caps eight cells, adds three unmentioned conditions and an adjacent surface, labels evidence and marks unrun cells NOT EXERCISED after 30 minutes.

Evidence mode precedes capture judgment

Wasverifiers could judge close prose before its supporting evidence.

Nowthe evidence-mode REJECT table runs before captures open; each capture judgment accompanies its row and close reason.

02

Release controls

One reusable report renderer

Waseach release needed bespoke source, design and PDF production.

Nowcas-release-report supplies the renderer, template, brief, token mapping and A4/Letter recipe, with continuous flow and fidelity checks.

An exemplar carried into preparation

Wasthe repository lacked a complete release-report example.

Nowpreparation carries forward the v3.19.0 Markdown, brief, HTML, PDF and QA receipt.

An explicit publication handoff

Wasannouncements could omit report artifacts or publication proof.

Nowstep 13 requires the report after publication, before authorized Slack posts. Drafts link source/HTML/PDF; the rubric retains four ordered posting receipts.

03

Runtime efficiency

A watcher that blocks when idle

Wasthe code watcher's idle path could spin without a filesystem change.

Nowthe idle path waits for events. This report records the shipped fix for #754; it does not claim a new CPU benchmark.

04

Ambient recall quality

Bound search and remove ranking noise

Wasa 30-second connect timeout sat outside the 400-millisecond semantic budget; old shallow rule matches outranked recent exact-overlap memories, unrelated task titles padded prompts, and tool triggers included hex IDs and durations.

Nowconnect and request deadlines are bounded, decision traces include timings, recency and overlap depth affect fusion, strong prompts avoid unrelated padding, and dictionary-like trigger terms filter noisy IDs and durations.
