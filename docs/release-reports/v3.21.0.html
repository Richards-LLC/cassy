What you can do now

02 / 06
01

Quality at the epic level

Walk the whole feature once

Waseach task could be exercised alone, leaving interactions between tasks to surface after release.

Nowwhen any child task names a demo outcome, Cassy walks the assembled epic once with a combined 60-minute matrix, records coverage and misses, and checks for contradictions across children.

Close an epic on evidence

Wasan epic could close on the strength of individual task reports.

Nowepic verification requires the flow-walk note and ledger on the current tip, then applies the evidence REJECT table before reading the close reason.

02

Telemetry in QA

Let a project sweep its own analytics

WasQA had no contract for production analytics, and a reporter with no events could look like a clean run.

Nowan optional read-only qa.telemetry_sweep command records NEW, RISING, HIGH_RATE, and BLACKOUT findings in the QA ledger, or says plainly when no sweep is configured.

03

Memory

Keep recall arriving in long sessions

Waslong Claude Code sessions could silently stop receiving Cassy's recall and factory mail when the prompt hook was omitted.

NowPostToolUse or an MCP response delivers the same turn context once per prompt when UserPromptSubmit is silent, and the doctor report makes observed hook silence visible.

Rank the matching lesson first

Wasrecent exact-match memories could lose to an eight-row recency window, semantic search could miss its budget, and unbound commits could outrank guidance.

Nowdiscovery ranks term overlap before recency, caps prompt terms at 16, gives semantic search a 1,500 ms deadline, and keeps commit history behind guidance.

04

Release

Re-check an unchanged release quickly

Wasthe release gate ran the workspace suite twice and retained no per-row timing evidence.

Nowthe suite runs once across complementary nextest and archive rows, each row records timing, and --reuse can re-gate an unchanged tree from content-keyed receipts without authorizing the pipeline.

05

Doctor

See when the prompt hook goes quiet

Wasa missing UserPromptSubmit invocation left a live session without a visible diagnosis.

Nowcas doctor reports prompt-hook silence and counts the observed misses so an operator can distinguish a quiet hook from an empty result.

Under the hood

03 / 06
01

Epic flow walk

Supervisor procedure

Wasthe supervisor checklist ran the suite on the epic branch and closed without one cross-child product pass.

Nowafter the detached gate launch, one verifier-class evidence agent derives a capped matrix from every child demo_statement, walks the assembled tip for 60 minutes, and writes one LEDGER.md plus one Epic flow walk note; retries resume the same pass.

Verifier gate

Wasverification_type=epic checked subtasks and the close reason.

Nowthe gate enumerates child demos, requires the walk note and ledger for the current tip, and applies the Step 0A REJECT table before reading close prose.

02

Telemetry sweep contract

Configuration seam

Wasproject analytics had no QA configuration seam.

Nowqa.telemetry_sweep is an optional project-relative string that round-trips through config get, list, and set.

Evidence labels

WasQA ledgers had four evidence labels and no defined treatment for analytics findings.

Nowa read-only sweep runs first with --reporter when configured; six-field TSV findings become eyewitness/telemetry rows, and the header records configured or not configured.

03

Memory and context delivery

Turn-context fallback

Wasthe UserPromptSubmit hook was the only delivery path for ambient recall, supervisor reminders, and factory inbox context.

NowPostToolUse and MCP response paths share a once-per-prompt turn-context receipt, using a local-only recall path that does not wait on the cloud when the prompt hook is silent.

Ambient ranking

Wasan eight-row recency window could omit a same-day nine-term match, the 400 ms semantic budget was too short, and unbound history could outrank guidance.

Nowoverlap-first discovery, a 16-term cap, a 1,500 ms semantic deadline, strong lexical evidence, and at most one history commit keep relevant guidance in front.

04

Release controls

One workspace suite

Wasin-tree nextest and the archive row repeated almost the same workspace execution.

Nowthe nextest row covers the snapshot complement and the archive row executes the workspace once, preserving coverage without duplicate execution.

Reuse without authorization drift

Wasa one-line release fix required a full re-gate and there was no content-keyed unchanged-tree reuse.

Now--reuse restores eligible PASS rows by exact content inputs while the pipeline still requires its own exact-SHA gate receipt.

05

Doctor observability

Hook-silence row

Wasprompt-hook silence had no durable operator-facing count.

Nowcas doctor reports the silent-hook condition and the number of observed misses, making a missing invocation diagnosable rather than inferred from an empty prompt.
