# Brief: Cassy v3.22.0 release report

## Single idea

One verified close and four capability surfaces show a release process that can assemble, gate, and explain its own evidence.

## Hero form

Verdict plus a directly labelled unit-dot plot. Verification is the only issue-bearing surface, so its single equal-area dot supports the claim without implying that Release, Memory, or Factory are less important. The other three surfaces are explicitly zero-closure capabilities.

The graph is an accounting of closures, not a proxy for effort, importance, or impact. Product-surface order is Release, Memory, Verification, Factory, matching the v3.22.0 announcement themes and the report's sections.

## Emotional register

Assured, humane, collected: sandstone paper, regular serif verdict, system sans reading text, mono folio, quiet rules. The project has no root `DESIGN.md`; the report uses `docs/design/petrastella-design-language.md` and maps `docs/design/design-tokens.json` into the renderer's light/dark roles. No network font loads.

## Distinctive move

The closure stitch is deliberately sparse: one indigo verification dot beside three labelled zero rows. It keeps the closure evidence honest while the Was → Now sections carry the broader release argument. One decorative six-point stitch returns beside Install.

## Deliberately omitted

No KPI cards before the argument, logo band, network assets, invented comparison metrics, or subjective severity bubbles. The receipts do not prove a fresh archive download or installed-binary rerun, so the report does not infer either.
