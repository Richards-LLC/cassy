Release reports

First run is the real report

Wasthe command's first run lost project settings from a secondary checkout, cut wrapped sentences, wrote placeholder "Was" lines, missed closed issues, called a live release unpublished, and opened with a generic line.

Nowit reads settings from any checkout, keeps sentences whole, tells the Was → Now story from your release notes, counts closed issues, shows the publication time, opens with the release headline, and groups changes the way the notes do.

PDF without setup

Wasthe PDF step stopped when the browser module was missing.

Nowit fetches a disposable copy and continues.

Nowit names the projects that did not refresh and the command to rerun.
