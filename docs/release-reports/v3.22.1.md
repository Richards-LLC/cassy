## What you can do now

### Release reports

#### First run is the real report

Was: the command's first run lost project settings from a secondary checkout, cut wrapped sentences, wrote placeholder "Was" lines, missed closed issues, called a live release unpublished, and opened with a generic line.

Now: it reads settings from any checkout, keeps sentences whole, tells the Was → Now story from your release notes, counts closed issues, shows the publication time, opens with the release headline, and groups changes the way the notes do.

#### PDF without setup

Was: the PDF step stopped when the browser module was missing.

Now: it fetches a disposable copy and continues.

### Updates

#### Refresh receipt kept

Was: after an update, Cassy could say the refresh outcome was unknown even though it had just printed which projects failed.

Now: it names the projects that did not refresh and the command to rerun.

### Quality of the checks themselves

#### Guardrails travel with the skill

Was: a change to a built-in skill could pass its own checks and still fail a release check minutes later.

Now: the hand-off proof includes the guardrail tests that read that skill.

#### No more racing test

Was: one pairing test could fail a release check by racing its own throwaway server.

Now: it waits for readiness and names the address if anything is refused.

#### Guidance parked, not lost

Was: three pieces of coordinator guidance survived only in a start-up prompt after a size trim.

Now: they live in a reference page the playbook points to.


## Under the hood

### Release changes

#### Sources

Was: `acquire_sources` read `project_root/.cas`; `parse_changelog_section` split bullets per line; `was_now_sections` hard-coded a placeholder Was for both audiences.

Now: `find_cas_root_from` + `[project].canonical_id`; continuation lines joined; draft Was/Now articles partitioned User/Dev with changelog fallback; inline-code headings preserved.

#### Evidence

Was: `closingIssuesReferences` only, publication from release metadata only, top-levels rendered as articles, fixed `THEME_ORDER`.

Now: PR body refs extracted and verified; `PUBLISHED_AT` from the receipt or release object; the User punch is the normalized verdict; themes derive from the draft's bold groups and persist in front matter.

#### PDF

Was: exit on `require('playwright')` failure.

Now: disposable `npm install --no-save playwright` and retry.

#### Receipt transport

Was: plain post-swap child with inherited stdio, every exit 1 → `refresh_failed_no_receipt`.

Now: hidden `--refresh-receipt <file>` carries `project_refresh_receipt_json` (with `refresh_status`) back to the parent on both paths; version probe kept for older children.

#### Scoped proof

Was: builtin skill/reference/agent paths were invisible to `--proof`.

Now: drift, agent-contract, and guardrail targets required, plus discovery by source and installed catalog spelling; rg errors fail closed; failure-log learn with self-test.

#### Pairing fixture

Was: client raced the listener's first `accept()`.

Now: readiness channel, bounded accept/read, address-bearing diagnostics; 50/50 under load.

#### Reference

Was: reporting/release-train/routing text trimmed from the body.

Now: `cas-supervisor/references/reporting-and-routing.md` in three flavors with catalog entries and a breadcrumb.
