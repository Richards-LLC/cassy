What you can do now

02 / 06
01

Safer coordination

Clear identities

Wasone exact identifier was required.

Nowstart, claim, and close accept a name or ID.

Supported messages

Wascoordination could use the wrong transport.

Nowmessages stay on the supported path.

Gate ownership

Wasonly one owner could finish a gate.

Nowauthorized reviewers can finish it and get a clear ownership warning.

Bounded completion

Waslarge completion checks could wait too long.

Nowchecks finish within a limit and safely show unfinished work.

Retryable proof

Wasa close retry could lose approved evidence.

Nowthe approved evidence is reused when the proof is still valid.

Merged results

Wasproof could point at an old result after a merge.

Nowit follows the result that was actually published.

02

Clearer recovery

Credential settings

Wasvariable placeholders could fail silently.

Nowvalues and defaults expand, and missing required settings explain the fix.

Hub recovery

Wasa stuck hub could block a restart.

Nowstartup is transactional, forced recovery restores service, and health checks explain the remedy.

Fresh notices

Wasold assignment notices could reappear.

Nowthey disappear once the work has started or finished.

03

Protected execution

Profile write-through

Wascredentials in linked profiles did not reliably follow the profile.

Nowconfigured credentials and linked profile updates stay in sync.

Whole-process stopping

Wasstopping a service could leave its children running.

Nowthe complete process group is stopped and checked.

Accurate proof targets

Wastest data could point proof at the wrong target.

Nowdeclarations identify the target precisely.

Oversized entries

Wasoversized history entries could remain quarantined.

Nowthey are shortened, retried, and recorded as recovered.

Protected image credentials

Wasimage-service keys could appear in command details.

Nowthe key is sent through a protected temporary header file.

Under the hood

03 / 06
01

Lifecycle contracts

Assignee identities (#799)

Waslifecycle calls required one identity form.

NowUUID and name resolve to the same assignee. Commit 42ae8311.

Message routing (#793)

Wassupervisors could use the host SendMessage transport.

Nowsupervisor coordination uses the CAS message path. Commit 86db4c81.

Gate ownership (#800)

Wasworker-assigned gates could not be closed by the supervisor.

Nowsupervisor closure is supported and cross-owner assignment warns. Commit c34f25e3.

Epic close (#802)

Wasclose evaluated children with unbounded repeated probes.

Nowbatched probes are bounded and partial evaluation fails closed. Commit d53e32d0.

Close retry (#755)

Wasretrying could mint a new dispatch and orphan an approved verdict.

Nowsuperseded dispatches preserve the approved result. Commit 9d7e1b49.

Post-merge proof (#753)

Wasproof could bind to a stale worker checkout.

Nowpost-merge verification binds to the published target head. Commit 9d7e1b49.

02

Runtime recovery

Proxy variables (#803)

Wasproxy configuration treated ${VAR} as literal text.

Now${VAR} and ${VAR:-default} expand, with missing_credential_env for required gaps. Commit 0a16d12e.

Hub startup (#804)

Wasa lock holder could strand startup between auth, bind, and recording.

Nowstartup is transactional and --force recovers wedged holders with a doctor remedy. Commit 219a033b.

Assignment delivery (#756)

Wasdelivered assignment boilerplate could replay after state changed.

Nowdirect, queued, MCP, and hook paths revalidate task state. Commit c43b112e.

Credential profiles (#758)

Wasisolated processes missed credentials from configured files and linked profiles.

Nowcredential discovery and symlink write-through are preserved. Commit 87614f4a.

03

Execution and proof

Process groups (#796)

Wasstopping a registered PID could leave nested watchers alive.

Noweach service has a dedicated group and stop verifies no survivors. Commit fc40166a.

Scoped proof (#778)

Wassource-path strings could claim integration-test ownership.

Nowexact targets and module declarations determine ownership. Commit 67733a3b.

Embedding recovery (#805)

Wasprovider-size failures quarantined units permanently.

Nowoversized units are truncated, retried, and marked with a recovery receipt. Commit d386dc56.

Image credentials (#757)

Wasthe API key appeared in curl arguments.

Nowa mode-600 header file carries the key without exposing it in argv. Commit 5dabbdcc.
