What you can do now

02 / 06
01

Supervisor conversations

Conversations first

Wasthe Hub opened on a wall of terminal panes.

Nowit opens on a Cassy Cloud-branded list of supervisor conversations, one per supervisor, each with a prominent project badge.

Real words

Wasreading a supervisor meant scrolling a terminal on a phone.

Nowthe conversation shows the supervisor's actual text, readable on 390 px, with the terminal one tap away as an alternate view.

Addressed send

Wasit was easy to send to the wrong pane.

Nowthe Send button names the supervisor it goes to.

Delivery states

Wasa sent message just disappeared.

Noweach bubble moves from sending to delivered to replied, and a refused message is marked rejected on that bubble.

02

Verified operator channel

Your identity

Wasa supervisor could not tell your message from agent traffic and ignored it.

Nowmessages from your paired device carry a verified operator stamp and supervisors treat them as you speaking.

Replies come back

Wassupervisor answers stayed in the terminal.

Nowthe reply is routed to the device you sent from and queued if it is offline.

03

Factory truth

Worker liveness

Wasstatus lines could say a worker was running when it was idle or dead.

Noweach worker shows executing, waiting for input, stalled, or dead with the evidence behind it.

Safer workers

Wasa worker could edit or commit inside your main checkout.

Nowwork outside its own worktree is blocked.

Fewer stuck closes

Wasa finished task could be impossible to close when its branch tip was a merge.

Nowclose verifies the task's real changes and says exactly what it compared.

04

Setup and pairing

Pairing on a Mac service

Wasfollowing the CLI's own advice could not pair a phone.

Nowstartup no longer wedges on the Tailscale app, restart understands launchd, and every error names the one command to run next.

Profile pickers

Waspicking a Codex profile could launch the wrong harness.

Nowthe picker launches exactly what the explicit profile launches.

Under the hood

03 / 06
01

Hub and Commander

Conversation UI

Washub-web defaulted to the terminal view.

Nowconversation list, per-supervisor thread over the real pane transcript, addressed composer, desktop context rail, Cassy Cloud brand section in hub-web/DESIGN.md; terminal is an explicit alternate. Playwright journeys for exact pane text, send, ack, reply, rejection, terminal return.

Operator stamping

WasSendMessage from a paired device carried no provenance.

NowQueueOrigin::PairedDevice plus OperatorStamp columns; the [cas #id operator <name>@<device> verified] header carries user authority in the supervisor skill.

Reply path

Wasno route from a supervisor back to a device.

Nowcoordination action=message target=operator in_reply_to=N → DaemonMessage::OperatorReply filtered to the authenticated device, with delivery receipts and offline queueing (m218 recipient transport table).

Send acknowledgment

Wassocket submission was the only signal.

NowSendMessage.client_ref → DaemonMessage::MessageQueued { client_ref, notification_id, target, stamped } relayed to the submitting device; legacy and multiplex refusals keep client_ref.

02

Factory

Worker liveness

Wasworker_status reported turn starts and heartbeats; Codex task_complete was never parsed.

Nowliveness: executing | waiting_for_input | stalled | dead from a bounded tail read of the rollout/transcript plus process state; five-worker summary poll measured under 20 ms; director relays share the source.

Workspace contract (#816)

Wasthe git-scope guard consulted only CAS_CLONE_PATH, so Edit and cd <primary> && git … from isolated workers passed.

Nowthe registered worktree root is authoritative for Edit/Write/MultiEdit and git add/commit/reset/checkout/push; denials name the assigned worktree.

Close verification (#818, #819)

Wasa merge-commit tip had no first-parent tree effect and close rejected; reachability errors were opaque.

Nowcontent proof walks the task's non-merge commits; rejections name the commit, evidence source, resolved ref and local-vs-origin; supervisor_override semantics are stated.

Risk declarations

Wasrelease blockers surfaced serially at the gate.

Nowrisk is required at create (none, blast-radius, platform, concurrency), enforced at close with proof-target checks, and every epic merge triggers a workspace sweep; gate rows equal CI rows.

03

CLI

Hub pairing on launchd (#817)

Wascas hub serve shelled out to the Tailscale bundle unconditionally and could wedge before bind; restart fought KeepAlive.

Nowprobe is gated behind --tailscale-serve, uses TAILSCALE/PATH only, writes hub.log first; restart uses launchctl/systemctl when supervised; service install --tailscale-serve refuses with the working alternative; pairing errors distinguish consumed codes; doctor row added.

Profile pickers (#820)

Wasthe picker did not carry the selected profile dir into the supervisor spec.

NowFactoryArgs.supervisor_config_dir is populated for picker and explicit paths on both cas codex and cas claude, with parity tests.

Skill friction (#810)

Wasunknown skill names failed cold.

Nownearest-match suggestions, ~/.local/bin on spawned agent PATH, doctor flags divergent duplicate skill copies.
