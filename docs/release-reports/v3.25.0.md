## What you can do now

### Supervisor conversations

#### Conversations first

Was: the Hub opened on a wall of terminal panes.

Now: it opens on a Cassy Cloud-branded list of supervisor conversations, one per supervisor, each with a prominent project badge.

#### Real words

Was: reading a supervisor meant scrolling a terminal on a phone.

Now: the conversation shows the supervisor's actual text, readable on 390 px, with the terminal one tap away as an alternate view.

#### Addressed send

Was: it was easy to send to the wrong pane.

Now: the Send button names the supervisor it goes to.

#### Delivery states

Was: a sent message just disappeared.

Now: each bubble moves from sending to delivered to replied, and a refused message is marked rejected on that bubble.

### Verified operator channel

#### Your identity

Was: a supervisor could not tell your message from agent traffic and ignored it.

Now: messages from your paired device carry a verified operator stamp and supervisors treat them as you speaking.

#### Replies come back

Was: supervisor answers stayed in the terminal.

Now: the reply is routed to the device you sent from and queued if it is offline.

### Factory truth

#### Worker liveness

Was: status lines could say a worker was running when it was idle or dead.

Now: each worker shows executing, waiting for input, stalled, or dead with the evidence behind it.

#### Safer workers

Was: a worker could edit or commit inside your main checkout.

Now: work outside its own worktree is blocked.

#### Fewer stuck closes

Was: a finished task could be impossible to close when its branch tip was a merge.

Now: close verifies the task's real changes and says exactly what it compared.

### Setup and pairing

#### Pairing on a Mac service

Was: following the CLI's own advice could not pair a phone.

Now: startup no longer wedges on the Tailscale app, restart understands launchd, and every error names the one command to run next.

#### Profile pickers

Was: picking a Codex profile could launch the wrong harness.

Now: the picker launches exactly what the explicit profile launches.


## Under the hood

### Hub and Commander

#### Conversation UI

Was: hub-web defaulted to the terminal view.

Now: conversation list, per-supervisor thread over the real pane transcript, addressed composer, desktop context rail, Cassy Cloud brand section in `hub-web/DESIGN.md`; terminal is an explicit alternate. Playwright journeys for exact pane text, send, ack, reply, rejection, terminal return.

#### Operator stamping

Was: `SendMessage` from a paired device carried no provenance.

Now: `QueueOrigin::PairedDevice` plus `OperatorStamp` columns; the `[cas #id operator <name>@<device> verified]` header carries user authority in the supervisor skill.

#### Reply path

Was: no route from a supervisor back to a device.

Now: `coordination action=message target=operator in_reply_to=N` → `DaemonMessage::OperatorReply` filtered to the authenticated device, with delivery receipts and offline queueing (m218 recipient transport table).

#### Send acknowledgment

Was: socket submission was the only signal.

Now: `SendMessage.client_ref` → `DaemonMessage::MessageQueued { client_ref, notification_id, target, stamped }` relayed to the submitting device; legacy and multiplex refusals keep `client_ref`.

### Factory

#### Worker liveness

Was: `worker_status` reported turn starts and heartbeats; Codex `task_complete` was never parsed.

Now: `liveness: executing | waiting_for_input | stalled | dead` from a bounded tail read of the rollout/transcript plus process state; five-worker summary poll measured under 20 ms; director relays share the source.

#### Workspace contract (#816)

Was: the git-scope guard consulted only `CAS_CLONE_PATH`, so `Edit` and `cd <primary> && git …` from isolated workers passed.

Now: the registered worktree root is authoritative for Edit/Write/MultiEdit and git add/commit/reset/checkout/push; denials name the assigned worktree.

#### Close verification (#818, #819)

Was: a merge-commit tip had no first-parent tree effect and close rejected; reachability errors were opaque.

Now: content proof walks the task's non-merge commits; rejections name the commit, evidence source, resolved ref and local-vs-origin; `supervisor_override` semantics are stated.

#### Risk declarations

Was: release blockers surfaced serially at the gate.

Now: `risk` is required at create (`none`, `blast-radius`, `platform`, `concurrency`), enforced at close with proof-target checks, and every epic merge triggers a workspace sweep; gate rows equal CI rows.

### CLI

#### Hub pairing on launchd (#817)

Was: `cas hub serve` shelled out to the Tailscale bundle unconditionally and could wedge before bind; `restart` fought `KeepAlive`.

Now: probe is gated behind `--tailscale-serve`, uses `TAILSCALE`/`PATH` only, writes `hub.log` first; `restart` uses launchctl/systemctl when supervised; `service install --tailscale-serve` refuses with the working alternative; pairing errors distinguish consumed codes; doctor row added.

#### Profile pickers (#820)

Was: the picker did not carry the selected profile dir into the supervisor spec.

Now: `FactoryArgs.supervisor_config_dir` is populated for picker and explicit paths on both `cas codex` and `cas claude`, with parity tests.

#### Skill friction (#810)

Was: unknown skill names failed cold.

Now: nearest-match suggestions, `~/.local/bin` on spawned agent `PATH`, doctor flags divergent duplicate skill copies.
