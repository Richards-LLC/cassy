What you can do now

02 / 06
01

Keep work moving

Type in the hosted terminal with the cursor in view

Wasa focused terminal harness could hide its cursor or leave it at the wrong position in the Cassy pane.

Nowthe focused pane follows the child terminal's cursor position, visibility, and shape through redraw and resize. Unfocused panes and modal behavior remain suppressed as intended.

Let rolling checks cross midnight

Wasa long-running factory daemon could keep watching yesterday's UTC log and miss newly written merge events.

Nowrolling integration follows the current UTC session log, retains incomplete lines, filters by session, and processes each matching merge event once.

Scope limits: a separate local all-project refresh returned cloud project_not_found, so no host-wide pass is claimed. No report upload or v3.25.7 Slack post is evidenced; v3.25.6 receipts are historical. The PDF is untagged; screen-reader behavior is untested.

Under the hood

03 / 06
01

Hosted terminal rendering

Preserve the child's current cursor state

Wasa cursor emitted by the child could remain hidden in the pane buffer or be absent or displaced in the host terminal.

Nowthe published rendering path forwards the focused PTY cursor position and style to the host, while focus and modal state continue to control visibility. The accepted geometry check used a rebuilt Cassy binary and a deterministic local child through hosted rendering. This is not evidence of an authenticated Codex or Claude session.

02

Rolling integration recovery

Follow dated session logs

Wasa daemon could keep polling only the UTC-date log it opened at startup, missing later merge events after midnight.

Nowthe coordinator follows dated session logs through the current UTC day, retains partial JSONL records until complete, filters events to its factory session, and processes each matching merge once.

Recover a missed integration through the real sweep

Wasafter rollover left an integration receipt stale, there was no bounded one-shot path to recover the focused epic without restarting a live factory session.

Nowthe hidden cas factory integration-recover command accepts only the live registered supervisor bound to the active factory session, same Git project, and focused epic. It constructs the production rolling-integration coordinator in a fresh process and runs the real sweep; it refuses when sweeps are disabled or another sweep is active, caps recovery at four times the configured sweep timeout and four hours, and reports success only for a passing receipt.
