## What you can do now

### Only reply:

#### Reports you can open

Was: a finished report sat in a folder you had to go find. →

Now: it is recorded with its size and fingerprint and can be handed to you directly.

#### Messages meant for you

Was: an update only reached you if you had asked a question first. →

Now: a status, an outcome, a question or a hold can reach you as it happens, each marked for what it is.

#### Your open issues stay visible

Was: your session summary quietly dropped the list of open issue titles when other guidance grew. →

Now: the titles stay and the boilerplate shrinks instead.

#### Passwords stay hidden

Was: a sign-in token could be written into an error message or log. →

Now: it is replaced with a placeholder everywhere, with a check that keeps it that way.

#### Faster doc changes

Was: a documentation-only change waited on the full build. →

Now: it runs a short text check and lands in minutes.

#### Clearer setup warnings

Was: a mismatch between this machine and its cloud record stayed silent until syncing failed. →

Now: the checkup names it and prints the exact line to fix.


## Under the hood

### Only reply:

#### Artifact publish

Was: no durable record for a produced file. →

Now: `cas artifact publish|show|list` plus the MCP tool records size and SHA-256, refuses escaping symlinks and `.cas`/`.git`, caps at 25 MiB before any request, and falls back to local-only when Cloud storage answers 404/501.

#### Operator turn kinds

Was: `target=operator` required `in_reply_to`, so only answers could reach the hub. →

Now: payload v2 carries `kind` and `attachments`; unprompted kinds route to the latest verified device, v1 still decodes.

#### SessionStart budget

Was: protected guidance grew and the assembler compacted the issue-triage evidence instead. →

Now: the Codex note is degradable and a pin fails the build when guidance leaves under 2400 B of the 9216 B budget.

#### Credential redaction

Was: fourteen structs derived `Debug` over a live bearer, API key or pre-signed URL. →

Now: each redacts, with a repo-wide guard test that resolves its tree at runtime.

#### Docs-only CI tier

Was: every docs change ran the full required tier. →

Now: a classifier routes docs-only events to `Docs Lint`, which lints only Markdown; required contexts still report.

#### Close gate

Was: expected proof base came from the current checkout, so a merged-before-close delivery was unprovable. →

Now: it comes from the delivery's first parent, and a supervisor can widen proof targets in one reasoned call.

#### Doctor

Was: alias checks passed while the git remote matched neither canonical id nor alias, and `--fix --json` emitted two documents. →

Now: drift is a warning with the exact remediation, identity conflicts count separately, and the JSON is one document.
