## What you can do now

### Only reply (user)

#### Formatted replies

Was: bold, bullets and code arrived as raw symbols in one paragraph. →

Now: the hub renders them as real formatting, in live replies, replayed history and pinned questions; list previews stay plain.

#### Short answers

Was: a status question could get a thousand-character essay. →

Now: Cassy answers first, then a few one-line bullets with the decision in bold, unless you ask for detail.

#### Talk to type

Was: a wide "Tap to talk" button squeezed the text box to a sliver. →

Now: a small mic that lights while listening; tap again and your words land in a roomy text box to review before sending.

#### History that shows up

Was: reopening a conversation could show nothing and a "waiting" label. →

Now: the hub asks every current machine for the thread on open, labels an idle pane "No activity yet", and records enough to trace any reply that still goes missing.


## Under the hood

### Only reply (dev)

#### Renderer

Was: paragraphs() split on blank lines. →

Now: hub-web/src/markdown-renderer.ts builds bold, italic, inline/fenced code, one-level nested lists, headings-as-lead-lines and https-only links as DOM nodes; XSS fixtures keep script tags, entities and javascript: links literal (PR #930).

#### Reply contract

Was: no guidance on phone replies. →

Now: cas-supervisor/references/operator-reply.md on all three harness catalogs, pointed to from the Commander-row inbox framing; pinned by tests inside the SessionStart headroom floor.

#### Composer

Was: text button, standing status line. →

Now: icon-only mic with aria-pressed, caret-anchored transcript insert, unsupported/denied states on the control; field ≥60% of a 390px row; keyboard-safe layout retained.

#### History

Was: request only when the Welcome capability list survived the relay; "waiting" for undated activity. →

Now: request on protocol ≥3, bounded hub tracing of forwarded requests and relayed response counts, "No activity yet".

#### Release train

Was: ten recorded interventions per cut. →

Now: merge-queue query shape validated with jq, env-file scratch base with the gate's mount rule, Zig directory link, prep version bump, publish ff-only, post-publication workflow wait plus receipts, announce.receipt thread ids, receipts mergeability wait, enqueue retry and idempotent resume; 162 self-test rows (PR #931). Generators emit lint-clean Markdown and the checkout-dependency guard derives its fixture list from the test tree (PR #929); the report poster picks the machine's registered MechaCassy token (PR #932).
