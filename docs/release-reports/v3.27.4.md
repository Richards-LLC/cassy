## What you can do now

### Only reply (user)

#### Landings are noticed

Was: after a change landed, nothing happened until someone looked. →

Now: Cassy picks it up at once and tells you if a step is still open five minutes later.

#### Second tasks start clean

Was: a second task could drag the first task's changes along with it. →

Now: the slate is reset, or you get the exact fix before anything starts.

#### Conflicts get resolved

Was: resolving a merge conflict could stall at the last step. →

Now: it completes on its own.

#### Releases cut cleaner

Was: the 3.27.3 release needed seven hand steps. →

Now: each of them is automated and self-tested.


## Under the hood

### Only reply (dev)

#### Daemon

Was: no view of delivery PRs. →

Now: PR numbers and merge commits recorded on the task; one typed assignee wake with the close command; supervisor relay after five minutes (PR #941).

#### Task start

Was: factory/<worker> kept prior commits. →

Now: reset when the prior delivery is merged, refuse with `git rebase --onto` otherwise; envelope carries commits_not_on_target_base (PR #938).

#### Guards

Was: commit guard refused detached rebase HEAD; checkout-read guard scanned only cas-cli/tests. →

Now: branch from rebase-merge/head-name (PR #939); every test-bearing source including lib cfg(test) modules (PR #942).

#### Release train

Was: receipts via docs PR; stale lockfile, wall-clock draft date, post-publish lint, enqueue race. →

Now: receipts commit on the release branch (PR #933); lockfile refresh, docs-only rebase, pinned run date, preflight lint, checks-aware enqueue (PR #940).

#### Integration

Now: ancestors skipped and base named (PR #936); one shared derivation, cached per close (PR #937).
