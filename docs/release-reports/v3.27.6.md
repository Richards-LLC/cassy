## Under the hood

### Only reply (dev)

#### Hub catalog

Was: `supervisor_sessions` default filter required `!workers.is_empty()`, hiding live supervisors with zero workers. →

Now: default lists every Live non-dormant supervisor session; `workers=1` and `dormant=1` reveals unchanged; tests pin staffed, empty-roster, worker-only, hung-empty and dormant rows (PR #952).

#### Renderer

Was: the legacy lead regex required two-digit minutes, so "Status 13:2xZ." never restructured; empty threads showed the end marker. →

Now: lead matches the real text; empty threads render the empty state (PR #951).

#### Release train

Was: assemble self-heal's integration-recover refused without the recorded supervisor identity; post-publication lacked the date helper. →

Now: recorded identity passed to recovery; helper sourced (PR #950).
