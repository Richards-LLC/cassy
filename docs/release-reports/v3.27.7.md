## What you can do now

### Only reply (user)

#### One question, once

Was: a question waiting on you appeared twice. →

Now: it sits once above the message box, with a short pointer in the conversation.

#### Long updates read well

Was: a long status update spilled out of its bubble in the quietest style. →

Now: it reads as a normal reply; short ones fold with "Show full update".

#### Failed sends are obvious

Was: a message that failed looked sent. →

Now: it says "Not sent" with Edit and Retry, and the question stays open.

#### Clearer controls

Was: main buttons looked like a selected row and some hints were too faint. →

Now: main buttons stand out and every hint is readable.

#### Phone and dark mode

Was: the phone header took a fifth of the screen and dark mode glared. →

Now: a one-row header, calm dark colours, and a clear listening state on the mic.


## Under the hood

### Only reply (dev)

#### Thread

Was: pinned ask duplicated in flow; long statuses coalesced into a radius-999 pill. →

Now: collapsed ask pebble; statuses over 140 chars or with an ask render as supervisor bubbles; 3-line clamp with expand (PR #956).

#### History state

Was: answered()/waiting() counted refused sends. →

Now: refused sends never answer an ask or acknowledge a blocker; Retry keeps in_reply_to.

#### Tokens

Was: .primary on --bg-active (1.18:1); dark floods. →

Now: .primary on --you-bg (8.61:1); dark tint + 4px edge set; --bg-raised derived from canvas; placeholders --ink-mid.

#### Layout

Was: 121px phone thread header; 240px desktop rail repeating the header. →

Now: 56px header; rail folds to 48px unless it has asks, progress or attachments.

#### QA

Was: fixtures hand-copied composer/pairing markup; Playwright picked by readdir order. →

Now: production markup builders; highest stable Playwright, version printed; pebble-qa 160/160, polish-qa 6/6.

Was: n/a. →

Now: `cas-x86_64-unknown-linux-gnu.tar.gz` `73f9c4b50a472f5c39872ccb3e9b772abc7afc2447f5b70c3e79afd170c1188c`; `cas-aarch64-apple-darwin.tar.gz` `1cdd78fcd3d82d509411afb46e755374d37c3a65c917c21d70b8c9eaef852e47`.
