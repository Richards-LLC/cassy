## What you can do now

### Only reply (user)

#### Clear selection

Was: the selected conversation and the active machine were marked by a faint shade. →

Now: each has a bold coloured edge in light and dark.

#### Fewer false alarms

Was: Cassy sometimes asked for work to start that was still waiting on something else. →

Now: it only suggests work that can actually start.

#### Smoother updates

Was: an update could stall while being prepared, or finish without being installed on the machine. →

Now: it installs itself and confirms the new version is running.

### Only reply (dev)

#### hub-web

Was: .conversation-row[aria-current] and .machine-icon.active marked by a fill only (1.16–1.39:1). →

Now: 3px var(--accent) edge bar, ≥3:1 in every accent set, pinned by machine-accent.test.ts; harness scores selected states by their best cue (PR #960).

#### Factory

Was: supervisor_stalled AssignReadyWork named Open tasks behind an open requires_start dependency. →

Now: DirectorData.start_gated_task_ids excludes them, same predicate as task start (PR #959).

Now: heal runs unlocked then revalidates; release-host-update.py installs and proves cas --version, hub version and refresh_binary_version (PR #958).
