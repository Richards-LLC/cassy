## What you can do now

### Only reply (user)

#### Newer models

Was: everyday coding ran on GPT-5.6 Luna and planning on Fable 5.1. →

Now: coding runs on GPT-6 Sol; planning, design and hard problems run on Claude Opus 5.5.

#### Haiku retired

Was: small chores ran on Claude Haiku. →

Now: they run on GPT-6 Luna, and Haiku is not used anywhere.

#### Faster session end

Was: ending a session could pause while summaries and reviews ran. →

Now: they run in the background after the session ends.

#### Claude Code check

Was: nothing told you when Claude Code was out of date. →

Now: Cassy warns below 2.1.280 and suggests `claude update`.

#### Better browser testing

Was: Cassy's testing guidance was several Playwright versions old. →

Now: it follows Playwright 1.63, checks accessibility modes and loading, error and empty states.


## Under the hood

### Only reply (dev)

#### Lane registry

Was: standard gpt-5.6-luna/xhigh, supervisor and taste claude-fable-5-1/medium, heavy gpt-6-astra/high, light claude-haiku. →

Now: standard gpt-6-sol/medium (fb gpt-6-luna/xhigh), supervisor/taste/heavy claude-opus-5-5/high (fb fable-5-1/high, opus-5/high, gpt-6-astra/high), light gpt-6-luna/xhigh (fb opus-5-5/low) (PR #964).

#### Haiku removed

Was: claude_haiku recipe plus Haiku defaults in daemon, hooks, init and extraction. →

Now: recipe deleted; registry, slug and spawn validation reject Haiku with a light-lane pointer (PR #964).

#### Maintenance jobs

Was: Stop blocked and asked the parent session to spawn Haiku subagents. →

Now: Stop queues light-lane one-shot Codex jobs (flock-serialized, 300 s cap); daemon extraction uses the same runner (PR #964).

#### Claude conformance

Was: no Claude Code live matrix or receipt. →

Now: claude-code-2.1.280 receipt (11 pass, 2 not_covered); preflight/doctor warn below the pin (PR #964).

#### Codex matrix

Was: pinned to suspended gpt-5.6-terra, two trivial cs calls. →

Now: follows the standard-lane recipe, complex-schema check, budget_aborted liveness, request_user_input disabled for workers (PR #964).

#### Playwright skills

Was: nuxt-playwright predated 1.56 (networkidle, no aria snapshots) and there was no managed debugging skill. →

Now: builtin cas-playwright-debug (trace CLI, --debug=cli, locks, isolated retries); nuxt-playwright and frontend-engineering on 1.63 idioms.

#### Release workflow

Was: commit-subject notes were pasted into a shell string, so a quoted subject broke v3.28.0 publishing. →

Now: notes go through a file; run blocks carry no GitHub expressions, enforced by lint and a gate row (PR #966).

#### Assets

Was: n/a. →

Now: `cas-x86_64-unknown-linux-gnu.tar.gz` `d449343612e14fbab52f4139696ec77062233172bae48cbb31f8cf41f1d6c5d7`; `cas-aarch64-apple-darwin.tar.gz` `588b2cd51533b3783ab0f9aad8a599fb88229e17be4133fe335e934329562b37`.
