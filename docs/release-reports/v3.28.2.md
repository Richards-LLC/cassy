#### Hub journeys

#### Palette filter

Was: .palette-command display:grid overrode [hidden]. →

Now: hidden rows hide, session matches sort first, HUB-J3 asserts it.

#### Palette keyboard and focus

Now: Enter closes and jumps, keyboard/mouse jumps focus the composer (touch does not), render() treats focus in the open palette as composing, and open resets the filter.

Now: ButtonBorder rows, CanvasText dialog edge, an inset ring, and an open-session Highlight fill that survives hover (8.73:1 minimum).

Now: nested modules are qualified, with tests (PR #972).

#### Ledger grammar
