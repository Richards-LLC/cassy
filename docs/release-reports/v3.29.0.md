## What you can do now

### Only reply (user)

#### Hub comes back after update

Was: a stuck or crashed hub stayed down after `cas update`, and Commander showed "Degraded". →

Now: update stops it, restarts it with Tailscale, checks the public address, and tries once more if needed.

#### No needless restarts

Was: n/a. →

Now: a healthy, current hub is only checked, so updating doesn't drop your Commander session.

#### Honest status

Was: `cas hub status` said "exited" for a hub that was running but frozen. →

Now: it says exactly what state the hub is in and what to run.

#### Clean Tailscale routes

Was: a forced restart could leave your ts.net address pointing at nothing. →

Now: the dead route is cleaned up or taken back automatically.

#### Mac service

Was: a Mac hub service without Tailscale made `cas update` fail. →

Now: it's updated to add Tailscale, like on Linux.

#### Mac tools

Was: image generation, drawings and background jobs broke on a stock Mac. →

Now: they work with the built-in macOS tools.

#### Commander shows every reply

Was: the Commander thread stayed blank unless you'd messaged first. →

Now: every reply from your session shows up there automatically.


## Under the hood

### Only reply (dev)

#### Update hub convergence

Was: `restart_stale_hub` returned early when `record_is_live` was false, so a wedged hub was never touched. →

Now: the new binary's post-swap child classifies the prior state and force-stops a wedged holder. It restarts with the recorded or receipted Tailscale setting and checks the lock, loopback /v1/health, the Serve route to the live shim and the public /v1/health. On failure it saves evidence and recovers once. A current healthy hub is `verified` without a restart, and a public-DNS-only failure is a warning. Tested against real v3.27.8, v3.28.1 and v3.28.2 hubs in 4 states each, 12 of 12 passing (PR #979).

#### launchd parity

Was: `restart_supervised` bailed on a plist without Tailscale. →

Now: the plist ProgramArguments are rewritten atomically, with bootout and bootstrap. It takes over from a detached or stuck no-phase holder, refuses ambiguous holders, and adds PATH to EnvironmentVariables (PR #979).

#### Lifecycle state

Was: one boolean readiness check drove every message. →

Now: `HubDisplayState` is exited, starting, startup_wedged, stopping, unresponsive or running, in text, `--json` and authorize (PR #979).

#### Serve ownership

Was: the receipt was written after `serve --bg`, and the process record was overwritten before `ensure`. →

Now: the receipt is written before publishing, the prior target is passed to the replacement, and a dead loopback shim on a Cassy-receipted port is reclaimed (PR #979).

#### macOS suite

Was: 96 failures running the full nextest suite on macOS. →

Now: 9788 of 9789 pass in each of two loops (two separate timing-sensitive flakes are tracked). Includes a shared `warm_stub` for dyld first-launch stalls, BSD socket and `/private/var` fixes, a Rust flock/timeout for light-lane jobs, and unknown-safe Mac worker liveness with a proc_pidpath kill check (PR #979).

#### Commander mirroring

Was: Commander history held only Commander-sent messages and explicit target=operator rows. →

Now: the factory daemon tails the supervisor transcript (Claude and Codex) and queues each completed turn's final text as a schema-2 operator reply. It is an answer with reply_to when a verified Commander message started the turn, otherwise a status to all devices. Text is redacted, capped at 4,000 characters and deduped by turn key, and it only starts after first pairing (PR #983).

#### Close gate

Was: a red base on the host blocked every close, the parked-task anchor followed branch reuse, and the parser read "failure" in test names as failures. →

Now: an audited inherited-failure close path, frozen parked anchors, and structured result parsing that accepts short bases (PRs #974, #975, #977).

#### Assets

Was: n/a. →

Now: `cas-x86_64-unknown-linux-gnu.tar.gz` `5a50078e73aa465fac235780f16586250b1e580a523994ed853a4a0c4eca0a08`; `cas-aarch64-apple-darwin.tar.gz` `370c6e0776d641cefeb8265aae3ae5d5a72f9b13bd33301c89f52bbaea6b9445`.
