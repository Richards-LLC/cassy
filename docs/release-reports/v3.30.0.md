## What you can do now

### Only reply (user)

#### Names and layout

Was: long machine and supervisor names ran under timestamps or were cut off. →

Now: they wrap or shorten cleanly in the list, header, picker and Send button.

#### Phone

Was: the "Jump to latest" chip and the "connected" toast covered messages and the header. →

Now: both sit clear of the thread, and the session picker shows every session's details.

#### Keyboard

Was: some routes dropped focus onto the page, so the next Enter did nothing. →

Now: focus always lands where you expect, including after the page refreshes.

#### Colours

Was: a new machine could re-colour the others, and high-contrast mode lost the selected row. →

Now: each machine keeps its colour, and the selected row stays highlighted.

#### Outages

Was: during a connection drop the whole conversation faded until it was hard to read. →

Now: only the terminal dims; the conversation stays readable.

#### Tasks stay yours

Was: a sync from another project could overwrite one of your tasks when the IDs matched. →

Now: your tasks are never replaced by another project's.


## Under the hood

### Only reply (dev)

#### Commander polish

Was: the 2026-09-23 journey evaluation logged clipping, overlap, focus-to-body, re-colouring and forced-colour gaps. →

Now: all fixed, each with independent QA and a journey stage; the combined epic walk scored 7/8 cells, and the eighth (outage contrast) is fixed too (PR #1010).

#### Team pull

Was: pull stamped origin-less rows with the requested scope, so a foreign task sharing an ID replaced a local one. →

Now: those rows are parked, and an ID collision with a live local task is journaled and shown by `cas doctor` (PR #1010).

#### Merge lane

Was: a task moved into an epic kept its trunk target, and worktree_merge pushed it to main. →

Now: the move carries the epic lane, and an epic child that resolves to trunk needs allow_trunk (PR #1010).

#### QA and close gates

Was: a rejected QA round sometimes opened no next round, and a close after a handoff measured a branch that didn't exist. →

Now: round N+1 always opens, and close measures the branch holding the commits (PR #1010).

#### Store and guards

Was: task writes failed with "database is locked" under load, and a worker's Neon SQL could write to production. →

Now: writes take BEGIN IMMEDIATE with retry, and production-branch writes from workers are denied (PR #1010).

#### Test hygiene

Was: journeys could attach to another checkout's server, and the systemd restart test killed itself on hosts running a hub. →

Now: journeys use per-checkout ports and refuse a taken port, and the test uses a disposable child PID (PRs #1010, #1012).
