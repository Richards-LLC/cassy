What you can do now

02 / 06
01

Commander

Disconnected machines

Wasan offline session could still look live and offer controls that could not work. →

Nowits controls and live row disappear until it reconnects.

Messages

Wasa send could spin on “Sending…” forever, and a refused reply left you without a clear next step. →

Nowunconfirmed sends offer Retry, and refusals explain the next action.

Keyboard focus

Wastaking control or receiving a refusal could drop keyboard focus away from the action. →

Nowfocus stays on the message or its Retry action.

Conversation order

Wasa fast machine clock or a reload could shuffle recent turns. →

Nowthe conversation keeps the same order across reconnects and reloads.

Find your session

Wasan open session with no other activity could vanish from the list, picker or search. →

Nowit stays visible and counted.

Project context

Wasthe terminal, picker and search could make similar machine names hard to place. →

Noweach leads with its project, while long names stay readable.

Phone navigation

Wasa search jump could leave the keyboard or search panel in the way. →

NowEnter dismisses the keyboard and a jump closes the panel.

Small-screen polish

Wasnotices could cover headings, long hints crowded the composer, and actions were small to tap. →

Nownotices clear the content, hints shorten, and phone actions have larger targets.

Reports

Wasa report that failed to open gave the same vague error whether the online service failed or your machine did not answer. →

Nowthe message tells you which happened, and published reports open through a secure link.

Fleet summary

Wasa stray separator appeared before summary text and times. →

Nowthe summary reads cleanly.

02

Your data and updates

Team sync

Wassyncing a team project could mix in personal changes. →

Nowthat project syncs only with its team.

Memory handoffs

Wasan older handoff could compete with the current one. →

Nowthe current handoff is clear, and older ones remain available as history.

Violet

Wasconnecting Violet required using older integration names. →

NowViolet has its own integration and issue routing; the older names still work during this release.

Mac updates

Wasthe source updater could claim running Cassy programs were current without checking them. →

Nowit says verification is unavailable and names what to restart; it also finds existing source checkouts more reliably.

Mac releases

Waspreparing a release on a Mac needed extra command-line workarounds. →

Nowthe release tools handle the standard Mac commands.

01

Runtime and product

Commander state

Wasoutage paths retained live session rows, active control or ambiguous refusal actions. →

Nowone visibility rule hides stale controls, preserves focus, and offers Retry only when it applies.

Thread delivery

Wasclock skew, reloads and missing delivery receipts changed order or left Sending indefinite. →

Nowdurable turn order is stable and receipt grace ends in Not confirmed with Retry.

Navigation

Waspalette jumps, phone keyboards, long names and notices collided. →

Nowjumps clear the palette and keyboard; project-first labels, bounded hints and touch targets keep the route readable.

Reports

WasCloud failure and an unreachable machine shared one open error; published artifacts lacked a safe browser route. →

Nowerrors are distinct and signed team-scoped view URLs open published reports.

Team scope

Wasa team-linked project still did personal push and pull. →

Nowits sync stays in team scope and never runs the personal path.

Violet

Wasintegration and issue routing used legacy names. →

NowViolet has dedicated commands, settings and routes with one-release aliases.

Memory and recall

Washandoffs could accumulate as competing current entries and envelope-only terms could pollute recall. →

Nowone current handoff remains per project and role, while recall suppresses noise and surfaces domain-matched context.

02

Access and delivery

Runtime access

Wasreading runtime errors and logs required write-capable proxy access. →

Nowread-only access exposes those routes while writes remain denied.

Database branches

Wastask SQL could target a shared branch. →

Nowa disposable Neon branch can be scoped to one task with credentials held in its checkout.

Review rounds

Wasreset review tasks held a dead claim, and a new delivery tip could leave an old round open. →

Nowreset releases the claim for a replacement and a new tip retires the earlier round.

Close proof

Wasan inherited hub diff could demand unrelated visual evidence, and a proof refusal omitted later targets. →

Nowclose judges the task's own diff and names every required proof target.

Spawn briefs

Wasspawn_workers accepted prompt and silently dropped it. →

Nowit rejects that parameter before queueing and names the message route; a normal spawn receipt says no brief was delivered.

Assignment paths

Wasa path mentioned in prose could trigger an output warning for /. →

Nowthe warning requires an output instruction and ignores a bare slash.

Task recovery

Wasblocked tasks could not transfer by name, rebases could lose delivery attribution, and unrelated base failures could be blamed for a new test. →

Nowtransfer, attribution and integration probes use the actual task and failing test identity.

Notifications

Waslocal tags, stale branch runs and old inbox replays could trigger premature or irrelevant alerts. →

Nowtag checks use origin, red-run wakes require the current failed job, and the named message arrives first.

Evaluation and tests

Wasmidnight recency changed ranking between evaluation modes and fixed sleeps or host probes made test results vary. →

Nowboth modes share one clock and timing-sensitive fixtures wait on conditions in isolated environments.

Mac operations

WasLinux procfs checks produced a false verified turnover on macOS, and release scripts needed manual tool shims. →

Nowturnover reports unverified with restart targets and source lookup fallbacks, while the release train handles stock macOS tools.

Tag handoff

Wasa guarded release checkout failed late when publishing a tag. →

Nowit prepares the local annotated tag and stops before the audit with an explicit publication handoff.
