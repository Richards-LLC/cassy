What you can do now

02 / 06
01

Everyday use

Suggested commands

Washelp text could offer a command Cassy rejects. →

Nowevery suggested command is checked against what Cassy accepts.

Startup guidance

Wassession startup text could exceed its size limit and arrive as a preview. →

Nowit fits in full for every role.

Closing tasks

Wasclose checks could judge an older version of your change. →

Nowthey check the version you just delivered.

Command names

Wasmessaging and team control shared one tool. →

Nowteam control has its own tool; the old names still work this release.

02

Your installation

Updates

Wascas update left some skill files at their first version and kept retired ones. →

Nowit refreshes every file, keeps your edits, removes the rest.

Grok, OpenCode and Codex

WasGrok and OpenCode could load skills with commands they cannot run. →

Noweach gets a copy that works for it.

Instruction files

WasCLAUDE.md repeated the shared project instructions and grew past its limit. →

Nowthe shared file leads and CLAUDE.md imports it.

Project boundaries

Wasrules and notes from one project could land in another. →

NowCassy refuses them and keeps them out of sync.

Release notes skill

Wasit was called release-notes. →

Nowit is cas-release-notes, so it no longer clashes with a Grok command.

Under the hood

03 / 06
01

Prompts and tools

Call-shape lint

Wassuggested calls could omit summary, remind_message or dispatch_id. →

Nowa test checks every call in skills and runtime templates.

Tool split

Wascoordination shipped 61 params to every session. →

Nowfactory holds fleet, worktree, server, db, loop and queue; old names alias for one release.

SessionStart

Wasworker and supervisor payloads hit 11.8–13.2 KB, past the hook cap. →

Nowat most 9,216 B for every role, pinned by a test.

MCP schema

Wasone description passed the 2 KB cut and 16% of tools/list was boilerplate. →

Nowdescriptions ≤2,048 chars, action enums, no nullable noise.

Worker prompts

WasClaude workers in a Codex session got mcp__cs__ names. →

Nowprefixes resolve per recipient and one renderer builds every contract.

Close gates

Wasgates keyed off stale heads, so one sibling merge voided other dispatches. →

Nowthey use the current tip; platform proof defers to assembly.

02

Catalog, install and store

One skill tree

WasClaude, Codex and Grok catalogs were hand-kept twins. →

Nowbare tool names; Grok and OpenCode get project copies, Codex no .md agents.

Install sync

Wasnon-SKILL.md files never refreshed after first install. →

Nowevery file refreshes, removed files prune, and cas doctor reports parity.

Store guard

Wasanother project's rules and pages could be written, pulled or pushed here. →

Nowwrites are refused and sync keeps them out.

Verifier and Stop jobs

Wastask-verifier was 27.7 KB and session-learn parsed skill text. →

Now9.3 KB, a dedicated classifier, and rule action=promote.

Operator-data lint

Wasshipped skills carried real names and ids. →

Nowa lint keeps them synthetic.

Instruction files

Wasrepo CLAUDE.md duplicated AGENTS.md. →

NowAGENTS.md is canonical and CLAUDE.md imports it with Claude-only lines.
