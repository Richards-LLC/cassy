Everyday use

Why questions

Wasasking why code was built a certain way got a plausible guess. →

Nowthe cas-why skill answers from recorded history, rates each claim Documented, Inferred or Unknown, and lists where it looked.

Claims of done

Was"done" could mean tested or merely assumed. →

Nowevery claim is VERIFIED, NOT VERIFIED or INCONCLUSIVE, with proof scaled to the risk of the change.

Verification kit

Wasevery QA pass rediscovered how to launch and drive your app. →

Nowcas-qa-craft writes a launch recipe and a feature map your project keeps in docs/qa/.

Feature map upkeep

Wasa feature map went stale without anyone noticing. →

Nowa static check and an opt-in close check name the stale file; map unchanged: <reason> accepts a change as is.

Automatic learning

Wassession learning reread whole transcripts at every stop. →

Nowby default it waits for 10 turns and 2 hours, then reads only what is new.

Lessons become checks

Wasevery recurring lesson ended as a written rule. →

Nowlessons a check could enforce are tagged, and promoting one opens a task to build that check.

01

Verification and QA

Claim verdicts

Wasverify-before-claim and task-verifier had no shared verdict. →

NowVERIFIED / NOT VERIFIED / INCONCLUSIVE per claim, a four-rung blast-radius ladder, same-command baseline/treatment.

Verification kit

Wasno reusable launch and drive recipe per project. →

Nowcas-qa-craft generates docs/qa/verify.md and docs/qa/features/; check-feature-map.mjs checks headings, Touches globs and the index.

Feature-map close gate

Wasnothing tied a diff to its feature doc. →

Nowopt-in on docs/qa/features/; a touched glob without its feature file refuses unless a map unchanged: <reason> decision note exists.

02

Merges and closes

Red lane CI

Wasworktree_merge treated CI as advisory, so a red lane merged. →

Nowred refuses with the run URL; supervisor_override=true needs a reason and is logged; pending never waits.

Repeat refusals

Wasthe same close gate could refuse the same patch loop again and again. →

Nowrepeatable refusals end with a premise-note stop; the merge-required handoff omits it.

Failure policy

Wasretries and close reasons were free-form. →

Nowretry by failure mode with a two-retry cap, four required brief fields, PASS/ISSUES close reasons, patch-id re-verify.

Learning and skills

Session-learn cadence

Wasevery Stop reread the whole transcript. →

Nowmemory.session_learn_min_turns (10) and memory.session_learn_min_minutes (120) gate runs; a path+mtime index mines only the delta.

Enforcement ladder

Nowreviewers tag enforceable:<lint|hook|gate|type>; promoting one with two or more sources files a single encode chore.
