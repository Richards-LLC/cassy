## What you can do now

### Only reply (user)

#### Your own work only

Was: a project's list slowly filled with tasks and memories from other projects. →

Now: every item remembers which project wrote it, and only those are shared with your team.

#### Real projects only

Was: container folders and old projects under Archive were refreshed like live projects. →

Now: only a Git folder or a pinned project counts; Archive and containers are left alone.

#### No borrowed stores

Was: a new repository inside another project quietly used its parent's store. →

Now: it has no store until you run `cas init` there.

#### See and clean up

Was: `cas doctor` counted only stray tasks. →

Now: it counts tasks, memories and rules from other projects or with no known owner, and names the command to remove or claim them.

#### Prompts stay private

Was: captured requests could be shared like any memory. →

Now: they stay on your machine.

#### Chrome ready

Was: Claude sessions Cassy started could use Chrome only if you had switched it on yourself. →

Now: every Claude session Cassy starts has Chrome available.


## Under the hood

### Only reply (dev)

#### Provenance

Was: only tasks had `origin_project`, re-stamped with the local project on every migration run. →

Now: m260 adds it to entries and rules, backfills once from `sessions.cwd` (else `unknown`), and stores stamp at creation.

#### Authored-only sync

Was: pushes stamped missing origins with the pushing project. →

Now: enqueue and push refuse foreign or `unknown` rows, legacy payloads take the stored origin, and `cas cloud status` counts the skips.

#### Project roots

Was: `cas update` fan-outs registered containers and store lookup walked past the Git top level. →

Now: `is_project_root` requires a Git top level or pinned `canonical_id`, and lookup stops at the repository boundary.

#### Queue and moves

Was: an upgrade requeued rows an older build had parked, and a task move pushed a copy under the new owner. →

Now: only version-gate rows requeue, and a move queues just the old-key delete.

#### Audit

Was: doctor and purge covered tasks only. →

Now: doctor classifies tasks, entries and rules as authored, foreign or unknown; `purge-foreign --include-unknown` and `cas cloud adopt-unknown` act on them.

#### Launch

Was: Claude sessions launched without a Chrome flag. →

Now: `--chrome` is passed when the installed CLI supports it.
