## What you can do now

### Only reply (user)

#### One conversation

Was: the phone showed only what it sent and what was sent back to it. →

Now: every paired device shows every message and reply, marked with where it came from.

#### Live on every screen

Was: a message sent from the computer appeared on the phone only after a reload. →

Now: it appears on the phone right away.

#### Terminal included

Was: what you typed straight into the terminal never showed in Commander. →

Now: it shows as a Terminal turn, without the automatic notices.

#### Start sessions without re-pairing

Was: allowing session starts meant pairing the device again. →

Now: press Allow starting sessions in Commander and confirm once.

#### No missing answers

Was: some answers written in the terminal never reached Commander. →

Now: they all do.


## Under the hood

### Only reply (dev)

#### History scope

Was: `conversation_history` and the hub relay filtered on `operator_device_id` and `recipient_device_id`. →

Now: every authenticated viewer gets every operator row, project-scoped; receipts still route to the addressee.

#### Live sends

Was: `MessageQueued` reached only the sender. →

Now: the daemon broadcasts an `OperatorMessage` frame that the hub forwards to other authenticated `pane:read` viewers.

#### Terminal turns

Was: supervisor `UserPromptSubmit` text was never recorded. →

Now: operator-origin prompts are written as processed `terminal` rows; harness envelopes are rejected on every line.

#### Mirror

Was: a coordination reply or a thinking-only `end_turn` suppressed the pane answer. →

Now: dedupe is by message content and a turn closes only when final text exists.

#### Worker default

Was: workers defaulted to `gpt-6-sol` at medium and ignored `llm.worker.*`. →

Now: the standard lane and stock default are `gpt-6.1-sol` at high, and `llm.worker.*` applies to spawns on the configured harness.

#### Self-grant

Was: `session-launch` came only from a pairing invitation. →

Now: `POST /v1/auth/scopes {"add":["session-launch"]}` adds it for a device holding pane input, message send and interrupt, audited.
