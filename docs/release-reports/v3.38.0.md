## What you can do now

### Only reply (user)

#### No lost messages

Was: a message to a Claude session could silently disappear, leaving finished work waiting. →

Now: every message arrives, and one that cannot is flagged where you can see it.

#### Violet

Was: the Slack assistant was called MechaCassy. →

Now: it is Violet everywhere; the old names keep working for one more release.

#### Faster checks

Was: every change waited on the whole test suite, sometimes more than once. →

Now: changes run the tests they affect, and a release candidate is tested once.

#### Quicker starts

Was: a new coding session spent its first minutes recompiling everything. →

Now: it starts from a cache refreshed after every release.


## Under the hood

### Only reply (dev)

#### Relay delivery

Was: `cleanup_orphans` compared a shared `CLAUDE_CONFIG_DIR` with sockets under the caller's `HOME`, so a temp-home test deleted live team trees and relays were abandoned after 15 ENOENT retries. →

Now: cleanup requires CAS ownership and a dead daemon, a missing tree is restored from the in-memory roster, and abandoned or stale relays escalate.

#### Test binaries

Was: 107 integration test binaries, each linked separately. →

Now: 4 grouped harnesses plus 6 standalone roots; `scripts/cas-test-targets.py --check` refuses unregistered suites, and self-re-exec tests require exactly one executed test.

#### Assembly proof

Was: the full suite ran at assembly, again in the integration sweep and again in the gate. →

Now: `scripts/assembly-proof.py prove` records native nextest plus a plain-clone archive run, keyed by code input with member versions and the ledger masked, and the sweep and gate reuse it.

#### Change-scoped CI

Was: factory and epic PR runs checked everything. →

Now: `scripts/ci-test-impact.py` selects crates, modules and suites from the diff, widens when unsure, and records recall against the unfiltered queue shards.

#### Worker checks

Was: workers could not compile at all. →

Now: a literal `cargo check -p <crate> --lib|--tests` is rewritten through a capped runner with OS slot locks and a private target.

#### Violet

Was: `mecha_*` tools and `MECHA_*` variables were primary. →

Now: `violet_*` and `VIOLET_*` are primary with a one-release fallback, and the announce preflight accepts either tool pair.

#### Release and close recovery

Was: `--cut --resume` after publish failed clean-worktree, and close gates dead-ended after a plain `git merge`. →

Now: resume starts at the publication boundary and accepts only this run's outputs, and an ancestor delivery or matching epic `ASSEMBLY_PROOF` satisfies the gates.
