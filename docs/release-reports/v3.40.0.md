## What you can do now

### Only reply (user)

#### Terminal endings

Was: when a worker's terminal went quiet, the last few characters, such as the end of a prompt, could stay hidden until more output arrived. →

Now: they appear as soon as the terminal goes idle.

#### Steadier releases

Was: a release could stall on a check that only ran at the very end, or wait too briefly for the published download. →

Now: those checks run earlier, and the release waits long enough to confirm the download.

#### Cleaner announcements

Was: a release note could go out with an unfilled placeholder. →

Now: a note with any unfilled placeholder is stopped before it posts.


## Under the hood

### Only reply (dev)

#### Lane compile proof

Was: a Rust lane merge could advance an epic without compiling. →

Now: `check-lane-compile.py --prove` records a capped `--lib` and `--tests` check of the merged tree, and the Git merge helper and `--check-lane` refuse to advance without it.

#### CI script tier at the gate

Was: `make test-ci-tiers` ran only in the merge queue. →

Now: the full release gate and assembly proof run it.

#### Pipeline push binding

Was: a rejected release-branch push was ignored and the stale PR head was enqueued. →

Now: PUSH_REJECTED stops the train, a re-assembled branch uses the train's recorded push as a lease, and enqueue passes `expectedHeadOid`.

#### Announcement lint

Was: leftover double-brace placeholders passed the lint. →

Now: any unresolved placeholder in the four bodies fails at preflight and again just before posting.

#### PTY carry

Was: the reader always withheld the last 4 bytes of a read. →

Now: it withholds only a real CPR prefix and flushes it when output goes idle.

#### Epic retargeting

Was: parenting a loose task to an epic left its delivery target on main. →

Now: it follows the epic branch, and a recorded delivery is refused with the repair command.

#### Reviewer accuracy eval

Was: no measurement of the two-axis reviewers. →

Now: a 20-case replay shows 3/14 seeded defects caught (legacy 4/14), so review stays in shadow mode.
