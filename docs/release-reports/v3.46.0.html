What you can do now

02 / 06
01

Commander stays connected

No more stuck "Reconnecting"

Wasafter a brief network failure in the browser, Commander could stay on "Reconnecting" or ask you to pair again while the machine was fine. →

Nowit keeps your pairing and keeps retrying by itself; only a real refusal asks you to pair again.

Lighter on your machine

Wasan open Commander tab asked for the session list about 12 times a second while updates arrived. →

Nowit asks at most about once a second and still ends on the latest list.

Browser permission named

Waswhen Chrome blocked a machine on your private network, Commander just kept retrying without saying why. →

Nowa notice names the machine and the browser setting to allow.

Pairing problems keep your place

Wasa revoked pairing emptied the conversation list, and re-pairing closed the conversation you came from. →

Nowconversations stay listed as needing pairing, and re-pairing takes you back.

Correct times

Wason a machine whose clock ran ahead, a reload could shift turn times and rows read "now" for minutes. →

Nowturns keep their recorded times and rows age from when they arrived.

Outages said once

Wasthe banner, file cards and terminal header could all repeat an outage, and a phone could cut off "Can't reach". →

Nowit is said once, footers lead with what is wrong, and a machine that can't be reached says what to do next.

02

Run projects from Commander

Project controls

WasCommander could only watch and message a project. →

Nowfrom the conversation list you can add, pause, restart or stop helpers, assign a ready task, set the current focus and ask for a merge, with confirmation and an 8-second Undo, on desktop and phone.

Clear permissions

Wasa pairing could not separate everyday control from stopping and restarting. →

Noweach pairing carries separate permissions for both, and a missing permission names the command that grants it.

03

Conversations and accessibility

Drafts are never lost silently

Wasa very long draft, or one the browser's storage refused, vanished on reload without a word. →

NowCommander says it could not be saved and keeps it on screen.

Safer End session

Wasa double-click on End session could end it at once, and nothing confirmed the end. →

Nowthe second click is ignored, the end is announced, and a failure is said once with a way to retry.

Keyboard can leave the terminal

Waskeyboard users could get trapped in the terminal. →

NowTab moves on, and while in control Ctrl+Alt+M or the visible Leave control takes you out.

Focus stays put

Wasa reconnect or a revoked pairing could drop keyboard focus or scroll Load earlier out of view. →

Nowfocus returns to the control you were on, and Back on a phone returns to the row you opened.

Readable notices

WasAttention notice details showed raw data, and the copy confirmation hid under the phone sheet. →

Nowdetails read as the message, and "Details copied" shows on top.

Cleaner search

Wasthe Enter hint covered unread counts and was read aloud, and Enter could reopen the conversation already open. →

Nowthe hint sits beside the count without being read aloud, and Enter goes to another conversation.

Clearer pairing and New session

Wascommands broke mid-word, the pairing countdown could go up, and a read-only link hid what it withholds. →

Nowcommands wrap cleanly, the countdown only goes down, and the link shows what it withholds with the command to change it.

Phone layout

Wason a phone an opened pinned question hid its question, the machine drawer sat under a panel, and long names ran over their status. →

Nowthe question scrolls into view, the drawer is on top, and long names shorten neatly.

04

Setup and updates

Phone access by default

Wasafter cas update the hub kept whatever network setting it last had, and a stopped hub stayed stopped. →

Nowcas update and cas hub start publish the hub over Tailscale by default and start a hub you set up before; turn this off with --no-tailscale-serve or hub.tailscale_serve = false.

Updates finish without Tailscale

Wasan update gave no plain answer when Tailscale could not publish the hub. →

Nowthe hub still runs on this computer, the update finishes, and it tells you why Tailscale is off and how to fix it.

Safer project upgrades

Wasan update could carry on after a failed project upgrade and then fail with a confusing database error. →

Nowit stops that project's later steps and names what is holding it open.

Settings reach the right project

Wassome settings commands could write to a different project than the folder you were in. →

Nowthey refuse and tell you how to choose.

Setup and health checks

Wascas init --force could report success without creating its data, and cas doctor showed raw database errors for a fresh project. →

Nowinit creates what is missing, and doctor reports a fresh project as healthy.

05

Behind the scenes

Faster release checks

Wasthe full pre-release check ran one step at a time and took about 8½ minutes. →

Nowsteps overlap and finish in about 5 to 6½ minutes, pausing rather than running the computer out of memory.

Starts never freeze everything

Waslow disk space could stall a new helper's start and everything queued behind it. →

Nowone stuck start fails with a reason while the rest continues, and starts are refused early when disk is low.

Keys stay where they belong

Washelpers inherited the same service connections and keys as the main session. →

Nowa project can keep named ones back and grant specific keys on purpose.

Fewer false alarms

Wasvisual checks flagged text you could scroll to, hidden screen-reader text and colours caught mid-animation. →

Nowthose false alarms are gone.

Under the hood

03 / 06
01

Assembly proof

Concurrent producers

Wasci-script-tests, native nextest and the archive-mode leg ran strictly in sequence (8m36s on soundwave, 3–6 of 32 cores busy). →

Nowthe script tier overlaps both producer compiles under memory admission while the two test consumers stay sequential; the receipt records per-leg intervals, CPU and the scheduling decision. The first concurrent proof took 4m56s.

Archive leg at native speed

Wasarchive-mode exported TMPDIR on ext4 NVMe, so fsync-heavy SQLite fixtures stalled (133.5s of tests vs 45s native). →

Nowonly disposable test temp and fixture HOMEs use the native tmpfs; extraction stays on disk via --extract-to and the clone stays outside every .cas ancestor. The test phase takes 34–40s.

Cargo jobs

Wasa parent checkout's jobs = 16 cap leaked into nested worktrees. →

Now.cargo/config.toml sets jobs = "default", so a cold 32-thread build takes 94.6s instead of 107.0s; CARGO_BUILD_JOBS, the worker throttle and the per-producer ceiling still apply.

Memory admission

Wasadmission refused outright below the reserve and missed the parallel test-binary link peak (MemAvailable fell to 10 GB). →

Nowit waits and resamples (CAS_RELEASE_GATE_ASSEMBLY_MEMORY_WAIT_SECS, default 600), pauses a producer within 2 GiB of the reserve and resumes at +4 GiB, aborts without PASS on a breach, and links one test binary at a time (measured 2.09 GiB ld.mold peak).

Proof fingerprint

Washarness and session identity variables entered the environment fingerprint and reached test children. →

Nowthe IDENTITY set is scrubbed from both, while build, test-safety and compiler controls stay inputs.

02

Commander and hub

Catalog refresh coalescing

Wasevery SSE/WS event awaited its own GET /v1/sessions, about 12/s per tab under load. →

Nowone shared CoalescedRefresh is single-flight with at least 1s between starts and a guaranteed trailing refresh.

Reconnect state machine

Wasan opaque fetch rejection on an authenticated stage could become needs-pairing, and event reads and refreshes had no deadline. →

Nowonly an explicit AuthenticationError blocks auth, both carry abort plus deadline, and a Local Network Access probe adds guidance for *.ts.net hubs.

Fleet operations API

WasCommander could drive a session only through terminal input. →

NowPOST /v1/sessions/{s}/operations runs merge requests, focus_epic, spawn, hold, recycle, shutdown and assign/unassign through ops::fleet with per-op scopes, 10-minute (device, op_id) replay, 409 stale preconditions, audit rows, FleetChanged events and Undo inverses.

Fleet scopes and UI

Wasno scope separated routine control from destructive control. →

Nowfactory:operate (self-grantable) and factory:manage gate each operation through one fleetControlGate that drives the rail ⋯ menu, inline confirm, Undo bar and 390px action sheets; status reports focused_epic.

Tailscale Serve default

Wasupdate copied the previous process's Serve flag and skipped a stopped hub. →

Nowstart, restart, service install and update default to Serve, --no-tailscale-serve or [hub] tailscale_serve = false opts out, update starts a stopped hub that has a service or machine-id, and a Serve failure keeps loopback with transport_verified=false.

Hub-web fixes

Wasover-bound or quota-refused drafts vanished, End session took a double-click, the terminal input trapped Tab (WCAG 2.1.2) and shell rebuilds dropped focus. →

Nowdrafts report not-saved, the confirm ignores detail>1 clicks, Ctrl+Alt+M leaves control, and focus returns to its owner across rebuilds.

Hub-web state

Wasclock-ahead machines rewound turn times on reload, outages were announced several times, and a revoked pairing's catalog expired into an empty list. →

Nowarrival times persist, live regions write only on change, and the catalog survives until the next post-Re-pair catalog.

03

Factory runtime

Provisioning off the loop

Wasa stalled worktree provision wedged the daemon in pending spawns and restart_spawn_queue could not recover it. →

Nowprovisioning runs off-loop with a process-group deadline and cancellation, and factory.spawn_min_free_gib (default 25) refuses spawns before staging.

Prompt-queue retention

Wasterminal rows were kept forever and gc_cleanup force=true wiped all history. →

Nowthe maintenance sweep prunes rows past factory.prompt_retention_days (default 7), keeping pending rows and relay dedupe keys.

Wakes and notices

Wasbusy or booting workers lost their wake budget, stalled notices fired per message, and one message could arrive on two channels. →

Nowbusy turns keep the budget and recipients are revalidated (#1054, #1101), notices coalesce until read (#1119), the channel is claimed before transport (#1096), assigned creates notify (#1123) and supervisor closes are credited correctly (#1124).

Worker lifecycle

Wasrecycle refused clean workers with tasks and dropped bindings, and dead workers outside scope kept alerting. →

Nowrecycle keeps bindings and re-delivers the brief, supervisors can release leases (#1098), shutdown retires the session's dead workers, and dead QA reviewer claims are released (#1089).

Server registry

Wasserver_start ignored name, server_stop left docker run containers alive and server_list overflowed MCP output. →

Nownames are honored with startup liveness (#1102), containers stop via injected --cidfile (#1099) and listings default to running servers, capped at 50 (#1103).

Credentials and isolation

Wasworkers inherited supervisor-only MCP servers and keys, Codex apply_patch bypassed the workspace guard and rm counted as file creation. →

Nowsupervisor_only_mcp/env and worker_credential_env control access (#1047), apply_patch is guarded, deletions allow only stale runtime files (#1105) and Codex cargo checks use the capped runner.

Worker build caches

Wasper-worktree target/ dirs grew to 10–29 GB and seeded builds reused stale fingerprints. →

Nowparked check caches are bounded (target_cache_retention_count, default 1), owned lane previews are reclaimable and seeded fingerprint records are copied, not hardlinked.

04

Close, merge and QA gates

Bounded epic close

Wasan override close of a large epic ran the surface checker unbounded and timed out at 55s. →

Nowan assembled or released epic defers its build proof to ASSEMBLY_PROOF and the checker is capped at 15s (PR #1114).

Committed timeouts

Wasa committed close, note or message could still answer UNKNOWN at 55s. →

Nowpost-commit work finishes in the background behind a COMMITTED answer, and message receipts carry notification_id (#1083).

Merge admission

Wasa docs-only tip could mask unvalidated code, CI lookups hit a moved repo, and a red-CI refusal left the delivery MergeAuthorized. →

Nowdelivery code beneath the tip needs CI, lookups bind to the canonical origin, and refusals withdraw merge intent.

Delivery attribution

Wasrebuilt dist bundles, epic merges and other tasks' commits could read as dropped or owned content. →

Nowregenerable artifacts, byte-identical epic content and foreign-claimed commits are excluded, and close resolves the branch whose commits claim the task.

Transfers and batches

Wastransfers stored session ids, inherited deliveries had no branch path, and batch squashes could not close. →

Nowtransfers store registered names, adopt_branch=true moves the delivery (#1100), retargets need no repo (#1107), and merged_into batches close by aggregate squash (#1097).

Supervisor closes

Wasevidence-only reports, locked methodologies and moved-on workers deadlocked close. →

Nowevidence_only closes (#1121), methodology repair (#1118), receipt-based override closes (#1068), stacked parks (#1087) and SHA-256 snapshot approvals are supported.

QA gates

Wasredaction placeholders, rebases, random ids and squash-merged deliveries tripped QA. →

Nowplaceholders pass (#1069), waivers bind to the current or explicit tip (#1048, #1122, #1110), ids normalize (#1078), integrated deliveries skip dispatch (#1120), classification uses the fresh target (#1066), bundles share one path (#1061) and Codex reviewers record verdicts (#1111).

05

CLI, store, Jev and tooling

Update, init and config

Wascas update continued past a failed migration, init skipped a missing store, and config writes followed CAS_ROOT silently. →

Nowlater phases stop with lock holders named, init creates and migrates the store, and writes refuse when CAS_ROOT and cwd differ.

Store and doctor

Wasrule writes failed on SQLITE_BUSY, proposal_accept rejected nulls and doctor created the prompt queue it diagnosed. →

Nowrule writes use BEGIN IMMEDIATE with retry, nulls decode (#1043), root discovery needs a store marker and doctor stays read-only.

Violet and publication

Wasviolet --json appended human output, partial reads looked like no replies, and deliverables could be shared before verification. →

NowJSON stays clean, partial reads are unknown (#1062), and a PreToolUse gate holds deliverable posts until verification passes (#1057).

Search and duplicates

Wasworktrees of one repo retired each other's index rows and generic words triggered duplicate warnings. →

Nowreconciliation is per checkout and generic tokens are ignored (#1108).

Jev

Washook risk could not be observed and jev files truncated silently. →

Nowopt-in jev.gate.shadow logs verdicts without changing decisions (PR #1117), files sweep with next_offset and rev (#1116), and triage abstains without current evidence (#1115).

QA and release tooling

Wasvisual-qa flagged scroll-reachable, hidden and mid-transition content, and several release scripts failed on macOS or after a queue failure. →

Nowclipping is per axis (#1073), helpers and closed drawers are skipped (#1081), colours settle first, the gate passes on macOS and --cut --resume resumes its own PR.
