What you can do now

02 / 06
01

Messages that always reach you

Your inbox when the machine is off

Waswith the computer off or asleep, Commander showed nothing and you couldn't reply. →

Nowup to 90 days of conversations, kept encrypted by Petra Stella Cloud, stay readable on every browser you sign in, including a new phone.

Replies wait for the machine

Wasa reply needed the machine to be on. →

Nowit waits as "Pending machine", is sent once when the machine is back, and shows "Accepted by machine".

Sign in with your account

Wasonly browsers paired to the machine could see its conversations. →

Nowyou approve a browser from your Petra Stella account by matching a code, and a message that can't be verified is held back with a note saying so.

Sends never go twice

Wastwo open tabs could both send the same queued message. →

Noweach queued message is sent from one tab only, and anything waiting survives a reload without being resent by itself.

Retry from any tab

Waswith two tabs open, a message confirmed in one tab could leave the other offering Retry, and retrying could stall. →

Nowa confirmation in either tab settles both, and Retry works from either tab without a second copy.

No stale "will go out by itself"

Wasthat line could stay after the message was delivered. →

Nowit clears once nothing is waiting, even when another tab sent it.

Notices stay resolved

Wasafter a reload, a delivery problem you had already resolved could come back in the conversation as a Blocker. →

Nowa resolved notice stays resolved, and "Taking control…" disappears once your message is on its way.

Replies show where they are

WasCommander counted a reply as delivered before your browser had saved it. →

Noweach reply says "Forwarded · not stored on this device" until this device saves it, then "Stored on this device".

Your devices, listed

Wasevery re-pair added another copy of the same browser, one computer had 14. →

Nowre-pairing refreshes the same entry, and each machine lists its browsers with Revoke and Remove from this browser.

Admin by explicit choice

Wasan invitation could not ask for the right to remove other browsers. →

Nowit can request Hub administration, which is never pre-ticked and must be chosen on purpose.

02

Clearer conversations

One screen for everything

WasCommander had a separate Terminal view that showed wrong status and stale alerts. →

NowConversations is the only screen, with Interrupt and a read-only Raw output view in the conversation header.

Questions show real choices

Wasevery question offered made-up "Yes, go ahead / Hold" buttons. →

Nowbuttons appear only for choices the question offers; otherwise you type the answer.

Each question once

Wasa "Waiting on you" panel repeated the question and covered the message box. →

Nowthe question appears once in the conversation, with a small bookmark that jumps to it.

Plain status words

Wasthe side panel showed raw codes like "AWAITINGMERGE", star markup in previews and a wrong count. →

Nowit says "In progress" or "Awaiting merge", previews read cleanly, and the list shows who is really working on what.

Connection problems explained

Was"Reconnecting" gave no reason. →

NowConnection details names the cause, what to do, the next retry and the last good connection, and can download a safe report for support.

Readable error notes

Wason a wide screen an error note squeezed into a narrow strip. →

Nowit uses the full row and names what failed.

Asked once to start a session

WasNew session asked you twice to allow starting sessions, under two different names. →

Nowone Allow, and the project list opens.

Steadier connection state

Wasa machine that briefly stopped answering could jump to "Reconnecting" after one missed check-in. →

Nowit shows "Unsteady" and only reconnects after four missed check-ins.

Whole machine names

Wasa long machine name stayed cut off even on the conversation you had selected, and the phone header clipped it. →

Nowthe selected or focused conversation shows the full name, and the phone header no longer clips it.

Phone search lands where you read

Wasopening a conversation from search on a phone left you nowhere on the page. →

Nowyou land on the conversation itself, and the keyboard stays down.

Connection card on a sideways phone

Wasin landscape, a connection problem's card cut off Retry. →

Nowthe card scrolls, so Retry and Diagnose are always reachable.

Hub status after a restart

Wasafter a reboot, cas hub status only said whether the hub answered, and a stuck system service could freeze it. →

Nowit reports what came back and what to do next, and gives up on a stuck service within half a second.

03

Faster, steadier checks

Browser tests in minutes

Wasevery change to Commander ran all of its roughly 80 browser tests three times, about an hour. →

Noweach change runs only the screens it can affect, often one, and the full set runs once per release batch.

Messages to busy helpers

Wasa message to a helper that stayed busy for a few minutes could be dropped as undeliverable. →

Nowit waits and appears at the helper's next step.

Quicker task wrap-up

Wasfinishing a task on a large project could hang for a minute with no answer. →

Nowit finishes, or says plainly within 35 seconds that it ran out of time and changed nothing.

Release lessons kept

Wasrelease problems were fixed by hand and forgotten, and reports said no one had stepped in. →

Nowa release can't finish until each problem is recorded as a lesson or an open job, and reports count every manual step.

Cleaner disk

Wasinterrupted release checks and an unbounded build cache piled up nearly 40 GB on one computer. →

Nowthey clean up on every exit, leftovers are swept on the next run and caches stay capped.

Release checks protected

Wasbrowser tests running alongside a release check could use up the computer's memory and stop the check. →

Nowtests share memory safely, several run side by side, quick checks never wait behind them, and the release check goes first.

Finished work closes cleanly

Wasmerged work could not be closed once the helper that did it had moved on to something else. →

Nowit closes from its merged result, and corrected work from a retired helper can still be reviewed and closed.

Build folders reclaimed

Wassome build folders could never be cleaned up while an unrelated program was running. →

NowCassy marks the folders it creates, so it can remove them safely later.

Release setup checked early

Wasa release tool setting failed only after the release was already merged. →

Nowit is checked before anything lands.

Fewer false alarms

Wasreadability checks failed easy-to-read buttons and renamed page parts looked like new problems. →

Nowthose checks read the real colours and match issues by what they are.

No false clipping reports

Waslayout checks reported text as cut off when it was deliberately shortened with "…" or not drawn at all. →

Nowthey skip what isn't drawn and still catch real clipping.

04

Team sync

Honest sync summaries

Wassyncing with your team could say "0 pending" while thousands of items were held back. →

Nowit counts what is really waiting or refused, shows when your team last synced, and gives the command that fixes a team-only setting mismatch.

Stuck items recover

Wasabout 200 task links and a few notes retried and failed forever. →

Nowthe missing tasks are sent first, and anything that can't sync is set aside with a reason.

Under the hood

03 / 06
01

Commander delivery

Operator inbox

Wasoperator turns existed only in the hub's SQLite, unreachable while the machine was off. →

Nowan HPKE/AES-GCM cloud inbox (cas-operator-crypto, byte-identical browser HPKE, cloud-held keys, not E2E) replays 90 days to each approved browser and withholds unverifiable envelopes.

Offline commands

Wasa reply needed a live hub connection. →

Nowreplies are sealed to the machine command key under a stable command_id, admitted once with the queue row in one transaction (m265), and expire after 24h.

Account sign-in and CSP

Wasno account-level browser enrollment existed. →

Nowbrowsers enroll by device-code approval or cas hub operator approve <code>, and connect-src pins exactly the cloud operator API origin.

Transactional outbox

Wasa reply was stamped in a separate write after it was queued. →

Noweach operator-visible turn and its immutable operator_delivery_outbox row commit in one transaction (m263), drained every 15s through a PSC-PoP signed transport.

Enrollment assertion

Wasinstallations were always unenrolled. →

NowPOST /v1/auth/account/{challenge,enrollment} verifies the issuer-signed psc-op-enrollment+jwt (one-use 5-minute challenge, aud, ins_jkt == DPoP key, acct == machine principal) before recording Enrolled.

Atomic pending sends

WaspendingSendStore did whole-namespace localStorage read-modify-write, so tabs raced. →

Nowan IndexedDB journal claims each held send per item, scoped to hub, device and session, and never auto-resends.

Cross-tab receipts and Retry

Wasa delivery receipt reached only the tab that sent, and peer captions could cancel a retry. →

Nowreceipts are shared by client_ref across tabs, explicit Retry reuses the original reference behind an owner fence, and a receipt racing the retry wins.

Held-send line

WasshowHeldSendStatus ran for live sends and nothing cleared its "will go out by itself" fallback. →

Nowit shows only for a held send, and settleHeldComposerStatus clears it after a flush, receipt, reconnect or another tab's journal change.

No-delivery settlement

Wasa refused or upstream-unavailable send could only re-hold through History, which the claim fence blocked, so Cancel refused and a late refusal could re-hold a newer Retry. →

Nowan authoritative no-delivery settles against the original wire claim (owner, credential and content fenced).

Notices out of the journal

WaspersistDeviceReply ran before the isOperatorNotice route and journal restore hydrated every row, so resolved notices returned after reload. →

Nownotices are routed first, never journaled, legacy notice rows are pruned, and the take-control notice clears once control is held.

Device reply receipts

Wasthe hub inferred delivery at WebSocket write, before client persistence. →

Nowthe browser sends OperatorReplyPersisted after storing, the hub records operator_reply_device_receipts (m264), and the caption tracks it.

Installation rotation

WasAuthStore::exchange_pairing minted a device UUID per re-pair. →

Nowa possession-proven re-pair rotates the installation via /v1/auth/pairing/{protocol,commit,abort}, /v1/auth/devices lists them, and hub:admin by explicit consent revokes others.

Connection causes

Wasany fetch failure looked the same and lagged SSE records were skipped. →

Now18 typed causes in a 64-entry ring, X-Cas-Request-Id for granted origins, viewer_lagged and epoch markers, 10s deadlines and a sanitized diagnostics export.

Terminal view removed

Wasa second Terminal surface with its own fleet model and a 130-event stale Attention feed. →

NowConversations only, with InterruptPane and a read-only Raw output dialog in the header; about 6,200 lines and 53 KB of JS gone.

Conversation polish

WasDEFAULT_ASK_OPTIONS invented quick replies, previews leaked Markdown and status rendered raw enums. →

Nowoptions only when declared, one in-thread ask plus bookmark, plain-text previews and roster-joined status labels.

Single launch consent

Wasthe grant view's Allow led to a second "Allow "Start new sessions"" confirm sheet. →

Nowthe first named Allow grants session:launch and opens the project list.

Half-open stays Unsteady

Wasan event-triggered catalog read's TypeError aborted the event stream and skipped the heartbeat gate, so one missed beat became Reconnecting. →

Nowfailed or timed-out event reads are left to the heartbeat (Reconnecting at beat 4), and only a refused pairing ends the stream.

Machine name on focus

Wasthe row's machine name stayed ellipsised on the open or keyboard-focused row. →

Nowfocused and open rows wrap the whole name clear of the time stamp; resting rows keep the allowlisted ellipsis.

Phone host line and focus

Wasthe phone header clipped machine glyphs, and a coarse-pointer search jump left focus on BODY. →

Nowthe host line has glyph room, and coarse-pointer jumps land on the reading region or back link with the composer unfocused.

Landscape connection card

Was#pane-grid's overflow: hidden cut Retry and Diagnose off the failure card at 844×390. →

Nowthe pane scrolls vertically while it holds the card.

Hub status

Wasa hung systemctl blocked cas hub status (10.6s measured). →

Nowprobes are capped at 500ms with a typed unknown state, and status --json adds a read-only runtime_receipt.

02

Browser test tiering

Impact selection

Wasjourneys-for-diff treated hub-web/dist as surface-wide, so every delivery selected all 18 journeys (~81 tests, ~20 min, run three times). →

Nowdist is ignored and selection follows Touches, imports, main.ts symbols and CSS selectors; a narrow fix selected 1.

Tier enforcement

Wasworker and QA browser runs executed the full suite. →

Nowthey run only the affected journeys at 4 workers, --full is supervisor-only at assembly, and a PreToolUse guard denies unfiltered Playwright to workers and QA.

Receipt gates

Wasclose and QA accepted any hand-picked subset. →

Nowthey recompute the selection at the tip and require a passing journey-receipt.json for every selected ID, and an epic close needs one full-suite receipt.

03

Cloud sync

Sync receipts

Wasa team-linked sync skipped the personal push, so its receipt read "0 pending, 0 failed/parked" over thousands of team_owned_project rejections, and status showed only the personal last_pull_at. →

Nowthe receipt refreshes from the queue, status reports the team pull watermark, and status and doctor flag the team_only mismatch with its fix.

Orphan dependency repair

Was196 parent-child edges burned retries as orphan_dependency and 3 origin-null memories had no attributable project. →

Nowhealed edges stage missing own-project endpoint tasks insert-only and wait for them, foreign or deleted endpoints park with a reason, and origin-null memories park as unattributed_origin.

04

Release train

Learning loop

Wasblockers were fixed by hand and never recorded. →

Nowreceipts refuse until each blocked stage and hand fix maps to a learned gate row or an open task, printing the exact release-gate.sh --learn command.

Honest interventions

WasINTERVENTIONS counted only kind=manual rows and printed 0 since 3.42.0. →

Nowit counts resumed blockers, hand fixes and manual rows (3.46.0 replays as 8), in the report and both replies.

Publish toolchain preflight

Wascargo-zigbuild rejected build.jobs only after the release landed on main (hotfix PR #1132). →

Nowa publish-toolchain row loads the real zigbuild config first, and a failed publish deletes its own local tag.

Tooling warning

Wasthe off-main tooling warning was buried under git merge-base noise and dead refs. →

Nownoise is captured and merged, stale, epic-covered and duplicate refs are skipped.

05

Gates and runtime

QA binds the delivered tip

Wasa park could bind QA two commits behind its tip, and qa_request re-found that stale pass. →

Nowan own-lineage advance binds the tip, qa_request rebinds and supersedes, and shared branches never move the anchor.

Bounded child close

Wasa supervisor close on a 450-child epic ran about 60k git processes and timed out at 55s claiming COMMITTED. →

Nowa 35s budgeted content gate with a timing log, about 1.3k processes, a typed retryable refusal and IN_PROGRESS on deadline.

Busy-recipient mail

Wasthree declined wakes stamped a message abandoned and hid it from hooks. →

Nowit parks as awaiting_busy_recipient, stays surfaceable, and the reassign notice waits for 10 minutes of silence.

Worker selection

Wasan explicit --worker-cli claude lost to the stock worker default, and a Claude fallback was routed as Codex over PTY. →

Nowexplicit flags win, launch specs are recorded per name, and --worker-spec names apply.

Retired-worker recovery

Wasthe pre-close hook validated a retired worker's moved-on worktree, and qa_request refused an Open task. →

Nowa live supervisor parks and closes a corrected delivery from its pushed receipt against the WorkTarget, and qa_request takes an explicit head on a reopened task.

Detached assignee close

Wasa merged commit_receipt was refused with "expected task worktree branch …, found ``" when the assignee's checkout was detached. →

Nowa supervisor receipt that is an ancestor of the WorkTarget closes without override; worker and unmerged paths are unchanged.

Snapshot hash approval proof

Wasthe SHA-256 snapshot approval had no public-path test. →

Nowan MCP notes→close test refuses a 1,500+ character literal, closes on the exact hash and refuses a same-prefix wrong hash.

Canonical proof targets

Wasclose suggestions prescribed --test agent_definition_contract_test and other modules now inside combined targets, which failed with "no test target named". →

Nowmodules map to their containing Cargo target (integration_contracts and so on), and unknown suites fail closed.

Recycle and reset

Wasrecycle_worker demanded force on a clean worker, then rejected force. →

Nowa clean recycle keeps name, tasks and worktree, and clear_context errors name clear_context.

Visual QA skipped and ellipsised content

Wascontent-visibility: hidden subtrees and ellipsised one-line text were measured as clipped. →

NowcheckVisibility() marks skipped content not drawn, the X walk stops at the ellipsising box, and a real visible clip still fails.

Visual QA identity and contrast

Wasfindings keyed on full selectors and color(srgb …) was unparsed (2.57:1 reported for 12.08:1). →

Nowfindings match by rule, state and text, and CSS Color 4 and opaque layers resolve.

Host-memory admission

Wasworker Playwright and Vitest runs admitted nothing, and 125 headless Chromium pushed MemAvailable under the proof reserve, aborting it. →

Nowworker-memory.py reserves weighted counting slots behind a proof-priority lease (two browser suites plus tsc under a normal budget, serial at 8 GiB, light commands never queued), waits visibly within CAS_RELEASE_GATE_ASSEMBLY_MEMORY_WAIT_SECS, and hook denies still win.

Private fixture pools

Wasthe test-release-gate train-proof fixture ran assembly-proof.py against the real host locks and held intent EX for 8 minutes. →

Nowin-process and subprocess fixtures use private admission pools, with no production env bypass.

Forked mold RSS

Waslink RSS receipts measured only the waited process. →

Nowthey also sample the same link's forked mold workers.

Owned worker targets

Wasseeded worker target/ dirs had no owner record, so retirement refused them whenever an opaque same-uid process existed. →

Nownew targets carry checkout, target and lease identity plus PID start and boot provenance before any data; an unignored target/ stays legacy and seeding still succeeds.

Scratch cleanup

Wasaborted proofs leaked about 9.7 GB of scratch and the shared assembly cache reached 29 GB. →

Nowowner leases reap on TERM/INT/HUP, dead owners are swept, the cache is capped by CAS_ASSEMBLY_TARGET_MAX_GIB (20) and age, and gc_report shows retained bytes.

Parallel links and proof targets

Wasassembly linked one test binary at a time and proofs shared one CARGO_TARGET_DIR across worktrees. →

Nowlink slots are admitted from live memory, capped by CAS_RELEASE_GATE_ASSEMBLY_LINK_JOBS, and each worktree proves into its own target.

Journey flakes

Wasreattach backoff grew to 16–30s, CI ran 16 recording browsers and failure traces never uploaded. →

Nowreattach is capped at 10s, CI runs 6 workers, and hidden .results traces upload on failure.

Journey fixtures and settle

Wasphone fixtures assumed a desktop layout, and a frozen screenshot settle could outlive its page. →

Nowfixtures follow the real phone layout in a responsive four-variant lane, settling is cancelled and drained with the page, and repeat captures are isolated by index.
