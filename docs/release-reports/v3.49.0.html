What you can do now

02 / 06
01

Slack mentions wake Cassy, files by path, steadier task closes

@Violet mentions wake Cassy

Waswhen someone mentioned @Violet or replied in a thread Violet started, nothing happened until Cassy next checked Slack. →

NowCassy wakes on it within about 15 seconds and keeps reading that channel every 5 minutes until an hour passes with no one talking. It is on by default but stays quiet until the Slack side starts sending these alerts; cas config set slack.wake_enabled false turns it off.

Post a file by its path

Wassharing a local file in Slack through Cassy meant copying its contents into the message by hand. →

Nowcas violet post --channel <name> --file <path> posts it, and cas violet thread posts a message with its replies and attachments in one go.

Share a published report by name

Wasgetting a published Cassy report into Slack meant downloading it and uploading it again. →

NowCassy sends it straight from its id and checks the file arrived unchanged.

Violet's new address

WasViolet settings pointed at the old hub address and used the old MECHA_ key names. →

Nowcas update and cas integrate violet move them to the new address and VIOLET_ names; the old names keep working for one more release.

Several closes at once

Wasclosing a few tasks at the same time could freeze Cassy for most of a minute and then answer "unknown". →

Nowcloses run side by side, and one that runs long records its result when it finishes.

Healthy sessions left running

Wason a busy machine Cassy could mistake a session it had just started for a broken one and shut it down. →

Nowfreshly started sessions are recognised and left alone.

Database times in the right zone

Wastimes read from a Neon or Postgres database could come back shifted by your time zone, so 14:34 read as 18:34. →

Nowthey come back exactly as stored.

Keyboard focus stays put in Commander

Wasin a Commander conversation, a live update could knock keyboard focus off the page while you tabbed to Interrupt. →

Nowfocus stays on the control you moved to, with its focus ring.

Clearer setup checks

Wascas doctor said to re-run Violet setup when a project settings file was hiding a missing key, which never fixed it. →

Nowit names that file and the block to remove.

Under the hood

03 / 06
01

Violet

Push-wake, on by default

Wasan @Violet mention or a reply in a Violet thread surfaced only when someone polled the channel. →

Nowa logged-in factory daemon claims the project's violet.slack_activity/v1 events from Cloud every 15 s, admits each once by dedupe_key, acks it and wakes the supervisor with a typed SlackActivity envelope; a no-op until the hub emits events. Opt out with slack.wake_enabled=false.

Channel watch

Wasafter one wake nothing re-read the channel. →

Noweach admitted channel is swept with violet_read every 5 min, stopping after 1 h without human activity, 3 failed reads or session end; slack.violet_bot_user_ids seeds the bot ids sweeps ignore.

cas violet post|thread|read

Wasposting a local file meant pasting base64 into violet_post. →

Nowthe CLI reads, hashes and encodes files from disk, sends up to 1 MiB inline and streams larger sets via file_external begin, upload, complete; thread is one kind:"thread" call with ordered --reply/--reply-file, and hub error codes pass through with a non-zero exit.

Artifact post

Wasa published artifact had to be downloaded and re-uploaded by hand. →

Nowartifact action=post resolves it through Cloud, verifies size and SHA-256, uploads through Violet and saves the permalink on the record; every failure is named.

violet-hub address and VIOLET names

Wasmanaged registrations kept the former hostname and MECHA_* names. →

Nowupdate/sync rewrite proxy files to violet-hub.vercel.app and VIOLET_* in place, cas integrate violet renames credential keys (0600, values never printed), and lookup falls back to MECHA_* for one release.

Skill contract

Wasthe violet skill described the pre-2026-10-09 violet_post and violet_read shapes. →

Nowit documents files[], file_external, kind=thread, the 100,000-byte read default and file_id/message_id/thread_id scopes, the attachments read route and the human-handoff rule.

02

Close and QA gates

No-code close

Wasa no-code task without its own commits was judged on the worker lane's other-task commits, so it read as stranded or parked. →

Nowit closes on its external_ref, foreign anchors are ignored, and a lane is foreign only when every unmerged commit names another task.

Batch-squash receipts

Wasa commit_receipt naming a multi-task squash charged every sibling's paths to the closing task. →

NowQA judges the delivery anchor's own paths when the squash carries all of them.

Fresher verification target

Wasresolve_target_branch_ref bound a local target ~1000 commits behind origin. →

Nowit binds origin/<target> when local is a strict ancestor; equal, ahead or diverged local still wins.

Close off the async runtime

Wassynchronous close work pinned a tokio worker, so parallel closes serialised and timed out as UNKNOWN at 55 s. →

Nowclose runs on the blocking pool with the caller's prefix and receipt scope; a late close answers IN_PROGRESS and appends CLOSE_OUTCOME, and an exact receipt replay returns the persisted boundary.

Snapshot and visual QA

Wasa shared change needed one approval note per snapshot line, a translated finding read as new, and placeholder-hidden loading text was flagged invisible. →

Nowfile-sha256:<digest> approves a whole file, pure translations pair, rejections always record, and a marker-hidden painted placeholder is exempt.

03

Factory and runtime

Delivery watchdog

WasPTY echo of injected text grew pane output, so a swallowed message read as delivered. →

Nowthe watchdog reads the recipient's transcript for a turn start, nudges once and then flags nudge_failed.

MCP start-up

Wasa pre-initialize server/discover probe made cas serve exit, and on macOS the dead child pid got a healthy worker killed; a failed start-up hung on stdin. →

Nowthe probe gets -32601, a live fingerprinted harness parent keeps the worker alive, and failed start-up exits within 2 s.

Launch canary floor

Wasthe canary floor was stamped after finish_worker_spawn, 0.8–19 s late, so fresh canaries were rejected and healthy workers killed. →

Nowthe floor is taken before the PTY starts.

Codex model preflight

Wasa Codex worker could spawn on a model its ChatGPT account cannot run and look busy. →

Nowspawn refuses it from models_cache.json, and a provider model refusal is fatal, relayed as a blocker and shown as stalled.

Task-store locks

Wasevery store open took the write lock and sync loaded the task under it, a lock inversion that stalled 31.6 s. →

Nowopens write only when repair is needed, the sync queue has a busy timeout, and the task loads before the lock.

Postgres UTC

Wasmcp-server-neon serialised naive timestamps in the host zone with a Z suffix. →

NowNeon and server-postgres stdio children run with TZ=UTC unless their env sets TZ.

Commander focus

Wasa deferred render's microtask flush ran mid-Tab and a closed palette left a stale shell signature, so a hub update rebuilt the shell and focus fell to body. →

Nowthe flush waits a task, the palette adopts the closed signature and focus returns with its ring.

Doctor

Wasa missing upstream credential got generic integrate advice even when a project proxy.toml block shadowed it, and a bad violet_post schema went unnoticed. →

Nowdoctor names the shadowing block, flags a violet_post schema with a top-level anyOf or missing kinds, and states bearer readiness.
