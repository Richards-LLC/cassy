Releases that ship themselves

One step to release

Wasa release passed a long chain of manual stages after the work was done. →

Nowone command prepares it, and landing the change publishes it.

Checked once

Wasthe same checks ran again and again before a release. →

Noweach check runs once, in the shared queue.

Built once

Wasthe release was built several times on its way out. →

Nowit is built while the final checks run, and those exact files ship.

Installs itself

Wassomeone had to install each new release by hand. →

Nowthe machine installs it within a minute of publishing.

Faster finishes

Wasfinishing a task waited on extra local checks. →

Nowwork finishes as soon as it is reviewed and merged.

Under the hood

01

Release pipeline

One-command release

Wasa release PR, its own queue cycle and a local tag push followed every epic. →

Nowscripts/release.sh commits the bump, CHANGELOG and draft to the epic PR, enables auto-merge and re-bumps when another release lands first.

Build once

Wasrelease binaries were built on the release branch, on main and by the local publisher. →

Nowrelease-prebuild.yml builds Linux and macOS on the merge_group run; release.yml adopts them by tree id, runs the ISA audit and launch smoke on both packaged assets, then tags and publishes.

Install on publish

Wasan agent hop installed each release. →

Nowa systemd user timer runs cas update within a minute and writes the PR-opened-to-installed time into the release notes.

Unpinned CI

Washundreds of text pins failed any CI edit and the queue preflight ran as one serial job. →

Nowpolicy.json holds only the required contexts and the preflight runs as independent jobs.

No re-runs

Wasthe daemon swept and re-tested after every merge, and close, merge admission and push re-ran the fast rows, journey and lane-compile receipts. →

Nowlane CI runs the fast checks once and the merge queue is the only gate to main; the self-hosted release routing is gone.

Measured on this release

Wascode-done → main 193.7 min and main → installed 95.4 min (3.53). →

NowPR opened → main 28 m 41 s, including one queue retry, and main → installed 6 m 17 s (published 5 m 18 s after the merge, installed 48 s after detection), against budgets of 30 and 20 minutes.
