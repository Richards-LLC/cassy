What you can do now

02 / 06
01

Release changes

Wait for results

Wasa change could be combined before its checks finished.

Nowit waits for them, and a later failure raises an urgent alert naming the affected branch.

Check related parts

Wasa change could miss checks in parts that use it.

Nowthose parts need their own passing checks before the change is handed over.

Catch release failures sooner

Wasa release could enter the final queue before its first checks finished.

Nowit waits, and a failure names the broken checks and tests.

Questions with a next step

Wasan unanswered question could leave work waiting indefinitely.

Nowit can include a deadline and a default, with a reminder to proceed when time runs out.

Unstick ready work

Wasready work could sit waiting without an urgent alert.

Nowit raises one when capacity sits idle, while changes still being checked stay out of the ready list.

Under the hood

03 / 06
01

Release changes

Merge admission

Waspending lane CI was advisory for code.

Nowworktree_merge refuses it without override, and a red merged commit raises a critical blocker naming its integration branch.

Dependent coverage

Wasblast-radius proof covered changed modules.

Nowdirect workspace dependents also need passing targeted-test receipts at the delivered commit.

Release admission

Wasrelease.sh enabled auto-merge immediately.

Nowit waits for Scoped Validation; red or cancelled checks stop with exit 5 and failing check/test names.

Commander deadlines

Wasasks had no deadline or default.

Nowkind=ask accepts remind_delay_secs with remind_message, schedules a proceed reminder and returns its cancellation ID.

Ready-work alerts

Wasstalled ready work emitted a routine notice and pending deliveries counted as ready.

Nowthe notice raises a blocker and excludes deliveries still awaiting CI.

OpenCode configuration

Wasthe projection test pinned full prompt text.

Nowit checks both agents' modes, models, variants, permissions, non-empty prompts and top-level keys.

Latency checks

Wastight upper bounds failed on busy runners.

Nowinjected-latency lower bounds and success assertions remain, with 10-times-RTT upper hang guards.
