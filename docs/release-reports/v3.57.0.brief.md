# Brief: Cassy v3.57.0 release report

Prepared under `cas-release-report`, `cas-html-reports`, and `cas-ui-craft`.

## Single idea

Ten verified closures, half of them in Factory workflows; the rest make workers safer to configure and narrow one delivery gate, while upgrades keep Slack (Violet) working.

## Hero form

The closure stitch is a unit-dot plot: five Factory dots, four Safety dots and one Delivery-gates dot, with a labelled zero row for the Violet upgrade and Teams message fixes that shipped without a GitHub issue. Dots count closures; their size never implies impact.

## Emotional register

Assured and grounded: sandstone behind the verdict, a regular serif conclusion, and quiet ruled ledgers keep the evidence readable.

## Distinctive move

The closure stitch carries the count from the verdict into the small six-dot install motif, so the map's dots are the report's repeating signature.

## Deliberately omitted

There are no KPI cards and no cross-release trend: this is one release snapshot. Referenced issues that were still open, or that closed before the release, are named in Evidence and not drawn as dots.

## Visual language

The renderer uses the project tokens in `docs/design/design-tokens.json`, with the Petrastella sandstone, serif-verdict, quiet-rule and closure-stitch identity. Surface labels are kept short (at most 14 characters) so they never run into the dots at desktop or phone width. `cas-ui-craft` and `cas-html-reports` guide the brief, critique and review.
