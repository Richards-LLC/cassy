# Brief: Cassy v3.59.0 release report

Prepared under `cas-release-report`, `cas-html-reports`, and `cas-ui-craft`.

## Single idea

This release is a speed release with one verified closure. Batch QA (#1203) is the only issue it closes; the session speed-ups that lead the verdict belong to the still-open factory-loop issue.

## Hero form

The closure stitch is a unit-dot plot with one Projects dot. Labelled zero rows for Sessions and Commander say what shipped without a closing issue. A single dot is the honest shape: the release's weight is in latency, which the glance strip carries as measured before → after values, not as dots. Dots count closures; their size never implies impact.

## Emotional register

Assured and grounded: sandstone behind the verdict, a regular serif conclusion, and quiet ruled ledgers keep the evidence readable.

## Distinctive move

The verdict leads with a measured outcome (keys echo at once even when every session is busy), and the glance strip backs it on the first page with four receipt-sourced before → after latencies. The stitch stays honest with a single dot instead of inflating the map with open or earlier issues. The six-dot install mark repeats the stitch.

## Deliberately omitted

There are no KPI cards before the argument and no cross-release trend: this is one release snapshot. The latency rows are pre-release candidate-build receipts, not production telemetry, and the report says so. No green-to-published or stage timing is claimed, because no release-latency receipt exists. #1225 (closed with v3.58.0) and #1211 (open) are named in Evidence and not drawn as dots.
