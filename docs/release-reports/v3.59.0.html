What you can do now

02 / 06
01

Smoother sessions

Instant typing

Waswith many sessions busy, a keystroke could take about 80 ms to appear.

Nowit appears in about 13 ms.

Faster tools under load

Wastool calls could take over 2 seconds while the database was busy.

Nowthey stay under 2 seconds.

Starts reliably

Wasa session could fail to start while another was creating a task.

Nowit starts.

One alert for a crash

Waswhen several helpers stopped at once, you got one alert per helper plus a group alert.

Nowone alert lists each helper's last output.

No stale alerts

Wasalerts for finished work, moved branches or old checks could arrive hours late.

Nowout-of-date alerts expire quietly, and the banner of undelivered alerts clears itself.

Focus kept on shutdown

Wasa project focus chosen just before shutdown could be lost.

Nowit is saved.

02

Projects, Slack and the cloud

Batch QA

Wasevery change needed its own QA pass.

Nowa project can choose one review walk for a whole batch of changes.

Two leads, one project

Wasstarting a second lead session on the same project stopped the first one's Slack watches.

Noweach keeps its own.

Clean sign-off

Wasa busy cloud could leave a closed session listed for up to a day.

Nowsign-off retries until it goes through, and "rate limited" is named as the cause.

Right session after /clear

Wasafter /clear, the old session could keep the heartbeat.

Nowthe new session keeps it.

Fresh project branches

Wasnew work could start from an unpublished or months-old project branch.

Nowthe branch is published and brought up to date first.

Finished work merges

Wasfinished work could not merge while its author had already started on something else.

Nowit merges, and the new work is left untouched.

Safer commands

Wassome read commands could be made to run other programs, while harmless searches were refused.

Nowrisky options are refused and plain searches work.

03

Commander

Designed type everywhere

WasCommander used each machine's own fallback fonts.

Nowit ships Inter and JetBrains Mono, so it looks the same on every machine.

Interrupt says who has control

WasInterrupt could fail with "Couldn't take control" when another device held the session.

Nowit names that device, and an admin pairing takes control and says from whom.

Readable receipts

Wasthe last line of the Write access receipt sat in a faded edge.

Nowit is fully readable.

Under the hood

03 / 06
01

Daemon loop (#1211, in part)

Relay and director I/O

Wasrelay, director-inject and director-refresh store I/O ran inline on the loop.

Nowit runs as store-worker jobs.

Spawn and wake gate

Wasthe per-pass spawn-queue poll and the prompt-queue wake gate blocked the loop.

Nowboth run off the loop; key-to-echo p99 under write pressure is 77.7 ms → 12.8 ms.

Turn probes

Wasthe idle-unacked and normal-delivery probes read the agent store and transcripts on the loop.

Nowthey run as off-loop relay jobs.

Epic focus

Wasset_active_epic wrote session metadata on the loop and could drop the last write at shutdown.

Nowthe store worker writes it, and shutdown flushes and drains.

Lane enforcement

Wasnothing stopped I/O from creeping back onto the input path.

Nowenforce_lane panics under the test harness and logs once per site otherwise; a synthetic-PTY load harness writes p99 receipts.

Worker exit

Wasmark_worker_crashed reaped process groups and checked worktrees inside the PTY exchange.

Nowthat runs after the exchange, and names stay reserved until crash cleanup ends.

02

Store and serve

Write lock only on writes

Wasprompt-queue opens, inbox stale sweeps, empty drains and the Viktor watch expiry took the SQLite write lock without writing.

Nowthey read first; MCP p99 under 16-agent pressure is 2.23 s → 1.88 s.

Heartbeat transaction

Wasa heartbeat and its task and worktree lease renewals took the write lock three times.

Nowone transaction that rolls back together.

Boot under concurrent creates

Wascas serve exited when task-sync recovery found another agent's unclassified intent.

Nowa retired snapshot is rechecked under the write lock and skipped; real ambiguity still fails.

Empty prompt_queue.db

Wasa 0-byte .cas/prompt_queue.db sat beside the live queue in cas.db.

Nowa regular empty file with no sidecars is removed on a writable open.

03

Relays and alerts

Folded deaths

WasN Critical worker_died relays plus workers_died_together.

Nowone Critical fold per recipient with each worker's cleaned tail; the sweep owns recovery, and a give-up is logged.

Lifecycle expiry

Wasan awaiting_merge relay for a closed task reached the supervisor 8.5 h late.

Nowterminal-obsolete lifecycle relays expire atomically in every drain, with a durable reason.

Other stale relays

WasCI-red relays for moved heads, verification dispatches past their deadline and old attention alerts were still delivered.

Nowthey expire the same way; fresh and uncertain relays stay eligible.

Dead-letter rows

Wasreminder_fired and task_lifecycle rows were never processed, and the undelivered-relay banner never aged.

Nowrows are reconciled, and the banner is capped.

04

Cloud, Violet and git

HTTP 429

Wasa 429 at session end was one-shot, leaving the agent listed for up to 24 h.

NowRetry-After or bounded backoff for shutdown, claim release and peer ack, plus a durable shutdown intent and a named "rate limited" health cause.

Shutdown snapshot

Wasnew shutdown intents were detected only by directory mtime.

Nowexact file identity, so a coarse mtime cannot hide a change.

Heartbeat after /clear

Wasensure_agent_active moved heartbeat ownership to the fenced old agent.

Nowowner precedence keeps it with the new session.

Violet watches

Waswatches.json was per clone, so a second daemon stopped a peer's watches.

Nowwatches are keyed per session, with owner routing and a login retry.

Epic publication

Wasfocus_epic and the first spawn could leave a missing or stale epic branch.

Nowthe branch is published to origin and fast-forwarded before lanes are cut.

Dirty reused worktree

Wasworktree_merge refused a pushed delivery while the worktree held the next task.

Nowit merges the parked SHA through an isolated temporary worktree.

05

Policy, QA and Commander

Command policy

Wasbase readers and git accepted flags that run other programs, while read-only awk, find … | xargs grep and gh … | grep were refused.

Nowfail-closed per-tool flag allowlists; grep-only xargs; a direct cas config get only.

Batch QA (#1203)

Wasqa.evidence_gate required a per-task QA bundle.

Nowwith qa.mode = "batch", one immutable batch receipt (ledger, task ids, staging SHA) satisfies each listed task.

Squash and stale-origin closes

Wasa squash-merged or stale-origin batch delivery was refused at close.

Nowthe squash maps to its anchor and the local target counts; an override never clears batch debt.

Bundled fonts

WasCommander shipped no fonts, so CI and users rendered fallbacks.

NowInter and JetBrains Mono woff2 (88,660 B) are served under font-src 'self'.

Interrupt on 409

Wasa refused take showed a generic failure.

Nowthe holder is read and named; hub-admin pairings retry with force.

Write access receipt

Wasits last line sat in the rail's bottom fade at about 3.4:1.

Nowit is clear of the fade.

Deterministic tests

Wasthe flv2 inject and slot-cap tests flaked under parallel load, and the Doctor Neon test leaked MCP children.

Nowboth are deterministic and hermetic.
