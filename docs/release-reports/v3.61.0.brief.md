# Brief: Cassy v3.61.0 release report

Prepared with cas-release-report; cas-html-reports and cas-ui-craft supply the
Markdown-first, standalone, accessible presentation and critique contract.

## Single idea

Sessions now reach each other across projects and wake once per event; 44
changelog changes ship across seven areas, with Sessions carrying the most (16).

## Hero form

A regular serif verdict over the equal-area change map, one dot per CHANGELOG
change, in the generator's area order: Commander, Sessions, Tasks, Releases,
Memory, Slack and Cloud, Other. Sessions is the emphasised row. Dots count
changes, never impact. No zero row is shown.

## Emotional register

Assured and collected: sandstone paper, regular serif argument, sans reading,
mono timestamps. No DESIGN.md exists; the renderer uses the repository's
`docs/design/design-tokens.json` with the bundled Petrastella release identity.

## Distinctive move

A large release stays legible: the map names every change by area before any
prose, and the glance strip puts the three measured publication times beside
the change count. The install section repeats the quiet six-dot mark.

## Deliberately omitted

No severity or impact weighting, no KPI cards above the argument, no claim that
cross-project delivery is live (it waits on the Cloud update), and no GitHub
issue counted as closed: the seven referenced issues were still open at
retrieval. Request-to-published, cut-to-published and per-stage timings were
not recorded, so they are named as unmeasured instead of shown.
