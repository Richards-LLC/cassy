What you can do now

02 / 06
01

Release changes

Supervisors across projects

Wasa supervisor could only message supervisors in the same project.

Nowany of your own live supervisors, on any project or machine, can be listed with cas peers --all and messaged; other people's supervisors stay invisible. Cross-project delivery needs the matching Cloud update.

Who else is here

Wasafter a restart, a supervisor didn't know another one was working on the same repo.

Nowit sees each live peer, its machine and its work as soon as it starts, gets an "about to merge" note before a peer merges into a shared branch, and is warned when two branches change the same file.

Quieter, clearer inbox

Wasmessages from other supervisors got lost among system notices, reminders could sit unread for minutes, and false "stalled" alarms piled up.

Nowmessages from other supervisors and from you come first, each reminder wakes the supervisor once, and alarms fire only when something is really waiting.

Updates tidy your projects

Wascas update installed Cassy's files but left Git out of step, with old files still tracked and ignore rules never committed.

Nowit fixes every project in one separate commit it never pushes, leaves your own edits alone, and reports a conflict instead of touching it.

Tidier backlog

Wasfinished work and stale tasks stayed open unnoticed.

Nowcas doctor and supervisor startup point them out with evidence, and finished epics close without manual steps.

Your memories are safe when projects merge

Wasmerging two projects could hide a memory that happened to share an id with another.

Nownew memories get unique ids, and earlier clashes are recovered.

Projects keep syncing

Wasa project nobody had open on a machine stopped syncing, and team projects could stop pulling.

Nowthe Commander hub syncs idle projects in the background, and team projects sync in team scope.

One Claude setup for every account

Wascommands and skills could disappear when you switched Claude accounts.

Nowcas accounts link shares everything but the login across accounts (preview it with --dry-run, undo it with the printed restore script).

Commander

Wasa reload while a machine was offline showed no conversations.

Nowyour last conversation appears at once, and a machine that reports its presence shows when it goes offline and comes back.

Lighter on your machine

Waseach Cassy session could grow to hundreds of megabytes and start its own Neon helper, and builds stalled whenever the machine was busy.

Nowidle sessions return their memory (about 81% smaller in testing), helpers start only when used, and builds wait on real CPU and memory pressure.

Safer cleanup

Wasa forced cleanup could delete recent task evidence.

Nowdeleting evidence needs an explicit opt-in, and recent or referenced evidence is kept.

Release reports you can read

Wasreports said "0 issues closed" and used internal jargon.

Nowthey lead with what shipped, in plain words, with Eastern times.

Under the hood

03 / 06
01

Release changes

Peer scope

Wasdiscovery and PeerSend were filtered by repo.

Nowcas peers --all and coordination peers scope=all list the caller's own live supervisors across projects and machines; targets resolve by name, name@machine or project; cross-user is refused. Live cross-project delivery waits on the Cloud deploy.

Shared-target helpers

Wasno peer signal before a merge.

Nowworktree_merge sends one best-effort about-to-merge note per tip, and cas peers plus SessionStart warn on same-file overlap; no locks, waits or CI stage. SessionStart also lists live same-repo peers with owner, and peers.same_repo_scope = own filters them.

Supervisor wakes

Waswake pointer, body and [redelivery] replays per event; fired ci_completed reminders gated as gated_not_ready; self reminders raised supervisor_unread.

Nowbounded bodies inline once, reminders wake once with transport-only cadence, self reminders park silently, peer and operator mail leads the block, and notices about ended recipients fold into a digest row.

False alarms

Wasstalled and unread notices for workers that had acted; abandoned merge-request wakes reported "(unknown task) moved on"; MERGE REQUIRED relays fired on pending CI and stale origin.

Nowimplicit acknowledgement from later outbound activity (workers only), actionable messages survive wake exhaustion, and relays wait for the tip's CI against a freshly fetched target.

Managed project files

Wasupdate rewrote managed files, but a survey of 19 projects found managed builtins committed, retired files tracked, the .gitignore block uncommitted and generated AGENTS.md untracked.

Nowone ownership inventory serves init, update, Git reconciliation and doctor; update untracks managed paths, drops pruned retired files from the index and commits chore(cassy): reconcile managed project files without pushing, never staging project bytes and keeping existing staged work. Conflicts are preflighted and left untouched with a managed_files JSON receipt, and doctor reports managed file drift.

Close and epic gates

Waslocal-only anchors, a pre-close check against the worktree's next branch, merge-only deliveries unattributed, proofs claimed without receipts, auto-unblock releasing non-dependency holds, adopt_branch refused for isolated workers.

Nowanchors must be on origin, each task is measured on its own branch, merge-only deliveries attribute, future proofs need citations, holds are structured, and isolated workers adopt into their managed worktree. Dead-owner epics are adopted on evidence, default-branch containment counts, and repos without a merge queue require green CI on the exact default-branch SHA (GH #1243, #1244).

Shell guard

Was) from a $(…) reset command position, and cd, sh -c and same-command links escaped path tracking.

Nowone statement splitter keeps argument position, the effective cwd is carried, and links are judged at their real destination, all fail-closed.

Sync

Wasper-checkout memory ids collided in alias folds (GH #1240); team-linked daemons pushed personal rows and never pulled team scope; purge freshness read the personal watermark; idle stores never synced.

Nowrandom 128-bit ids with deterministic recovery and Cloud's rekey rule v1, team-scope-only daemon sync, scope-aware purge freshness, and hub idle sync under a per-store lease.

Health and hygiene

Wasnothing measured comms regressions or stale backlog.

Nowfive communication SLOs in doctor, shutdown and the release gate, and four backlog-hygiene detectors (delivered-but-open, finished-but-open epics, idle, cited code gone) in doctor and supervisor SessionStart.

Factory runtime

WasClaude /clear dropped registration; standalone-daemon Claude workers lacked a cas_root; macOS relaunch dropped resolved specs; Codex PreToolUse could fail open under load; worker status could hang on gh.

Nowall fixed. Claude agents get role session names and cas-only strict MCP by default (factory.claude.worker_mcp = "inherit" opts out), plus remote_control and fallback_model keys; factory.scratch_root relocates worker targets, build cache, merge-sweep and assembly caches, and release_env accepts it across devices.

Accounts

WasClaude account folders drifted.

Nowcas accounts link [--dry-run] and cas accounts drift share everything but login files, with a printed restore script.

Commander

Wasconversations depended on the pane grid; an unreachable machine showed zero conversations.

Nowconversations mount without the grid and keep the thread on reconnect, the last conversation renders from a cached catalog, and the opted-in hub presence reporter feeds machine-offline notices; the cloud inbox journey runs against the deployed cloud.

CI and releases

Wasweb-only lanes reran Rust, QA replayed journeys, the journey shards installed fonts, and one 403 failed the stale-run watchdog.

Nowfirst-push scope uses the epic merge base, journeys run once, the font step is gone, and the watchdog relays only CI verdicts. Release reports count issues after closure, group by area and print Eastern 12-hour times.

Host resources

Wasload_1m > cpu_count vetoed every capped build; each long-lived cas serve held 500–900 MB and spawned its own Neon MCP (GH #1247).

NowCPU PSI, memory PSI and MemAvailable gate admission with registered factory.build_guard.* limits and a load-ratio fallback; serve arenas are bounded and freed pages reclaimed while idle (same-binary idle RSS+swap about 644 MiB → 122 MiB); proxy upstreams start lazily and stop idle, db_branch_*, cas integrate neon and its generated skills use neonctl with the key in the environment, and credential-looking argv is refused.

Upgrades and cleanup

Wasan upgraded binary under a running daemon failed spawn_workers with provision_build_mismatch (GH #1242); gc_cleanup force=true deleted closed-task evidence and left dev-server children (GH #1248).

Nowthe daemon provisions from a pin of its own build (foreign pins still refused); evidence deletion needs artifacts=true, keeps a 7-day close floor and open or recent references, and fingerprinted descendants are reaped before their wrapper.

Team claims

Wasteammates' locks showed as not visible.

Nowpeer details read project locks with owners, and a 409 carrying the owner refuses start, claim and spawn by name.

Commander sends

Wasqueue and replay could seal one command twice, then show Not sent after Cloud accepted it; forced-colors alert buttons had no boundary.

Nowsealing is serialized with stale-snapshot rereads, and the buttons are outlined.

API QA path

WasQA had only browser and CLI drivers, so server-only changes needed a visual bundle or a waiver (GH #1245).

Nowqa.api_paths triggers an API evidence path of an HTTP transcript plus a contract-fixture diff; browser journeys still apply where they are selected.

Groundwork, inactive

Wasno client for shared work claims, and no in-place reply request in Commander.

Nowa request journal and factory claim, status, release, transfer and accept actions exist, inert until the Cloud and Violet services ship; Commander's "Ask to reply" grant upgrade is built but gated off until Cloud supports it.

Tests

Wasflakes in a shutdown drain, a torn inbox read (inbox writes are now atomic under a lock), random-id ordering, env-leaking update tests, epic-close tests reaching real gh, and fixture repos racing detached git maintenance; the release's new tests duplicated cases.

Nowdeterministic and isolated, and trimmed to one proof per behaviour (net -1,085 test lines). Skills now carry one "fewest tests" principle, and merge requests show test, source and docs line counts.
