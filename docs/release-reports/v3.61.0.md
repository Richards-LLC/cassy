## What you can do now

### Release changes

#### Supervisors across projects

Was: a supervisor could only message supervisors in the same project.

Now: any of your own live supervisors, on any project or machine, can be listed with `cas peers --all` and messaged; other people's supervisors stay invisible. Cross-project delivery needs the matching Cloud update.

#### Who else is here

Was: after a restart, a supervisor didn't know another one was working on the same repo.

Now: it sees each live peer, its machine and its work as soon as it starts, gets an "about to merge" note before a peer merges into a shared branch, and is warned when two branches change the same file.

#### Quieter, clearer inbox

Was: messages from other supervisors got lost among system notices, reminders could sit unread for minutes, and false "stalled" alarms piled up.

Now: messages from other supervisors and from you come first, each reminder wakes the supervisor once, and alarms fire only when something is really waiting.

#### Updates tidy your projects

Was: `cas update` installed Cassy's files but left Git out of step, with old files still tracked and ignore rules never committed.

Now: it fixes every project in one separate commit it never pushes, leaves your own edits alone, and reports a conflict instead of touching it.

#### Tidier backlog

Was: finished work and stale tasks stayed open unnoticed.

Now: `cas doctor` and supervisor startup point them out with evidence, and finished epics close without manual steps.

#### Your memories are safe when projects merge

Was: merging two projects could hide a memory that happened to share an id with another.

Now: new memories get unique ids, and earlier clashes are recovered.

#### Projects keep syncing

Was: a project nobody had open on a machine stopped syncing, and team projects could stop pulling.

Now: the Commander hub syncs idle projects in the background, and team projects sync in team scope.

#### One Claude setup for every account

Was: commands and skills could disappear when you switched Claude accounts.

Now: `cas accounts link` shares everything but the login across accounts (preview it with `--dry-run`, undo it with the printed restore script).

#### Commander

Was: a reload while a machine was offline showed no conversations.

Now: your last conversation appears at once, and a machine that reports its presence shows when it goes offline and comes back.

#### Lighter on your machine

Was: each Cassy session could grow to hundreds of megabytes and start its own Neon helper, and builds stalled whenever the machine was busy.

Now: idle sessions return their memory (about 81% smaller in testing), helpers start only when used, and builds wait on real CPU and memory pressure.

#### Safer cleanup

Was: a forced cleanup could delete recent task evidence.

Now: deleting evidence needs an explicit opt-in, and recent or referenced evidence is kept.

#### Release reports you can read

Was: reports said "0 issues closed" and used internal jargon.

Now: they lead with what shipped, in plain words, with Eastern times.


## Under the hood

### Release changes

#### Peer scope

Was: discovery and `PeerSend` were filtered by repo.

Now: `cas peers --all` and `coordination peers scope=all` list the caller's own live supervisors across projects and machines; targets resolve by name, name@machine or project; cross-user is refused. Live cross-project delivery waits on the Cloud deploy.

#### Shared-target helpers

Was: no peer signal before a merge.

Now: `worktree_merge` sends one best-effort about-to-merge note per tip, and `cas peers` plus SessionStart warn on same-file overlap; no locks, waits or CI stage. SessionStart also lists live same-repo peers with owner, and `peers.same_repo_scope = own` filters them.

#### Supervisor wakes

Was: wake pointer, body and `[redelivery]` replays per event; fired `ci_completed` reminders gated as `gated_not_ready`; self reminders raised `supervisor_unread`.

Now: bounded bodies inline once, reminders wake once with transport-only cadence, self reminders park silently, peer and operator mail leads the block, and notices about ended recipients fold into a digest row.

#### False alarms

Was: stalled and unread notices for workers that had acted; abandoned merge-request wakes reported "(unknown task) moved on"; MERGE REQUIRED relays fired on pending CI and stale origin.

Now: implicit acknowledgement from later outbound activity (workers only), actionable messages survive wake exhaustion, and relays wait for the tip's CI against a freshly fetched target.

#### Managed project files

Was: update rewrote managed files, but a survey of 19 projects found managed builtins committed, retired files tracked, the `.gitignore` block uncommitted and generated `AGENTS.md` untracked.

Now: one ownership inventory serves init, update, Git reconciliation and doctor; update untracks managed paths, drops pruned retired files from the index and commits `chore(cassy): reconcile managed project files` without pushing, never staging project bytes and keeping existing staged work. Conflicts are preflighted and left untouched with a `managed_files` JSON receipt, and doctor reports managed file drift.

#### Close and epic gates

Was: local-only anchors, a pre-close check against the worktree's next branch, merge-only deliveries unattributed, proofs claimed without receipts, auto-unblock releasing non-dependency holds, `adopt_branch` refused for isolated workers.

Now: anchors must be on origin, each task is measured on its own branch, merge-only deliveries attribute, future proofs need citations, holds are structured, and isolated workers adopt into their managed worktree. Dead-owner epics are adopted on evidence, default-branch containment counts, and repos without a merge queue require green CI on the exact default-branch SHA (GH #1243, #1244).

#### Shell guard

Was: `)` from a `$(…)` reset command position, and `cd`, `sh -c` and same-command links escaped path tracking.

Now: one statement splitter keeps argument position, the effective cwd is carried, and links are judged at their real destination, all fail-closed.

#### Sync

Was: per-checkout memory ids collided in alias folds (GH #1240); team-linked daemons pushed personal rows and never pulled team scope; purge freshness read the personal watermark; idle stores never synced.

Now: random 128-bit ids with deterministic recovery and Cloud's rekey rule v1, team-scope-only daemon sync, scope-aware purge freshness, and hub idle sync under a per-store lease.

#### Health and hygiene

Was: nothing measured comms regressions or stale backlog.

Now: five communication SLOs in doctor, shutdown and the release gate, and four backlog-hygiene detectors (delivered-but-open, finished-but-open epics, idle, cited code gone) in doctor and supervisor SessionStart.

#### Factory runtime

Was: Claude `/clear` dropped registration; standalone-daemon Claude workers lacked a cas_root; macOS relaunch dropped resolved specs; Codex PreToolUse could fail open under load; worker status could hang on `gh`.

Now: all fixed. Claude agents get role session names and cas-only strict MCP by default (`factory.claude.worker_mcp = "inherit"` opts out), plus `remote_control` and `fallback_model` keys; `factory.scratch_root` relocates worker targets, build cache, merge-sweep and assembly caches, and release_env accepts it across devices.

#### Accounts

Was: Claude account folders drifted.

Now: `cas accounts link [--dry-run]` and `cas accounts drift` share everything but login files, with a printed restore script.

#### Commander

Was: conversations depended on the pane grid; an unreachable machine showed zero conversations.

Now: conversations mount without the grid and keep the thread on reconnect, the last conversation renders from a cached catalog, and the opted-in hub presence reporter feeds machine-offline notices; the cloud inbox journey runs against the deployed cloud.

#### CI and releases

Was: web-only lanes reran Rust, QA replayed journeys, the journey shards installed fonts, and one 403 failed the stale-run watchdog.

Now: first-push scope uses the epic merge base, journeys run once, the font step is gone, and the watchdog relays only CI verdicts. Release reports count issues after closure, group by area and print Eastern 12-hour times.

#### Host resources

Was: `load_1m > cpu_count` vetoed every capped build; each long-lived `cas serve` held 500–900 MB and spawned its own Neon MCP (GH #1247).

Now: CPU PSI, memory PSI and MemAvailable gate admission with registered `factory.build_guard.*` limits and a load-ratio fallback; serve arenas are bounded and freed pages reclaimed while idle (same-binary idle RSS+swap about 644 MiB → 122 MiB); proxy upstreams start lazily and stop idle, `db_branch_*`, `cas integrate neon` and its generated skills use `neonctl` with the key in the environment, and credential-looking argv is refused.

#### Upgrades and cleanup

Was: an upgraded binary under a running daemon failed `spawn_workers` with `provision_build_mismatch` (GH #1242); `gc_cleanup force=true` deleted closed-task evidence and left dev-server children (GH #1248).

Now: the daemon provisions from a pin of its own build (foreign pins still refused); evidence deletion needs `artifacts=true`, keeps a 7-day close floor and open or recent references, and fingerprinted descendants are reaped before their wrapper.

#### Team claims

Was: teammates' locks showed as not visible.

Now: peer details read project locks with owners, and a 409 carrying the owner refuses start, claim and spawn by name.

#### Commander sends

Was: queue and replay could seal one command twice, then show Not sent after Cloud accepted it; forced-colors alert buttons had no boundary.

Now: sealing is serialized with stale-snapshot rereads, and the buttons are outlined.

#### API QA path

Was: QA had only browser and CLI drivers, so server-only changes needed a visual bundle or a waiver (GH #1245).

Now: `qa.api_paths` triggers an API evidence path of an HTTP transcript plus a contract-fixture diff; browser journeys still apply where they are selected.

#### Groundwork, inactive

Was: no client for shared work claims, and no in-place reply request in Commander.

Now: a request journal and factory claim, status, release, transfer and accept actions exist, inert until the Cloud and Violet services ship; Commander's "Ask to reply" grant upgrade is built but gated off until Cloud supports it.

#### Tests

Was: flakes in a shutdown drain, a torn inbox read (inbox writes are now atomic under a lock), random-id ordering, env-leaking update tests, epic-close tests reaching real `gh`, and fixture repos racing detached `git maintenance`; the release's new tests duplicated cases.

Now: deterministic and isolated, and trimmed to one proof per behaviour (net -1,085 test lines). Skills now carry one "fewest tests" principle, and merge requests show test, source and docs line counts.
