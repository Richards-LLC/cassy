What you can do now

02 / 06
01

Release changes

Sessions start on their own

Wasa new cas claude session opened and waited until you typed.

Nowit starts its first turn by itself.

Reminders arrive on time

Wasa reminder could sit unseen until something else woke the session.

Nowit wakes the session when it fires.

Commander sends after a hiccup

Wasa brief problem on the machine made Commander refuse every message and blame browser storage.

Nowmessages send again once the machine answers, and errors name the real cause.

Commander inbox keeps updating

Wasthe inbox could silently stop showing new messages.

Nownew messages keep arriving.

Ask to reply

Wasa read-only Commander browser couldn't ask to reply.

Nowit asks, you tap Allow, and the same browser replies without signing in again.

Slack threads, once each

Wasafter a restart, a Slack message could be missed or answered twice.

Nowin Cloud-managed channels each message arrives once, with its text, even across restarts.

Finished work closes itself

Wasmerged work waited for one more manual close.

NowCassy closes it once the merge is green and the review approves.

Holds stick

Wasa task you put on hold reopened when the work it waited on finished.

Nowit stays held until you release it.

Updates refresh old instructions

Wassome projects kept running outdated Cassy instructions after cas update.

Nowold Cassy-written copies are replaced and only your own edits are kept.

Disk stays free

Wastest recordings piled up (784 GB on one machine), and cleanup called finished work unfinished.

Nowrecordings go a day after their task closes, and cleanup checks the latest code first.

Codex starts cleanly

Wason Codex 0.162, new sessions stuck on a "Hooks need review" screen, and starting one could change your main checkout.

Nowthey start normally and leave your checkout alone.

Memory you can see

Wasnothing showed how much memory each session's background server used.

Nowthe cleanup report shows it per session, with a total.

Release reports

Wasreport links were dead text and timing was typed by hand.

Nowlinks work and timing comes from the measurement.
