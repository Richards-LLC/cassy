## What you can do now

### Release changes

#### Sessions start on their own

Was: a new `cas claude` session opened and waited until you typed.

Now: it starts its first turn by itself.

#### Reminders arrive on time

Was: a reminder could sit unseen until something else woke the session.

Now: it wakes the session when it fires.

#### Commander sends after a hiccup

Was: a brief problem on the machine made Commander refuse every message and blame browser storage.

Now: messages send again once the machine answers, and errors name the real cause.

#### Commander inbox keeps updating

Was: the inbox could silently stop showing new messages.

Now: new messages keep arriving.

#### Ask to reply

Was: a read-only Commander browser couldn't ask to reply.

Now: it asks, you tap Allow, and the same browser replies without signing in again.

#### Slack threads, once each

Was: after a restart, a Slack message could be missed or answered twice.

Now: in Cloud-managed channels each message arrives once, with its text, even across restarts.

#### Finished work closes itself

Was: merged work waited for one more manual close.

Now: Cassy closes it once the merge is green and the review approves.

#### Holds stick

Was: a task you put on hold reopened when the work it waited on finished.

Now: it stays held until you release it.

#### Updates refresh old instructions

Was: some projects kept running outdated Cassy instructions after `cas update`.

Now: old Cassy-written copies are replaced and only your own edits are kept.

#### Disk stays free

Was: test recordings piled up (784 GB on one machine), and cleanup called finished work unfinished.

Now: recordings go a day after their task closes, and cleanup checks the latest code first.

#### Codex starts cleanly

Was: on Codex 0.162, new sessions stuck on a "Hooks need review" screen, and starting one could change your main checkout.

Now: they start normally and leave your checkout alone.

#### Memory you can see

Was: nothing showed how much memory each session's background server used.

Now: the cleanup report shows it per session, with a total.

#### Release reports

Was: report links were dead text and timing was typed by hand.

Now: links work and timing comes from the measurement.


## Under the hood

### Release changes

#### Startup brief

Was: 3.61's quiet park held the unstamped brief.

Now: Daemon-stamped `cas-startup` class wakes, vetoes kept.

#### Self-reminders

Was: held to the 45 s silence bar.

Now: wake on waiting-for-input evidence, vetoes kept.

#### Hub fd limit

Was: auth-store EMFILE gave a bare 401.

Now: retryable 503, NOFILE 8192 in the hub and its launchd/systemd units, one task store per project.

#### Commander pairing

Was: a reasonless 401 purged the pairing.

Now: needs-pairing only, stale blocks self-heal.

#### Inbox origin

Was: a grant origin mismatch stalled replay.

Now: replay continues.

#### Reply retries

Was: re-forwarded every ~100 ms.

Now: 1 s doubling to 60 s.

#### Ask to reply

Was: protocol double only.

Now: on via Cloud PR #181, live-checked.

#### Slack v2

Was: v1 claim plus sweep, per-launch slot.

Now: claim → ack → Violet body → dispatch_uncertain → type → consumed, stable slot, recovery.

#### Auto-close

Was: workers re-closed merged deliveries.

Now: green merges close with the parked reason after approval.

#### Citations

Was: pattern-checked.

Now: `art-` ids and paths must resolve (GH #1235).

#### Holds

Was: unmet-dependency blocks recorded no hold.

Now: always `blocked_hold` (GH #1234).

#### Rebased anchors

Was: close parked the pre-rebase commit.

Now: the superseding pushed tip.

#### Renames

Was: read as DELIVERY CONTENT DROPPED.

Now: followed, up to 8.

#### Verifier

Was: told to omit `dispatch_id`.

Now: `task show` prints it.

#### Held workers

Was: idle relays repeated.

Now: dropped at revalidation.

#### Codex hooks

Was: 0.162.1 read the main checkout's untrusted hooks.json, rewritten by CAS.

Now: trusted on hash match, never rewritten.

#### Codex checks

Was: backgrounded checks died with empty logs.

Now: detached, log ends `worker-check: EXIT <code>`.

#### Test PATH

Was: whole dirs dropped, so macOS used Apple Git.

Now: only cas, codex, claude hidden.

#### Skills

Was: older shipped bodies looked like user edits.

Now: all are in the reference history.

#### Disk

Was: traces kept forever (784 GB), sweep on a stale ref.

Now: pruned 24 h after close, sweep fetches first.

#### Serve memory

Was: unmeasured.

Now: `gc_report` RSS per session and total.

#### Team pins

Was: leaf-name match, then pull failed.

Now: Cloud alias or `unregistered_pin_alias`.

#### QA whitespace

Was: Apple Git listed whitespace-only edits.

Now: per-path `git diff -w --quiet`.

#### Release tooling

Was: release.sh couldn't rerun after an ejection.

Now: reruns resume, `--latency-receipt` reads a run.

#### Tests and docs

Was: a queue race, a `master` assumption, duplicated setup.

Now: deterministic, about 400 fewer lines, lane-CI cost map.
