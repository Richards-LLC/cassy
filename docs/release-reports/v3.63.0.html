What you can do now

02 / 06
01

Sessions and messages

Sessions start without typing

Wasa new Codex or Claude session could sit idle.

Nowits first turn starts on its own.

Messages arrive whole

Wasa long message could arrive without its opening lines.

Nowthe complete message arrives in one turn.

Quieter activity

Wasroutine updates crowded the pane.

Nowshort cards keep them compact, direct messages stay whole, and full text is available on request.

Inbox history keeps loading

Wasa failed reply-permission check could hide conversations.

Nowhistory keeps loading, with clear loading and unavailable states.

02

Updating

Clear update results

Wasmessages from each step were mixed together.

Nowone line per step, short findings, and a plain final verdict.

Install prompts

Wassaying no looked like a failure.

Nowit says cancelled, and a failed install says how to retry.

Honest counts

Wasa problem with your personal settings counted as a failed project.

Nowprojects and personal settings are counted separately.

Old settings cleaned up

Wasretired Cassy settings warned on every run.

Nowcas update removes them once and prints one short note.

Fewer repeat writes

Wasevery update rewrote files that hadn't changed.

Nowunchanged files are left alone.

Blocked saves reported

Wasa refused save looked like a file conflict on a finished run.

Nowthe run says it is incomplete and keeps your staged work.

Stuck Git lock explained

Wasa leftover Git lock file failed the update with a vague error.

Nowit names the file, its age and how to clear it.

03

Cloud sync

Your changes stay queued

Wasswitching a project to team-only could drop changes the team copy hadn't confirmed.

Nowthey stay until confirmed, and cleanup previews exactly what it removes.

Unsupported characters explained

Wasa note with an invisible null character failed to sync with no reason.

Nowthe error says Cloud can't store it yet, keeps your text, and you retry once Cloud supports it.

Running tasks stay running

Wassyncing with teammates could flip a task you were working on back to Open.

Nowit stays in progress.

04

Checks and builds

Missing Git hooks spotted

Wascas doctor stayed quiet when Git hooks pointed at a deleted folder.

Nowit names the folder and how to restore hooks, without changing your settings.

Builds watch the disk

Wasbuilds started on a nearly full disk.

Nowthey wait for free space, and cleanup finds forgotten caches.

Mac file limits

Wassome edited Mac background settings got an invalid file limit after repair.

Nowthe limit stays valid and keeps your higher values.

01

Sessions and messages

Startup wake

Wasqueued startup briefs could leave new sessions idle.

NowCodex and Claude start without input, retaining readiness and typing vetoes.

Pane input

Wasrepeated offers could truncate long messages.

Nowbusy parking, edge re-offer and bracketed paste preserve one complete turn.

Routine cards

Wasstatus and copied notices expanded into full messages.

Nowcompact cards preserve explicit full reads and whole direct messages.

Inbox replay

Wasoptional grants/me failures blocked history.

Nowreplay continues with explicit read states, preserving revoked-access refusal.

02

Update

Renderer

Wasmixed output and blanket retry advice.

Nowphase lines, compact findings, reason-specific remedies and separate user-store counts.

Self-update

Wasdownload output hid results and declines read as failure.

Nowphase-line progress, cancellation and 80-column clause breaks.

Config retirement

Wasretired TOML keys warned each run.

Nowlocked atomic retirement, one scoped maintenance receipt, read-only configs untouched.

Refresh cost

Wasidentical hook settings and rules rewritten.

Nowbytes and mtime preserved, no-op writes skipped.

Refused commit

Wascommit-guard refusal read as a conflict.

Nowincomplete refresh, staged work kept.

index.lock

Wasgeneric skills-phase failure.

Nowpath, age and busy/stale classification with a manual remedy, lock and index untouched.

03

Cloud

Team-only cleanup

Waspersonal rows dropped on route change.

Nowremoved only with an exact durable team ACK receipt, --purge-team-owned --dry-run and --ids.

NUL payloads

Wasunexplained invalid_json_nul.

Nownamed upstream storage block, payload kept unchanged, --retry-reason invalid_json_nul only after Cloud supports lossless NUL; no drain.

Team pull

Waslive InProgress tasks downgraded to Open.

Nowlive execution ownership preserved.

04

Runtime

Session restart

Wasteardown stopped the replacement.

Nowit affects only the old generation.

Stall alarms

Wasfalse unread-delivery warnings.

Nowrecorded lifecycle actions count as receipt evidence.

Merge alerts

Wasmerged or unrelated deliveries triggered alerts.

Nowfresh-target checks and local ownership filter them.

Remote merges

Wasa local worktree was required.

Nowpushed branches merge with CI tied to the exact SHA.

Close gate

Wasreopened deliveries closed before integration.

Nowtarget containment and independent QA are required.

Codex hooks check

Wascompared after the budget upgrade, reported "stale".

Nowcompares first, shows the real error.

Codex startup guidance

Wasunknown evidence treated as stale.

Nowfollows the active MCP state, names unknown evidence.

doctor hooksPath

Wasno finding for a missing core.hooksPath.

Nowread-only warning and a trusted main-checkout installer.

Hub plist

WasNumberOfFiles outside the dict, Hard below Soft.

Nowinside the dict, Hard ≥ max(Soft, 8192).

05

Builds and CI

Admission

Waslanes admitted at 93% disk, macOS load unknown.

Nowdisk reserve plus a macOS host-pressure probe.

GC

Wasunknown caches invisible, terminal warm targets kept.

Nowcaches inventoried, terminal targets released under pressure.

Build logs

Wasretries truncated logs.

Nowlogs append with UTC admission and release stamps.

Optional slim CI

Wasbroad Rust on every development push.

Nowan opt-in CAS_LANE_SLIM switch, default off, uses pre-push fast rows and exact-tip receipts.
