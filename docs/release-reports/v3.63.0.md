## What you can do now

### Sessions and messages

#### Sessions start without typing

Was: a new Codex or Claude session could sit idle.

Now: its first turn starts on its own.

#### Messages arrive whole

Was: a long message could arrive without its opening lines.

Now: the complete message arrives in one turn.

#### Quieter activity

Was: routine updates crowded the pane.

Now: short cards keep them compact, direct messages stay whole, and full text is available on request.

#### Inbox history keeps loading

Was: a failed reply-permission check could hide conversations.

Now: history keeps loading, with clear loading and unavailable states.

### Updating

#### Clear update results

Was: messages from each step were mixed together.

Now: one line per step, short findings, and a plain final verdict.

#### Install prompts

Was: saying no looked like a failure.

Now: it says cancelled, and a failed install says how to retry.

#### Honest counts

Was: a problem with your personal settings counted as a failed project.

Now: projects and personal settings are counted separately.

#### Old settings cleaned up

Was: retired Cassy settings warned on every run.

Now: `cas update` removes them once and prints one short note.

#### Fewer repeat writes

Was: every update rewrote files that hadn't changed.

Now: unchanged files are left alone.

#### Blocked saves reported

Was: a refused save looked like a file conflict on a finished run.

Now: the run says it is incomplete and keeps your staged work.

#### Stuck Git lock explained

Was: a leftover Git lock file failed the update with a vague error.

Now: it names the file, its age and how to clear it.

### Cloud sync

#### Your changes stay queued

Was: switching a project to team-only could drop changes the team copy hadn't confirmed.

Now: they stay until confirmed, and cleanup previews exactly what it removes.

#### Unsupported characters explained

Was: a note with an invisible null character failed to sync with no reason.

Now: the error says Cloud can't store it yet, keeps your text, and you retry once Cloud supports it.

#### Running tasks stay running

Was: syncing with teammates could flip a task you were working on back to Open.

Now: it stays in progress.

### Checks and builds

#### Missing Git hooks spotted

Was: `cas doctor` stayed quiet when Git hooks pointed at a deleted folder.

Now: it names the folder and how to restore hooks, without changing your settings.

#### Builds watch the disk

Was: builds started on a nearly full disk.

Now: they wait for free space, and cleanup finds forgotten caches.

#### Mac file limits

Was: some edited Mac background settings got an invalid file limit after repair.

Now: the limit stays valid and keeps your higher values.


## Under the hood

### Sessions and messages

#### Startup wake

Was: queued startup briefs could leave new sessions idle.

Now: Codex and Claude start without input, retaining readiness and typing vetoes.

#### Pane input

Was: repeated offers could truncate long messages.

Now: busy parking, edge re-offer and bracketed paste preserve one complete turn.

#### Routine cards

Was: status and copied notices expanded into full messages.

Now: compact cards preserve explicit full reads and whole direct messages.

#### Inbox replay

Was: optional grants/me failures blocked history.

Now: replay continues with explicit read states, preserving revoked-access refusal.

### Update

#### Renderer

Was: mixed output and blanket retry advice.

Now: phase lines, compact findings, reason-specific remedies and separate user-store counts.

#### Self-update

Was: download output hid results and declines read as failure.

Now: phase-line progress, cancellation and 80-column clause breaks.

#### Config retirement

Was: retired TOML keys warned each run.

Now: locked atomic retirement, one scoped maintenance receipt, read-only configs untouched.

#### Refresh cost

Was: identical hook settings and rules rewritten.

Now: bytes and mtime preserved, no-op writes skipped.

#### Refused commit

Was: commit-guard refusal read as a conflict.

Now: incomplete refresh, staged work kept.

#### index.lock

Was: generic skills-phase failure.

Now: path, age and busy/stale classification with a manual remedy, lock and index untouched.

### Cloud

#### Team-only cleanup

Was: personal rows dropped on route change.

Now: removed only with an exact durable team ACK receipt, `--purge-team-owned --dry-run` and `--ids`.

#### NUL payloads

Was: unexplained `invalid_json_nul`.

Now: named upstream storage block, payload kept unchanged, `--retry-reason invalid_json_nul` only after Cloud supports lossless NUL; no drain.

#### Team pull

Was: live InProgress tasks downgraded to Open.

Now: live execution ownership preserved.

### Runtime

#### Session restart

Was: teardown stopped the replacement.

Now: it affects only the old generation.

#### Stall alarms

Was: false unread-delivery warnings.

Now: recorded lifecycle actions count as receipt evidence.

#### Merge alerts

Was: merged or unrelated deliveries triggered alerts.

Now: fresh-target checks and local ownership filter them.

#### Remote merges

Was: a local worktree was required.

Now: pushed branches merge with CI tied to the exact SHA.

#### Close gate

Was: reopened deliveries closed before integration.

Now: target containment and independent QA are required.

#### Codex hooks check

Was: compared after the budget upgrade, reported "stale".

Now: compares first, shows the real error.

#### Codex startup guidance

Was: unknown evidence treated as stale.

Now: follows the active MCP state, names unknown evidence.

#### doctor hooksPath

Was: no finding for a missing `core.hooksPath`.

Now: read-only warning and a trusted main-checkout installer.

#### Hub plist

Was: `NumberOfFiles` outside the dict, Hard below Soft.

Now: inside the dict, Hard ≥ max(Soft, 8192).

### Builds and CI

#### Admission

Was: lanes admitted at 93% disk, macOS load unknown.

Now: disk reserve plus a macOS host-pressure probe.

#### GC

Was: unknown caches invisible, terminal warm targets kept.

Now: caches inventoried, terminal targets released under pressure.

#### Build logs

Was: retries truncated logs.

Now: logs append with UTC admission and release stamps.

#### Optional slim CI

Was: broad Rust on every development push.

Now: an opt-in `CAS_LANE_SLIM` switch, default off, uses pre-push fast rows and exact-tip receipts.
