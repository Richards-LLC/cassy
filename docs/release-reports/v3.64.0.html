Checks and status

Health checks

Wasmatching web addresses could be reported as a mismatch.

Nowthe missing live connection is named and its address appears once.

Project identity

Waswarnings repeated and advised splitting paths you had set on purpose.

Nowthe shared identity appears once, with no split advice.

Older activity

WasCassy could say history was current while older records lacked details.

Nowhealth checks spot the gap, and upgrades repair it without losing history.

Output and recovery

Project lists in JSON

Wasasking for JSON could still print ordinary text.

Nowthe project list and status each return one JSON document.

Updates for every project

WasJSON updates could print several separate documents.

Nowone document holds each project's update steps.

Support reports

Wasa missing setting could send Cassy reports to your project's tracker.

Nowthey go to Cassy's tracker, and a bad setting stops with a clear fix.

Saved patterns

Wasa pattern that saved could still be reported as failed.

Nowsuccess is clear, and an uncertain result says to check before retrying.

Upload recovery

Wasblocked uploads still suggested a retry that would not help.

Nowretry advice appears only when retrying can work.

Setup and cleanup

Your /finish command

Wasupdates could overwrite or drop it.

Nowit installs everywhere you use Cassy and keeps your own edits across updates.

Cache cleanup

Wascaches with an unknown owner could only be listed.

Nowyou can opt in to remove one named cache after safety checks; not yet verified on Mac.

Under the hood

01

Diagnostics

Hub route status

Wasa missing live Serve shim read as a route mismatch.

Nowmissing-shim state is named; mismatch diagnosis is kept for real mismatches.

Registry collisions

Wasrepeated per project, with split advice for pinned roots.

Nowhost collisions reported once; pinned roots get an identity-review warning only.

Legacy queue schema

Wasledger reported current while a lazy queue lacked report columns.

Nowdoctor names the gap; explicit migration repairs it and preserves delivery meaning.

02

Structured output and routing

Known-project JSON

Wasknown-repos list/status could ignore --json.

Noweither flag position returns one document; human defaults unchanged.

Update JSON

Wasupdate --all-projects --json emitted multiple documents or leaked phase text.

Nowphases nest in one document; uncapturable phases are not run.

Cassy issue routing

Wasan unset component key fell back to the project tracker.

Nowthe effective Cassy key wins; invalid targets fail closed with a staged remedy.

Push retry advice

Wasblocked-only Cloud errors got generic retry advice.

Nowsuppressed for blocked-only; retryable work keeps its recovery path.

03

Managed replies and delivery signals

Pattern creation

Wasa bare-row create response decoded as failure.

Nowbare and wrapped shapes decode; incomplete replies return uncertain with no-retry guidance.

Managed-thread replies

Wasno journaled claim-renew or reply-intent operations.

Nowexplicit actions check thread, claim generation and expiry; expired claims fail closed.

Communication SLOs

Wasunenrolled operator snapshots counted as zero receipts.

Nowthey render N/A; enrolled deliveries without receipts still breach.

Pending notices

Wasidle notices repeated while exact-tip CI was pending.

Nowmatching lease, task, pushed tip and pending CI suppress repeats; unknown states keep them.

04

Codex and operator setup

Child cache env

Wasapproved tool-cache paths were dropped at Codex child launch.

Nowallowlisted cache variables pass through; unrelated secrets stay filtered.

/finish

Wasupdates could overwrite or omit the user-level command.

Nowinstalled across supported harnesses, user overrides preserved through updates.

Codex lifecycle hooks

Wassupported hooks reported unavailable; trusted setup incomplete.

Nowgenerated config provisions trust and supported hooks; idle-wake stays a separate contract.

Codex specialist review

Wassubagent support undetected, no native task-verifier role.

Nowcapability detection installs the role without weakening independent review.

Verification-only close

Wasproof-only work refused or pointed at a foreign shared branch.

Nowbounded proof recorded without merging or attributing a foreign tip.

Release and cache operations

Post-publication report

Wasa successful main-push release could be rejected before report delivery.

Nowaccepted only when workflow, tag and landed source agree.

Unknown-owner cache reclaim

Wasinventory only.

Nowexplicit exact-target opt-in after ownership, process, evidence, path and lease checks; macOS not verified.
