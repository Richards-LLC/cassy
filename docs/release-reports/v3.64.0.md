## What you can do now

### Checks and status

#### Health checks

Was: matching web addresses could be reported as a mismatch.

Now: the missing live connection is named and its address appears once.

#### Project identity

Was: warnings repeated and advised splitting paths you had set on purpose.

Now: the shared identity appears once, with no split advice.

#### Older activity

Was: Cassy could say history was current while older records lacked details.

Now: health checks spot the gap, and upgrades repair it without losing history.

### Output and recovery

#### Project lists in JSON

Was: asking for JSON could still print ordinary text.

Now: the project list and status each return one JSON document.

#### Updates for every project

Was: JSON updates could print several separate documents.

Now: one document holds each project's update steps.

#### Support reports

Was: a missing setting could send Cassy reports to your project's tracker.

Now: they go to Cassy's tracker, and a bad setting stops with a clear fix.

#### Saved patterns

Was: a pattern that saved could still be reported as failed.

Now: success is clear, and an uncertain result says to check before retrying.

#### Upload recovery

Was: blocked uploads still suggested a retry that would not help.

Now: retry advice appears only when retrying can work.

### Setup and cleanup

#### Your /finish command

Was: updates could overwrite or drop it.

Now: it installs everywhere you use Cassy and keeps your own edits across updates.

#### Cache cleanup

Was: caches with an unknown owner could only be listed.

Now: you can opt in to remove one named cache after safety checks; not yet verified on Mac.


## Under the hood

### Diagnostics

#### Hub route status

Was: a missing live Serve shim read as a route mismatch.

Now: missing-shim state is named; mismatch diagnosis is kept for real mismatches.

#### Registry collisions

Was: repeated per project, with split advice for pinned roots.

Now: host collisions reported once; pinned roots get an identity-review warning only.

#### Legacy queue schema

Was: ledger reported current while a lazy queue lacked report columns.

Now: doctor names the gap; explicit migration repairs it and preserves delivery meaning.

### Structured output and routing

#### Known-project JSON

Was: `known-repos list/status` could ignore `--json`.

Now: either flag position returns one document; human defaults unchanged.

#### Update JSON

Was: `update --all-projects --json` emitted multiple documents or leaked phase text.

Now: phases nest in one document; uncapturable phases are not run.

#### Cassy issue routing

Was: an unset component key fell back to the project tracker.

Now: the effective Cassy key wins; invalid targets fail closed with a staged remedy.

#### Push retry advice

Was: blocked-only Cloud errors got generic retry advice.

Now: suppressed for blocked-only; retryable work keeps its recovery path.

### Managed replies and delivery signals

#### Pattern creation

Was: a bare-row create response decoded as failure.

Now: bare and wrapped shapes decode; incomplete replies return uncertain with no-retry guidance.

#### Managed-thread replies

Was: no journaled claim-renew or reply-intent operations.

Now: explicit actions check thread, claim generation and expiry; expired claims fail closed.

#### Communication SLOs

Was: unenrolled operator snapshots counted as zero receipts.

Now: they render N/A; enrolled deliveries without receipts still breach.

#### Pending notices

Was: idle notices repeated while exact-tip CI was pending.

Now: matching lease, task, pushed tip and pending CI suppress repeats; unknown states keep them.

### Codex and operator setup

#### Child cache env

Was: approved tool-cache paths were dropped at Codex child launch.

Now: allowlisted cache variables pass through; unrelated secrets stay filtered.

#### /finish

Was: updates could overwrite or omit the user-level command.

Now: installed across supported harnesses, user overrides preserved through updates.

#### Codex lifecycle hooks

Was: supported hooks reported unavailable; trusted setup incomplete.

Now: generated config provisions trust and supported hooks; idle-wake stays a separate contract.

#### Codex specialist review

Was: subagent support undetected, no native task-verifier role.

Now: capability detection installs the role without weakening independent review.

#### Verification-only close

Was: proof-only work refused or pointed at a foreign shared branch.

Now: bounded proof recorded without merging or attributing a foreign tip.

### Release and cache operations

#### Post-publication report

Was: a successful main-push release could be rejected before report delivery.

Now: accepted only when workflow, tag and landed source agree.

#### Unknown-owner cache reclaim

Was: inventory only.

Now: explicit exact-target opt-in after ownership, process, evidence, path and lease checks; macOS not verified.
