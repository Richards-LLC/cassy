What you can do now

02 / 06
01

Slack replies

Fresh asks first

Wasdays-old Slack messages could replay ahead of new asks.

Nowmessages from before a channel was connected are set aside; new asks come first.

Message age

Wasan old message picked up late looked brand new.

Nowit shows when it was written, or unknown.

Reply attachments

Wasa reply could report success without its files.

Nowit names the missing files and how to check, and never posts twice.

Ordinary channels

Wasa refusal there read like "you may not reply".

Nowit says to reply as usual.

Long Slack posts

Wassplit posts showed one part's id.

Nowevery part is listed.

02

Hub on Mac and Linux

Mac hub start and stop

Wasstart, stop and restart could race the system service or wait on a lock.

Nowthey use the installed service and one fixed deadline; the wider Mac checks remain unverified.

After a reboot

Washub status could show two different fixes on one screen.

Nowit shows the one command that actually restores the hub.

Hub status on any Mac

Wasstatus could fail on a Mac with no hub service installed.

Nowan uninstalled service is reported plainly, not as an error.

Fits the screen

Wassome hub status, install preview and Claude sign-in lines ran past 80 columns.

Nowthey fit, and the sign-in line shows the short ~/ path.

03

Updates, health checks and settings

Failed updates in JSON

Wasa failed program download printed nothing usable for scripts.

Nowit returns one structured failure report, with or without a pinned version.

Sync output on light terminals

Wasupdate's sync lines were nearly invisible on white or light themes.

Nowthey stay readable on light and dark palettes.

Health check text

Wasa database problem could print internal query text and odd symbols.

Nowit names the missing piece and the fix in plain text.

Plain terminals

Wassome warnings and success marks used symbols a plain terminal could not show.

Nowthey fall back to plain text there.

Store override notice

Wasthe notice about using a different data folder ran to 300 cells.

Nowit wraps to the screen and keeps both folder paths.

Coordination help

Wascoordination commands had unexplained flags and help lines past 80 columns.

Nowevery flag is explained and the help fits.

Issue tracker settings

Wasa malformed repository name was saved silently.

Nowit is refused, and the blank opt-out is explained.

04

Cloud sync and shared work

Full pulls

Wasa full Cloud download could queue hundreds of pointless uploads.

Nowonly real changes are queued, and a cleanup command removes old ones.

Projects with old names

Wasa project known under two names could stop refreshing its name list.

Nowthe name is matched within your team first, then your personal projects.

Tasks from other projects

Wasan accepted task could not start where it was sent.

Nowit starts there, and its origin stays recorded.

Proposal confirmations

Wasa refused proposal could hide that Cloud had saved it.

Nowit shows the saved proposal and says to retry the same attempt.

Commander during outages

Wasthe conversation list emptied when a machine lost its connection.

Nowit keeps that machine's conversations, and only those are marked last known.

Commander connection log

Wasa temporary hub sign-in outage read as "HTTP request was refused".

Nowthe log names the hub's reason and that it will retry.

Commander dark mode

Wasthe inbox reply box stayed pale in dark mode.

Nowit matches the theme.

Under the hood

03 / 06
01

Managed Violet reader

Historical admission

Waspre-activation and unknown-time deliveries were typed, recovery walked first.

Nowthey are quarantined as metadata only; fresh claims walk first.

Late activation

Wasa binding activated after the first read stayed unknown.

Nowactivation is re-read once per tick for unknown channels.

Wake age

Wasmanaged wakes reported age_secs=0.

Nowage comes from message_ts; invalid or future times read unknown.

Claim receipts

Wasno per-tick claim record.

Nowthe newest 20, body-free, shown by cas doctor.

Binding repair

WasViolet-mapped channels drifted from Cloud bindings.

Nowcas update reconciles them through a durable intake gate.

Unmanaged refusals

Wasbinding_unverified suggested link_team_project.

Nowmanaged=false, next_action reply_via_violet_v1; others stay fail-closed.

Thread receipts

Wasviolet thread trusted success-shaped receipts.

Nowdistinct attached file ids are required; multipart part_ids render.

02

Supervisors and tasks

Corrected identity

Wasproject scope froze at startup.

Nowsnapshot reads re-resolve it off-loop.

Peers

Waspeers named no owners and peer workers were unreachable.

Nowfocused epics are declared, supervisor:<epic> resolves, workers relay.

Shared clones

Wasthe older supervisor lost claims as unknown_registration.

NowCloud slots are per factory session.

Accepted proposals

Wasthey could not start in the target, and mismatches returned no ids.

Nowattested provenance grants execution; refusals return the persisted ids.

Review races

Wasre-park undid request_changes; team pull reopened parked tasks.

Nowpark writes are guarded, sync clocks kept.

Task start

Washeavy tasks timed out with an unknown outcome.

Nowthe local start commits before Cloud handoffs.

Signals

WasFYI rows counted as unread and busy drains dropped mail.

Nowrows classify from the stamp; drains retry.

Escalation

Wasorphaned ejections and blocked PTY writes waited indefinitely.

Nowboth escalate without retyping bytes.

Routes and nudges

Wasnotices advertised unregistered targets and named peer-owned tasks.

Nowroutes resolve; peer-owned tasks are omitted.

03

Hooks, sync and CLI

Git guards

Wasprose and write-free heredocs mentioning git were refused.

Nowonly actual git commands are guarded.

Pull echoes

Wasfull pulls queued team rows for push.

Nowno echoes; cas cloud queue --purge-pull-echoes cleans old ones.

Alias scope

Wasalias records matched across scopes.

Nowactive team first, then personal.

Doctor and update output

WasSqlInputError leaked SQL, and pre-swap failures emitted no JSON.

NowSQL is dropped, and one JSON receipt is emitted.

04

CI

Factory lanes

Wasslim lanes queued behind merge-queue jobs and spent minutes on skipped jobs.

Nowa small dedicated lane workflow runs on local light slots in 26–52 s.

Verdicts

Wasa cancelled same-SHA run read as red.

Nowthe newest non-cancelled run decides; watchdogs retry API errors.

macOS proof

Wasunknown-cache reclaim lacked native proof.

Nownative reclaim tests passed; broader hub update/transport checks on Mac remain unverified.

Optional proxy build

Wasupdate imported its Violet URL from an optional proxy crate and could not compile without that feature.

Nowit reads the shared type constant in either build.

Startup guidance

Wasexpanded startup instructions exceeded the available budget.

Nowcompact instructions retain the required checkout, review, dispatch and liveness contracts.
