## What you can do now

### Slack replies

#### Fresh asks first

Was: days-old Slack messages could replay ahead of new asks.

Now: messages from before a channel was connected are set aside; new asks come first.

#### Message age

Was: an old message picked up late looked brand new.

Now: it shows when it was written, or unknown.

#### Reply attachments

Was: a reply could report success without its files.

Now: it names the missing files and how to check, and never posts twice.

#### Ordinary channels

Was: a refusal there read like "you may not reply".

Now: it says to reply as usual.

#### Long Slack posts

Was: split posts showed one part's id.

Now: every part is listed.

### Hub on Mac and Linux

#### Mac hub start and stop

Was: start, stop and restart could race the system service or wait on a lock.

Now: they use the installed service and one fixed deadline; the wider Mac checks remain unverified.

#### After a reboot

Was: hub status could show two different fixes on one screen.

Now: it shows the one command that actually restores the hub.

#### Hub status on any Mac

Was: status could fail on a Mac with no hub service installed.

Now: an uninstalled service is reported plainly, not as an error.

#### Fits the screen

Was: some hub status, install preview and Claude sign-in lines ran past 80 columns.

Now: they fit, and the sign-in line shows the short ~/ path.

### Updates, health checks and settings

#### Failed updates in JSON

Was: a failed program download printed nothing usable for scripts.

Now: it returns one structured failure report, with or without a pinned version.

#### Sync output on light terminals

Was: update's sync lines were nearly invisible on white or light themes.

Now: they stay readable on light and dark palettes.

#### Health check text

Was: a database problem could print internal query text and odd symbols.

Now: it names the missing piece and the fix in plain text.

#### Plain terminals

Was: some warnings and success marks used symbols a plain terminal could not show.

Now: they fall back to plain text there.

#### Store override notice

Was: the notice about using a different data folder ran to 300 cells.

Now: it wraps to the screen and keeps both folder paths.

#### Coordination help

Was: coordination commands had unexplained flags and help lines past 80 columns.

Now: every flag is explained and the help fits.

#### Issue tracker settings

Was: a malformed repository name was saved silently.

Now: it is refused, and the blank opt-out is explained.

### Cloud sync and shared work

#### Full pulls

Was: a full Cloud download could queue hundreds of pointless uploads.

Now: only real changes are queued, and a cleanup command removes old ones.

#### Projects with old names

Was: a project known under two names could stop refreshing its name list.

Now: the name is matched within your team first, then your personal projects.

#### Tasks from other projects

Was: an accepted task could not start where it was sent.

Now: it starts there, and its origin stays recorded.

#### Proposal confirmations

Was: a refused proposal could hide that Cloud had saved it.

Now: it shows the saved proposal and says to retry the same attempt.

#### Commander during outages

Was: the conversation list emptied when a machine lost its connection.

Now: it keeps that machine's conversations, and only those are marked last known.

#### Commander connection log

Was: a temporary hub sign-in outage read as "HTTP request was refused".

Now: the log names the hub's reason and that it will retry.

#### Commander dark mode

Was: the inbox reply box stayed pale in dark mode.

Now: it matches the theme.


## Under the hood

### Managed Violet reader

#### Historical admission

Was: pre-activation and unknown-time deliveries were typed, recovery walked first.

Now: they are quarantined as metadata only; fresh claims walk first.

#### Late activation

Was: a binding activated after the first read stayed unknown.

Now: activation is re-read once per tick for unknown channels.

#### Wake age

Was: managed wakes reported age_secs=0.

Now: age comes from message_ts; invalid or future times read unknown.

#### Claim receipts

Was: no per-tick claim record.

Now: the newest 20, body-free, shown by cas doctor.

#### Binding repair

Was: Violet-mapped channels drifted from Cloud bindings.

Now: cas update reconciles them through a durable intake gate.

#### Unmanaged refusals

Was: binding_unverified suggested link_team_project.

Now: managed=false, next_action reply_via_violet_v1; others stay fail-closed.

#### Thread receipts

Was: violet thread trusted success-shaped receipts.

Now: distinct attached file ids are required; multipart part_ids render.

### Supervisors and tasks

#### Corrected identity

Was: project scope froze at startup.

Now: snapshot reads re-resolve it off-loop.

#### Peers

Was: peers named no owners and peer workers were unreachable.

Now: focused epics are declared, supervisor:<epic> resolves, workers relay.

#### Shared clones

Was: the older supervisor lost claims as unknown_registration.

Now: Cloud slots are per factory session.

#### Accepted proposals

Was: they could not start in the target, and mismatches returned no ids.

Now: attested provenance grants execution; refusals return the persisted ids.

#### Review races

Was: re-park undid request_changes; team pull reopened parked tasks.

Now: park writes are guarded, sync clocks kept.

#### Task start

Was: heavy tasks timed out with an unknown outcome.

Now: the local start commits before Cloud handoffs.

#### Signals

Was: FYI rows counted as unread and busy drains dropped mail.

Now: rows classify from the stamp; drains retry.

#### Escalation

Was: orphaned ejections and blocked PTY writes waited indefinitely.

Now: both escalate without retyping bytes.

#### Routes and nudges

Was: notices advertised unregistered targets and named peer-owned tasks.

Now: routes resolve; peer-owned tasks are omitted.

### Hooks, sync and CLI

#### Git guards

Was: prose and write-free heredocs mentioning git were refused.

Now: only actual git commands are guarded.

#### Pull echoes

Was: full pulls queued team rows for push.

Now: no echoes; cas cloud queue --purge-pull-echoes cleans old ones.

#### Alias scope

Was: alias records matched across scopes.

Now: active team first, then personal.

#### Doctor and update output

Was: SqlInputError leaked SQL, and pre-swap failures emitted no JSON.

Now: SQL is dropped, and one JSON receipt is emitted.

### CI

#### Factory lanes

Was: slim lanes queued behind merge-queue jobs and spent minutes on skipped jobs.

Now: a small dedicated lane workflow runs on local light slots in 26–52 s.

#### Verdicts

Was: a cancelled same-SHA run read as red.

Now: the newest non-cancelled run decides; watchdogs retry API errors.

#### macOS proof

Was: unknown-cache reclaim lacked native proof.

Now: native reclaim tests passed; broader hub update/transport checks on Mac remain unverified.

#### Optional proxy build

Was: update imported its Violet URL from an optional proxy crate and could not compile without that feature.

Now: it reads the shared type constant in either build.

#### Startup guidance

Was: expanded startup instructions exceeded the available budget.

Now: compact instructions retain the required checkout, review, dispatch and liveness contracts.
