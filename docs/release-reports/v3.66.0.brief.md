# Brief: Cassy v3.66.0 release report

## Single idea

Eighteen changes in v3.66.0 make account access safer and make stuck work easier to recover without weakening evidence checks.

## Hero form

The first screen pairs the verdict with an equal-area unit-dot map across Commander, Sessions and Tasks. Sessions has eight of the eighteen changes, showing that this release is led by recovery and wake reliability while still shipping setup and cleanup safeguards.

## Emotional register

Assured and collected: sandstone paper, a regular serif verdict, system sans reading text and a quiet mono folio. The renderer uses the bundled Petrastella fallback because this repository has no `design-tokens.json` or `docs/design/design-tokens.json` override for the report template.

## Distinctive move

The equal-dot map connects three areas without implying severity or effort; its eight-dot Sessions row makes recovery the visual claim. The recurring decorative row beside Install returns the motif after the technical detail.

## Deliberately omitted

No KPI cards, logo band, network assets or inferred speed comparison. The release measures green-to-published latency only; request-to-published and cut-to-published endpoints are unavailable. GitHub issue closures occurred after the counting window and are disclosed separately rather than added to the count.
