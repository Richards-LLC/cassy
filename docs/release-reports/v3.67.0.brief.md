# Brief: Cassy v3.67.0 release report

## Single idea

Cassy makes delivery easier to trust and easier to resume, so work can move to the right person without losing its context.

## Hero form

The verdict sits beside a labelled unit-dot map of 20 titled change groups across seven product areas. Tasks leads with eight groups; that weight supports the release's emphasis on clear ownership, recoverable proof and fair handoffs. Each dot represents one named group, never its effort or impact.

## Emotional register

Assured, humane and collected: the serif verdict, Inter reading text, JetBrains Mono labels and quiet glass chrome come from the Cassy Commander brand. The renderer reads `DESIGN.md`, whose CSS sources are `hub-web/public/cassy-tokens.css` and `hub-web/src/fonts.css`; the Cassy tile comes from `hub-web/public/favicon.svg`.

## Distinctive move

The change map makes the release's breadth visible without turning status into a score: seven labelled rows of equal dots, with the Tasks row longest. The Commander-branded report change repeats that visual argument in the real before/after pair, showing the same v3.66.0 report content in the earlier and shipped layouts.

## Deliberately omitted

No issue row appears because no issues closed in the release window. That does not imply the release had no defects. Green-to-published and other release timings remain unmeasured because no latency receipt was available; no estimate or tag-based substitute is shown. Tests and documentation are not counted as shipped changes.
