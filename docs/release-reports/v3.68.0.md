## What you can do now

### Your hub stays put

#### Remembered sharing setting

Was: restarting or updating could forget how your hub is shared on your network.

Now: Cassy keeps your saved choice every time.

#### A clear sharing warning

Was: when network sharing failed, the hub quietly stayed on this computer only.

Now: you see a warning and the command for local use, and a Mac background start retries by itself.

#### Updates on a Mac

Was: an update could leave the old hub running and needed a manual restart.

Now: the update restarts the hub and checks that the new version is the one running.

#### Accurate hub status

Was: status could say the hub had stopped while a new one was already running.

Now: it reports the hub that is actually running.

### Messages and reminders

#### Messages to a finished session

Was: a message to someone whose session in another project had ended failed with "no one by that name".

Now: it reaches whoever took over, or tells you the session ended.

#### Reminders after a shutdown

Was: a reminder could get stuck when the session holding it shut down normally.

Now: it is set to go off again.

#### Honest delivery logs

Was: logs said a prompt was being sent even when it never reached the screen.

Now: logs show whether it was actually typed and submitted.

### Safety

#### Saved sign-ins stay private

Was: a few unusual command shapes could still read saved sign-in files.

Now: those shapes are checked and blocked.

#### Fewer false refusals

Was: some harmless one-line lookups were refused.

Now: they run when all they do is read.

#### Connected apps for a dedicated account

Was: a session started under a dedicated account lost that account's connected apps, such as Gmail.

Now: list the apps you approve for that account and only those load.

### Reviews and reports

#### Steady screenshot reviews

Was: adding a section to a page could flag existing visual issues as new.

Now: each issue stays matched to the same element.

#### Reviews that finish

Was: a review could stall after a failed check or skip a reviewer who was already waiting.

Now: reviews recover cleanly and reuse the waiting reviewer.

#### Already-merged work

Was: merging work that was already in place reported success and asked for another review.

Now: Cassy says the work is already there.

#### Split work stays where it belongs

Was: work promised to the other side of a split could still be handed out here.

Now: it stays with that side unless a handover is approved.

#### Trustworthy proof

Was: a closing comment could pose as attached proof.

Now: only proof Cassy attached itself counts.

#### Large Slack files

Was: a file too large for a Slack reply was refused only after other checks.

Now: it is refused right away.


## Under the hood

### Hub lifecycle

#### Persistent transport mode

Was: restart and update could lose the host's hub transport policy.

Now: `cas hub restart` and `cas update` honor `auto`, `required` or `loopback` from `~/.cas/config.toml`; CLI flags override one launch.

#### Auto publication retries

Was: an `auto` Tailscale Serve failure fell back to loopback silently.

Now: interactive start/restart warn on stderr, and macOS service startup retries within a bound, then exits so launchd retries.

#### macOS update turnover

Was: without procfs, a source update left the old hub running beside the new binary.

Now: it runs `cas hub restart`, checks `cas --json hub status` for the new version and fails the update if restart fails.

#### Live lock owner

Was: `cas hub status` trusted an exited process record over a live machine-lock holder.

Now: the live holder leads the verdict; the stale record stays in JSON as history.

### Delivery and reminders

#### Ended cross-project peers

Was: ended sessions resolved only by exact name, so `project` and `project@machine` selectors failed.

Now: they use the live-peer selectors, pick the latest match and still route through the successor check.

#### Held reminder shutdown

Was: a normal worker shutdown could strand its held reminders.

Now: shutdown re-arms them in order.

#### Submit receipts

Was: "Injecting prompt" logged for an attempt whether or not the payload and submit landed.

Now: Codex reminder and peer-reply logs separate the attempt from a confirmed payload write and submit.

### Command safety

#### Credential guard round 5

Was: `env -C`/`sudo -D` chdir prefixes, a separate `tar -f` value and clusters like `curl -sd@file` evaded the guard.

Now: the wrapper chdir applies and each form's file operand is checked.

#### Nested substitution quotes

Was: double quotes inside a `$(…)` within a double-quoted word broke tokenizing and refused read-only one-liners.

Now: the substitution keeps its own quoting context for the effect collector.

#### Explicit-account connectors

Was: strict MCP removed a dedicated config dir's claude.ai connectors.

Now: an operator-provisioned `cassy-worker-connectors.json` admits exactly the named connectors with their tool-permission ceilings; default workers stay Cassy-only.

### Review, QA and proof

#### Visual-QA pairing

Was: findings keyed on `:nth-of-type` selectors re-keyed as introduced after an inserted section (GH #1321).

Now: they pair on `#id`/`data-testid`, else a DOM path without positional pseudo-classes.

#### Merged review authority

Was: a merged delivery refused by another gate got no dispatch, QA re-rounds ignored the idle reviewer and a failed parked verdict dead-ended.

Now: dispatch is prepared, idle reviewers are reused, the first verdict binds and blocked parked reviews recover.

#### Merged-content refusal

Was: a pending dispatch could mask a dropped-content refusal on the next close.

Now: the read-only integration gate runs first; passing still needs that dispatch's verdict.

#### Contained merges

Was: `worktree_merge` of an already-merged old tip reported success and opened a verification dispatch.

Now: it reports the contained source before close and verification, rechecking after origin reconciliation.

#### Split takeovers

Was: assignment could bypass an accepted split and take a child on the peer supervisor's side.

Now: a takeover grant from the current task snapshot authorizes exactly one assigned worker.

#### Trusted note markers

Was: close/cancel/reopen/request_changes reasons appended verbatim could plant an `ARTIFACT_PROOF:` line.

Now: the timeline is an untrusted sink; markers need a trusted append and rendered provenance, and survive reordering.

### Tooling

#### Managed reply size

Was: the 1 MiB managed-reply file check ran after the publication gate.

Now: it runs before the gate.

#### Announcement body edges

Was: validation and posting could normalize fenced body edges differently.

Now: both share one normalization.

#### Simulator ownership on macOS

Was: ownership-probe waits ran on the async runtime.

Now: they run on the blocking pool, with cross-process checkpoint coverage restored.

#### QA field-report skills

Was: QA, TDD, supervisor and worker skills lacked the field-report rules.

Now: they cover entry-path enumeration, system-of-record read-back, build mapping, combination tables, red-first regressions and pre-respawn handoffs.
