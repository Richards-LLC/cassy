# Brief: Cassy v3.72.0 release report

## Single idea

Cassy 3.72 keeps parallel sessions coordinated on shared tasks and files, and reports what a merge, close or restart really did.

## Hero form

The verdict sits beside a labelled unit-dot map of the 13 titled CHANGELOG groups in six areas: Commander (1), Sessions (1), Tasks (5), Messages (1), Releases (2) and Other (3). Tasks is the largest area because the release centers on task claims, merges and close evidence holding up while several sessions work at once. Dots count changes, not effort or importance. GitHub issues closed (none in the counting window) is named in the hero note, not drawn.

## Emotional register

Assured and orderly: a serif verdict, Inter reading text, JetBrains Mono labels and quiet surfaces from the Cassy Commander brand. The renderer reads the project's `DESIGN.md` token maps and CSS sources `hub-web/public/cassy-tokens.css` and `hub-web/src/fonts.css`; the Cassy tile comes from `hub-web/public/favicon.svg`.

## Distinctive move

Five of the 13 equal dots sit in Tasks, in the verdict colour, showing that coordination of claimed work is this release's largest area. The six-dot motif returns once beside install.

Editorial area placement: the generator put the gc and locale groups in Sessions. The gc group (scratch reclamation and its report) moves to Releases beside build priority, where 3.71 placed disk-space recovery. The locale group moves to Other. The CHANGELOG "Fixed — other" group carries the plain title "Rule observations survive load". The count, 13, is the generator's and matches the CHANGELOG 3.72.0 section's 13 titled groups.
