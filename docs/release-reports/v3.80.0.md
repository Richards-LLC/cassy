## What you can do now

### Release changes

#### Slack wake-ups in status

Was: Status and `cas doctor` could not show which Slack wake-up listener a running session used.

Now: They show what that session recorded at start, say "unknown" when it recorded nothing, and say when a settings change needs a restart.

#### Slack channel checks

Was: `cas doctor` did not check the Slack channels listed in your settings.

Now: It checks up to 16 of them within 3 seconds, and each new session lists channels that are unchecked, out of date or flagged.

#### Closing grouped work

Was: Checking a finished group of tasks could look at whatever happened to be checked out locally.

Now: It checks the published branch, and accepts the merge that released the work as proof.

#### Terminal capture checks

Was: The terminal check tool treated a backspace as deleting text and counted a doubled carriage return before a line end as a redraw.

Now: A backspace only moves the cursor, and that doubled return is no longer counted.


## Under the hood

### Violet diagnostics (GH #1267)

#### Daemon consumer receipt

Was: Neither `cas factory status` nor `cas doctor` reported the running daemon's consumer id or capabilities.

Now: Each daemon writes a locked per-session receipt (PID, start time, build, capabilities, wake_enabled at start); a mismatch reads unknown, and a failed write is named only when its failure record matches.

#### Configured-channel doctor row

Was: Doctor did not check `slack.channels`.

Now: Up to 16 configured channels are checked with GETs under a shared 3 s budget that also bounds DNS; an overrun reports unchecked, and the snapshot save is skipped if the deadline has passed when it is reached.

#### Offline session-start evidence

Was: Session start said nothing about configured channels.

Now: It reads `.cas/violet-channel-check.json` with no channel network call and warns on unchecked, flagged or 24-hour-stale channels.

### Task close and tooling

#### Epic close verification

Was: Epic close proof could bind to the supervisor checkout's HEAD, so unrelated local work could break verification.

Now: Proof binds to the published origin epic branch (local when unpublished or local_merge); commit_receipt accepts a default-branch merge containing the epic tip.

#### terminal-qa backspace and CR runs

Was: Backspace deleted the last cell, and a CR run ending at LF counted as a redraw.

Now: Backspace moves the cursor left without deleting, and that CR run is not counted.
