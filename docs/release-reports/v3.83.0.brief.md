# Brief: Cassy v3.83.0 release report

Workflow: cas-release-report, cas-html-reports and cas-ui-craft. The release contract fixes the section order and the equal-dot change map.

design: DESIGN.md@b43940e43

## Single idea

Commander messages reach idle conversations without being refused or lost.

## Hero form

A serif verdict sits above directly labelled equal dots, one per CHANGELOG change: 26 changes in 7 areas. Commander leads with 9, then Sessions and Tasks with 5 each, Releases with 3, Other with 2, and Messages and Slack and Cloud with 1 each. The generator's area order is kept. Issue closures are a secondary count, and there are none this release.

## Emotional register

Collected and precise. The root DESIGN.md maps `hub-web/public/cassy-tokens.css` and `hub-web/src/fonts.css` to report roles: Commander's violet-to-teal aurora, glass chrome, opaque reading cards, Inter prose and JetBrains Mono labels. `cas deliverable brand` resolved it (source design-md-css). No second palette is used.

## Distinctive move

The equal-dot change map shows that the release concentrates on Commander before any detail is read. One decorative row of dots returns at Install. Dots count changes, never impact or severity.

## Deliberately omitted

- No invented speedups or fabricated before/after captures; no paired captures exist for these runtime changes.
- Stage timings are missing from the latency receipt, so they are named in scope rather than shown as zero.
- The report was produced after publication, from the published release and the committed release-notes draft.
