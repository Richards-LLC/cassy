# Brief: Cassy v3.85.0 release report

Workflow: cas-release-report, cas-html-reports and cas-ui-craft. The release contract fixes the section order and the equal-dot change map.

design: DESIGN.md@b43940e43

## Single idea

A Codex coordinator acts on each update, speaks only when needed, and keeps the user's own voice.

## Hero form

A serif verdict sits above directly labelled equal dots, one per CHANGELOG change: 9 changes in 2 areas. Sessions leads with 7, then Tasks with 2. The generator's area order is kept. Issue closures are a secondary count, and none fell inside the counting window this release.

## Emotional register

Collected and precise. The root DESIGN.md maps `hub-web/public/cassy-tokens.css` and `hub-web/src/fonts.css` to report roles: Commander's violet-to-teal aurora, glass chrome, opaque reading cards, Inter prose and JetBrains Mono labels. `cas deliverable brand` resolved it (source design-md-css, inheriting hub-web/DESIGN.md@ce0d8adc9). No second palette is used.

## Distinctive move

The equal-dot change map shows that the release concentrates on Sessions before any detail is read. One decorative row of dots returns at Install. Dots count changes, never impact or severity.

## Deliberately omitted

- No invented speedups or fabricated before/after captures; no paired captures exist for these runtime changes.
- Stage timings are missing from the latency receipt, so they are named in scope rather than shown as zero.
- The eight referenced GitHub issues were still open at retrieval, so the fixes ledger counts none and lists them as referenced-but-open.
- The report was produced after publication, from the published release and the committed release-notes draft.
