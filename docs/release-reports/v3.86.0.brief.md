# Brief: Cassy v3.86.0 release report

Workflow: cas-release-report, cas-html-reports and cas-ui-craft. The release contract fixes the section order and the equal-dot change map.

design: DESIGN.md@b43940e43

## Single idea

Commander becomes the place to work without a terminal: it opens fast, shows the whole picture of the work, renders rich content, and takes phone pastes on slow links.

## Hero form

A serif verdict sits above directly labelled equal dots, one per CHANGELOG change: 24 changes in 7 areas. Sessions leads with 10, then Commander with 4, Tasks and Messages with 3 each, Releases with 2, Memory and Slack and Cloud with 1 each. The generator's area order is kept. One change the generator placed under Tasks ("Device-addressed rows stop bouncing", a Commander reply-queue fix) was moved to Messages in the Change map table before rendering. Issue closures are a secondary count, and none fell inside the counting window this release.

## Emotional register

Collected and precise. The root DESIGN.md maps `hub-web/public/cassy-tokens.css` and `hub-web/src/fonts.css` to report roles: Commander's violet-to-teal aurora, glass chrome, opaque reading cards, Inter prose and JetBrains Mono labels. `cas deliverable brand` resolved it (source design-md-css, DESIGN.md@b43940e43). No second palette is used.

## Distinctive move

The equal-dot change map shows breadth this time: Commander's headline work sits in four large changes while Sessions carries the most entries, the account, relay and supervisor fixes that make the no-terminal path dependable. One decorative row of dots returns at Install. Dots count changes, never impact or severity.
