What you can do now

02 / 06
01

Stay connected and know what happened

Steadier connections

WasCommander could flicker between connected and disconnected or stay waiting after your machine recovered.

NowSlow background reads do not hold up connection checks, and recovery retries stay bounded.

Honest status

WasA machine starting up could look broken, and refused access could leave Working on.

NowStartup says Connecting; lost or refused access clears Working.

A clear ending

WasLeaving with /exit could leave a stale work panel.

NowA dated Session ended receipt tells you what stopped and what is still running.

Your messages stay yours

WasTerminal-typed messages could appear late, and a message already received could still say Not confirmed.

NowTerminal input appears in order, and sent messages retain their own identity through reload and replay.

02

Find the work and read it comfortably

Project navigation

WasSessions were a flat list with little context.

NowProject cards, Needs you, machine filters and reported account details help you find the right conversation. Before/after screenshots compare project grouping.

Release progress

WasA narrow panel dumped the whole task board beside unavailable buttons.

NowRead merged progress, current work and tasks that need you. All tasks opens the wider board; permission guidance folds into one line.

Room to read

WasThe progress panel stayed narrow and phone feedback could cover a task.

NowResize by dragging or keyboard, keep your chosen width, and read phone feedback without overlaps. Scrollbars match your theme.

Readable replies

WasTable words broke into single letters and headings and warnings blended together.

NowTables wrap whole words and formatting, headings keep their levels, and notes and warnings stand out.

Code and files

WasCopying code meant selecting it, previews sat apart from files and sent pictures became paths.

NowCode has Copy and Wrap. Files stay with their previews; your sent pictures remain thumbnails after reload, including on another device. Before/after screenshots compare the code frames.

Preview recovery

WasA failed picture could leave an empty panel and stay failed.

NowFailures are compact and retry after reconnect.

03

Accounts, Macs and updates

Account choices

WasThe picker made capacity hard to compare and could lose text typed ahead.

NowWeekly usage leads each usable account's row, recommendations are clear, and typed answers keep their normal meaning.

Claude and Mac support

WasClaude usage came from a direct private request, and valid Mac logins could be refused.

NowUsage comes from Claude's own tool, Mac credentials are recognized consistently and startup handoffs stay compact.

The hosted app stays current

WasA runtime release did not update hosted Commander.

NowPublication deploys its released Commander bundle automatically.

Under the hood

03 / 06
01

Hub and Commander

Recovery

WasSlow subscription and catalog work blocked health checks and recovery churn shared retry pressure.

NowHealth and interactive service are isolated, sessions retain independent backoff and outage recovery is bounded.

Measured recovery

WasA dropped connection could leave stale state waiting.

NowThe measured check detects the drop in about 2 seconds and recovers in about 4 seconds; this is a measured check, not a network-wide guarantee.

Auth persistence

WasRequests repeatedly parsed and rewrote accumulated connection tickets and synchronously appended audit data.

NowTicket pruning, cached identity reads and batched rotating audit writes reduce contention while retaining revocation checks and capability compatibility.

Measured store size

Was7.96 MB.

Now88 KB in the recorded comparison.

Measured lock-wait p95

Was504 ms.

Now0.07 ms in that comparison.

Session truth

WasEnded identity vanished during teardown, terminal capture could lag completion and durable sends lost their client reference.

NowGeneration-bound exit receipts survive cleanup, terminal input orders by input time and durable history correlates the original client reference before text.

Scoped progress

WasThe project-wide epic catalog was treated as session ownership.

NowHeader and task groups share an open, pinned-first or owner-based filter, matching names and registration IDs. Optional verification ownership is carried on the wire; All tasks remains explicit.

Rich chat

WasProse tables collapsed columns, split messages damaged fenced code and status folding could consume code-shaped replies.

NowWord-aware tables render inline formatting, code frames preserve source with Copy and Wrap, and headings and callouts keep their semantics.

Attachments and work detail

WasPreview failures stayed cached and sent uploads exposed host paths; background command output could disappear.

NowSession-bound previews recover on reconnect, sent uploads hydrate across devices and typed work facts retain background-command outcomes with legacy fallback.

02

Runtime and delivery correctness

Official Claude usage

WasSubscription credentials were used for a direct private usage request.

NowCapacity is consumed only from the official binary's native statusline output.

Account input and portability

WasPicker buffers crossed prompt boundaries, profile spelling affected Keychain lookup and push checks used GNU-only commands.

NowBuffered input retains terminal editing and EOF semantics, profile paths normalize and readable Mac credentials work, and distribution checks are portable.

Startup and help

WasCodex startup emitted raw context or invalid hook output; help could require a default Claude login and empty Codex homes propagated.

NowNative startup produces compact valid handoffs, help parses first and empty homes are unset.

Close and review identity

WasAccumulated branch changes, stale tips or competing proof pointers could misclassify a delivery.

NowActual attributed commits and explicit final receipts govern classification; independent evidence, renamed paths, accepted drops and identical-tree repairs keep their identities.

Notifications and state

WasBackground review dispatch could expire silently, later transitions could swallow completion relays and routine reads repeated settled bodies.

NowDispatch is delivered, durable relays survive transitions, delayed notices are labelled and recipient projections retain intent without replaying settled content.

Artifacts and diagnostics

WasPeer artifact retrieval depended on local lookup, and partial issue queries or schema errors could yield misleading doctor results.

NowVisible Cloud metadata resolves committed evidence, authenticated metadata reads refuse redirects, and diagnostics retain partial results with explicit unavailable states.

Local safety and cleanup

WasLiteral clipboard text could trip policy guards, expanding heredocs escaped inspection and retired-cache scans depended on a global budget.

NowLiteral and expanding bodies are distinguished, missing bodies fail closed, memory writes stay bound to the active profile/project and known retired caches can be reclaimed while preserving proof.

Process ownership and checks

WasCleanup could miss child processes, resumed sessions lost server ownership and push checks could inspect the wrong checkout.

NowProcess-tree cleanup and resumed ownership are retained; checks bind to the pushed branch and accept named CommonJS browser cases.

Hosted deployment

WasRuntime publication left the hosted web build behind and transient promotion checks could roll back a healthy deployment.

NowPublication deploys its released bundle, pins the deployment CLI, removes the GitHub token from its environment and retries the live read before rollback.
