## What you can do now

### Stay connected and know what happened

#### Steadier connections

Was: Commander could flicker between connected and disconnected or stay waiting after your machine recovered.

Now: Slow background reads do not hold up connection checks, and recovery retries stay bounded.

#### Honest status

Was: A machine starting up could look broken, and refused access could leave Working on.

Now: Startup says Connecting; lost or refused access clears Working.

#### A clear ending

Was: Leaving with /exit could leave a stale work panel.

Now: A dated Session ended receipt tells you what stopped and what is still running.

#### Your messages stay yours

Was: Terminal-typed messages could appear late, and a message already received could still say Not confirmed.

Now: Terminal input appears in order, and sent messages retain their own identity through reload and replay.

### Find the work and read it comfortably

## Under the hood

### Hub and Commander

#### Recovery

Was: Slow subscription and catalog work blocked health checks and recovery churn shared retry pressure.

Now: Health and interactive service are isolated, sessions retain independent backoff and outage recovery is bounded.

#### Measured recovery

Was: A dropped connection could leave stale state waiting.

Now: The measured check detects the drop in about 2 seconds and recovers in about 4 seconds; this is a measured check, not a network-wide guarantee.

#### Auth persistence

Was: Requests repeatedly parsed and rewrote accumulated connection tickets and synchronously appended audit data.

Now: Ticket pruning, cached identity reads and batched rotating audit writes reduce contention while retaining revocation checks and capability compatibility.

#### Measured store size

Was: 7.96 MB.

Now: 88 KB in the recorded comparison.

#### Measured lock-wait p95

Was: 504 ms.

Now: 0.07 ms in that comparison.

#### Session truth

Was: Ended identity vanished during teardown, terminal capture could lag completion and durable sends lost their client reference.

Now: Generation-bound exit receipts survive cleanup, terminal input orders by input time and durable history correlates the original client reference before text.

#### Scoped progress

Was: The project-wide epic catalog was treated as session ownership.

Now: Header and task groups share an open, pinned-first or owner-based filter, matching names and registration IDs. Optional verification ownership is carried on the wire; All tasks remains explicit.

#### Rich chat

Was: Prose tables collapsed columns, split messages damaged fenced code and status folding could consume code-shaped replies.

Now: Word-aware tables render inline formatting, code frames preserve source with Copy and Wrap, and headings and callouts keep their semantics.

#### Attachments and work detail

Was: Preview failures stayed cached and sent uploads exposed host paths; background command output could disappear.

Now: Session-bound previews recover on reconnect, sent uploads hydrate across devices and typed work facts retain background-command outcomes with legacy fallback.

### Runtime and delivery correctness

#### Official Claude usage

Was: Subscription credentials were used for a direct private usage request.

Now: Capacity is consumed only from the official binary's native statusline output.

#### Account input and portability

Was: Picker buffers crossed prompt boundaries, profile spelling affected Keychain lookup and push checks used GNU-only commands.

Now: Buffered input retains terminal editing and EOF semantics, profile paths normalize and readable Mac credentials work, and distribution checks are portable.

#### Startup and help

Was: Codex startup emitted raw context or invalid hook output; help could require a default Claude login and empty Codex homes propagated.

Now: Native startup produces compact valid handoffs, help parses first and empty homes are unset.

#### Close and review identity

Was: Accumulated branch changes, stale tips or competing proof pointers could misclassify a delivery.

Now: Actual attributed commits and explicit final receipts govern classification; independent evidence, renamed paths, accepted drops and identical-tree repairs keep their identities.

#### Notifications and state

Was: Background review dispatch could expire silently, later transitions could swallow completion relays and routine reads repeated settled bodies.

Now: Dispatch is delivered, durable relays survive transitions, delayed notices are labelled and recipient projections retain intent without replaying settled content.

#### Artifacts and diagnostics

Was: Peer artifact retrieval depended on local lookup, and partial issue queries or schema errors could yield misleading doctor results.

Now: Visible Cloud metadata resolves committed evidence, authenticated metadata reads refuse redirects, and diagnostics retain partial results with explicit unavailable states.

#### Local safety and cleanup

Was: Literal clipboard text could trip policy guards, expanding heredocs escaped inspection and retired-cache scans depended on a global budget.

Now: Literal and expanding bodies are distinguished, missing bodies fail closed, memory writes stay bound to the active profile/project and known retired caches can be reclaimed while preserving proof.

#### Process ownership and checks

Was: Cleanup could miss child processes, resumed sessions lost server ownership and push checks could inspect the wrong checkout.

Now: Process-tree cleanup and resumed ownership are retained; checks bind to the pushed branch and accept named CommonJS browser cases.

#### Hosted deployment

Was: Runtime publication left the hosted web build behind and transient promotion checks could roll back a healthy deployment.

Now: Publication deploys its released bundle, pins the deployment CLI, removes the GitHub token from its environment and retries the live read before rollback.
