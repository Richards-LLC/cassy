What you can do now

02 / 06
01

A tidier Commander

Dismissed sessions stay dismissed

WasAn ended session you dismissed came back after a live update or a reload, and dismissing it on one device never reached your others.

NowDismiss and Clear ended are saved on the machine itself, so the session stays hidden through updates, reloads and every browser you have paired. A new session with the same name still shows up once.

Idle no longer looks offline

WasA supervisor that was running but quiet showed the same gray dot as one that was offline.

NowWorking is solid green, idle is a hollow green ring, and only offline is gray. Each dot names its state when you hover or use a screen reader, and high-contrast mode tells them apart by shape. Team's Waiting and Offline labels follow the same colors. The captures show the same live, idle Claude supervisor on 3.92.0 and on this release.

02

Commands that finish

Usage works on Claude again

WasSending Usage to an idle Claude supervisor from Commander hung for about 90 seconds, showed no Close button, and blocked the next Usage until the screen was cleared.

NowUsage opens within a second with a working Close, and later commands and messages go through. The captures send Usage to the same idle Claude 2.1.312 supervisor on 3.92.0 and on this release.

03

Smoother delivery

Inherited work can be delivered

WasWhen a worker went away mid-task, the replacement's finished work could not be merged.

NowA supervisor can approve the replacement's own clean branch, and the work merges and closes normally while the hand-over stays on record.

Under the hood

03 / 06
01

Commander and hub

Durable dismissals

WasDismissals lived only in each browser's localStorage, keyed by session plus end time.

NowThe hub writes an atomic marker per dismissed session in its own folder, keyed by a hash of session name and start time. GET /v1/sessions returns dismissed=true, and dismissing a live or stale generation returns 409.

Status marks

WasLive-idle and offline supervisors computed the same gray mark.

NowWorking, Idle and Offline each have one DESIGN.md rule and matching CSS. Each mark carries role="img" with a state label, forced colors distinguish Idle (square) from Offline (round), and Team's Waiting and Offline pills have explicit styles.

Claude Usage observation

WasThe daemon confirmed /usage only when the screen said "Current session", which Claude 2.1.312 no longer prints, so receipts went unconfirmed at 90 s and blocked later commands. 3.91.1 failed the same way.

NowObservation matches the Usage view Claude prints today, and an uncertain receipt keeps a Close control so the native view can be dismissed before the next command. A regression test is built from the real captured screen.

02

Factory

Takeover of a gone worker's task

WasAfter a worker was gone, a replacement's delivery could not be merged: rebind_branch refused because the assignee differed from the recorded start, and worktree_merge then refused the unresolved source.

Nowrebind_branch accepts the current assignee when it is a live registered worker in the supervisor's session, holds no conflicting lease and has its own clean task branch in the same repository. The old owner, branch and anchor stay in the audit. The route is documented in CONTRIBUTING.
