# Brief: Cassy v3.98.0 release report

Workflow: `cas-release-report` owns the release structure; `cas-html-reports` governs source fidelity and offline delivery; `cas-ui-craft` governs composition and critique.

design: `DESIGN.md@b43940e43`; source `design-md-css`.

## Single idea

v3.98.0 is mostly about how finished work closes: 11 of its 25 changes are in Tasks, led by one release verdict in place of a review per delivery.

## Hero form

Verdict plus a directly labelled unit-dot plot of 25 shipped changes by product area. Tasks is the largest group at 11, more than twice Releases at 5, so the map's one long row is the claim that closeout was the point of this release. The graph counts titled changes, not effort or impact. GitHub issues closed is a secondary figure in the hero note; none are counted.

## Emotional register

Assured, humane, collected. The root `DESIGN.md` inherits Commander's violet-to-teal aurora and opaque reading cards, with a serif verdict, Inter prose and JetBrains Mono numbers; the report inlines those local sources.

## Distinctive move

The change map gives each of the 25 changes one equal dot. Tasks is the only row that wraps and the only one in the verdict color, and six decorative dots return at Install. The generator's first placement scattered closeout work across Sessions and Messages and made Sessions look largest at 10; the hand correction, recorded in Evidence and scope, is what lets the shape carry the argument.

## Deliberately omitted

No KPI cards before the argument, logo band, network assets or severity bubbles. No before and after images: QA captured only the new session dots, and a lone after shot is not evidence. No claim that closeout got faster: from freeze, v3.98.0 reached main in 3h 08m against 2h 48m for v3.97.0, measured the same way. The v3.96.0 baseline of about 6.5 h has no recorded endpoints and is not compared. Verifier tokens were not measured, so the saving from one verifier per release is not stated.
