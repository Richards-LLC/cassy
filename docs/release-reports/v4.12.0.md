## What you can do now

### Quieter alerts, steadier closes

#### No more stale delivery alerts

Was: after an update, replies from earlier sessions that never reached a device set off an alert every minute or so.

Now: replies from earlier sessions expire quietly; a reply from your current session that never arrives still raises an alert, so a lost decision is caught.

#### Fixed work closes the first time

Was: a fix that came back for changes could be refused at close because its changelog entry was edited while merging.

Now: the entry is recognized wherever it was edited, so the close goes through.


## Under the hood

### Release changes

#### Transcript mirror expiry

Was: the 4.11 expiry notice sent one blocker per tick to the current supervisor for every expired, undelivered mirror, including ones authored by previous sessions.

Now: prior-session mirrors retire without a blocker; a mirror authored during the current supervisor session that expires undelivered still warns once, and durable outbox retries continue.

#### Close changelog gate

Was: a returned delivery that merged its target and edited its own fragment in the merge commit was refused as missing a changelog fragment.

Now: the gate keeps task fragment provenance across returned merges, while merged-in fragments from other tasks still don't count.
