## What you can do now

### Faster flow: fewer stalls, right-sized capacity, leaner tests

#### No more silent stalls

Was: a release could sit ready for hours because nothing woke the person driving it.

Now: Cassy sends the wake itself when a release is ready or work stalls, and repeats it until someone acts.

#### Capacity counted correctly

Was: a project's limit was checked against every running job on the computer, so a quiet project couldn't add help.

Now: each project counts only its own, and the computer-wide limit still counts everything.

#### Merged pull requests close cleanly

Was: work merged through a GitHub pull request got stuck in a loop of refusals.

Now: one recorded review closes it, and a merge alone still never counts as a review.

#### Fewer, stronger tests

Was: many tests checked wording, guessed timings or repeated each other, slowing every change.

Now: weak tests were removed across most of the codebase, each one kept only where it guards a real behaviour.

#### Release friction measured

Was: we estimated where time went by hand.

Now: every release report measures wake noise, lost CI machines, issue intake and time from finished to merged.


## Under the hood

### Release changes

#### Supervisor wakes

Was: an owned train stayed silent after its last child merged; candidate notices waited for a turn.

Now: ready trains and stalls re-wake on the stall cadence, and candidate success/failure wakes an idle supervisor.

#### Worker caps by scope

Was: spawn admission compared the project `max_workers` against every live worker on the machine.

Now: the project cap counts that project's workers, the user cap counts all; refusals name each limit.

#### Contained PR deliveries

Was: G-70 → worktree_merge "already contained" → verification add "run worktree_merge".

Now: a registered supervisor records a verdict on the contained candidate; containment alone grants nothing.

#### Stability proof survives unrelated failures

Was: a broader-module failure wiped valid five-pass proof for changed tests that passed.

Now: passing owned tests keep their proof; failed or unrun ones still lose it.

#### Friction ledger sensors

Was: wakes were mostly "unknown", runner losses and park-to-merge time were counted by hand.

Now: authenticated notice kinds, hosted-runner losses, daily issue open/close with agent share, and park→train-merge percentiles.

#### Deletion campaign

Was: wording pins, implementation mirrors, duplicates and fixed sleeps across the crates.

Now: six slices cut them with a ledger naming each surviving guard; cas-writing-tests and cas-test-audit teach the rules.

#### Test-shape markers

Was: exact single-token stdout markers in dependency-selection tests tripped TEST_ASSERTION_PROSE.

Now: a bare one-token literal operand passes; composed or commented prose is still flagged.
