## What you can do now

### Work that can always be handed in, and names that never collide

#### Commander changes hand in cleanly

Was: a change to Commander's screens had to include the rebuilt app files, and then hand-in asked for test proof those built files can never have.

Now: the built files need no proof of their own. The screens they're built from keep theirs.

#### Mac-only and Linux-only tests count

Was: a test that only runs on Linux couldn't be proven from the Mac, or the other way round, so that work could never be handed in.

Now: the Linux test run in CI proves a Linux test, and a Mac test is proven by passes recorded on the Mac. A lint-only pass never counts.

#### Data and migration changes are proven by the tests that read them

Was: changing a data file, a database migration or a test fixture asked for a command that could never run.

Now: Cassy finds the tests that read the changed file, gives one command that runs, and accepts their passes.

#### New session names never collide

Was: a new session could get a name that clashed with another session's branches, even one from the other machine.

Now: names that would clash are refused or redrawn, and `cas doctor` lists any that slipped in earlier.

#### A moved task checks the right branch

Was: after a task moved to a fresh branch, its checks still looked at the old one until the first save.

Now: they look at the new branch from the start.


## Under the hood

### Close proof (G-61)

#### Generated Commander bundles

Was: C-37 made a hub-web/src lane commit the rebuilt `hub-web/dist`, then G-61 demanded a widened Related() receipt per bundle, which runs 0 tests (GH #2329).

Now: `hub-web/dist` paths owe no proof and never widen; their `hub-web/src` inputs keep normal proof.

#### Platform-gated tests

Was: a changed `#[cfg(target_os = "linux")]` test parked from macOS selected 0 tests and could never park, and the mirror case held on Linux (GH #2320).

Now: park reads the fn/module/file `target_os` gate. A Linux-gated test is proven by the exact-tip Linux Rust test job (lint-only green is refused), other OSes by five-pass receipts synced on the task, and the refusal is `PLATFORM_TEST_PROOF_REQUIRED`.

#### Data, migration and fixture inputs

Was: JSON catalogues, Prisma migrations and fixtures widened to a package proof that printed `worker-check -- jest <file>.json|.sql`, which the runner refuses (GH #2224, #2266).

Now: park finds the specs in the package that read each input by relative path, prints one runnable command, and accepts their whole-file passes; unread inputs keep the package requirement and are named.

### Factory

#### Worker name namespaces

Was: spawn checked only the local store, so a name could share `factory/<name>-…` with an origin branch or a registered worker, and minion overflow `kevin-2` overlapped `kevin`.

Now: `WORKER_NAME_OVERLAPS` refuses those, the generators redraw them, overflow reads `kevin2`, and `cas doctor` reports existing overlaps without changing anything.

#### Shared ownership rule

Was: SessionStart, CI-retry wakes and branch-only merges each parsed branch owners their own way.

Now: all three use the shared rule; wakes name the registered owner or `unregistered`.

#### Rebound lanes

Was: an empty `-r2` lane fell back to the old per-task branch in close checks (GH #1698).

Now: every close gate measures the rebound lane from the start.
