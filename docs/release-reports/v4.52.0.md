## What you can do now

### Less waiting, an optional route

#### Ready and merge messages arrive promptly

Was: a six-per-hour message cap could delay a ready or merge handoff for minutes.

Now: these handoffs wake the owner promptly, as blockers already did.

#### Checks finish without a second build

Was: repeated compilation could add three to six minutes after tests.

Now: the matched post-test step fell from 302 s to 0.59 s, with the same tests retained.

#### GitHub polling makes fewer calls

Was: 111 parked deliveries could trigger 111 PR reads per minute and shared lockouts.

Now: one combined read per repository per poll answers those deliveries locally.

#### The home gateway stays optional

Was: Claude and Codex sessions used their selected account directly.

Now: a project can opt into a private home gateway. Leaving it off preserves existing launches.

## Under the hood

### Coordination and transport

#### Actionable handoffs bypass the wake cap

Was: only blockers bypassed the six-per-hour worker wake cap.

Now: ready and merge handoffs also bypass the cap and burst debounce; routine status remains capped and quiet messages stay inbox-only.

#### Gateway overlays the selected account

Was: model traffic could reach providers only directly.

Now: project opt-in overlays a loopback or private-network endpoint and a mode-0600 key file. Hooks, MCP and sessions keep the native account. Failed readiness starts direct; requests identify their client. Live gateway rollout remains separate.

### CI and GitHub budget

#### Inventory reuses the compiled binary

Was: an imported Python helper wrote bytecode into a tree watched by the build script, triggering a second compile in 5 of 10 measured runs.

Now: child processes do not write bytecode. The matched run retained all 11,533 test identities; test selection and attribution are unchanged.

#### PR matching is batched and cached

Was: each parked delivery issued an uncached PR-list request every 60 seconds, consuming shared request headroom.

Now: PR reads group up to 150 branches per repository request, match locally and use jittered cache expiry. Open and merge wakes keep their behavior.
