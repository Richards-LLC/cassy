# Brief: Cassy v4.55.0 release report

Audience: practitioner

Craft: `cas-release-report`, `cas-html-reports` and `cas-ui-craft`.

## Plan alignment

The November 24 release-report assignment asks what shipped in v4.55.0: page one leads with the shipped changes, one dot per tagged CHANGELOG change, each with a plain Was → Now, under the headline that Macs keep privacy permissions across updates. It sets no pass or fail threshold, so the test is whether the takeaway answers that question. The map carries six dots for the six CHANGELOG entries, every dot title heads exactly one Was → Now card, and the verdict is the Mac change. The assignment also requires a readable HTML and a checked PDF at two viewports and both color schemes; the verification receipt records that proof. The report makes no performance claim beyond the one timing figure its receipt measures.

## Single idea

Macs keep their privacy permissions across Cassy updates: one of the six changes gives every Mac install the same signing identity, and the other five clear a hidden reload button, a blocked merge, a lost Slack reply and two unreliable tests.

## Hero form

The serif verdict sits beside a directly labelled unit-dot plot. Releases is the longest row, three dots, and the only violet one; it holds the Mac signing change the verdict names, and the caption under the dots says so. Four positive rows keep the generator’s area order. No GitHub issue closed inside the release window, so the hero and the glance strip show no issue count.

## Emotional register

Assured and quiet. Brand resolution: `DESIGN.md@b43940e432`, inherited from `hub-web/DESIGN.md@3577bff4a1` and Petrastella, source `design-md-css`. The aurora stays behind the hero glass; opaque reading cards, a serif verdict and a mono folio do the rest.

## Distinctive move

This is a small release, so the map is four short rows in place of a wall of dots: three single dots and one row of three. The shape says “one area did most of the work” without ranking any change. Six dots return beside the install command.

## Deliberately omitted

No KPI row ahead of the verdict, no issue count of zero, no invented comparison and no one-sided screenshots. No before-and-after capture pair exists for any of the six changes, so none is shown. The Mac result is taken from the posted developer notes; this report did not repeat it on a Mac, and it cannot say that any particular installation kept its permissions.
