What you can do now

02 / 06
01

Commander stays in sync, and cleanup is tidier

Answers keep reaching Commander

Wasafter /clear and a reload of Cassy's tools, later answers silently stopped showing up in Commander.

Nowthey keep arriving, once each.

Finished commands clear themselves

Wasa finished command such as Reload Cassy left a result card that needed Dismiss.

Nowa short message appears and fades on its own. Failed or unconfirmed commands keep their card.

Project card names are readable

Wasthe first letters of a name hid under the avatar, and long names ran past the edge of phone-width cards.

Nowthe name starts after the avatar and fits; the machine name gives way first.

A stuck Cancel recovers

Wasa refused or timed-out Cancel left the command stuck at queued and blocked every later command.

NowCassy keeps following the command to its real outcome, and later commands work.

Finish cleans up after itself

WasFinish could leave background shells and servers it started still running.

Nowit stops its own background work and checks that none is left.

Releases start themselves when ready

Wasa release that passed every check waited for someone to start it.

NowCassy starts it once every check is green and the notes are ready.

Mac Claude logins stay put

Wasaccount linking could move a Claude login kept in the macOS Keychain and report it as drift.

Nowactive logins are left in place.

Search and memories

Wastasks made on another machine could be missing from search, and renaming a memory by title alone did not save.

Nowsearch reads the current task list and stops exact duplicates, and title-only renames save.

Under the hood

03 / 06
01

Release changes

Commander mirror

Was/mcp reconnect after /clear restored the first pane's session id, and a second registration for one pane double-mirrored.

Nowthe rebound session survives reconnect, and one transcript mirrors once.

Commander UI

Wasfinished commands left a result card, a refused Cancel froze the receipt at queued, and project-card names clipped or overflowed.

Nowsuccess shows a self-clearing toast, Cancel resumes outcome polling, and the who-line sizes to the avatar and ellipsizes in narrow cards.

Auto-cut

Wasa green train waited for a manual scripts/release.sh.

Nowan exact train tip with a green full-suite receipt, changelog fragments and a notes draft freezes and cuts itself. Backfill skips frozen successor trains.

Close gates

Wasfirst park could read an earlier failing-test commit, refusals hid paths and revisions, and filenames counted as proof claims.

Nowfirst park reads the recorded pushed tip, refusals name the path, gate and checked revision, and local summaries are not external proof.

Delivery identity

Washistorical branches or lane reuse could displace the current delivery, and shared upkeep invalidated sibling reviews.

Nowclose follows the recorded parked branch, recovery keeps the current receipt, and generated CODEMAP or overview upkeep keeps approvals.

Verification

Wasa crashed automatic verifier held its claim, a stale agent row blocked verdicts, and a target-only move re-asked an answered call.

Nowone retry replaces a crashed verifier, process liveness decides "running", and a target-only re-dispatch reuses the answer.

Task start and moves

Wasan epic move kept the old lane target, an empty retargeted branch could not be rebound, and linked-checkout WIP lost ownership.

Nowmatching targets follow the move, a clean empty replacement branch can be approved, and linked WIP keeps its recorded owner.

Tasks and queues

Wasdep_remove echoed the removed edge, duplicate deps acted as blocking, and startup assignments could reorder.

Nowthe receipt names the removed edge, unsupported types are refused, and startup queues keep order with Current and Held shown apart.

Spawn and accounts

Waslane models were resolved before the account was chosen, and Keychain Claude logins looked like link drift.

Nowmodels resolve per selected account with its registered fallback, and native Claude auth paths are preserved.

Notices and handoffs

Wascapacity waits woke the supervisor per worker, cached reads tripped auto-clear, and handoffs crossed machines.

Nowdisk waits share one notice, auto-clear measures the latest call, and handoffs stay within machine, project and role.
