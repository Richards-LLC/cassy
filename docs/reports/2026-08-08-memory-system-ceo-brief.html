The experience: start oriented, retrieve precisely, learn again

1. Start with the shape of the work

Pinned guidance and compact session context offer an immediate orientation. CAS does not need to place the entire project in the prompt to make the next action informed.

2. Pull evidence when the task needs it

Search and read surfaces reach durable entries, knowledge, tasks, rules, skills, source symbols, and history/provenance. The agent discovers first and loads detail second.

3. Keep the evidence inspectable

Knowledge is ordinary Markdown with source lineage, not an opaque prompt cache. A reader can inspect, lock, and trace the underlying record.

4. Let an outcome compound

A correction, preference, or hard-won operating pattern can return through capture with the right scope, then improve a future task or session.

Vectorization is a guarded pipeline, not a black box

Current boundary: knowledge, history, and eligible source-code symbols can be vectorized today. Semantic retrieval contributes only when cloud authentication and a populated, compatible local cache make that channel live. Local lexical and structural retrieval remains available without it.

A loop a human can trust and inspect

  • Scope is intentional. Project, host-global, and optional team-shared surfaces are distinct; sharing is not assumed.
  • Human authority is visible. Knowledge pages are readable Markdown and can be locked against automated overwrite.
  • Failure is not completion. Pending queues, zero-vector rejection, and dimensional checks stop a bad embedding from becoming a silent retrieval artifact.
  • Exact identifiers retain their edge. Source-code ranking keeps tree-sitter/BM25 precision for names and paths while semantic candidates broaden conceptual recall when live.
  • Cloud is additive. Logged-out lookup does not create an empty vector cache or imply that semantic results exist.
  • Evidence remains reachable. Knowledge lineage, symbol data, and history/provenance provide a route back from a recalled item to its source.
