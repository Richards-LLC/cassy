Reasoning chain

  1. The immutable artifact and two installs are genuine, so the findings are not local-build substitutions.
  2. The documented first start fails on a clean host; the workaround cannot become an implicit prerequisite.
  3. The real browser traversed the public hub-to-daemon path and still received an unknown cause for exact SIGILL.
  4. Either failure blocks release. Partial gates must rerun on a new public artifact.

What would falsify this verdict

A new immutable release must contain both fixes, start on a clean installed host without manual initialization, identify SIGILL honestly in Chrome, and pass hostile auth, two-device arbitration, simultaneous fan-out/slow-viewer, compatibility, restart, no-polling, full-suite, and unchanged before/after counts. Source-only fixes are insufficient.

Cleanup and redaction

  • No pairing token, credential, proof, key, ticket, Authorization value, tailnet IP, prompt content, or raw audit payload is retained.
  • H7 browser credentials were revoked on both hubs; active count is zero.
  • The fixture was terminated, pre-existing metadata restored, and its server entry marked dead.
  • Physical Android is unclaimed. Slack remains explicitly unposted.
