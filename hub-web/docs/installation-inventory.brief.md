# Brief: installation inventory

## Single idea

Re-pairing updates this browser's installation; the operator can identify and explicitly revoke another browser without guessing from its label.

## Hero form

Ledger: the current browser leads the list with its active generation and account enrollment state, followed by exact device IDs and last use. One row represents one installation.

## Emotional register

Calm, accountable: existing Commander dialog typography and sandstone surfaces, factual timestamps, and a confirmation naming the exact device before revocation.

## Distinctive move

The current installation is marked “This browser” above its full copyable device ID, so repeated labels cannot masquerade as identity.

## Deliberately omitted

No automatic duplicate cleanup or label matching: old rows remain until the operator chooses an exact device. No invented verified account badge; enrollment is explicitly un-enrolled pending cas-4c78.

## Critique

Real production-bundle renders at 1280×800 and 390×844, light and dark, use
Commander's existing sandstone sheet, ruled detail ledger and typography. The
current browser's heading and exact identity lead; origin and signing key wrap
on phone. The live journey proves keyboard Escape returns to its opener and
exact-device revoke requires consent. The inventory is reachable from each row
of Paired machines in the default conversation view as well as Terminal view.
