# Rich-content dependencies

- Pele 1.12.0, copyright kepano, MIT: <https://github.com/obsidianmd/pele>. The full notice is embedded in the lazy rich-diagram JavaScript bundle; the source copy is pele-MIT.txt. Individual diagram-type chunks do not each carry a separate header.
- DOMPurify (version pinned in package-lock.json), copyright Cure53 and contributors, available under MPL-2.0 OR Apache-2.0. This distribution chooses Apache-2.0. Its full Apache license is embedded in the same lazy renderer bundle, and its upstream `@license` comment is preserved in the emitted JavaScript. The source copy is DOMPurify-LICENSE.txt: <https://github.com/cure53/DOMPurify>.

- PDF.js (version pinned in package-lock.json), copyright Mozilla Foundation, Apache-2.0: <https://github.com/mozilla/pdf.js>. Full license in PDFjs-LICENSE.txt.

The unified-diff viewer is authored in this repository and adds no third-party dependency.
