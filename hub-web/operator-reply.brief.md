# Brief: Commander operator-reply thread

## Single idea

When a supervisor answers a phone message, the reply is visibly tied to the exact Commander message that prompted it.

## Hero form

Threaded conversation: a compact ruled lane places the supervisor's reply directly below the composer, with the durable notification number as the visual join.

## Emotional register

Calm, accountable — the existing panel tokens, a quiet thread label, and one good-state indigo/green edge make receipt feel durable without turning it into an alert.

## Distinctive move

Every reply carries a plain-language “reply to #N” marker inside the same conversation lane, so the operator never has to infer which earlier message was answered.

## Deliberately omitted

No separate toast-only reply notice: transient toasts disappear before a phone operator can inspect the thread.

## Critique

Real-build review scored Distinctiveness 4/5, Fit 5/5, and Hierarchy 4/5. The
desktop capture keeps the thread visually subordinate to the composer while
the phone capture preserves the `reply to #41` join without clipping. The
remaining refinement is intentionally deferred: the compact lane could gain a
slightly stronger separation from the composer after an operator has several
replies, but the current single-reply state is calm and legible. Evidence:
