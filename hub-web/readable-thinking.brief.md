# Brief: readable thinking in Commander

## Single idea

A published reasoning summary can be skimmed between replies and expanded in place without reading like the supervisor's answer.

## Hero form

Annotated timeline: one quiet preview remains anchored between the two replies, with its detail below the same disclosure.

## Emotional register

Calm, precise — existing ink-mid captions, a compact chevron and the same opaque detail surface as tool evidence.

## Distinctive move

A short, plain-language preview sits beneath a neutral Reasoning summary label; only a reported lifecycle changes that label to Thinking or Thought.

## Deliberately omitted

No new card, status color, animation or private-reasoning request. Safe Markdown is restricted to explicitly published v2 reasoning; legacy rows retain their literal record. The raw published text stays available beneath the formatted detail. This JavaScript application requires its existing live hub transport; print must expose opened detail.
