# Brief: supervisor reply bubbles

## Single idea

The supervisor's actual reply can be scanned on a phone because its meaning survives as readable structure instead of a wall of markers.

## Hero form

Ruled thread lane: a compact message bubble keeps prose, lists and code in one addressed reply while indentation and line rhythm expose the answer's shape.

## Emotional register

Calm, legible, trustworthy — Pebble's existing warm canvas, supervisor surface and house mono code treatment make structure feel native rather than like a pasted document.

## Distinctive move

The same safe structured body travels through live, hydrated and pinned reply paths, so a phone operator sees one consistent supervisor voice wherever the reply appears.

## Deliberately omitted

No full Markdown dependency, HTML interpolation, or heading elements inside bubbles: the narrow subset is explicit, auditable and cannot turn supervisor text into executable markup.
