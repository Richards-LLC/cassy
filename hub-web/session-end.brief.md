# Brief: Session ended receipt

## Single idea
A supervisor that exits leaves a dated, factual end to its conversation, with every worker accounted for.

## Hero form
Timeline: a terminal receipt closes the existing thread, while the conversation row and heading use the same ended state.

## Emotional register
Calm, certain: the existing Glass chrome and muted evidence text carry the receipt; an orphan's name uses the established warning role.

## Distinctive move
One timestamp anchors the reason and worker outcome, so the operator can match the terminal exit to the last turn at a glance.

## Deliberately omitted
Process identifiers and teardown internals stay outside the conversation; the receipt names worker outcomes that the operator can act on.
