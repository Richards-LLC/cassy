# Brief: machine presence in the Operator inbox

## Single idea

I can see which enrolled machine stopped reporting even while every machine is unreachable, and turn those account alerts off from this phone.

## Hero form

Status ledger: a machine name, a plain observation and its report age share one row; the observer's own unavailable state precedes the rows so a fresh lease cannot disguise an unhealthy watchdog.

## Emotional register

Calm and accountable: the existing inbox sheet, house ink and spacing tokens, worded status and a named monitoring decision make the source and consequence clear.

## Distinctive move

Each recovered notice retains its outage reference; reporting status and the separate Hub, Serve and Factory observations never turn into a supervisor conversation or a claim that the computer is powered off.

## Deliberately omitted

No online/offline traffic-light score or notification-channel picker: the cloud observes a lease, and v1 delivers notices only through this durable inbox. No production service install, raw process identity, address or error text is exposed.

## Contract and transitions

Final cloud contract §17 and §7.4; machine notices already use verified replay and atomic device persistence. Snapshot data belongs to the inbox controller and is refreshed independently of conversation connectivity. A fetch error labels cached information; it never removes a known outage or claims the observer is healthy. Account:manage devices may choose Enable or Disable. The consent names 60-second samples, up to five-minute detection while the observer is healthy, cloud-readable storage, latest snapshot and 90-day notices. A pending mutation is disabled; a refusal preserves the previous setting and exposes a retry/review action. Monitoring is never implicitly enabled by enrollment or rendering.

## Accessibility and proof

Native headings, lists, buttons and a consent details disclosure; all actions reachable by keyboard. Machine rows wrap on 390px and use existing light/dark/forced-colors tokens. Snapshot and notice text work without motion. Planned real-cloud proof: a disposable opted-in hub stops, a separate enrolled phone stores one signed outage, then stores the matching recovery. Local protocol-double tests prove choreography only. Runtime proof belongs to the supervisor.
